# e139 과거 자료로 학습한 FCSRL 구성의 다음 기간 성능

Kaggle DARROW Tilburg 한 시설에서 과거 자료로 학습한 기법을 바로 다음 40일에 적용한다. 같은 공기량으로 수질이 개선되는지, 같은 수질 수준을 만족하는 데 필요한 공기가 줄어드는지를 묻는다. 네 조건은 기본 FCSRL, Actor 보정, 위험 선택, Actor 보정과 위험 선택의 결합이다. [사전 설계와 근거](REFERENCES_AND_DESIGN.md)

## 비교 구간

| 과거 학습일 | 평가 기간(2021) | 사용 |
| ---: | --- | --- |
| 108 | 8월 22일~9월 30일 | 새로 학습한 첫 비교 |
| 148 | 10월 1일~11월 9일 | 새로 학습한 둘째 비교 |
| 188 | 11월 10일~12월 19일 | e135에서 평가한 겨울 참고 |

학습은 모두 5월 6일부터 시작한다. 한 구간을 마칠 때마다 계절과 학습 자료량이 함께 달라지므로 두 효과를 따로 추정하지 않는다. 과거 실험에서 이미 다룬 날짜에 새로 시간 경계를 적용한 후향 비교다. e66의 시험 41일은 평가 경로에 포함하지 않는다.

## 재현

설계 커밋 9008963, 분할 및 학습 실행 1e30c15. 학습 환경은 e133과 동일한 PyTorch 2.14.1+cu130 CPU, scikit-learn 1.9.1, 기존 가속 GBM을 사용한다. 날짜별 95개 전이, 15분 간격, 공기 Nm³/h를 0.25시간으로 적분한다. 보상은 정규화 공기량의 음수다. NH4>4 또는 구역 최대 DO>2인 전이를 각각 집계하며 합산 비용 한도는 12다. 비용과 별도로 각 위반 분 및 NH4 초과 적분을 비교한다. [센서와 단위 및 학습 설정](../e133/README.md)

e50의 해시 검증을 통과한 센서 및 유입 정렬 표를 사용한다. 각 기간만 추출해 구역별 중앙 배분, GBM의 범위와 가중치, 모방 평균 정책, 정규화, RL과 위험 선택기를 다시 적합한다. 첫 모방 학습은 86일과 내부 점검 22일, 둘째는 118일과 30일이다. 두 기간 모두 대리 모델 5개, RL 정책당 401,280전이(66회), 시드 10~14, 고정 마지막 가중치를 사용한다. 위험 선택기 학습은 시드당 두 정책이 만든 네 전이짜리 창으로, 첫 기간 24,840개와 둘째 기간 34,040개다. 네 방법 모두 배율 0.8, 0.9, 1.0, 1.1, 1.25에서 평가한다.

같은 공기량은 시드별 두 방법의 실측 공기 범위 교집합에서 21점 보간 차이의 평균이다. 같은 수질은 기본 정책 원배율의 세 수질 수준을 넘지 않는 다섯 측정점 중 최소 공기다. 각 방법의 달성 가능 여부와 같은 시드에서 둘 다 달성한 경우의 공기 차이를 공개한다. 이때 평가 배율별 수치를 제어기 성능 곡선으로 사용하며 실제 배치 배율을 선택하지 않는다. 공통 공기 범위 재표집에서는 같은 날짜 블록과 시드 표본으로 곡선과 교집합을 다시 계산하고, 뽑힌 모든 시드의 교집합이 있는 반복의 수를 남긴다.
