# e106 폭기 증가 이후 NH4 하락의 지속 시간 보정

**보정은 채택하지 않았다.** DARROW 겨울 40일에서 폭기를 올린 뒤의 NH4 하락은 더 잘 예측했다. 그러나 폭기를 내린 뒤의 NH4 상승은 더 작게 예측했고, 보정 강도 선택에서 떼어 둔 학습 뒤 48일에서도 증가 구간의 이득이 재현되지 않았다.

| 평가 구간 | 폭기 방향 | 3시간 NH4 MAE, 기본 → 보정 | 1~3시간 NH4 변화 MAE, 기본 → 보정 |
| --- | --- | ---: | ---: |
| 학습 뒤 48일 | 증가 | 0.842 → 0.894 | 0.858 → 0.872 |
| 학습 뒤 48일 | 감소 | 0.506 → 0.483 | 0.449 → 0.417 |
| 겨울 개발 40일 | 증가 | 3.116 → 2.776 | 2.043 → 1.841 |
| 겨울 개발 40일 | 감소 | 1.772 → 1.904 | 1.756 → 1.863 |

NH4 농도의 단위는 mg N/L다. 겨울 폭기 증가 67건의 3시간 오차 차이(보정 빼기 기본)는 −0.340, 7일 블록 탐색 95% 구간은 [−0.481, −0.180]이다. 감소 65건은 +0.131 [+0.077, +0.173]이다. 같은 두 방향의 3시간 최대 DO MAE는 0.630 → 0.608, 0.296 → 0.287 mg O₂/L였다.

## 원인과 다음 판단

- 같은 폭기 증가 뒤에도 1~3시간 동안 실측 NH4는 학습 뒤 48일에서 평균 +0.027, 겨울에서 −1.730이었다. 계수 0.05를 적용하자 예측은 각각 −0.346 → −0.474, −0.346 → −0.601로 움직였다. 보정은 두 기간 모두 더 강한 하락을 만들었고, 관측 방향은 기간별로 달랐다. 겨울 감소 구간 실측은 +1.952였고 보정은 기존의 과소예측을 키웠다(+0.596 → +0.429). 이 기록만으로 계절이나 폭기가 그 차이의 원인이라고 단정할 수 없다.
- 학습 앞 140일의 324개 창으로 강도를 정했다. 무보정의 변화 MAE는 0.700, 비영 후보 0.05, 0.10, 0.20은 각각 0.735, 0.754, 0.804였다. 비영 후보 안에서 가장 작은 오차를 낸 0.05를 진단용으로 고정했다. 무보정이 가장 좋았다는 사실을 포함해 전 후보를 보고한다. 비교 대상은 e50 공통 모델이다. 시험 날짜는 평가하지 않았다.
- 다음 판별 질문은 같은 방향의 공기 변화에서 증가 직전 NH4 추세와 유입 등 결정 시점에 알 수 있는 정보로 후속 NH4 변화를 학습 날짜 안에서 구분할 수 있는가다. 기존 e37의 대응 구간을 우선 재사용할 수 있다. 겨울 평균에 맞춰 하락 강도를 높이거나, 이번 결과로 정책을 다시 학습할 근거는 없다. 공기 명령을 고정했으므로 공기 절감이나 FCSRL 정책의 트레이드오프 개선은 측정하지 않았다.
