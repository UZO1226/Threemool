# e69: e68 학습 연장 (갱신 500번)

**2026-11-17 19:00 KST 완료. 학습 20개, 실패 0, holdout 과 test 미사용.** [결과 표](results.md), [요약](summary.json). [사전 조건](protocol.json), [실행](run69.py), [집계](report69.py). 학습 코드는 [e68/train68.py](../e68/train68.py) 를 바꾸지 않고 쓴다.

## 왜 하는가

e68 에서 원본 FCSRL 은 같은 망 PPO-Lag 보다 위반일 10/10, NH4 초과 9/10, 예산 초과 8/10 짝에서 낮았지만, 사전 기준 (세 조건을 함께 만족하는 짝 8/10) 에는 5/10 으로 못 미쳤다. 두 방법 모두 한도 0.3 을 못 지켰고, 학습 수집의 예산 초과 스텝이 마지막 50번 갱신에도 0.67 에서 0.51 로 줄고 있어 수렴하지 않았다. 원본 FCSRL 은 약 2M 전이를 쓰는데 e68 은 그 수준 (250번 x 7,980) 이었고, 이 문제는 그보다 오래 배워야 한다.

갱신 수만 늘려, 두 방법이 한도에 가까워졌을 때도 FCSRL 의 우세가 남는지 본다. 같은 seed 라 처음 250번은 e68 과 같아야 하므로 재현 검사도 함께 한다.

- **재현 검사 통과.** 처음 250번 갱신의 학습 수집 (비용, 공기) 이 e68 과 20개 모두 같다. [실행 감사](../../analysis/e69_review_audit/README.md) 의 audit.py 로 완료 뒤 다시 확인했고, 학습 로그의 모든 수치 필드 (벽시계 시간 제외) 250번이 20/20 일치, manifest 해시 변경 없음이다.
- **H1 (주, dev): 차이 불명확.** 세 조건을 함께 만족한 짝은 FCSRL 5/10, PPO-Lag 0/10 으로 e68 과 같다. 지표별로는 FCSRL 이 예산 초과 9/10, 위반일 9/10, NH4 초과 9/10 짝에서 낮고 공기는 6/10 짝에서만 낮다. 제약 지표의 우세는 e68 보다 뚜렷해졌지만, 공기 조건 때문에 사전 기준 8/10 에 못 미쳤다.
- **H1 (보조, val 겨울): 차이 불명확** (세 조건 FCSRL 1/10, PPO-Lag 0/10). 지표별로는 FCSRL 이 NH4 초과 9/10, 위반일 8/10, 예산 초과 7/10 짝에서 낮고 공기는 3/10 이다.
- **H2: 두 방법 모두 dev 한도 0.3 을 못 지켰다** (0/10, 0/10). FCSRL 의 seed 별 값은 0.33 ~ 0.62 다.
- **H3: ABAC 대비 우위 아님.** e68 과 같은 구도다.
- **학습이 정체했다.** 학습 수집의 예산 초과 스텝은 FCSRL 이 갱신 239 ~ 263 에서 0.50, 마지막 50번에서 0.40 ~ 0.44, PPO-Lag 은 0.76 에서 0.74 ~ 0.77 이다. 승수는 계속 오르는데 (FCSRL 2.63 에서 2.84, PPO-Lag 3.14 에서 3.68) 표준편차도 1.8 ~ 2.0 에서 2.3 으로 커졌다. 행동 범위가 [-1, 1] 인데 표준편차가 2 를 넘어 표본 대부분이 범위 끝에서 잘리므로, 정책이 공기를 켜고 끄는 무작위 운전에 가깝다. 500번 예산에서 한도는 해결되지 않았다. 더 긴 학습의 결과를 입증한 것은 아니다.

## 해석

- 표현 학습은 같은 망 대조보다 제약 지표를 dev 와 val 에서 일관되게 낮춘다. 갱신을 늘리면 FCSRL 은 세 제약 지표가 모두 조금 좋아졌고, PPO-Lag 은 NH4 초과는 줄었지만 예산 초과가 0.78 에서 0.92 로 늘어 차이가 벌어졌다.
- 그러나 공기는 두 방법이 거의 같아 (평균 차이 527 m³, 1.4 %) 사전 규칙의 세 조건 우위는 생기지 않았다. 사전 계획의 "FCSRL 우위면 차단 B 로 간다" 조건은 충족하지 않았다.
- 두 RL 모두 한도를 못 지키는 원인으로 범위 끝에서 잘리는 큰 표준편차를 의심하지만, 검증하지 않은 가설이다.
- dev 는 학습과 조정, val 은 반복 사용한 개발 자료다. 상대 우위가 한도 충족을 뜻하지 않으므로 안전한 효율 개선이라고 부르지 않는다.
