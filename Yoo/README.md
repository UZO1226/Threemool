# Yoo (유지오)

**FCSRL 공개 구현체 구동과 원 논문 재현 실험을 완료했다. 현재 연구는 Kaggle DARROW 폐수처리 데이터에 FCSRL을 적용하고, 핵심 구조를 유지한 제한적 확장을 검증하는 단계다.**

최종 갱신: 2026-11-13. e54 학습 6개는 11월 12일 22:40에 모두 정상 종료했다. 현재 우선 작업은 대리 환경의 저온 구간 진단 검산이다. 신규 정책 학습과 grey-box 모델 학습은 아직 시작하지 않았다.

## 연구 범위와 목표

- 본 실험은 [Kaggle DARROW 원자료](https://www.kaggle.com/competitions/dynamic-modeling-of-wastewater-treatment-process/data)만 사용한다. Avedore와 BSM1은 과거 기록이며 현재 대표 성과로 사용하지 않는다.
- 목표는 **공기 사용량, NH4 위반, DO 위반을 함께 개선**하는 것이다. 한 지표의 개선을 위해 다른 지표가 악화되면 교환관계로 보고한다.
- 정책은 15분마다 총 공기 유량 하나를 결정한다. 95개 전이의 공기 부피 단위는 **m³/23.75시간**이며 실제 전력량(kWh)이나 표준상태 부피(Nm³)를 측정한 것이 아니다.
- 현재 Yoo 개인 조건은 NH4>4, max(DO)>2인 전이 수를 각각 비용으로 세며 평균 한도는 6/6이다. NH4 센서는 호기 구간 끝의 센서로 최종 방류수와 구별한다. 이 한도를 현장 법적 기준으로 주장하지 않는다.
- NH4 초과 농도 적분, 최악 날짜, seed별 한도 충족과 편차도 함께 확인한다. 보상은 공기량에 비례하므로 별도의 독립 성과가 아니다.
- 원 FCSRL의 dynamics/feasibility 표현 학습, Encoder, EMA와 정책 학습의 큰 구조를 유지한다. 대리 환경 개선과 FCSRL 알고리즘 확장의 기여는 분리해 검증한다.

### 최신 정책 결과: e52 대 e54

같은 e35 수정 대리 환경, 각 401,280전이, 마지막 정책, 개발 40일과 모델 구성원 5개로 평가한 seed 3개 평균이다. 모델 구성원은 독립 날짜가 아니다.

| 방법 | 공기량 (m³/23.75h) | NH4 비용 | DO 비용 | 평균 두 한도 충족 seed |
| --- | --- | --- | --- | --- |
| FCSRL, 기존 불확실성 여유(e52) | 93,281 | 5.26 | 0.685 | 2/3 |
| FCSRL, 날짜 분할 여유(e54) | 83,665 | 10.45 | 0.953 | 0/3 |
| PPO-Lag, 기존 불확실성 여유(e52) | 89,168 | 7.10 | 1.438 | 2/3 |
| PPO-Lag, 날짜 분할 여유(e54) | 89,493 | 6.11 | 1.457 | 2/3 |

FCSRL은 평균 공기량이 10.31% 줄었지만 NH4 비용과 초과 적분, 최악 날짜가 악화했다. PPO도 세 지표 동시 개선은 아니다. [원 정책 결과](experiments/e54/results.md). 별도 기록 행동 검사에서도 날짜 분할 신호의 FPR은 34.09→34.72%, 탐지율은 66.50→66.38%로 동시 개선을 확인하지 못했다. 두 차이의 95% 구간은 0을 포함하므로 확정된 악화 또는 동등성으로 주장하지 않는다. [신호 검사](experiments/e52/uncertainty_gate/README.md).

## 해석할 때 지킬 조건

- **현장 제어 성공을 입증한 상태가 아니다.** 결과는 관측 데이터로 만든 대리 환경 안의 성능이다. 기록 행동 재생과 실제 관측도 구분한다. 예를 들어 e50의 NH4 28.48%는 실제 관측률이 아니라 모델 재생값이다.
- 학습 날짜와 개발 날짜의 격차는 확인됐지만, 겨울 수온, 유입 부하, 정책 과적합과 대리 모델 오류의 기여는 아직 분리하지 못했다. 온도 하나를 단일 원인으로 확정하지 않는다.
- train188일과 개발 val40일을 사용한다. 반복 사용한 val은 독립 확증 자료가 아니다. 현재 후속 작업에서는 test41일의 행을 추출하거나 평가하지 않는다.
- e50은 공통 v1.1 환경(scikit-learn 1.9.1, 관측 11개, 합산 한도 12), e52~e54는 Yoo 개인 수정 환경(1.7.2, 관측 16개, 한도 6/6)이다. 절대 수치를 같은 순위표에 섞지 않는다.
- 같은 환경, 데이터 분할, 예산, 평가 방식에서 비교한다. 평균 공기량 변화율은 평균의 비율로 계산한다. 유리한 비교군만 고르거나 유의하지 않은 차이를 동등성으로 설명하지 않는다.

## 다음 작업

1. **저온 진단 검산부터 진행한다.** 학습 수온 범위 밖과 범위 안에서 NH4 예측 오류, 거짓양성, 놓친 위반을 분리한다. 한 스텝과 반복 예측을 구분하고, 기존 e45 조건별 분석을 중복하지 않는다.
2. 모방 prior 사용 여부를 같은 코드와 초기 탐색 설정에서 비교하는 실험을 설계한다. PPO의 결과만으로 FCSRL 확장 효과를 주장하지 않는다.
3. 환경 오류의 근거가 확인되면 train 내부 저온 날짜를 분리해 grey-box 후보를 평가한다. 물리식에 자유로운 잔차를 더하는 것만으로 온도 방향이 보장되지는 않는다. 통과 전 환경 교체나 본 RL 재학습은 하지 않는다.
4. 환경이 검증된 뒤 동일 조건의 PPO, FCSRL, 제한된 확장과 MPC 기준선을 비교한다. 환경, prior, 비용 정의를 동시에 바꾸지 않는다.

이 순서는 Yoo 개인 후속 작업이며 팀 공통 모델이나 공식 채택 결정을 변경하지 않는다.
