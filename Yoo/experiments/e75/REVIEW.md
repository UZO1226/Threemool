## 이번에 실제로 실행한 일

[설계](REFERENCES_AND_DESIGN.md)와 같이 e74 비용/자료/전이를 고정하고, 미래 외생 입력과 정확한 모델 구성원으로 하루 행동열을 최적화한다. 이것은 PETS의 후보 행동열 평가와 CEM 원리를 활용한 사후 계획 진단이며 PETS 전체 재현이나 온라인 MPC 실험은 아니다. 같은 예산 random shooting을 함께 돌려 탐색 선택에 따른 민감도도 본다.

공기/수질 비악화 조건을 날짜별로 걸어 개선이 보일 때 해석을 명확하게 했다. 반대로 이 조건은 평균 제약만의 최적화보다 보수적이므로 결과가 작다고 여지가 없다는 결론은 못 낸다. 모델 구성원을 바꾼 열린 고리 재생은 민감도 검사이며 외부 실험이 아니다.

## 결과를 보고 고칠 순서

1. 후보의 계산이 맞는지: 공기 집계, 비용 OR, 상태 갱신, cap, 미래 정보 사용 범위를 먼저 검산한다. 사전 검사는 통과했다.
2. 같은 모델에서 개선이 발견되고 다른 구성원에서도 유지되는지: 유지되면 현재 비용에서 제어 여지가 있다는 근거다. 이후 온라인에 허용된 관측만으로 접근 가능한지 확인해야 RL 학습 문제로 좁힐 수 있다.
3. 같은 모델에서는 개선되나 다른 구성원에서 깨지는지: 모델 의존성과 열린 고리 취약성을 분리할 검증이 우선이다. 새 RL 튜닝을 바로 추가하지 않는다.
4. 개선을 못 찾는지: 탐색 예산 증가/무작위 대조 차이와 후보의 표현 제한을 보고 결론을 보류한다. 전역 상한 없이 주제의 가능성 부재를 선언하지 않는다.

FCSRL 적용 및 제한적 확장이라는 주제, DARROW 데이터 사용 결정은 유지한다. 현실적 환경 신뢰도 검증과 알고리즘 기여 입증을 서로 대체하지 않는다.
