# e51: 공통 기준 대리 모델의 DO 구간 대응 오류 영향 점검

2026-11-12. 정책 학습 없음, test 구간 사용 없음.

## 목적

Yoo/e35 에서 Kaggle 원 설명과 공정도로 DO1/2/3 센서가 공기 구간 3/4/5(호기조 1/2/3)에 대응함을 확인했다. 그런데 팀 공통 환경(`Lee/code/darrow/surrogate_dw.py:monotone_constraints`)은 DO1/2/3 에 같은 번호의 공기 구간 1/2/3 증가 방향을 강제한다. e35 는 Yoo 서버의 scikit-learn 1.7.2 모델로 쟀으므로, 공통 평가 조건 v1.1 의 기준 모델(scikit-learn 1.9.1)에서 이 오류가 팀이 쓰는 수치를 얼마나 바꾸는지 다시 잰다.

## 방법

- 기준 모델: e50 준비물 (`/home/jio/fcsrl_src/results/e50/prepared/surrogate.pkl`). 기록 운전 재생이 PROTOCOL v1.1 검산값(검증 28.77, NH4 28.48%, DO 1.80%, 학습 12.17)과 같음을 e50 에서 확인했다
- 수정 모델: e35 와 같은 절차로 DO 모델 15개(구성원 5 x DO 3)만 대응을 고쳐 다시 학습했다. 하이퍼파라미터, 표본, 조기 종료는 그대로다. NH4 와 NO3 모델 10개는 같은 객체를 그대로 쓴다
- 동일성 확인: 기존 DO1 구성원 0 모델을 같은 절차로 다시 학습하면 검증 예측이 완전히 같았다. 바꾸지 않은 모델은 예측값으로 같음을 확인했다. e35 의 pickle 바이트 비교는 1.9.1 에서 같은 모델도 달라져 쓰지 않았다
- 비교: 기록 공기량 재생, e35 와 같은 장기 재생 오차와 위반 탐지, 직접 구간 공기 증가에 대한 DO 반응 방향, 기록 총 공기량 배율(0.5 ~ 1.5) 재생

## 해석

1. 기준 모델은 물리적으로 직접 연결된 호기조에 공기를 더 넣었을 때 DO 가 줄어든다고 예측하는 경우가 많다 (DO1 의 53%, DO3 의 43%). 단조 제약이 엉뚱한 구간(공기 1, 2 는 선택조와 임의조)에 걸려 있어서 생긴 결과다. 정책이 구간 배분이 아닌 총 공기량만 정하므로 영향이 섞여 나타나지만, DO 초과 비용이 공기량에 대해 잘못된 방향으로 움직일 수 있다
2. 대응만 고쳐도 학습 구간 기록 운전 재생 비용이 12.17 에서 9.58 로 바뀐다. 비용 한도 12 는 이 값을 반올림해 정했으므로, 고친 환경에서는 같은 규칙으로 한도가 10 이 된다. 검증 재생도 28.77 에서 31.85 로 바뀐다. NH4 모델은 그대로인데 NH4 수치가 바뀌는 것은 NH4 모델이 예측된 DO 를 입력으로 받기 때문이다
3. 고친 모델이 모든 면에서 낫지는 않다. DO 와 NO3 장기 오차는 줄지만 NH4 장기 오차와 거짓양성률은 늘고 DO 위반 탐지는 더 낮아진다. e35(1.7.2) 와 같은 방향이다
4. 두 모델 모두 기록 총 공기량을 25% 줄이면 검증 NH4 위반이 28% 에서 78% 로 급증한다. 공기 절감 여지를 이 환경으로 판단할 때 이 급격한 반응을 함께 고려해야 한다. 고친 모델에서 공기를 줄였는데 DO 위반이 늘어나는 구간(0.75 배)은 직접 구간 외 입력(NH4 상태 등)과 공기의 기록상 상관을 모델이 학습한 결과로 보이며, 인과 반응으로 해석하지 않는다

## 결론과 제안

- 팀 공통 환경에 DO 구간 대응 오류가 있고, 그 영향이 비용 한도를 정하는 값(12.17 대 9.58)까지 바꿀 만큼 크다. 팀 결과(Lee, Park, Yoo)의 비교 자체는 같은 오류를 공유하므로 유지되지만, DO 관련 해석과 한도 12 의 근거는 이 오류에 기대고 있다
- 공통 평가 조건을 바꾸는 일은 팀 결정이다. Yoo 개인 실험에서는 자동으로 채택하지 않는다. 다음 공통 조건(v2) 후보로 "DO 대응 수정 모델, 한도 재산정"을 제안한다
