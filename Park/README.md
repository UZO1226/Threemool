## 현재 상태

e01 ~ e06 은 BSM1 물리 시뮬레이터에서 했다. 팀은 2026-11-09 수행계획서에 따라 Kaggle 데이터로 본 실험을 옮겼으므로 (Yoo/e23, Lee/e06, Lee/e07), 이 결과들은 보조 검증으로 본다. 2026-11-10 사용자가 팀 공식 데이터를 Kaggle DARROW 대회 자료로 확인했다 (Compare/PROTOCOL.md 에는 아직 적히지 않음). e08 부터 DARROW 로 한다. 코드는 `code/` 에 직접 작성한다. 구성과 순서는 `code/README.md`, 외부 코드와 참고한 곳은 `code/SOURCE.md` 에 있다.

| 실험 | 내용 | 상태 |
| --- | --- | --- |
| e01 | feasibility 점수로 실행 시점에 위험 행동을 막는 안전 차단 | 2026-11-09 완료. 위반은 줄었지만 F 가 NH4 규칙보다 낫다는 주 가설은 지지 안 됨. [실험 기록](experiments/e01/README.md) |
| e02 | 더 먼 미래를 보는 F (feasibility discount 0.97, 0.99) | 2026-11-09 완료. F 의 조기 경보와 같은 에너지 비교 우위 확인, discount 효과는 없음. 학습 표본 안 결과. [실험 기록](experiments/e02/README.md) |
| e03 | F 조기 경보의 학습 표본 밖 확인과 단순 예측기 비교 | 2026-11-09 완료. 표본 밖에서도 NH4 측정값보다는 높지만, 시각과 유입 및 관측 전체 로지스틱 회귀보다 낮음. [실험 기록](experiments/e03/README.md) |
| e04 | 관측 전체 로지스틱 회귀로 거는 안전 차단 | 2026-11-09 완료. 같은 에너지에서 F 와 NH4 규칙보다 평균 약 1.8 %p 낮음 (규칙상 지지, 비교 점이 적어 근거 약함). [실험 기록](experiments/e04/README.md) |
| e05 | 위험에 비례해 미리 폭기를 올리는 차단 | 2026-11-09 완료. 같은 에너지에서 켜고 끄기보다 위반 적음 (9/9, 중앙값 -0.28 %p, 작음). 예측기 차단이 NH4 규칙보다 약 2 %p 적음 재확인. [실험 기록](experiments/e05/README.md) |
| e06 | 우기에서 차단 순서가 유지되는가 | 2026-11-09 완료. 비례가 켜고 끄기보다 나음은 유지(9/9), 예측기가 NH4 규칙보다 나음은 우기에서 사라짐(2/9). [실험 기록](experiments/e06/README.md) |
| e07 | Kaggle Avedøre 에서 실행 시점 안전 차단 (Yoo 와 같은 데이터, 환경) | 2026-11-09 완료. 모든 차단이 하루 비용을 늘림. 대리 모델에서 NH4 가 높을 때 공기를 더 넣으면 NH4 가 덜 내려가는 반대 반응 확인 (사후 진단). [실험 기록](experiments/e07/README.md) |
| e08 | 팀 공식 데이터(Kaggle DARROW) 에서 실행 시점 안전 차단 | 2026-11-10 완료. NH4 규칙 차단이 5개 seed 모두 하루 비용을 줄임 (13.66 에서 6.62, 공기량 +18%). 예측기와 비례 방식의 이점은 없음. [실험 기록](experiments/e08/README.md) |
| e09 | 학습 중에도 NH4 규칙 차단을 켠 정책 (DARROW) | 2026-11-10 완료. theta 3.0 에서 e08 보다 공기량 9% 감소 (5/5), 비용은 6.62 에서 8.04. 같은 공기량 비교 주 가설은 지지 안 됨. 차단을 끄면 크게 나빠짐 (5/5). [실험 기록](experiments/e09/README.md) |
| e10 | 필요한 만큼만 공기량을 올리는 최소 개입 차단 (DARROW) | 2026-11-10 완료. 같은 공기량에서 NH4 규칙 차단보다 비용이 낮음 (1스텝 4/5, 4스텝 5/5). target 3.5 는 theta 3.0 과 공기량이 비슷하고 비용 6.62 에서 5.46. 공기량 10% 절감은 지지 안 됨. [실험 기록](experiments/e10/README.md) |
| e11 | DO 상한도 함께 보는 최소 개입 차단 (DARROW) | 2026-11-10 완료. DO 위반은 줄었지만 (5/5) NH4 위반이 약 10% 로 늘어 하루 비용이 e10 의 약 두 배 (5.46 에서 10.66). 충돌할 때 공기를 올리지 않는 규칙이 원인 (사후 진단). [실험 기록](experiments/e11/README.md) |
| e12 | 학습 중에도 최소 개입 차단을 켠 정책 (DARROW). 목표: 공기량과 비용을 함께 낮추기 | 2026-11-10 완료. e08 차단보다 공기량 7.9% 감소와 비용 6.62 에서 5.51 을 함께 달성 (5/5). e10 대비 공기량 7.4% 감소, 비용은 5.51 대 5.46 으로 강한 가설은 지지 안 됨. 차단을 끄면 크게 나빠짐. [실험 기록](experiments/e12/README.md) |
| e13 | 차단 개입에 학습 비용을 줘서 차단 의존 줄이기 (DARROW). 목표: 안정성 | 2026-11-11 완료. 차단을 꺼도 비용이 34.44 에서 11.48 (w 0.5), 9.49 (w 1.0) 로 낮아져 차단 의존 감소 (5/5). 대신 차단과 함께 쓰면 e12 보다 공기량과 비용이 높아 공기량과 비용 동시 감소 가설은 지지 안 됨. [실험 기록](experiments/e13/README.md) |
| e14 | DO 가 넘칠 때 공기량을 내리기도 하는 양방향 차단 (DARROW). 목표: 공기량과 비용을 함께 낮추기 | 2026-11-11 완료. 양방향 차단으로 하루 비용이 5.51 에서 5.35 (학습에도 사용), 5.27 (e12 정책에 바꿔 끼움) 으로 낮아지고 DO 위반이 줄었지만, 공기량은 거의 같아 공기량과 비용 동시 감소 가설은 모두 지지 안 됨. [실험 기록](experiments/e14/README.md) |
