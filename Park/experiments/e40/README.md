# Park/e40: 틀린 차단 모델의 여유를 닫힌 고리로 다시 맞추기 (Kaggle DARROW)

상태: **완료 (2026-11-19). 고른 delta 0.6. H1 지지 (5/5): 다시 맞추면 비용이 11.23 에서 7.47 로 낮아진다. H2 기각 (1/5): 비용은 기준선 (10.79) 보다 낮지만 공기량이 90,694 로 기준선 (90,121) 보다 조금 많다.** 대표는 바꾸지 않는다. 가설, 후보, 고르는 규칙은 고르기와 검증 결과를 보기 전에 정했다 (커밋 `a06d5fa`).

## 목적

Park/e38 에서 차단 예측이 공기 효과를 절반만 알면 (섞음 w = 0.5) NH4 위반이 3.58% 에서 11.31% 로 늘어 대표가 공식 기준선보다 비용이 높아졌다. 이 오류는 기록된 공기량에서의 예측 오차로는 잘 드러나지 않고 (1 스텝 NH4 RMSE 0.045 에서 0.061), 차단이 고르는 적은 공기량에서 커진다. 그래서 기록 잔차로 여유를 다시 정하는 대신, 학습 구간에서 차단을 실제로 돌려 보며 (닫힌 고리) NH4 여유를 키우는 정도를 고른다. 틀린 모델을 쓰더라도 시운전으로 여유를 맞추면 이득을 되찾는지 본다.

## 방법

- 환경: 그대로 GBM 대리 모델 (PROTOCOL v1.1)
- 차단: Park/e38 의 w = 0.5 차단 (대표 차단 + 예측만 0.5 x GBM + 0.5 x MLP). NH4 여유 P1 의 모든 칸에 delta 를 더한다. 나머지 (DO 한도, 회복 검사, 충돌 여유 0.1, 회복 계획) 는 그대로
- 고르기: 학습 구간 마지막 40일 x 구성원 5개, FCSRL 대표 seed 0 ~ 3 앙상블, 후보 delta 0, 0.2, 0.4, 0.6. **하루 비용이 가장 낮은 delta** 를 고른다 (같으면 작은 쪽). delta = 0 이 고르면 "닫힌 고리로 여유를 키워도 학습 구간에서 나아지지 않는다" 로 끝내고 검증하지 않는다
- 검증: 고른 delta 로 FCSRL 대표의 구성원이 겹치지 않는 묶음 5개 (seed 0 ~ 3, 4 ~ 7, 8 ~ 11, 12 ~ 15, 16 ~ 19). 여유 그대로 (delta = 0) 의 검증 값은 Park/e38 fcsrl w05 를 쓴다
- 정책은 다시 학습하지 않는다

## 평가

검증 40일 x 구성원 5개 = 200 에피소드, 결정적. test 는 쓰지 않는다.

## 가설 (사전 등록)

- H1 (다시 맞춤이 듣는가). 다시 맞춘 차단의 FCSRL 대표가 같은 묶음의 여유 그대로 (e38) 보다 하루 비용이 낮은 묶음이 5개 중 4개 이상이고, 평균도 낮다
- H2 (기준선 위로 돌아오는가). 다시 맞춘 차단의 FCSRL 대표가 RESULT.md 공식 표의 기본 PPO-Lag (차단 없음, 90,121 Nm3/일, 하루 비용 10.79) 보다 공기량과 비용이 둘 다 낮은 묶음이 4개 이상이고, 평균도 둘 다 낮다

참고 (판정 없음): 맞는 차단 (w = 0, e35) 과의 남은 차이, 공기량 변화, NH4 위반.

## RESULT.md 처리 (미리 정함)

대표 방법은 바꾸지 않는다.

- H1, H2 지지: "공기 반응이 틀린 모델이라도 시운전 (닫힌 고리) 으로 여유를 맞추면 기준선보다 나은 성능을 되찾는다" 고 적고, 맞는 차단과의 남은 차이를 함께 적는다
- H1 지지, H2 기각: "여유를 맞추면 나아지지만 기준선 위로는 돌아오지 못한다" 고 적는다
- H1 기각: "공기 반응이 틀린 모델은 여유를 키우는 것으로 고칠 수 없다" 고 적는다

## 미리 밝히는 한계

- 고르기는 환경 (정답 모델) 에서 차단을 돌려 본 값을 쓴다. 실제로는 처리장 시운전 기간에 해당한다. 시운전 비용과 위험은 따지지 않았다
- 후보는 4개, delta 는 모든 여유 칸에 같은 값을 더하는 가장 단순한 형태다
- 고르기에 FCSRL seed 0 ~ 3 을 썼고, 검증 묶음 0 ~ 3 에도 같은 구성원이 들어간다 (구간은 겹치지 않음)
- 섞음 w = 0.5 는 인위적인 불일치 단계다. 묶음 5개는 판정 표본이 작다 (4/5 기준). 검증 구간은 e10 부터 반복해서 썼다

## 해석

- 사전 등록 처리에 따라 "여유를 맞추면 나아지지만 기준선 위로는 돌아오지 못한다" 고 적는다. 정확히는 비용은 기준선보다 31% 낮고 공기량은 0.6% 많다. 맞는 차단보다는 공기 11% 와 비용 60% 를 더 쓴다
- 중요한 관찰: 학습 구간에서는 틀린 차단도 여유 그대로 비용 4.49 로 무너지지 않았다. 검증 구간에서는 같은 차단이 11.23 이다. 공기 반응 오류는 부하가 큰 날에만 드러나고, 학습 구간 마지막 40일에는 그런 날이 적었던 것으로 보인다. 짧은 시운전으로 여유를 맞추면 그 기간에 없던 상황에서 다시 무너진다
- 학습 구간에서 delta 0.6 은 NH4 위반 1.83% 로 넘치게 안전했지만, 검증 구간에서는 7.35% 다. 고정 여유는 기간이 바뀌면 맞지 않는다. 틀린 모델에는 기간과 무관하게 실제 관측으로 계속 고치는 방법 (온라인 오차 보정) 이 필요하다 (Park/e41)
