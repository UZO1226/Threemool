# Park/e54: 넓힌 ABAC 격자로 다시 고른 같은 공기량 기준 (Kaggle DARROW)

상태: **완료 (2026-11-21). H1 지지 (5/5).** 격자, 고르는 규칙, 가설은 넓힌 격자를 돌리기 전에 정했다 (사전 등록 커밋 `c714c30`). 대표는 바꾸지 않는다.

## 목적

Park/e43 은 같은 공기량에서 대표가 현장 표준 ABAC 보다 하루 비용이 0.79 낮다고 보고했고, 이것이 Park 의 주 주장 (Park/e50) 의 중심 근거다. 그런데 e43 이 고른 ABAC 의 Kp 2000 은 격자의 끝이었고, e43 은 "ABAC 를 더 다듬을 여지가 있다" 고 한계에 적었다. 팀 중간점검 (Yoo/analysis/TEAM_RESEARCH_REVIEW_20261117.md) 은 기준을 약하게 두고 이긴 결과를 경계한다 (7.1 절, 8절 2번). 이 실험은 Kp 를 격자 끝 너머로 넓혀 ABAC 를 다시 고른 뒤에도 주 주장이 유지되는지 본다.

## 방법

- 넓힌 격자: 설정값 2.6 ~ 3.4 (0.1 간격, e43 이 고른 3.0 주변) x Kp 4,000, 8,000, 16,000, 32,000 x Ki 400, 800, 1,600, 3,200, 6,400 = 180 조합. 학습 구간 마지막 40일 x 구성원 5개에서 돈다
- 고르기: e43 격자 992 조합의 학습 구간 값 (다시 돌리지 않음) 과 합친 1,172 조합에서 e43 과 같은 규칙 (대표 학습 구간 공기량 73,345 의 ±2% 안에서 하루 비용 최소, 없으면 공기량이 가장 가까운 조합) 으로 고른다
- 검증: 고른 ABAC 를 검증에서 한 번 돈다. 대표는 Park/e35 orig 의 묶음 5개 값을 쓴다

## 평가

검증 40일 x 구성원 5개 = 200 에피소드, 결정적. test 는 쓰지 않는다.

## 가설 (사전 등록)

- H1. 다시 고른 ABAC 의 검증 공기량이 대표 평균의 ±3% 안이고, 대표 묶음의 하루 비용이 다시 고른 ABAC 보다 낮은 묶음이 5개 중 4개 이상이며 평균도 낮다. 공기량이 ±3% 밖이면 판정하지 않는다

참고 (판정 없음): 다시 고른 ABAC 와 e43 ABAC 의 차이, 고른 Kp 가 넓힌 격자의 끝인지.

## RESULT.md 처리 (미리 정함)

대표 방법은 바꾸지 않는다.

- H1 지지: "Kp 격자를 넓혀 ABAC 를 다시 골라도 같은 공기량에서 대표의 하루 비용이 낮다" 고 적고, e43 의 "ABAC 를 더 다듬을 여지" 한계를 이 결과로 갱신한다. 다시 고른 ABAC 를 Park 기준표의 ABAC 로 쓴다
- H1 기각: "격자를 넓히면 ABAC 가 대표만큼 한다" 고 주 주장의 한계에 적는다
- 판정 안 함: 값을 참고로 적는다

## 미리 밝히는 한계

- 넓힌 격자도 유한하다. 고른 Kp 가 다시 끝이면 그 사실을 적는다
- ABAC 는 NH4 피드백 PI 하나의 형태다 (Park/code/baselines_darrow.py). 앞먹임이나 DO 내부 고리 같은 다른 현장 구조는 보지 않는다
- 검증 구간은 e10 부터 반복해서 썼다

## 결과

고르기는 [select.md](select.md), 전체 표는 [results.md](results.md).

- 고르기: 1,172 조합 가운데 ±2% 안이 96 개였고, 하루 비용이 가장 낮은 조합은 넓힌 격자의 설정값 3.2, Kp 4,000, Ki 1,600 (학습 구간 72,692, 3.735) 이다. e43 이 고른 조합 (4.000) 은 3번째다. 고른 Kp 4,000 은 넓힌 격자의 끝이 아니다 (넓힌 격자는 32,000 까지)

| 방법 | 공기량 | 대표 대비 | 하루 비용 | NH4 위반 % | DO 위반 % |
| --- | --- | --- | --- | --- | --- |
| 대표 (Park/e35) | 82,104 | +0.0% | 4.658 | 3.58 | 1.32 |
| ABAC 다시 고름 (3.2, 4,000, 1,600) | 80,673 | -1.7% | 5.195 | 3.71 | 1.76 |
| ABAC Park/e43 (3.0, 2,000, 800) | 82,345 | +0.3% | 5.450 | 3.92 | 1.82 |

- H1: 다시 고른 ABAC 의 검증 공기량은 대표의 -1.7% 로 허용폭 안이고, 대표 비용이 5개 묶음 모두 낮다 (평균 4.658 대 5.195, 차이 -0.537, 95% 신뢰구간 -0.606 ~ -0.468). **지지**
- 참고: 다시 고른 ABAC 는 e43 ABAC 보다 공기량 1,673, 비용 0.255 낮다

## 해석

- 사전 등록 처리에 따라 "Kp 격자를 넓혀 ABAC 를 다시 골라도 같은 공기량에서 대표의 하루 비용이 낮다" 고 적고, 다시 고른 ABAC 를 Park 기준표의 ABAC 로 쓴다
- 대표의 ABAC 대비 이득은 0.79 에서 0.54 로 약 3분의 1 줄었다. e43 의 "ABAC 를 더 다듬을 여지" 는 실제로 있었고, 다듬은 뒤에도 이득은 남는다
- 다시 고른 ABAC 는 대표보다 공기를 1.7% 덜 쓴다. 같은 공기량이면 ABAC 비용이 조금 더 낮아질 수 있어 0.54 는 약간 과대일 수 있다 (사후 관찰, 판정 없음). 기여 분리 (차단 0.33, 정책 0.46, Park/e50) 는 e43 ABAC 기준이며, 새 기준으로는 차단만 (5.120) 과 다시 고른 ABAC (5.195) 의 차이가 0.08 로 줄어 차단의 몫이 작아진다
