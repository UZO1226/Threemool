# e39: 학습과 분리한 날짜로 DARROW NH4 위험 판정 보정

## 가설과 사전 조건

e38은 NH4 이력 입력으로 오차/FPR/위험 순위가 개선됐지만 고정 농도 판정의 탐지율이 떨어졌다. 검증 정답으로 판정점을 고른 사후 결과 대신, 모델 학습에 쓰지 않은 날짜로 보정해도 개선이 유지되는지 확인한다. DARROW만 사용하고 공기/NH4/DO 동시 개선 목적을 유지한다.

- 기존 train188일의 앞140일은 전이 모델 학습, 뒤48일은 보정, 기존 val40일은 최종 이번 대조 평가에 사용한다. 반복 사용한 개발val이며 독립 최종test라고 부르지 않는다. test41일은 평가하지 않는다.
- NH4뿐 아니라 NO3/DO 모델과clipping 상한도140일로 다시 학습한다. 같은140일로 기존24입력모델25개와 NH4이력44입력모델5개를 맞춘다. 이력유무 비교의다른20개 상태 모델은 공유한다. e38의188일 모델 수치와 직접 성능 증감을 비교하지 않는다.
- 데이터 준비는 e30 그대로며 online 결측 대체는 없었다. 전이 입력은실제 구간 공기량을 사용해188일로 정한 구간배분중앙값을 쓰지 않는다. 보조 유입은원래보간한합성자료로 유지한다. 모든 예측은기록된미래행동/외생입력을 재생하는조건부예측이다.
- 보정용48일에서 각 모델의95전이 자기반복 NH4 예측값을 입력, 실측NH4>4 여부를 정답으로 isotonic 단조 확률 보정을 학습한다. 모델 구성원은독립seed표본으로 해석하지 않는다. 보정은판정확률만바꾸며 농도상태나후속전이를바꾸지않는다.
- 주 판정점은보정자료에서탐지율80%이상을달성하는가장높은확률경계(해당범위최소FPR)다. 별도보조판정은FPR10%이하에서최대탐지율이다. 두 규칙을미리고정하고검증결과로유리한프로필을고르지않는다.
- 보정기와판정점을저장/해시고정한뒤val을평가한다. 4조건은기존/이력각각보정전/후다. 보정전은예측NH4>4, 보정후는고정확률경계다. 실제위반기준NH4>4와비용한도는유지한다.
- 검증에서실제달성한탐지율은다를수있으므로이를동일탐지율비교라고부르지않는다. 두모델의보정된주조건에서이력의탐지율이낮지않고FPR이높지않으며하나이상개선되는지, 목표80%도달여부를함께보고한다. 날짜7일블록bootstrap2000회는탐색적불확실성으로보고한다.
- e37고정구간중공기감소후실제NH4가0.1mg/L넘게상승한구간의위반탐지도15/60/180분별공개한다. 미래상승여부는평가부분집합에만사용하며보정/모델입력에는쓰지않는다. 정상/위반표본이없는조건은해당지표를미정의로보고한다.
- DO는보정하지않는다. 모델간DO예측/탐지는보고하되보정만으로DO문제가해결됐다고주장하지않는다. 농도예측오차와반응궤적은보정전후같다. 새RL학습/채택은없다.

## 실행

CPU1스레드, 기존 Python3.10/cu130 가상환경. 모델30개와 보정기2개 학습이며 정책 학습이 아니다. 정확한 커밋/입력/판정점 SHA256은manifest.json에 저장한다.

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 OMP_WAIT_POLICY=PASSIVE \
/home/jio/fcsrl_src/.venv/bin/python Yoo/experiments/e39/run.py \
  --prepared /home/jio/fcsrl_src/results/e30/prepared \
  --events /home/jio/fcsrl_src/results/e37/main \
  --out /home/jio/fcsrl_src/results/e39/main
```

사전규칙은protocol.json으로고정하며 실행후결과를추가한다. 팀공통평가조건변경이아닌개인후속진단이다.
