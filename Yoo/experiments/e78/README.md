# e78 기본 FCSRL과 감량 전용, 양방향 실행 비교

2026-11-23 완료. 겨울 검증에서 증량을 허용하자 감량 전용보다 모든 seed의 NH4 위반 횟수와 초과 적분이 줄었다. 평균 공기는 520 m³/23.75h 늘고 DO 위반도 0.175스텝 늘었다. 이 비교의 사전 공동 개선 조건은 1/5로 미달했다. [전체 결과와 공기 차이 분해](results.md), [정책별 지표](records.json).

기본 FCSRL과 비교하면 양방향 모드는 NH4 초과 적분이 5/5 낮고 평균 공기가 0.75% 적었다. 평균 NH4 위반 횟수는 14.087에서 14.247로, DO는 1.648에서 1.738로 증가했다. 감량 전용도 평균 공기는 1.36% 줄었으나 NH4 위반과 초과 적분이 증가했다. 기본 대비 공기 및 세 수질 지표 공동 개선은 두 모드 모두 0/5로, 이번 설정은 채택 기준에 미달했다.

증량이 감량으로 생긴 NH4 악화 일부를 회복한 만큼, 방향 선택에는 효과가 있었다. 학습 표적의 증량 행 수는 각 seed에서 14, 1, 13, 10, 9개였다. seed 1은 증량 표적이 1개였지만 양방향 모드에서 겨울 평균 하루 10.415회 증량했다. 클래스 균형 가중치와 날짜 간 분포 차이가 영향을 줬을 가능성이 있으나 각각의 원인을 이 비교로 식별하기는 어렵다.

학습 정책은 Yoo/e58의 DARROW 기본 FCSRL 최종 seed 0~4다. e50의 데이터와 GBM을 사용했다. 현재 수질과 직전 총공기를 기준으로 비슷한 기록에서 관측한 공기 범위를 구했다. 각 기본 정책 명령에서 ±500 Nm³/h의 후보를 비교해 결정트리 한 개를 학습하고 원본, 감량 전용, 양방향 실행을 비교했다. 보정기의 표적은 1시간 뒤까지 계산하고 운전 성과는 날짜 전체 95스텝으로 집계한다. 증량 또는 감량 1회는 그 시점에 125 m³의 차이다. 이후 상태와 기본 명령도 달라지므로 하루 차이는 직접 개입량과 다를 수 있다. [사전 조건과 문헌](REFERENCES_AND_DESIGN.md).

## 실행과 재현

실행 커밋 eb0d8c7. e58의 CPU 평가 환경(scikit-learn 1.9.1)을 사용했다. e77 입력 해시를 대조하고 정책 seed마다 기본 FCSRL 지문이 전후로 같은지 확인한다. 앞 140일로 보정기를 훈련했다. 학습 뒤 48일 및 반복 사용한 겨울 검증 40일 각각에서 같은 5개 모델 구성원과 날짜를 모든 실행 방식에 사용했다. 이 기간의 결과는 대리 환경 안에서의 개발 평가다. 원시 궤적, 분기 표적, 보정기는 /home/jio/fcsrl_src/results/e78/main 에 있다.

```sh
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1
py=/home/jio/fcsrl_src/.venv-skl191/bin/python

$py Yoo/experiments/e78/report.py --root /tmp/e78-replay --dest /tmp/e78-replay
```
