# e155: 같은 정책 위의 차단과 위험 선택, 날짜 블록과 다른 대리 모델로 판정

**상태: 완료 (2026-11-28).** 결과를 보기 전에 설계, 가설, 판정 규칙을 정해 커밋했고 (78b5902), 그 규칙 그대로 판정했다. [실행 코드](run.py), [사전 조건](protocol.json), [집계 코드](report.py), [전체 결과표](results.md), [요약 수치](summary.json).

**판정: H1 지지, H2 미지지, H3 세 방법 모두 차단 우위, H4 미지지.** 수질 이득은 실행 직전 차단에서 나오고, 차단 아래에서 FCSRL 고유 기여와 학습 정책의 우위는 확인되지 않았다. 다른 대리 모델에서 ABAC 의 차단 몫이 사라져 순환 구조를 주 한계로 올린다.

## 왜 하는가

세 사람의 결과가 같은 쪽을 가리킨다. 수질 이득은 학습 정책보다 실행 직전에 행동을 고치는 모듈에서 나온다.

- Park: ABAC 에 대표 차단만 씌워도 학습 188일 하루 비용 −0.737 (날짜 블록 구간 −1.035 ~ −0.472), 공기도 줄었다 (Park/e86). 차단 위에서는 학습 정책, ABAC, 예측 제어가 날짜 흔들림 안에서 갈리지 않는다 (Park/e82 ~ e84). FCSRL 고유 효과로 재현된 것은 차단 개입률이 낮다는 것뿐인데, 비교 대상이 무작위 고정 표현이다 (Park/e51)
- Lee: 정책 행동 주변 후보 중 예측 위험이 가장 낮은 행동을 고르면 같은 공기량에서 위반이 준다 (Lee/e63). 새 seed 에서는 재현되지 않았다 (Lee/e71, 병합 전 브랜치)
- Yoo: e139 의 수질 이득은 위험 선택에서 나왔다. e59 는 Park 의 이전 차단 (e19 설정) 을 e50 정책에 씌웠지만 날짜 블록 판정, 위험 선택과의 직접 비교, 다른 대리 모델 평가는 하지 않았다

논문 초안 결론도 "두 방법이 같은 정책과 조건에서 직접 경쟁한 결과는 아직 없다" 고 적는다. 또 차단과 평가 환경이 같은 대리 모델 계열이라는 순환 구조가 Park 결과 전체의 한계다. 이 실험은 그 빈칸을 한 번에 채운다.

## 가설과 판정 (사전 등록)

- **H1 (주, 차단의 몫이 학습 정책에도 있는가).** 학습 188일, v1.1. 방법마다 (차단 빼기 없음) 하루 비용의 블록 구간이 0 아래면 그 방법 지지. 세 방법 모두 지지면 H1 지지. 검증 40일은 확인으로 함께 적는다. 공기량 차이와 그 구간도 적는다
- **H2 (FCSRL 고유: 같은 공기량에서 차단 개입이 적은가).** 검증, v1.1, 차단. seed 마다 PPO-Lag 의 세 배율 점 (실행 공기량, 개입률) 을 선형 보간해 FCSRL 배율 1 의 실행 공기량에서 PPO-Lag 개입률을 구하고 FCSRL 개입률과 뺀다. 그 공기량이 PPO-Lag 범위 밖인 seed 는 지지하지 않은 것으로 센다. 4/5 이상 음수이고 평균이 음수면 지지. 같은 방식의 하루 비용 차이와 반대 방향 보간 (FCSRL 곡선에서 PPO-Lag 공기량) 은 참고로 적는다
- **H3 (차단 대 위험 선택, 같은 정책).** 검증, v1.1. 방법마다 (위험 선택 빼기 차단) 의 하루 비용과 공기량 블록 구간을 낸다. 비용 구간이 0 위이고 공기량 구간이 전부 0 아래가 아니면 "차단 우위". 비용 구간이 0 아래이고 공기량 구간이 전부 0 위가 아니면 "위험 선택 우위". 그 밖은 "가르지 못함". 학습 188일 값은 위험 선택기를 그 날짜로 적합했으므로 참고로만 적는다
- **H4 (다른 대리 모델에서도 차단의 몫이 남는가).** 검증, past148. ABAC 와 세 방법 각각 (차단 빼기 없음) 하루 비용 구간이 0 아래면 그 제어기 지지, 넷 모두면 H4 지지. dofix 결과와 위험 선택 (위험 선택 빼기 없음) 도 같은 방식으로 함께 적는다

## 사전 검사 (본 실행 전)

- 검증, v1.1, 차단 없음에서 15개 정책이 e50 의 검증 지표를 재현한다 (공기 상대 1e-7, 비용 1e-9, e59 와 같은 허용치)
- ABAC 차단 없음과 차단이 Park/e86 의 검증 (80,673 / 5.195, 80,602 / 4.625) 과 학습 188일 (69,838 / 2.577, 69,414 / 1.839) 을 표시 자릿수에서 재현한다. Park 은 자기 자료 pickle 로 돌렸으므로, 다르면 원인을 찾기 전에는 판정하지 않는다
- 위험 선택기의 빠른 예측이 sklearn 예측과 1e-12 안에서 같다
- 2일 시험 실행 (결과 저장소 밖, 날짜 2일, 모든 작업 경로) 은 오류와 시간만 확인했다. 이때 시스템 libgomp 가 4 스레드로 잡혀 있어 작업자마다 스레드를 1로 묶었다 (ABAC + 차단 8일 결과가 묶기 전과 같음을 확인)
- 개입률은 Park 정의 그대로 차단이 공기량을 바꾼 스텝 비율이다. 올린 스텝과 DO 때문에 내린 스텝이 함께 들어가므로, 내린 스텝 수 (lowered_steps) 를 따로 적는다

## 결과 처리 (미리 정함)

- H1, H4 지지: 논문의 주 주장을 "차단의 몫은 제어기와 평가 모델을 바꿔도 남는다" 로 둔다
- H4 미달: 차단의 몫은 차단과 같은 모델 안에서만 확인된다고 적고, 순환 구조를 주 한계로 올린다
- H2 지지: FCSRL 고유 기여를 "같은 공기량에서 차단 개입을 줄인다" 로 적는다. 미달이면 FCSRL 고유 기여는 이 표본에서 확인되지 않는다고 적는다
- H3 는 결과 그대로 적고, 결과를 본 뒤 차단 설정이나 위험 선택기를 다시 맞추지 않는다

## 미리 밝히는 한계

- 검증 40일은 세 사람이 여러 번 쓴 날짜다. 학습 188일은 정책과 위험 선택기를 학습한 날짜다
- ABAC 이득은 학습 구간 마지막 40일에서 골랐다 (Park/e54)
- dofix 는 NH4 모델을 v1.1 과 공유하므로 NH4 쪽 순환은 그대로다. past148 은 같은 적합 절차라 구조가 다른 모델이 아니다. 둘 다 "다른 모델" 의 약한 형태다
- 모든 결과는 대리 환경 안의 비교이며 현장 성능이 아니다

## 결과

208개 작업 (정책 15개와 ABAC, 모듈 3개, 평가 모델 3개, 학습 188일과 검증 40일) 이 모두 끝났다. 사전 검사는 모두 통과했다. e50 검증 지표 15/15 재현, Park/e86 ABAC 네 값 표시 자릿수 일치, 위험 선택기 적합 64,860행 (seed 마다). test 41일은 불러오지 않았다. 공기량 단위는 m³/23.75h, 비용은 하루 평균 (한도 12) 이다. 구간은 모두 날짜 블록 95% 구간이다.

### H1 차단의 몫 (지지)

| 학습 188일, v1.1 | 없음 비용 | 차단 비용 | 비용 차이 (구간) | 공기량 차이 (구간) |
| --- | --- | --- | --- | --- |
| ABAC | 2.577 | 1.839 | −0.737 (−1.035 ~ −0.472) | −425 (−683 ~ −182) |
| PPO-Lag | 11.796 | 1.763 | −10.032 (−10.817 ~ −9.255) | +2,980 (+2,521 ~ +3,457) |
| FCSRL | 12.650 | 1.710 | −10.940 (−12.148 ~ −9.776) | +2,734 (+2,236 ~ +3,258) |
| FCSRL + Actor 보정 | 11.509 | 1.725 | −9.783 (−11.279 ~ −8.428) | +3,265 (+2,659 ~ +3,887) |

세 학습 정책 모두 188일 전부에서 차단이 비용을 낮췄다. 검증 40일도 세 방법 모두 구간이 0 아래다 (−9.873, −6.990, −5.947). 학습 정책에서 차단은 공기를 더 써서 NH4 위반을 막는다 (학습 188일 +2,700 ~ +3,300). ABAC 에서는 개입 5.81% 중 4.54% 가 DO 때문에 공기를 내린 스텝이라 공기도 준다.

### H2 같은 공기량에서의 차단 개입 (미지지)

차단 아래 FCSRL 의 실행 공기량이 PPO-Lag 의 세 배율 (0.9, 1, 1.1) 범위보다 많은 seed 가 4/5 였다. 사전 규칙대로 이 넷은 미지지로 센다. 비교가 가능한 seed 2 에서는 FCSRL 개입률이 16.30% 로 보간한 PPO-Lag 8.45% 보다 7.85%p 높았다. 검증 평균 개입률도 FCSRL 8.21%, PPO-Lag 8.46% 로 공기량을 맞추지 않으면 차이가 거의 없다. Park/e51 의 "FCSRL 은 차단 개입이 적다" 는 무작위 고정 표현과의 비교였고, PPO-Lag 와 같은 공기량에서는 재현되지 않았다.

| PPO-Lag | +1.037 (+0.313 ~ +2.028) | +7,332 (+6,343 ~ +8,430) |

같은 정책 위에서 위험 선택은 차단보다 비용이 높고 공기도 더 썼다. 위험 선택기를 적합한 학습 188일에서도 (참고) 셋 모두 차단 우위였다. 위험 선택은 후보 폭 ±0.25 안에서만 움직이므로 정책 자체의 NH4 위반을 다 막지 못하고, 위반 위험을 줄이는 방향이 대체로 공기 증가라 공기가 늘었다.

### H4 다른 대리 모델 (미지지)

| 검증, 차단 빼기 없음 | past148 비용 차이 (구간) | dofix 비용 차이 (구간) |
| --- | --- | --- |
| ABAC | −0.070 (−1.105 ~ +1.255) | −0.280 (−0.560 ~ −0.045) |
| PPO-Lag | −20.586 (−24.473 ~ −16.916) | −8.194 (−9.618 ~ −6.968) |
| FCSRL | −14.942 (−19.770 ~ −10.430) | −5.252 (−5.869 ~ −4.667) |
| FCSRL + Actor 보정 | −19.284 (−24.647 ~ −14.168) | −4.409 (−5.495 ~ −3.547) |

past148 에서 ABAC 의 차단 몫은 구간이 0 을 포함했다. 차단이 DO 위반을 줄였지만 (2.04% 에서 1.34%) NH4 위반은 늘었다 (7.68% 에서 8.31%). 학습 정책은 past148 에서 차단 없이 하루 비용 23.9 ~ 29.8 로 크게 무너지고, 차단이 이를 9 근처로 되돌렸다. 즉 다른 모델에서도 남는 것은 "크게 어긋난 정책을 되돌리는 몫" 이고, 이미 한도 안에 있는 ABAC 를 더 낫게 하는 몫은 차단과 같은 모델 안에서만 확인된다. dofix 는 NH4 모델을 v1.1 과 공유하므로 넷 모두 0 아래인 것이 순환을 벗어난 증거는 아니다. 위험 선택도 두 모델 모두에서 비용을 줄였지만 (past148 −8.0 ~ −14.3) 공기를 더 썼다.

### 사후 탐색: 같은 차단 위의 학습 정책 대 ABAC (사전 등록 밖, 판정 아님)

차단 아래 학습 정책과 ABAC 의 하루 비용 차이는 모든 평가 모델에서 −0.38 ~ +0.12 였고, 구간이 0 아래인 것은 검증 dofix 세 방법과 검증 v1.1 FCSRL + Actor 보정뿐이다. 공기량은 학습 188일에서 학습 정책이 2,400 ~ 4,600 적었지만 정책을 학습한 날짜이고, 검증 v1.1 에서는 FCSRL 이 +8,696 (+6,549 ~ +10,876) 더 썼다. 날짜를 바꾸면 공기 우위가 유지되지 않아 Park/e82 ~ e84 의 "차단 위에서는 갈리지 않는다" 와 같은 그림이다. 수치는 [results.md](results.md) 마지막 표.

## 결과 처리 (사전 규칙 적용)

- H1 지지, H4 미지지: 차단의 몫은 학습 정책에서 크게 남지만, ABAC 수준의 제어기를 더 낫게 하는 몫은 차단과 같은 모델 안에서만 확인된다. 차단과 평가 환경이 같은 대리 모델 계열이라는 순환 구조를 논문의 주 한계로 올린다
- H2 미지지: FCSRL 고유 기여는 이 표본에서 확인되지 않았다
