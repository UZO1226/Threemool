# Park/e93: 차단 NH4 여유를 줄였을 때의 공기와 비용, 학습 구간 188일 (Kaggle DARROW)

상태: **사전 등록 (2026-11-26).** 여유 값, 가설, 판정 규칙은 이 실험의 결과를 보기 전에 정했다. 대표는 바꾸지 않는다.

## 목적

연구 목표는 공기와 비용을 함께 줄이는 것이다. 차단의 NH4 여유는 공기와 비용 사이의 손잡이다. 여유를 줄이면 차단이 공기를 덜 올려 공기가 줄 것이고, 대신 NH4 위반이 늘 수 있다. Park/e78 은 예측 제어 아래에서 여유 -0.2 가 +0.041 (점 판정, 기각) 이었고 공기량은 거의 같았다. 이 실험은 그 맞바꿈을 학습하지 않는 ABAC 위에서 188일 날짜 블록으로 판정한다.

## 방법

- 차단 위 ABAC (설정값 3.2, Kp 4,000, Ki 1,600). 대표 차단 NH4 여유 표 (Park/e15 여유 + 0.1) 의 모든 칸에서 0.2 를 뺀다. 나머지 차단 설정은 같다
- 학습 구간 188일에서 스텝 기록과 함께 돈다 (4 조각). 대표 차단 쪽은 Park/e86 의 `abac_b` 기록
- (여유 -0.2 빼기 대표 차단) 의 하루 비용과 공기량 차이, Park/e82 와 같은 블록 95% 구간 (세 갈래)

## 평가

학습 구간 188일 x 구성원 5개, 결정적. test 는 쓰지 않는다.

## 가설 (사전 등록)

방향은 Park/e78 (여유를 줄이면 비용이 오름) 과 차단의 작동 (여유가 작으면 공기를 덜 올림) 에서 정했다.

- H1. (여유 -0.2 빼기 대표 차단) 하루 비용의 블록 95% 구간이 0 위다 (비용이 오름)
- H2. 같은 차이의 하루 공기량 블록 95% 구간이 0 아래다 (공기가 줆)

## RESULT.md 처리 (미리 정함)

- H1, H2 둘 다 지지: "차단 여유는 공기와 비용의 맞바꿈 손잡이다 (여유 -0.2 에서 공기 X 줄고 비용 Y 오름)" 고 적고, 목표 (함께 줄임) 에는 여유를 줄이는 것이 맞지 않는다고 적는다
- H1 차이 없음이고 H2 지지: "여유를 줄이면 비용을 날짜 흔들림 넘게 올리지 않고 공기를 줄인다" 고 적고, 공기 절감 후보로 적는다 (대표 변경은 하지 않음)
- H2 가 지지가 아니면: "여유 -0.2 는 공기를 날짜 흔들림 넘게 줄이지 않는다" 고 적고 H1 결과를 함께 적는다

## 미리 밝히는 한계

- 여유 -0.2 에서는 표준편차가 작은 구간의 여유가 0.03 으로 거의 0 이다
- ABAC 위의 결과이고, 대표 (학습 정책) 위에서의 맞바꿈은 다를 수 있다
