# e93 첫 폭기 감량 전 수질 위험 선별

**감량 전 공정 관측 11개는 두 후속 조치 모두 수질을 지키지 못하는 구간을 어느 정도 구별했다(평균 AUC 0.710). 이 점수로 첫 감량을 선택하면 기본 FCSRL보다 6시간 공기량이 61.86 m³ 늘고 NH4와 DO 위반 횟수도 늘었다.** 평균 및 4/5 seed 공동 개선 기준에 미달했다.

## 감량 시점을 골랐을 때

거리 조건을 만족한 1,185개 비중복 6시간 창이다. 위험은 첫 15분 500 m³/h 감량 뒤 B(기본 FCSRL 되먹임)와 D(한 시간 뒤 초과 공기 제거) 모두에서 기본 명령 경로 A보다 하나 이상의 수질 지표가 악화된 경우다. 선별 결과에 따른 실제 선택은 A 또는 B다. 양성 196건 중 148건에서 감량을 생략했고 48건을 놓쳤다. 날짜 내 평균 및 날짜와 seed 동일 가중으로 계산한 재현율은 70.0%, 동일 횟수 무작위 생략은 64.4%였다. 선별기 거짓양성률은 49.9%, 정밀도는 27.9%였다.

차이는 선택 경로에서 A를 뺀 값이며 작을수록 좋다. 무작위보다 선별 시 NH4 위반과 초과 적분은 작았으나 공기는 14.25 m³ 더 썼고 DO 위반이 0.00065스텝 늘었다. 무작위 대비 네 지표 공동 개선은 0/5였다. 완벽한 위험 판별도 B가 안전하게 공기를 절감할 모든 구간을 찾아주는 것은 아니다. 이 표적에는 B로 운전하면 악화되지만 D로 회복 가능한 경우도 음성으로 포함되며, 절감량 자체는 학습하지 않는다.

AUC 0.60과 재현율 90%를 함께 넘은 seed는 2/5였다. seed 0은 보정 양성이 3건뿐이었고 뒤 날짜의 위험 21건 중 1건만 생략했다. 표본 수와 날짜 변화의 효과는 분리하지 못했다. 거리 조건을 풀어 전체 1,433개를 포함해도 AUC 0.706, 재현율 67.2%, 공기 +67.22 m³, 기본 대비 공동 개선 1/5였다.

**후속 공기 사용의 사후 검산.** 선별기가 실제로 고른 경로를 e90의 15분 단위 누계와 대조했다. 기본 대비 창당 평균 공기 차이는 15분 −56.74 m³, 1시간 −165.54 m³, 3시간 −47.36 m³, 3시간 45분 +5.64 m³, 6시간 +61.86 m³였다. 이는 미감량 창까지 포함한 평균이다. 이 자료에서 첫 감량 이득을 이후 기본 제어가 상쇄했다. 후속 명령 중 무엇을 안전하게 줄일 수 있는지는 따로 검증해야 한다.

## 재현과 해석 범위

Kaggle DARROW e50 대리 모델과 e58 FCSRL seed 0~4를 고정했다. e91에 저장한 A/B/D 6시간 결과로 위험 표적을 만들었다. 앞 100일 적합, 다음 40일 문턱 보정, 뒤 48일 평가다. 평가일은 정책과 대리 모델이 이미 본 학습 날짜다. 첫 결정에는 e88의 감량 직전 관측만 넣었다. 같은 날짜에 같은 수의 창을 균등 무작위 추출하는 대조의 기대값을 전체 창에 대해 계산했다. 이 결과는 구간별 모의 운전 평가다. 겨울, 독립 시험, 하루 연속 운전, 실제 에너지 소비를 측정하지 않았다.

사전 설계 482dd07, 분류 실행 5dd4559. Python 3.11, scikit-learn 1.9.1, CPU. 정책 학습 0스텝, seed별 선형 선별기 하나 적합. 입력 해시, 후보 키, 감량 전 NH4, e92 양성 수, 수질 지표별 실패 예제 및 무작위 조합 열거, 날짜별 별도 합산을 검산했다. [계산 전 설계와 원문](REFERENCES_AND_DESIGN.md), [seed별 양성 수, 문턱과 결과](summary.json).
