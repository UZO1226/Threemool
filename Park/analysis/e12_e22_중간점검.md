# Park e12 ~ e22 중간 점검 (2026-11-13)

목표는 공기량(전기) 과 하루 비용(벌점) 을 함께 낮추는 것이다 (Park/e12 부터). 모든 값은 Kaggle DARROW 대리 모델, 검증 40일 x 구성원 5개 = 200 에피소드, Compare/PROTOCOL.md v1 조건이다. e23 (새 seed 로 e22 재현) 은 진행 중이라 빠져 있다.

## 1. 성능 변화

| 단계 | 공기량 Nm3/일 | 하루 비용 | 판정 | 기록 |
| --- | --- | --- | --- | --- |
| e12 A (출발점, 학습 중 차단 target 3.5) | 84,031 | 5.51 | | [e12](../experiments/e12/README.md) |
| e17 회복 가능성 검사 | 80,944 | 5.08 | 지지 (4/5) | [e17](../experiments/e17/README.md) |

| e22 같은 예산의 4 x 16 정책 앙상블 (현재 대표) | 79,633 | 4.68 | 지지 (4/5) | [e22](../experiments/e22/README.md) |

판정은 사전 등록 규칙 (seed 5개 중 3개 이상과 평균에서 공기량, 비용 둘 다 낮음) 이다. 개선은 목표 방향으로 세 번 있었지만, 공기량 감소 폭이 비용 감소 폭보다 훨씬 작다.

## 2. 실패한 실험과 이유

| 실험 | 내용 | 실패 이유 |
| --- | --- | --- |
| e15 | 예측 불확실성에 맞춘 NH4 여유 | 여유를 줄이자 한 번 넘은 NH4 가 연쇄로 넘었다 (e17 이 해결) |
| e16 | DO 여유와 헛수고 방지 | 평균은 좋아졌지만 seed 2/5. 헛수고 방지는 겨울 검증 구간에서 NH4 회복을 늦췄다 |
| e18 | 회복 기준과 DO 기준 조이기 | 효과가 작아 seed 별 판정이 2/5 (보조 가설만 3/5) |
| e20 | 정책 5개 앙상블 | 주 가설(중앙값) 기각. 평균 앙상블은 5/5 였지만 학습 예산이 5배 |
| e21 | 업데이트 12번 x 5 앙상블 | 덜 학습한 정책은 공기를 아끼는 법을 못 배워 공기량이 늘었다 (e22 가 해결) |

학습 구간에서 버린 후보: 회복 검사에 유입 시간대 예측 넣기, 정책 공기량 위에서 자르기, 정책 행동 시간 평활, 학습 한 번 안의 스냅샷 앙상블. 모두 e17 또는 e19 보다 나빴다.

## 3. 공통 원인

1. NH4 위반은 바닥에 가깝다. 하루 종일 공기 9,000 을 넣어도 검증 NH4 위반은 3.12% 이고, 현재 3.37 ~ 3.49% 다. 차단으로 줄일 여지가 거의 없다.
2. seed 사이 차이가 효과보다 크다. 평균은 좋아져도 seed 별 판정에서 자주 떨어졌다. e22 도 다른 seed 조합에서는 판정이 0 ~ 2/5 였다.
3. 학습 구간과 검증 구간(겨울, NH4 높음) 의 순서가 자주 뒤집혔다. 학습 구간에서 고른 1등이 검증에서 1등이 아닌 경우가 e18, e20, e21 에서 나왔다.
4. 공기를 아끼는 주체는 정책이다. 차단을 고쳐서는 공기량이 조금만 줄었고, 정책이 미리 넣는 공기를 깎으면 오히려 공기량이 늘었다. 공기를 아끼는 법은 학습 뒷부분에서 배운다.

## 4. 보완 방법과 앞으로의 방향

| 순서 | 방향 | 고치려는 원인 |
| --- | --- | --- |
| 1 | 정책 쪽 개선: 앙상블 구성원 학습 방식, 공기량을 더 의식하는 학습 | 4 (남은 공기 절감 여지는 정책에 있음) |
| 2 | 설정을 고를 때 학습 구간 중 겨울 날짜를 함께 쓰기 | 3 (계절 차이로 순서가 뒤집힘) |
| 3 | seed 를 10개로 늘려 판정 | 2 (seed 운) |
| 4 | 마지막에 test 구간으로 한 번만 최종 확인 | 아직 test 를 쓰지 않음. 논문 최종 수치 |
| 5 | 차단 모델 오차를 더 크게 둔 시험 | 차단 모델과 환경 모델이 같은 방법의 구성원이라는 한계 |

다음 결정: e23 이 e22 를 새 seed 에서 재현하면 4 (test 최종 확인) 와 논문 정리로 간다. 재현하지 못하면 3 (seed 늘리기) 으로 효과 크기를 다시 잰다.
