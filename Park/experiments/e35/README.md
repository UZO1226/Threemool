# Park/e35: 회복 계획 비용 합 수정판과 원판 비교 (Kaggle DARROW)

상태: **검증 중 (2026-11-18).** 가설과 판정 규칙은 검증 결과를 보기 전에 정했다. 새 학습과 고를 설정은 없다.

## 목적

팀 검토 (Yoo/analysis/TEAM_RESEARCH_REVIEW_20261117.md 4.1 절) 에서 e28 회복 계획의 예측 비용이 문서와 다르게 계산된다는 지적을 받았다. `min_brake.py` 의 `_plan_recovery` 는 각 예측 스텝의 비용을 `(NH4 > 4) + (DO > do_lim)` 로 더하는데, 두 값이 NumPy bool 배열이라 더하면 OR 가 된다. 한 스텝에 두 위반이 함께 예측돼도 1 로 센다 (NumPy 2.3.1 에서 직접 확인). 환경의 실제 비용은 float 로 더하므로 지금까지 보고한 비용 값은 맞다. 틀린 것은 계획이 고르는 목적의 설명이다.

이 실험은 세 가지를 확인한다.

1. 같은 경로에서 두 목적이 얼마나 다른 공기량을 고르는지 (학습 구간 진단)
2. 문서대로 고친 수정판이 원판보다 나은지 (검증 구간)
3. 원판 회복 계획의 이득이 구성원이 겹치지 않는 앙상블 묶음에서도 이어지는지 (검토의 비독립 조합 지적)

## 방법

`min_brake.py` 에 `plan_sum` 을 더했다. True 이면 두 지시값을 float 로 바꿔 더한다. 기본 False 는 e28 ~ e34 의 원판과 같은 계산이다 (원판 결과를 바꾸지 않는다). NH4 기준 4, DO 기준 1.8, 계획 길이 4, 격자 500 은 바꾸지 않는다 (원인을 섞지 않으려고). `plan_both`, `plan_cells` 에 두 위반이 함께 예측된 칸 수를 센다.

## 조건과 평가

검증 40일 x 구성원 5개 = 200 에피소드, 결정적. test 는 쓰지 않는다. 판정 단위는 **구성원이 겹치지 않는** 4 x 16 앙상블 묶음 5개 (seed 0 ~ 3, 4 ~ 7, 8 ~ 11, 12 ~ 15, 16 ~ 19, 구성원은 `dw_u16_runs`, `dw_new16_runs`, `dw_rep16_runs`) 다. 조건 세 개를 모두 새로 계산한다.

| 조건 | 차단 |
| --- | --- |
| noplan | e19 차단 |
| orig | e19 차단 + 원판 회복 계획 (지금 대표) |
| fixed | e19 차단 + 수정판 회복 계획 (plan_sum=True) |

seed 0 ~ 3 의 orig, noplan 은 e28 H2 (79,457, 4.585) 와 e22 H1 (79,633, 4.68) 값이 다시 나와야 한다 (재현 검사).

## 가설 (사전 등록)

- H1 (주 가설). fixed 가 같은 묶음의 orig 보다 공기량과 하루 비용이 둘 다 낮은 묶음이 5개 중 4개 이상이고, 묶음 5개 평균도 둘 다 낮다
- H2 (재현). orig 가 같은 묶음의 noplan 보다 공기량과 하루 비용이 둘 다 낮은 묶음이 5개 중 4개 이상이고, 묶음 5개 평균도 둘 다 낮다

참고 (판정 없음): fixed 대 noplan. 짝 차이 평균과 95% 신뢰구간, NH4 위반률과 DO 위반률 차이를 함께 적는다. 묶음 5개는 구성원이 겹치지 않지만 같은 학습 설정과 같은 검증 날짜를 쓴다.

## RESULT.md 처리 (미리 정함)

- H1 지지: 대표를 수정판으로 바꾼다. 원판 값 (4.58) 은 원판의 결과로만 남기고, 수정판 값은 이 실험의 값을 새로 적는다
- H1 기각: 대표는 원판 그대로 두고, 회복 계획의 설명을 실제 계산대로 고친다 ("예측 4 스텝 중 NH4 또는 DO 위반이 하나라도 있는 스텝 수가 가장 적은 공기량"). 수정판 결과도 함께 적는다
- H2 기각: 회복 계획의 이득이 겹치지 않는 묶음에서 이어지지 않았다고 적고, e28, e32 의 해석을 그에 맞춰 낮춘다

## 미리 밝히는 한계

- 두 위반이 함께 예측되는 경우가 드물면 두 목적의 차이도 작아, 결과가 묶음마다 갈릴 수 있다
- 묶음 5개는 판정 표본이 작다 (4/5 기준)
- 검증 구간은 e10 부터 반복해서 썼다. 이 실험의 결과도 검증 구간 결과다
- e10 ~ e34 와 같은 대리 모델 한계
