# e129 후기 감량 뒤 첫 추가 명령에서 NH4와 직전 공기량의 역할

**새 시드의 첫 추가 명령 49건에서 NH4만 후기 감량을 생략한 경로의 값으로 되돌리면 43건의 공기 명령이 내려갔다. 직전 공기량만 되돌리면 44건에서 명령이 올라갔다.** 당시 실제 명령은 감량 경로가 대조 경로보다 평균 67.28 m³/h 높았다. NH4 입력만 치환한 뒤에는 28/49건에서 명령이 대조 경로 수준 이하가 됐다. [사전 설계](REFERENCES_AND_DESIGN.md), [e128 사건 정의](../e128/README.md)

## 입력만 바꿨을 때 정책이 내린 명령

새 시드 49건에서 같은 정책의 가중치와 나머지 관측을 고정하고 매번 한 가지 조건으로 다시 질의했다. 아래 표의 부호는 **치환 뒤 명령 빼기 원래 감량 경로 명령**이다. 음수는 해당 입력을 대조값으로 되돌렸을 때 공기를 덜 공급한다는 뜻이다.

| 대조 경로 값으로 되돌린 입력 | 명령 변화 평균 (m³/h) | 중앙값 (m³/h) | 감소 / 동률 / 증가 |
| --- | ---: | ---: | ---: |
| NH4 | −75.44 | −54.21 | 43 / 3 / 3 |
| 직전 공기량 | +40.18 | +22.88 | 0 / 5 / 44 |
| NH4와 직전 공기량 동시 | −35.17 | −8.77 | 32 / 1 / 16 |

차이의 절댓값이 0.05 m³/h 이하이면 동률로 셌다. 새 시드 49건 중 NH4가 대조보다 높았던 44건에서 43건은 NH4만 되돌려도 명령이 내려갔다. 첫 추가 명령 이전까지는 감량 경로가 대조보다 많이 공급한 적이 없다는 사건 선정 조건이 있다. 이 표본에서 직전 유량 차이(감량 빼기 대조)는 평균 −47.03 m³/h였고 양수인 사례는 없었다. 이전의 낮은 명령은 다음 명령을 낮추는 방향으로 작용했으며, 다른 관측의 영향이 이를 넘어서는 순간을 비교했다. 이 결과의 부호를 다른 모든 시각에 적용할 수는 없다.

## 네 입력 묶음이 설명하는 실제 명령 차이

입력 간 상호작용을 포함하기 위해 NH4, NO3, 세 구역 DO, 직전 공기를 네 묶음으로 나누어 16개 조합에 정책을 질의했다. 대조 입력에서 감량 입력으로 한 묶음씩 바꾸는 24개 순서의 평균 기여다. 여기서 양수는 원래 감량 경로의 명령이 대조보다 높아지는 쪽을 뜻한다.

| 감량 경로의 첫 추가 명령에 대한 평균 기여 (m³/h) | 새 시드 49건 | 기존 시드 82건 |
| --- | ---: | ---: |
| NH4 | +76.62 | +93.72 |
| NO3 | +3.32 | +2.72 |
| DO 세 구역 | +27.50 | +16.68 |
| 직전 공기량 | −40.17 | −45.99 |
| 실제 명령 차이 | +67.28 | +67.13 |

반올림 전 네 기여 합은 각 원본 정책 출력 차이와 일치한다. 두 시드 집합에서 NH4가 평균 양의 기여가 가장 컸고 직전 공기는 일부를 상쇄했다. 새 시드 5~9 각각에서도 NH4 단독 치환은 평균 명령을 낮췄고, 직전 공기량 단독 치환은 평균 명령을 높였다. 이 분해는 한 번 질의한 정책의 출력에 대한 것으로, 수질이나 하루 공기 사용량을 개선한 결과는 아니다. [시드별 및 기간별 결과](summary.csv)

새 시드 중 결국 하루 공기를 더 쓴 29건에서는 NH4 치환에 따른 명령 감소가 평균 98.52 m³/h, 하루 공기를 절약한 20건에서는 41.99 m³/h였다. 기존 시드에서는 각각 92.26과 93.92 m³/h로 그 차이가 반복되지 않았다. NH4가 첫 추가 명령을 높이는 입력이라는 점과, 그 반응 크기로 하루 손실을 구분할 수 있는지는 별도의 문제다. 입력을 바꿔 계산한 명령은 환경에 실행하지 않았고, 서로 다른 두 관측을 섞은 상태가 공정에서 실제로 발생할 수 있는지도 확인하지 않았다. [사례별 정책 출력과 하루 결과](cases.csv)

## 재현과 검산

Kaggle DARROW 공통 대리 환경 v1.1, e113과 e127에서 학습한 가중 FCSRL 정책 시드 0~9, 대리 모델 5개, 동일 겨울 개발 40일(2021년 11월 10일~12월 19일). e126과 e127의 동일 예산 최초 감량 집합에서 두 번째 250 m³/h 감량이 발동한 88건과 54건 중, e128 정의에 따라 첫 추가 명령이 당일 관찰된 기존 82건 및 새 49건만 분석했다. 추가 명령은 감량 경로 명령이 대조보다 1e-6 m³/h 초과 높아진 첫 결정이다. 원 환경은 행동에서 총공기 0~9,000 m³/h로 변환하고 하루에 15분 전이 95개를 평가한다. 원 보상은 −유량/9,000, 비용은 구간 뒤 NH4 >4 mg N/L와 구역 최대 DO >2 mg/L의 지시함수 합이다.

설계 02878bb, 실행 83f6d91. CPU, Python 3.11.14, PyTorch 2.14.1+cu130, sklearn 1.9.1, NumPy 1.26.4. 입력 데이터와 e126/127 기록 해시를 확인했다. 각 경로의 유량을 대리 모델에 재생해 11개 정책 입력을 복원했다. 해당 결정 직전의 NH4와 직전 공기량, 외생 입력 동일성, 저장한 전이 후 수질 및 원 명령을 확인했다. 131건의 감량 및 대조 명령 재현 오차 최대는 0.000537 m³/h 미만이었다. 기존 시드 0과 새 시드 8의 총 35건에서는 원 sklearn 추론기로 별도 재생해 16개 입력 조합의 출력 및 기여가 일치했다. 같은 값을 그대로 치환할 때의 영 효과, 상호작용 합성 예, 순열 평균과 독립 부분집합 공식의 일치, 집계 건수 및 평균을 검산했다.
