# Park/e38: 차단의 대리 모델이 틀릴 때 (Kaggle DARROW)

상태: **진행 중 (2026-11-19).** 가설과 판정 규칙은 검증 결과를 보기 전에 정했다. 학습 구간 사전 진단 ([diag.md](diag.md)) 만 보고 불일치 단계를 정했다. 새 학습과 고를 설정은 없다.

## 목적

Park/e36, e37 에서 대표 방법이 공기량을 줄이는 몫은 대부분 차단 (평가 때 차단, 학습 중 차단) 에서 나왔다. 그런데 지금 차단은 환경과 같은 GBM 대리 모델 계열 (환경이 쓰는 구성원을 뺀 4개) 로 예측한다. 차단의 이득이 "모델이 정확할 때" 만의 값인지, 모델이 틀려도 남는지를 본다 (팀 검토 4.4 절, 6.2 절). 함께, 차단에 덜 기대는 정책 (e37 에서 개입률 FCSRL 24%, PPO-Lag 60%) 이 모델이 틀릴 때 덜 무너지는지 본다.

## 사전 진단 (학습 구간 마지막 40일, 검증 구간은 보지 않음)

Lee/e08 MLP 대리 모델 (`darrow_surrogate_mlp.npz`, 같은 입력 24개) 을 차단에 넣을 수 있게 `Park/code/mlp_surrogate.py` 를 썼다 (Lee 구현과 차이 1e-16).

| 차단 예측 (환경 정답 = 그 구성원 GBM) | NH4 오차 RMSE | 최대 DO 오차 RMSE | 공기 2,000 -> 6,000 일 때 NH4 변화 | NH4 가 줄어드는 스텝 % |
| --- | --- | --- | --- | --- |
| GBM 다른 구성원 4개 (지금) | 0.045 | 0.027 | -0.208 | 96.6 |
| 섞음 w = 0.5 | 0.061 | 0.038 | -0.106 | 79.9 |
| MLP (w = 1.0) | 0.097 | 0.061 | +0.005 | 32.5 |

MLP 는 1 스텝 오차가 2배쯤이고, 무엇보다 "공기를 넣으면 NH4 가 준다" 는 반응을 거의 배우지 못했다 (운전 기록에서는 부하가 클 때 공기도 많아 인과가 섞인다). 실제 처리장 기록으로 만든 모델에서 가장 생기기 쉬운 오류다. MLP 만 쓰면 차단이 공기 효과를 모르므로 결과가 거의 정해져 있어, 주 판정은 공기 효과를 절반만 아는 섞음 w = 0.5 에서 하고 w = 1.0 은 참고로 둔다.

## 방법

- 환경: 그대로 GBM 대리 모델 (PROTOCOL v1.1)
- 차단: 대표 차단 (e19 차단 + e28 원판 회복 계획) 그대로, 예측만 구성원 m, 상태 j 마다 (1 - w) x GBM + w x MLP 로 바꾼다. 여유 (P1) 는 GBM 기준 그대로 두고 다시 맞추지 않는다 (모델이 틀린 줄 모르는 상황). 상태 상한은 GBM 값
- 정책: FCSRL 대표 (e22 4 x 16 앙상블) 와 같은 설정의 PPO-Lag (e37), 구성원이 겹치지 않는 묶음 5개 (seed 0 ~ 3, 4 ~ 7, 8 ~ 11, 12 ~ 15, 16 ~ 19). 정책은 다시 학습하지 않는다
- w = 0 값은 Park/e35 orig (FCSRL) 와 Park/e37 (PPO-Lag) 를 그대로 쓴다
- 평가 20번: 정책 2 x w (0.5, 1.0) x 묶음 5

## 평가

검증 40일 x 구성원 5개 = 200 에피소드, 결정적. test 는 쓰지 않는다.

## 가설 (사전 등록)

- H1 (차단 이득이 남는가). w = 0.5 차단의 FCSRL 대표가 RESULT.md 공식 표의 기본 PPO-Lag (차단 없음, 90,121 Nm3/일, 하루 비용 10.79) 보다 공기량과 비용이 둘 다 낮은 묶음이 5개 중 4개 이상이고, 묶음 5개 평균도 둘 다 낮다
- H2 (FCSRL 이 덜 무너지는가). w = 0 에서 w = 0.5 로 갈 때 하루 비용 증가가 FCSRL 대표 쪽이 같은 묶음의 PPO-Lag 보다 작은 묶음이 4개 이상이고, 평균 증가도 작다

참고 (판정 없음): 같은 비교를 w = 1.0 에서, 공기량 변화, NH4 와 DO 위반률, 개입률, 짝 차이 95% 신뢰구간. 진단으로 보면 w = 1.0 에서는 차단이 NH4 를 거의 막지 못해 비용이 크게 오를 것으로 예상한다 (예상이며 판정에 쓰지 않음).

## RESULT.md 처리 (미리 정함)

대표 방법은 바꾸지 않는다.

- H1 지지: "차단의 모델이 공기 효과를 절반만 알아도 대표가 공식 기준선 (기본 PPO-Lag) 보다 공기량과 비용이 둘 다 낮다" 고 적는다
- H1 기각: 한계에 "대표의 이득은 공기 반응을 맞게 아는 대리 모델이 있어야 나온다" 고 적고, 실제 처리장 적용에는 물리 제약이 있는 모델이 필요하다고 적는다
- H2 지지: "차단에 덜 기대는 FCSRL 정책이 모델 불일치에 더 강하다" 를 FCSRL 기여의 근거로 적는다. 기각이면 그런 근거가 없다고 적는다

## 미리 밝히는 한계

- 환경도 대리 모델 (GBM) 이라, 여기서 "틀린 모델" 은 GBM 에 대해 틀린 모델이다. 실제 처리장에 대한 오차는 아니다
- 불일치는 평가 때 차단에만 넣었다. 학습 중 차단은 GBM 그대로다 (실제로는 학습 때도 같은 틀린 모델을 쓸 것이다)
- MLP 의 구성원 번호는 GBM 과 짝이 없는데, 'others' 로 같은 번호를 뺀다 (뺀 MLP 구성원은 임의로 정해진 셈)
- 섞음 w = 0.5 는 인위적인 불일치 단계다
- 묶음 5개는 판정 표본이 작다 (4/5 기준). 검증 구간은 e10 부터 반복해서 썼다
