# Park/e67: 대표의 공기량 곡선과 차단 위 예측 제어 곡선의 곡선 대 곡선 비교 (Kaggle DARROW)

상태: **완료 (2026-11-24). H1 기각 (0/5), H2 지지 (예측 제어 곡선이 낮은 묶음 5/5).** 사전 등록 커밋 `3fd94f3`. 배율, 비교 규칙, 가설은 새 점을 돌리기 전에 정했다. 대표는 이 실험만으로 바꾸지 않는다.

## 목적

Park/e58, e59 는 차단 위 예측 제어에만 검증 구간 곡선 (공기 가중치 11개) 을 주고 대표는 점 하나로 비교했다. 미리 밝힌 대로 이 비교는 예측 제어에 유리하다. 이 실험은 대표에도 같은 방식의 손잡이를 주어 두 곡선을 같은 조건에서 비교한다.

## 방법

- 대표의 손잡이: 정책 공기량에 배율을 곱한다 (`ScaledPolicy`, Park/e33, 모든 스텝). 차단은 배율을 곱한 공기량 위에서 그대로 동작한다
- 배율: 0.8, 0.9, 1.1, 1.25 (1.0 은 Park/e35 orig 값). 묶음 5개 x 배율 4개 = 20번
- 묶음마다 5개 점에서 지배되지 않는 점으로 곡선을 만든다 (Park/e58 과 같은 규칙)
- 차단 위 예측 제어 곡선은 Park/e58, e59 의 11개 점 곡선 (72,392 ~ 96,097) 이다
- 묶음마다 두 곡선이 겹치는 공기량 범위를 21개 점으로 나눠 (대표 곡선 빼기 예측 제어 곡선) 의 평균을 낸다. 겹치지 않으면 그 묶음은 판정에서 빼고 "겹침 없음" 으로 센다

## 평가

검증 40일 x 구성원 5개 = 200 에피소드, 결정적. test 는 쓰지 않는다.

## 가설 (사전 등록)

- H1. 평균 차이가 0 아래인 묶음이 5개 중 4개 이상이고 묶음 평균도 0 아래다 (대표 곡선이 낮다)
- H2 (반대 방향). 평균 차이가 0 위인 묶음이 4개 이상이고 묶음 평균도 0 위다 (예측 제어 곡선이 낮다)

## RESULT.md 처리 (미리 정함)

- H1 지지: "대표에도 곡선을 주면 같은 공기량에서 대표가 차단 위 예측 제어보다 낮다" 고 적고, Park/e59 의 결론을 "대표는 점 하나, 예측 제어는 곡선인 조건에서만" 으로 좁힌다
- H2 지지: "곡선 대 곡선으로 비교해도 차단 위 예측 제어가 낮다" 고 적고 Park/e65 의 팀 결정 사항에 근거로 더한다
- 둘 다 아님: "곡선 대 곡선으로는 두 방법이 비슷하다" 고 적는다

## 미리 밝히는 한계

- 배율은 정책이 학습하지 않은 손잡이라, 배율이 1 에서 멀면 정책이 덜 잘 맞을 수 있다 (대표에 불리할 수 있음)
- 곡선은 선형 보간이다. 검증 구간은 e10 부터 반복해서 썼다

- H2: 예측 제어 곡선이 낮은 묶음 5/5, 묶음 평균 +0.135 (95% 신뢰구간 +0.011 ~ +0.259). **지지**
- 참고: 배율을 올리면 대표의 공기량이 늘고 차단 개입이 준다 (예: 묶음 0_1_2_3 의 배율 0.8, 1.0, 1.25 에서 개입 36.8, 16.1, 6.6%). 배율 1.25 에서 비용은 묶음 5개 모두 배율 1.0 보다 낮다 (공기를 더 씀)

## 해석

- 사전 등록 처리에 따라 "곡선 대 곡선으로 비교해도 차단 위 예측 제어가 낮다" 고 적고 Park/e65 의 팀 결정 사항에 근거로 더한다
- 대표에도 손잡이를 주어 Park/e59 의 "예측 제어만 곡선" 이라는 유리함을 없앴지만 방향은 같다. 차이는 +0.135 로 e59 (+0.193), e66 (+0.229) 보다 작고 묶음 16_17_18_19 에서는 거의 0 (+0.007) 이다
- 미리 밝힌 대로 배율은 정책이 학습하지 않은 손잡이라 대표에 불리할 수 있다. 다만 배율을 올린 쪽 (1.1, 1.25) 은 대표 자신의 점보다 낮거나 비슷해 배율이 정책을 망가뜨린다는 흔적은 없다
- 사후 관찰 (판정 없음): 묶음 12_13_14_15 는 배율에 따라 공기량이 79,656 ~ 83,597 로 좁게 움직이고 지배되지 않는 점이 2개뿐이라 비교 범위가 좁다. 대표의 공기량을 정하는 것은 정책보다 차단이라는 Park/e70 의 관찰과 같은 방향이다
