# Park/e33: 남은 비용 진단과 상태에 따른 정책 공기량 조절 (Kaggle DARROW)

상태: **사전 등록 (2026-11-16).** 진단은 학습 구간만 썼다. 고르기 규칙은 결과를 보기 전에 정했고 (커밋 `5f557a2`, 아래 그대로), 가설과 판정 규칙은 검증 결과를 보기 전에 정했다.

## 목적

목표는 공기량과 하루 비용을 함께 낮추는 것이다. 새 대표 (e22 H1 + e28 H2 회복 계획) 에서 남은 비용과 공기량이 어디서 나오는지 먼저 나누고, 그 결과로 방법을 정했다.

## 진단 (학습 구간 마지막 40일, seed 0 ~ 3 앙상블 + e19 차단 + 회복 계획)

| 항목 | 값 |
| --- | --- |
| 하루 공기량: 정책 / 최종 | 71,850 / 73,527 |
| 하루 비용: NH4 / DO | 1.385 / 1.020 |
| NH4 위반 중 막을 수 없는 스텝 (9,000 에서도 다음 NH4 > 4) | 1.285 회/일 (93%) |
| DO 위반: 차단이 공기를 올린 스텝 / 내린 스텝 / 그대로 | 0.685 / 0.310 / 0.025 회/일 |
| 차단의 필요 공기량 (1 스텝 여유 검사 + 회복 가능성 검사) 합 | 16,203 /일 |
| 최종 공기량 중 필요 공기량을 넘는 양 | 57,521 /일 (78%) |
| 그중 다음 NH4 가 0 ~ 2, 2 ~ 3, 3 ~ 4 인 스텝 | 8,407, 20,736, 28,378 |

NH4 위반은 거의 막을 수 없는 스텝에서만 남아 줄일 여지가 작다. 정책은 차단이 요구하는 양보다 훨씬 많은 공기를 넣는다. 그 여유가 낭비인지 완충인지 보려고, 정책 공기량에 배율을 곱하고 모자란 만큼은 차단이 채우게 했다 (seed 0 ~ 3 조합 하나).

| 정책 공기량 배율 | 공기량 | 하루 비용 | NH4 위반 % | DO 위반 % | 개입 % |
| --- | --- | --- | --- | --- | --- |
| 1.0 (새 대표) | 73,527 | 2.405 | 1.46 | 1.07 | 13.1 |
| 0.9 | 71,277 | 2.295 | 1.51 | 0.91 | 18.9 |
| 0.8 | 70,451 | 2.695 | 1.58 | 1.25 | 30.7 |
| 0.5 | 73,439 | 3.850 | 2.25 | 1.81 | 66.8 |
| 0 (차단만) | 69,862 | 4.290 | 2.62 | 1.89 | 74.6 |

여유의 대부분은 완충이다. 차단만으로 1 스텝 필요량만 넣으면 NH4 가 한도 근처에 머물다 막을 수 없는 상황에 자주 빠져 비용이 거의 두 배가 된다. 하지만 조금 줄이면 (0.9) 공기량과 비용이 함께 낮았다. 완충이 필요한 때는 NH4 가 한도에 가까울 때이므로, NH4 가 낮을 때만 줄이면 완충을 지키면서 공기를 줄일 수 있다.

## 방법

`min_brake.py` 에 `ScaledPolicy` 를 더했다. 지금 관측 NH4 가 기준 below 보다 낮은 에피소드에서만 정책 (4 x 16 앙상블) 공기량에 factor 를 곱하고, 그 위에 새 대표와 같은 차단 (e19 H1 + 회복 계획 H 4) 을 건다. 새 학습은 없다.

| S35_85 | 3.5 | 0.85 |
| S3_85 | 3.0 | 0.85 |

## 고르기 규칙 (결과 전에 기록)

"학습 구간 마지막 40일 (2021-10-01 ~ 11-09) x 구성원 5개, seed 0 ~ 4 의 4개 조합 5개를 같은 조합의 새 대표 (Park/e30 select_e30.py P2 값, e28 H2 와 같음) 와 짝 비교. 조합 평균 공기량 < 기준, 평균 비용 < 기준, 둘 다 이긴 조합 최다 (3/5 이상), 같으면 공기량 최소. 없으면 버린다. 규칙을 통과한 후보 중 평균 비용이 가장 낮은 후보가 고른 후보와 다르면 보조 가설로 함께 검증한다".

## 고르기 결과

학습 구간 마지막 40일 x 구성원 5개, seed 0 ~ 4 의 4개 조합 5개 평균.

| 후보 | 공기량 | 하루 비용 | NH4 위반 % | DO 위반 % | 기준보다 둘 다 낮은 조합 |
| --- | --- | --- | --- | --- | --- |
| 기준: 새 대표 | 73,753 | 2.478 | | | |
| U90 | 71,910 | 2.564 | 1.61 | 1.09 | 2/5 |
| S35_85 | 70,871 | 2.531 | 1.55 | 1.11 | 2/5 |
| S3_85 | 72,364 | 2.425 | 1.47 | 1.09 | 3/5 |
| S3_75 | 72,110 | 2.453 | 1.44 | 1.14 | 2/5 |
| **S25_70 (규칙으로 고름)** | **72,738** | **2.431** | 1.39 | 1.17 | **4/5** |

S3_85 와 S25_70 이 규칙을 통과했다. 둘 다 이긴 조합이 더 많은 S25_70 을 골랐다. 평균 비용이 가장 낮은 S3_85 를 보조 가설로 함께 검증한다. 모든 스텝을 줄이거나 (U90) NH4 3.5 까지 줄이면 (S35_85) 공기량은 가장 많이 줄지만 비용이 올랐다. 진단에서 seed 0 ~ 3 조합 하나로 본 0.9 배의 이득은 다른 조합에서 이어지지 않았다.

## 조건과 평가

검증 40일 x 구성원 5개 = 200 에피소드, 결정적. test 는 쓰지 않는다. 판정 단위는 4 x 16 앙상블 조합 20개 (seed 0 ~ 4, 5 ~ 9, 10 ~ 14, 15 ~ 19 에서 각각 4개 조합 5개, 구성원은 Park/e22 `dw_u16_runs`, Park/e23 `dw_new16_runs`, Park/e32 `dw_rep16_runs`) 다. 기준은 같은 조합의 새 대표 값 (seed 0 ~ 9 는 Park/e28 H2, seed 10 ~ 19 는 Park/e32 결과, 새로 계산하지 않음) 이다.

## 가설 (사전 등록)

- H1 (주 가설). S25_70 (NH4 < 2.5 에서 정책 공기량 0.7 배) 이 같은 조합의 새 대표보다 공기량과 하루 비용이 둘 다 낮은 조합이 20개 중 12개 이상이고, 조합 20개 평균도 둘 다 낮다
- H2. S3_85 (NH4 < 3.0 에서 0.85 배) 가 같은 판정을 통과한다

짝 차이 평균과 95% 신뢰구간 (조합끼리 독립이 아니라 낙관적) 은 참고로 적는다. 가설이 기각되는 결과도 그대로 기록한다.

## RESULT.md 처리 (미리 정함)

H1 이 지지되면 대표 방법에 S25_70 조절 층을 더한다 (정책과 학습 예산은 같다). 값은 seed 0 ~ 3 조합 값과 조합 20개 평균을 함께 적는다. H2 만 지지되면 대표는 바꾸지 않고 해석에 적는다 (e28 처럼 새 seed 로 다시 확인한 뒤에 바꾼다).

## 미리 밝히는 한계

- 진단에서 본 0.9 배의 이득이 고르기의 다른 조합에서 이어지지 않았듯, 효과가 조합에 따라 다를 수 있다
- 조절 층은 지금 NH4 만 본다. 유입 부하가 갑자기 오르는 때에는 완충이 모자랄 수 있다
- 검증 구간 (겨울) 은 NH4 가 높은 날이 학습 구간보다 많아, NH4 < 2.5 인 스텝 비율이 다를 수 있다
- e10 ~ e32 와 같은 대리 모델 한계
