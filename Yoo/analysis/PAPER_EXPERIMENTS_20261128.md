# 논문에 쓰는 실험 정리 (세 사람, 2026-11-28)

논문 초안 (PR #292, `team/paper-first-draft`) 이 인용하는 실험을 Yoo, Lee, Park 별로 모았다. 각 실험의 목적, 조건, 핵심 수치, 논문에서 쓰이는 자리, 해석할 때 주의할 점을 적는다. 수치는 각 실험 기록에서 옮겼고, 근거 경로는 실험 번호의 README 다. 모든 결과는 대리 환경 안의 비교이며 현장 성능이 아니다. test 41일은 e66 에서 한 번 쓴 뒤 다시 쓰지 않았고, holdout 은 쓰지 않았다.

## 4. e155 자세히 (논문 주 결과)

사전 등록 커밋 78b5902, 결과 커밋 7080520 (PR #291). 정책 15개 (e50) 와 암모늄 피드백 제어기 (ABAC, 설정값 3.2, Kp 4,000, Ki 1,600, Park e54) 에 모듈 없음, Park 대표 차단 (Park 코드 그대로 불러옴), Lee e63 원리의 위험 선택 (Yoo e135 와 같은 절차, seed 마다 64,860행으로 적합) 을 붙였다. 학습 188일과 검증 40일은 v1.1 로, 검증 40일은 dofix 와 past148 (학습 앞 148일로 적합) 로도 평가했다. 차단과 선택기는 언제나 v1.1 로 예측한다. 사전 검사로 e50 검증 지표 15/15, Park e86 ABAC 네 값을 재현했다.

- H1 지지: 학습 188일 (차단 빼기 없음) 비용 −10.03, −10.94, −9.78, 세 방법 모두 188일 전부에서 낮아짐. 공기 +2,734 ~ +3,265. ABAC 는 −0.737 (−1.035 ~ −0.472), 개입 5.81% 중 4.54% 가 DO 때문에 내린 스텝
- H2 미지지: 차단 아래 FCSRL 공기가 PPO-Lag 배율 0.9 ~ 1.1 범위 밖인 seed 4/5. 비교 가능한 seed 2 는 FCSRL 개입률이 7.85%p 높음
- H3 세 방법 모두 차단 우위: (위험 선택 빼기 차단) 검증 비용 +1.037 ~ +1.079, 공기 +5,550 ~ +7,332, 구간 모두 0 위
- H4 미지지: past148 에서 ABAC 차단 몫 −0.070 (−1.105 ~ +1.255). DO 위반 2.04 → 1.34% 지만 NH4 위반 7.68 → 8.31%. 학습 정책은 차단으로 23.9 ~ 29.8 에서 9 근처로 내려감. dofix 는 넷 모두 0 아래지만 NH4 모델 공유
- 사후 탐색 (판정 밖): 차단 아래 학습 정책 빼기 ABAC 비용 −0.38 ~ +0.12. 공기 우위는 학습 날짜에서만, 검증에서는 FCSRL 이 +8,696 더 씀

## 7. 남은 빈칸

- 현장 반응 검증: 차단이 자주 개입하는 조건에서 폭기 변화 뒤 한 시간 NH4 반응을 실측과 대조 (e104 의 방향 불일치 해소가 먼저)
- 송풍 전력: 공기 부피를 에너지 대리 지표로만 쓴다. 실제 kWh 없음
- 구조가 다른 평가 모델: dofix 와 past148 은 같은 적합 절차라 "다른 모델" 의 약한 형태다
- Lee e71, Park e87 ~ e95 는 각자 정리 뒤 인용 여부를 정한다
- 논문 절 담당 배정과 Compare/RESULTS.md 채택 표는 비어 있다 (team PR 필요)
