# Park/e91: 공식 기준선 PPO-Lag 에 차단만 씌웠을 때 (Kaggle DARROW)

상태: **사전 등록 (2026-11-26).** 가설과 판정 규칙은 이 실험의 결과를 보기 전에 정했다. 대표는 바꾸지 않는다.

## 목적

Park/e86 은 학습하지 않는 ABAC 에서, Park/e88 은 예측 제어에서 차단의 몫을 본다. 차단이 이미 있는 학습 정책에도 그대로 붙어 이득을 내는지 보려면, 차단 없이 학습한 정책에 차단만 씌워 보아야 한다. 공식 기준선 PPO-Lag (차단 없이 학습, seed 0 ~ 4) 에 대표 차단을 씌운다. 대표는 차단을 켠 채 학습했으므로 이 비교는 "학습 뒤에 차단만 더해도 되는가" 를 본다.

## 방법

- PPO-Lag seed 0 ~ 4 (공식 표, 차단 없음) 에 대표 차단을 씌운 것과 씌우지 않은 것을 스텝 기록과 함께 돈다
- 검증 40일: 차단 없는 쪽은 Park/e89 의 기록, 차단 쪽은 새로 돈다. 학습 구간 188일: 둘 다 새로 돈다 (날을 4 조각으로 나눔)
- 같은 정책이라 학습한 날의 이점은 양쪽에 같다. 판정 방법은 Park/e82 와 같다 (세 갈래). 공기량 차이도 같은 방식으로 구간을 적는다 (판정 없음)

## 평가

검증 40일, 학습 구간 188일, 각각 x 구성원 5개, 결정적. test 는 쓰지 않는다.

## 가설 (사전 등록)

방향은 Park/e86 (차단이 ABAC 를 낮춤) 에서 정했다.

- H1. 검증 40일에서 (차단 빼기 차단 없음) PPO-Lag 하루 비용의 블록 95% 구간이 0 아래다
- H2. 학습 구간 188일에서 같은 구간이 0 아래다

## RESULT.md 처리 (미리 정함)

- 둘 다 지지: "차단은 차단 없이 학습한 정책에 나중에 씌워도 비용을 낮춘다" 고 적고, Park/e86, e88 과 함께 "제어기에 따르지 않는 차단의 몫" 의 근거로 적는다. 공기량 변화를 함께 적는다
- 하나만 지지: 지지된 구간만 적는다
- 둘 다 아니면: "학습 뒤에 씌운 차단은 날짜 흔들림을 넘는 이득이 없다" 고 적는다

## 미리 밝히는 한계

- PPO-Lag 는 공기를 많이 쓰고 (90,121) NH4 위반이 많다 (10.42%). 차단이 할 일이 많은 정책이라 이득이 크게 나올 수 있다
- 대표 (차단을 켠 채 학습) 와의 차이, 즉 "차단을 켜고 학습하는 몫" 은 이 실험이 보지 않는다
