# e107 폭기 변경 전 관측으로 이후 NH4 하락 판별 (정정)

**겨울 폭기 증가 67건 중 보정 선택은 66건, 학습 후반 48건 중 32건이다.** 첫 보고의 67건, 47건을 바로잡는다. 중간 모델의 확률을 원시 추세와 유입량 열에 써서 최종 모델이 잘못된 입력을 받았다. 출력 열을 분리하고 동일한 앞 140일 학습 계수와 확률 문턱 0.5로 뒤 48일과 겨울 40일을 재생했다. 기존 검산은 생성된 확률을 다시 집계해서 입력 오류를 잡지 못했다. 정정 실행에서는 원자료와 저장 계수로 모델별 확률을 별도 재계산했다.

하락은 폭기 변화 뒤 1~3시간 실측 NH4가 0.1 mg N/L 넘게 감소한 경우다. Brier는 확률의 평균제곱오차로 낮을수록 좋고, AUC는 하락을 더 높게 평가하는 순위 성능이다. 지표는 날짜 동일 가중이다.

| 기간, 방향 | 하락/전체 | Brier 상수 / 농도 / 세 변수 | AUC 농도 / 세 변수 | 보정 선택 | 재현율 / 거짓양성률 | 세 변수 빼기 농도 Brier의 탐색 95% 구간 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 학습 후반 증가 | 26/48 | 0.249 / 0.220 / 0.234 | 0.743 / 0.621 | 32 | 74.4% / 56.3% | [-0.039, +0.081] |
| 학습 후반 감소 | 17/48 | 0.269 / 0.257 / 0.258 | 0.747 / 0.673 | 0 | 0.0% / 0.0% | [-0.011, +0.018] |
| 겨울 증가 | 53/67 | 0.182 / 0.158 / 0.163 | 0.704 / 0.589 | 66 | 96.8% / 100.0% | [-0.013, +0.027] |
| 겨울 감소 | 8/65 | 0.083 / 0.067 / 0.070 | 0.801 / 0.794 | 3 | 27.8% / 3.3% | [-0.006, +0.013] |

현재 농도에 직전 추세와 유입량을 추가한 모델은 네 집합 모두에서 농도만 쓴 모델보다 Brier가 높았다. 폭기 증가에서 세 변수 AUC는 학습 후반 0.621, 겨울 0.589였다. 각 변수 단독 추가 대조와 모든 정밀 수치는 [정정 수치](summary.json)에 있다.

각 셀은 기본 / 항상 보정 / 정정된 조건부 보정이다. 농도 단위는 NH4 mg N/L, DO mg O₂/L. 학습 후반 증가의 3시간 NH4 오차와 겨울 감소의 1~3시간 변화 오차가 기본보다 커져 두 기간 모두 채택 기준 미달이었다. 이 기록에서 실제 공기 절감이나 제어기의 효과를 측정하지 않았다.
