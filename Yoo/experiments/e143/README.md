# e143 비슷한 날에도 NH4 회복을 잘못 예측하는가

**가을의 두 발견일을 통째로 제외해도 6월 16일과 11월 16일에 오경보가 재발했다.** 초기 NH4가 4 초과 4.5 mg N/L 이하이고 폭기가 500 Nm³/h 이상 증가한 구간은 31일에 걸친 36건이었다. 실제로 1시간 안에 회복한 32건 중 e142 후보가 30건을 검출했다. 1시간 내내 4를 넘은 4건 중에서는 2건을 잘못 회복으로 판정했다. 미회복 4건으로 일반적인 오경보율을 추정하기는 어렵다. [사전 설계](REFERENCES_AND_DESIGN.md)

| 예측 방법 | 회복 검출 / 실제 회복 | 15분 단위 정확한 회복 시점 / 실제 회복 | 회복 오경보 / 실제 미회복 |
| --- | ---: | ---: | ---: |
| e142 후보 | 30/32 | 16/32 | 2/4 |
| 기존 GBM | 20/32 | 6/32 | 0/4 |
| 새 공기 입력을 빼고 재학습한 대조 | 24/32 | 9/32 | 1/4 |
| 같은 후보에서 향후 구역 공기를 직전값에 고정 | 11/32 | 6/32 | 0/4 |

마지막 행은 같은 회귀식에서 공기 변화 입력만 0으로 만든 진단이다. 관측된 수질은 실제 입력에서 나온 것이므로 직전 공기를 정말 유지했을 때의 수질을 알려주지는 않는다. 공기 항을 껐을 때 오경보 두 건이 사라졌지만 실제 회복 검출도 19건 줄었다. 재학습 대조에서는 6월 오경보가 남았고 11월 오경보는 사라졌다. 두 사건의 오판 원인을 하나로 단정하지 않는다.

## 두 사례와 기간별 분모

| 날짜 | 초기 NH4 | 1시간 최저 실측 | 60분 실측 | 후보가 예측한 최초 회복 시점 |
| --- | ---: | ---: | ---: | ---: |
| 6월 16일 | 4.094 | 4.003 | 4.651 | 30분 |
| 11월 16일 | 4.287 | 4.193 | 4.193 | 60분 |

농도 단위는 mg N/L다. 6월은 실측이 문턱을 약 0.003만큼 웃돌았다. 센서 정밀도를 검증하지 않아 이 근소한 차이의 현장 의미는 불확실하다. 11월에는 4.99와 5.21까지 올랐다. 겨울에 쓸 계수를 새로 적합한 경우와 9월 30일에 학습을 끝낸 가을 계수를 그대로 적용한 경우 모두 같은 겨울 사건에서 60분 회복을 예측했다.

e142에서 평가하지 않았던 앞 120일의 적격 창 13건 중 유일한 미회복이 6월 사례다. 두 발견일을 뺀 기존 80일의 적격 창 23건 중 미회복 3건, 오경보 1건이었다. 200일 중 발견일을 제외한 198일이 주 집계 범위다. 8~9월과 여름 일부에 미회복이 없어서 그 시기 오경보 여부는 검증할 수 없었다. 같은 시설의 개발 자료이며 새 외부 시험은 아니다.

## 창 선정에 따른 차이

e142는 방향이나 초기 농도와 관계없이 큰 공기 변화 사건을 먼저 잡고 다음 3시간을 건너뛰었다. 이번 주 분석은 초기 농도와 증량 기준을 먼저 적용한 뒤 1시간씩 겹치지 않게 선별했다. 11월 16일 사건은 원래 e142 집합에 포함되지 않았다. 같은 옛 선정 규칙을 써도 발견일 제외 적격 창 21건 중 실제 미회복 2건, 후보 오경보 1건(6월)이었다. 초기 NH4 상한을 5까지 둔 별도 민감도 분석은 63건 중 미회복 13건, 오경보 3건이었다. 각 집합은 시작점부터 다시 선택하므로 합산하지 않는다. [기간 및 대조별 전체 분모](summary.csv)

**연구 판단.** 공기를 넣은 예측은 실제 회복을 더 잘 잡았지만 미회복을 회복으로 부르는 오류도 다른 날에 관찰됐다. 이번 검산으로 e142의 환경 채택 보류를 유지한다. 실제 FCSRL 위험 선택은 한 시간 중 NH4와 DO 위반 스텝 비율을 본다. 사후 검산 결과 두 오경보 모두 실제 NH4 위반은 60분이었고 후보는 6월 15분, 11월 45분으로 각각 45분, 15분 과소예측했다. 같은 창의 GBM은 두 경우 모두 60분이었다. 이 값은 공정 모델의 NH4 오차로, 선택기 자체의 위험 점수나 개입 효과는 측정하지 않았다. [두 사건의 위반 분](false_case_minutes.csv) 제어 효과나 공기 절감은 이번 검산에서 측정하지 않았다.
