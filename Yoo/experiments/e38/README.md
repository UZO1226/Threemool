# e38: DARROW NH4 전이에 직전1시간 수질 이력 추가

## 가설과 고정 조건

e37에서 NH4 반응 크기의 재현이 부족했고 공기 변화 전 수질 추세도 크게 달랐다. 현재 상태만으로 부족한 시간 정보를 추가하면 NH4 반복 예측이 개선되는지 한 조건만 대조한다. 이것은 원인으로 확정된 사실이 아니라 후보 가설이다. DARROW만 사용하며 FCSRL 적용/확장의 큰 방향은 유지한다.

변경은 NH4 GBM의 입력에15/30/45/60분 전 NH4, NO3, DO1~3을 추가하는 것이다. 24개 기존 입력에20개를 더해44개다. NH4 모델5개만 재학습하고 NO3/DO 모델, clipping 상한, 기록 행동/외생 입력과 모든 정책은 고정한다. NH4 공기량 단조 제약은 유지하고 추가 이력에는 단조 제약을 걸지 않는다. 후보 파일은 이력 어댑터가 필요한 별도 형식이며 기존 환경에 자동 대입하지 않는다.

## 사전 평가 원칙

- train188일의 모든95전이를 사용해 기존과 동일한 표본 수, 구성원별80%추출, GBM 설정과 조기종료 난수를 유지한다. 기존 NH4 입력24개로 재학습해 원 모델 예측이 정확히 재현되는지도 확인한다. 외부 val로 튜닝하지 않는다.
- 날짜 초반에 없는 이력은 그날 첫 상태를 반복한다. 학습과 초기화 모두 같은 규칙이다. 최근 이력부터 오래된 순서로 정렬한다.
- val40일에서1스텝 실측 이력 예측, 주 평가인 첫 시각 초기화95전이, 보조 평가인 첫1시간 관측 후91전이를 구분한다. 서로 다른 길이의 수치를 직접 비교하지 않는다. 보조 평가의 미래 관측을 주 평가에 넣지 않는다.
- e37의132개 공기 변화 구간도 그대로 재평가한다. 시작 전 이력만 실측으로 주고 반복 예측 중에는 자신이 예측한 상태로 이력을 갱신한다.
- 모델 교체 후보의 점추정 선별 기준은 주 평가 NH4 MAE 감소, NH4 recall 비감소/FPR 비증가, DO1~3 MAE 비증가와 DO recall 비감소/FPR 비증가, 공기 증가/감소 양쪽15/60/180분 NH4 반응 MAE 비증가다. 작은 상충도 숨기지 않도록 허용폭0의 보수적 선별을 사용하며, 미통과가 실용적 무가치의 증명은 아니다. 날짜7일 블록 불확실성도 공개한다. 사후 기준을 완화하지 않는다.
- 선별을 통과해도 인과적 제어 효과나 공기/NH4/DO 동시 개선 성공이 입증되는 것은 아니다. 정책 학습과test41일 평가는 하지 않는다. reward와 연구 제약도 변경하지 않는다.

자료/기본 환경은 e30 준비 자료와 e35 수정 환경이다. 원본 준비/체크포인트는 변경하지 않는다. 정확한 코드 커밋, 입력 및 후보 SHA256은 manifest.json, 조건은 protocol.json에 저장한다. CPU1스레드와 기존 Python3.10/cu130 가상환경을 사용한다.

주 평가(40일, 날짜별00시 시작95전이, 모델5개 구성원)의 결과다. 분류 기준NH4>4, max(DO)>2는 고정했다. 모든 공기량은 같은 기록 운전으로 고정했으므로 제어 절감 결과가 아니다.

| NH4 FPR % | 29.663 | 4.125 | 개선 |

1스텝 NH4 MAE는0.2783→0.2052로 줄었다. 다른4개 상태의1스텝 예측은 가중치 고정대로 정확히 동일하다. 반복 예측에서 DO 오차도 달라진 것은 NH4 상태가 후속 DO 입력에 들어가기 때문이다. 모든 오차 척도가 개선된 것은 아니며 DO2 RMSE는0.4497→0.4533으로 소폭 악화했다. RMSE 전체 값도 comparison.json에 공개했다.

첫1시간 실제 이력으로 시작한 보조91전이에서도 NH4 MAE2.436→1.390, recall54.20%→23.35%였다. 따라서 날짜 시작의 이력 padding만 없애면 탐지율 문제가 해결된다고 볼 수 없다. 이 보조 평가 수치를 주95전이 평가와 직접 비교하지 않는다.

공기 증가 후3시간 NH4 평균 변화는실측-3.142, 기존-0.152, 이력-2.551mg/L로 더 잘 재현했다. 그러나 공기 감소 후3시간은실측+2.114, 기존+0.697, 이력+0.473으로 상승을 여전히 놓쳤다. 이 구간 NH4 MAE도1.886→1.937로 악화했다. 관측 운전 피드백을 포함하므로 이 변화가 순수한 공기량 효과인 것은 아니다.

### 위험 순위 정보는 개선됐다 (사후 진단)

기존 판정 기준에서 recall이 떨어졌다는 사실만으로 이력 정보를 버리지는 않는다. 저장 예측에 사후 ROC 분석을 추가했고, 이 분석은 원래 선별 기준과 구분했다.

| 지표 | 기존 | 이력 추가 |
| --- | --- | --- |
| NH4 AUC | 0.704 | 0.760 |
| Average precision | 0.311 | 0.456 |
| 탐지율61.82%에 맞춘 FPR | 29.62% | 22.81% |
| FPR10%에 맞춘 탐지율 | 28.02% | 39.97% |

AUC 차이의7일 블록 탐색95%구간은[0.0096,0.1165]였다. **같은 탐지율 비교의 판정점은 검증 정답을 보고 고른 것이므로 배포 성능이나 독립 보정 검증 결과가 아니다.** 원래 농도 판정은 바꾸지 않았고 실제 위반 기준NH4>4도 유지했다. 사후 판정값을 그대로 쓰거나 실패를 성공으로 바꿔 적지 않는다.

### 다음 결정

- 원래 사전 선별14개 중11개 통과,3개 미통과다. NH4/DO recall과 공기 감소3시간 반응이 미통과여서 기존 환경을 교체하거나 새 RL 학습을 시작하지 않는다. 위험 누락은 허용폭0이 지나치게 엄격해서 생긴 사소한 실패가 아니다.
- 이력 입력은 오차, FPR, 위험 순위 개선의 유용한 후보로 보존한다. 다만 현재 형태의 NH4 상승과 위험 사건 누락은 해결되지 않았다.
- 다음 제한적 후보는 **train 내부에서 모델 학습에 쓰지 않은 날짜를 별도 확보하거나 시간 블록 교차 예측을 만들어 위험 판정을 보정**하고, 고정val에서 탐지율과FPR을 함께 비교하는 것이다. 이미 같은188일로 학습한 모델의 in-sample 예측만으로 보정해서 검증했다고 주장하지 않는다. 공기량이나 비용 한도를 사후 완화하지 않는다.
- 이 보정은 위험 판정 후보이며 물리 상태 예측이나 DO 탐지를 자동 해결하지 않는다. 농도에 일정값을 더해 반복 전이에 넣는 것은 별도 모델 변경이다. 이번에는 보정 학습이나 새로운 정책 학습을 실행하지 않았다.
- 공기/NH4/DO 제어 지표 동시 개선은 아직 미달성이다. 환경 예측 개선과 제어 성과를 구분한다.

## 검산

- 동일24입력/표본/난수로 기존 NH4 모델5개를 다시 학습한 예측이 원본과 정확히 일치했다.
- NO3/DO 가중치와clipping 불변, 기존 환경의e35 하루 재생과e37 이벤트 궤적을 재현했다.
- 후보에서 실제 미래 수질을999로 바꿔도 예측 궤적이 그대로임을 확인했다. 모델이 예측 이력을 갱신하며 미래 정답을 사용하지 않는다.
- NH4 공기량 단조 제약의 반대 부호0건, 이력 순서/초기padding/갱신 합성검사, 독립 집계88개와 입력/후보/protocol SHA256 검사를 통과했다.
- Python 문법, 범위 검사, 논문 통합과git diff 검사를 통과했다. 기존 미작성 논문 절 경고만 있다.
