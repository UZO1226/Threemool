# Yoo/e14 하루 예측과 조건별 거짓경보 제한

**2026-11-06 22:00:33 KST, 학습 8개와 평가 완료. 하루 길이 학습의 개선을 확인했지만 전체 채택 기준은 미통과.** e13에서는 짧은 학습 창의 평균 FPR이 낮아 제약 승수가 0이 되었지만, 위반 예측을 늘리는 FN proxy 항은 계속 남았다. fit 하루 평균도 취약한 운전 조건의 높은 FPR을 가렸다. 이번에는 FN proxy를 제거하고 실제 평가 길이의 자기 예측과 전체 및 조건별 제약을 나누어 점검했다. FCSRL 표현 학습, PPO, 보상 및 물리 위반 기준은 유지하며 대리환경만 시험했다. 팀 공식 비교가 아닌 개인 탐색이다. 아래 설정은 실행 전 커밋으로 고정했다.

## 사전 대조와 학습 예산

각 seed의 e12 `multi_mse` 마지막 모델에서 시작한다. 모든 군은 같은 날 batch 16, 같은 275개 전이를 300회 학습한다. 하루 초기 1시간까지의 관측 중 01:00 상태를 초기값으로 사용하고 01:05부터 23:55까지 예측한다. 중간 입력에 실제 농도를 사용하는 시점만 대조한다.

| 군 | 실측 상태 재시작 간격 | 거짓경보 제약 |
| --- | --- | --- |
| short_mse | 36스텝 | 없음 |
| day_mse | 275스텝 | 없음 |
| day_global | 275스텝 | 전체 평균 |
| day_group | 275스텝 | 전체 및 조건별 |

주 후보는 사전에 `day_group`으로 고정한다. seed 0, 1의 8개 학습이며 마지막 가중치를 사용한다. 36스텝 대조도 같은 하루의 모든 정답을 사용하므로 관측 수와 갱신 수가 같다. 학습의 상태 방문 분포와 연결된 gradient 길이는 의도적으로 다르다. 초기 모델 동결, e11 경로 모델, e12 single_mse도 평가한다.

## 손실과 제약

기본 목적은 fit 농도 표준편차로 정규화한 연속 MSE와 실측 상태 입력의 한 스텝 MSE다. 한 스텝 계수는 e13에서 fit gradient로 정한 seed별 8.4514486, 11.2222795를 그대로 모든 군에 사용한다. 학습률 0.0001, Adam weight decay 0.00001, gradient clip 1도 유지한다.

FN proxy는 모든 군에서 제거한다. 실제 비위반 정답에 대한 `softplus((예측 농도 - 한도) / fit 변화량 표준편차)`만 FP proxy로 사용한다. 따라서 lambda가 0이면 별도의 위반 판정 손실이 완전히 0이 되고 농도 MSE만 남는다. NH4 > 4, DO > 2라는 물리 기준을 바꾸거나 별도 위험 head를 만들지 않는다.

전체 제약은 실제 비위반 중 예측 위반의 비율(FPR)이다. 조건별 제약은 전체, 운전 단계 0/1/2, fit 수온 하위/중간/상위 1/3의 총 7집단에 대해 NH4와 DO를 각각 계산한다. 온도와 운전 단계의 교차 집단은 표본이 너무 적을 수 있어 이번 학습에는 쓰지 않는다. 같은 표본이 여러 제약에 속할 수 있다.

각 집단의 목표 FPR은 10%, 승수 초기값 0, EMA 0.9, 갱신률 1이며 음수만 0으로 투영하고 상한은 두지 않는다. 하루 batch 안에서 실제 비위반이 64개 미만이면 해당 집단의 proxy 항과 승수 갱신을 모두 건너뛴다. 처음 유효한 관측으로 EMA를 시작하고 이후 부재 시 EMA와 승수를 유지한다. 이 조건은 작은 분모의 불안정을 완화할 뿐 독립 날짜 수나 안전성의 충분조건은 아니다. 집단별 유효 갱신 수를 함께 보고한다.

모델 손실의 제약 항은 활성 집단의 `lambda * FP_proxy`를 전체 집단 수 및 변수 수로 나눠 더한다. day_global은 전체 집단 1개, day_group은 7개를 사용한다. 공통 계수 alpha는 별도의 고정 fit batch에서 모든 집단의 승수가 1이라고 가정한 FP proxy의 gradient norm이 하루 MSE의 0.5배가 되도록 한 번 정한다. 모델과 정규화는 공유하지만 각 제약의 승수는 독립이다. 실제 FPR로 승수를 갱신하고 proxy를 실제 FPR이라고 해석하지 않는다.

이는 e13의 고정 물리 기준용 시험 구현을 수정한 것이며, TFCO 전체 알고리즘의 재현이나 새로운 이론적 보장을 주장하지 않는다. 관련 원리와 구현의 차이는 [e13](../e13/README.md)에 기록했다. 하루 BPTT를 끝까지 연결하고 detach나 중간 실측 주입을 하지 않는다. short_mse의 36스텝 재시작과 한 스텝 MSE에만 실측 상태를 사용한다.

## 데이터와 평가 기준

e12 및 e13과 같은 fit 263일, 제외 1일, 내부 holdout 66일을 사용한다. 원자료 경로 신호와 전처리는 e11 그대로다. 내부 holdout은 반복 관찰한 탐색 자료이며 새 독립 확인으로 부르지 않는다. 모든 학습, 수온 경계와 계수 계산은 fit만 사용한다. 외부 val과 test는 사용하지 않는다. 데이터 및 초기 가중치 해시가 e13 기록과 같은지 검사한다.

275전이 평가의 비용은 NH4 및 DO 위반 스텝 수 합이며 기존 287전이 정책 한도 15와 비교하지 않는다. 평가 재시작 간격은 1, 36, 275다. 기존 e12의 강화된 gate를 유지한다. 각 seed에서 e11 및 single_mse 양쪽 대비 recall 악화 없음, precision 감소 2%p 이내, FPR 증가 1%p 이내, 한 스텝 및 장기 MAE 악화 5% 이내, 비용 및 최장 NH4 위반 길이 MAE 악화 5% 이내, NH4 시작 F1 악화 없음, 평균 NH4 recall 향상 5%p 이상을 요구한다. recall 80% 및 FPR 10% 절대 점검도 별도로 표시한다.

새 tradeoff gate는 시작 다중 스텝 모델과 같은 예산 day_mse 각각에 대해 두 seed 모두 NH4 recall과 FPR이 악화하지 않고, 평균 FPR이 각각 1%p 이상 낮아져야 통과한다. 낮은 recall을 낮은 FPR로 덮지 않는다. 주 후보를 사후 교체하지 않으며, 실패하면 가중치 탐색을 이어가지 않고 미해결 한계를 기록한다. 통과해도 외부 확인 전 실제 환경 교체와 RL 재학습을 자동 진행하지 않는다.

## 실행 결과와 효과 분리

실행 커밋 `90a4bdc93084c19be7c1f2eb001ad704727d8802`, 2026-11-06 21:50:15부터 22:00:33 KST까지 약 618초다. 8개 학습과 84개 구간 평가를 완료했다. 모든 군의 초기 가중치와 관측 날짜 순서가 seed별로 같고, 미래 실측 비참조, 유한 gradient, 저장 복원 검사를 통과했다. 내부 holdout 66일, seed 2개 평균은 다음과 같다.

**하루 길이 MSE는 시작 모델 대비 두 seed 모두 recall이 높아지고 FPR이 낮아졌다.** seed 0은 recall 45.23%에서 45.92%, FPR 13.72%에서 8.74%다. seed 1은 recall 47.23%에서 55.12%, FPR 14.93%에서 12.11%다. 평균으로 recall +4.29%p, FPR -3.90%p이며 날짜별 비용 MAE는 40.35에서 29.05로 28.0% 감소했다. 이는 대리 모델의 관찰된 실제 운전 재생 결과이며 정책 성능 개선이나 실제 공정 안전성 증명이 아니다.

같은 예산의 36스텝 대조와 비교하면 하루 MSE의 평균 FPR은 16.60%에서 10.42%로 낮지만 recall도 53.13%에서 50.52%로 낮다. 이 비교까지 무조건 우월하다고 쓰지 않는다. 같은 FPR 10%에서 비교한 사후 ROC 진단은 36스텝 대조 recall 40.02%, 하루 MSE 50.10%, 조건별 제약 50.65%다. 구분 능력 개선의 대부분이 하루 학습에서 나타났다는 근거지만, 반복 관찰한 같은 holdout에서 임계값을 움직인 결과라 독립 확인이나 적용 성능으로 보고하지 않는다. 물리적 판정 기준은 변경하지 않았다.

전체 평균 제약은 두 seed 모두 학습 내내 lambda가 0이었다. 하루 MSE 모델과 가중치 및 정규화 buffer가 완전히 같음을 확인했다. FN proxy를 제거했으므로 e13처럼 승수가 0일 때 위반 예측을 미는 손실이 남지 않았다.

## 조건별 제한의 이득과 손해

조건별 제약은 운전 단계 0의 fit FPR을 하루 MSE 10.27%에서 8.37%, 내부 holdout FPR을 15.49%에서 12.71%로 낮췄다. 이 조건의 시작 모델 holdout FPR은 36.21%였으므로 개선의 큰 부분은 이미 하루 MSE에서 발생했다.

조건별 제약을 더하면 두 seed 모두 하루 MSE보다 recall이 낮아졌다. 특히 seed 0은 시작 모델 45.23%보다 낮은 42.65%가 되어, 탐지율을 유지하면서 거짓경보를 줄인다는 주 후보 gate에 실패했다. 평균 FPR 9.55%만 보고 성공으로 판단하지 않는다. seed 1의 FPR은 여전히 11.97%로 10%를 넘는다.

주 후보의 seed 0은 e12 screening의 모든 개별 조건을 통과했지만 seed 1은 기준 대비 FPR, 한 스텝 NH4 MAE, DO recall 조건을 일부 통과하지 못했다. 하루 MSE도 전체 screening을 통과하지 못했다. 각 후보의 NH4 및 DO recall은 절대 점검 기준 80%에 미달한다. 주 후보를 사후에 하루 MSE로 바꿔 채택하지 않았다. 하루 MSE의 개선은 후속 확인의 근거로 보존하고 기존 환경은 교체하지 않는다.

조건별 승수의 최대값은 seed 0, 1에서 각각 3.659, 3.422였고 상한에 막히지 않았다. 운전 단계 0의 NH4 제약은 300회 중 186회, 195회에서 최소 비위반 표본 수를 만족했다. 학습 시작의 계수 alpha는 0.346433, 0.260490이며 fit만으로 정했다. 모든 군에서 gradient clip 비율이 99.7~100%이므로 제한된 300갱신 시험을 완전 수렴으로 해석하지 않는다. 비교 조건을 바꾸는 추가 가중치 탐색은 하지 않았다.

## 입력 정보와 남은 누적 오차

하루 MSE 모델에 실제 현재 NH4와 DO를 매번 주는 한 스텝 재생에서는 NH4 recall 89.31%, FPR 2.25%였다. 자기 예측을 하루 동안 이어 쓰면 50.52%, 10.42%다. 따라서 현재 측정 상태가 주어져도 위반을 구분할 정보가 전혀 없다는 결론은 맞지 않는다. 이는 미래 유입 부하까지 충분히 관측한다거나 실제 상태 주입만으로 배포 성능을 확보했다는 뜻도 아니다.

하루 MSE의 장기 농도 편향은 여전히 +0.751이며 예측 첫 36스텝 +0.253에서 145~275스텝 +0.861로 커졌다. 한 스텝 오차와 장기 자기 예측의 차이가 남아 있다. 원인 후보로 누적 동역학 오차와 미래 부하의 관측 한계를 구분해야 하며, 이번 시험만으로 입력 부족이나 특정 누락 변수를 단독 원인으로 확정하지 않는다.

이번 결과는 하루 학습의 효과와 조건별 제약의 추가 탐지 손실을 구분했다. 더 강한 벌점이나 다른 가중치를 연속 탐색하지 않았다. 기존 FCSRL + PPO, 환경 모델, 보상과 위반 기준은 유지했고 외부 val, test, RL 재학습은 수행하지 않았다. 공식 확장 성공으로 세지 않는다.
