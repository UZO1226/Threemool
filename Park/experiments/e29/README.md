# Park/e29: 학습률이 다른 구성원을 섞은 4 x 16 앙상블 (Kaggle DARROW)

상태: **사전 등록 (2026-11-15).** 고르기 규칙은 결과를 보기 전에 정했고 (커밋 `f105833`, 아래 그대로), 가설과 판정 규칙은 검증 결과를 보기 전에 정했다. 설정은 학습 구간만으로 골랐다.

## 목적

목표는 공기량과 하루 비용을 함께 낮추는 것이다. 대표 결과 Park/e22 H1 의 줄기를 잇는다.

- 같은 예산에서 공기량과 비용을 함께 낮춘 정책 쪽 방법은 seed 가 다른 정책의 앙상블 (e22) 뿐이다. 같은 학습의 중간 정책 평균은 효과가 없었다 (e25). 앙상블 효과는 구성원이 서로 다를 때 나온다
- 예산 나누기 (5 x 8, 5 x 12, 4 x 16, 3 x 22, 2 x 32) 는 e21, e22 에서 이미 봤고 4 x 16 이 가장 좋았다
- 구성원 학습률을 모두 6e-4 로 올리면 공기량은 조합 5개 모두 줄었지만 (평균 3.1%) 비용이 올랐다 (e26)

그래서 4 x 16 앙상블의 구성원 일부만 학습률이 높은 정책으로 바꾼다. 공기를 아끼는 구성원과 비용을 지키는 구성원을 섞어, seed 다양성에 학습 성질의 다양성을 더한다. 구성원 수와 업데이트 수는 4 x 16 그대로라 학습 예산이 같다.

## 방법

seed 조합 (a, b, c, d) 의 자리마다 학습률을 정한다. 학습률 3e-4 구성원은 Park/e22 `dw_u16_runs`, 6e-4 와 1e-3 구성원은 Park/e26 `dw_u16_lr6e-4`, `dw_u16_lr1e-3` (모두 `--updates 16`, seed 0 ~ 9 학습을 마침) 을 쓴다. 새 학습은 없다. 행동은 네 구성원의 평균이고, 차단은 e22 와 같은 e19 H1 차단이다.

| 후보 | a | b | c | d |
| --- | --- | --- | --- | --- |
| M1 | 3e-4 | 6e-4 | 3e-4 | 6e-4 |
| M2 | 3e-4 | 1e-3 | 3e-4 | 1e-3 |
| M3 | 3e-4 | 6e-4 | 3e-4 | 1e-3 |
| M4 | 3e-4 | 3e-4 | 3e-4 | 6e-4 |

## 고르기 규칙 (결과 전에 기록)

"학습 구간 마지막 40일 (2021-10-01 ~ 11-09) x 구성원 5개, e19 H1 차단, seed 0 ~ 4 의 4개 조합 5개를 같은 조합의 학습률 3e-4 4 x 16 (Park/e26 의 기준값) 과 짝 비교. 조합 평균 공기량 < 기준, 평균 비용 < 기준, 둘 다 이긴 조합 최다 (3/5 이상), 같으면 공기량 최소. 없으면 버린다. 규칙을 통과한 후보 중 평균 비용이 가장 낮은 후보가 고른 후보와 다르면 보조 가설로 함께 검증한다".

## 고르기 결과

| 후보 | 공기량 | 하루 비용 | 기준보다 둘 다 낮은 조합 |
| --- | --- | --- | --- |
| 기준 4 x 16 (학습률 3e-4) | 73,965 | 2.64 | |
| **M1 (규칙으로 고름)** | **72,021** | **2.53** | 4/5 |
| M2 | 73,336 | 2.63 | 3/5 |
| M3 | 72,871 | 2.58 | 3/5 |
| M4 | 72,288 | 2.53 | 4/5 |

네 후보 모두 규칙을 통과했다. M1 과 M4 가 4/5 로 같아 공기량이 적은 M1 을 골랐다. 평균 비용도 M1 (2.530) 이 M4 (2.534) 보다 낮아 보조 가설은 없다. NH4 위반은 네 후보 모두 기준 (1.51%) 과 비슷했다 (1.50 ~ 1.53%). 학습률을 모두 6e-4 로 올린 e26 (71,640, 2.82) 과 비교하면, 공기량 감소 일부를 지키면서 비용 상승은 없앴다.

## 조건과 평가

검증 40일 x 구성원 5개 = 200 에피소드, 결정적. test 는 쓰지 않는다. 판정 단위는 4 x 16 앙상블 조합 10개 (seed 0 ~ 4 의 4개 조합 5개, seed 5 ~ 9 의 4개 조합 5개) 다. 조합 (a, b, c, d) 에서 b, d 자리는 학습률 6e-4 구성원 (Park/e26 `dw_u16_lr6e-4`), a, c 자리는 3e-4 구성원 (Park/e22 `dw_u16_runs`, Park/e23 `dw_new16_runs`) 이다. 기준은 같은 조합의 3e-4 4 x 16 + e19 차단 값 (Park/e22, e23 결과, 새로 계산하지 않음) 이다.

참고 조건 (판정에 쓰지 않음): M1 에 Park/e28 H2 회복 계획 (H 4, do_lim 1.8) 을 함께 건 값.

## 가설 (사전 등록)

- H1 (주 가설). M1 + e19 차단이 같은 조합의 기준보다 공기량과 하루 비용이 둘 다 낮은 조합이 10개 중 6개 이상이고, 조합 10개 평균도 둘 다 낮다

짝 차이 평균과 95% 신뢰구간 (조합끼리 독립이 아니라 낙관적) 은 참고로 적는다. 가설이 기각되는 결과도 그대로 기록한다.

## RESULT.md 처리 (미리 정함)

H1 이 지지되면 학습 예산이 같으므로 (구성원 4개 x 업데이트 16번) 대표 방법을 "학습률 섞은 4 x 16 앙상블 (M1) + e19 차단" 으로 바꾼다. 값은 seed 0 ~ 3 조합 (seed 0, 2 는 3e-4, seed 1, 3 은 6e-4) 값과 조합 10개 평균을 함께 적는다. 참고 조건 (회복 계획) 은 해석에만 적는다.

## 미리 밝히는 한계

- 학습률 6e-4 구성원은 e26 에서 학습 구간 고르기에 이미 쓰였다. 이번 고르기도 같은 학습 구간 40일이라, 학습 구간 결과는 검증 결과보다 낙관적일 수 있다
- 어느 자리를 6e-4 로 둘지는 미리 정한 규칙 (b, d 자리) 을 따랐고, 자리를 바꾼 경우는 보지 않는다
- 앙상블은 제어기 하나라 안정성은 조합 사이 차이로만 본다
- e10 ~ e28 과 같은 대리 모델 한계
