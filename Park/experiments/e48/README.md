# Park/e48: 같은 정보의 짧은 예측 구간 모델 예측 제어와의 비교 (Kaggle DARROW)

상태: **사전 등록 (2026-11-20).** 가설, 기준, 고르는 규칙은 학습 구간 맞춤과 검증 결과를 보기 전에 정했다. 대표는 바꾸지 않는다.

## 목적

팀 중간점검 (Yoo/analysis/TEAM_RESEARCH_REVIEW_20261117.md) 6.2 절은 Park 의 독창성 점수 근거로 "predictive filter, MPC, ensemble 의 조합 성격이 큼" 을 들고, 점수를 올리는 증거로 "동일 정보의 짧은 horizon 제어, 기존 차단 대비 왜 이 조건부 계획이 필요한지 분리" 를 요구했다. 같은 절은 "현재 개선의 상당 부분은 FCSRL 보다 모델 예측 제어기의 성과로 보인다" 고 했다.

Park/e43 의 차단만 (정책 없음) 은 1 스텝 최소 공기 규칙이라 모델 예측 제어로는 약한 기준이다. 이 실험은 학습 정책 없이 같은 대리 모델과 같은 정보로 1시간 앞을 최적화하는 모델 예측 제어를 만들어, 같은 공기량에서 대표 (학습 정책 + 차단) 가 이 제어기보다 나은지 본다. 대표가 지면 "학습 정책 없이 모델 예측 제어만으로 충분하다" 는 뜻이다.

## 기준: 짧은 예측 구간 모델 예측 제어 (`Park/code/mpc_darrow.py`)

- 정보: 대표 차단과 같다. 관측한 지금 상태, 그 시각의 외부 입력과 구간 배분 (예측 구간 동안 그대로 둠), 직전 구간 공기량, 환경이 쓰는 구성원을 뺀 4개 구성원의 평균 예측
- 예측 구간 H = 4 스텝 (1시간, 대표의 회복 계획과 같은 길이). 후보: 첫 스텝 공기량 u0 (0 ~ 9,000, 500 간격), 나머지 3 스텝 공기량 u1 (0 ~ 9,000, 1,500 간격)
- 목적: 4 스텝 동안 [1(NH4 + 여유 > 4) + 1(구간 DO 최댓값 > 1.8) + 공기 가중치 x 공기량 / 9,000] 의 합. 위반 항은 환경 비용과 같은 모양이다. 가장 작은 후보의 u0 를 실행하고 매 스텝 다시 푼다
- 손잡이: NH4 여유 (0, 0.2, 0.4) x 공기 가중치 (0.1, 0.25, 0.5, 1, 2), 15 조합

## 고르기 (학습 구간 마지막 40일 x 구성원 5개)

Park/e43 과 같은 규칙이다. 대표의 학습 구간 공기량 (Park/e43 의 73,345) 의 ±2% 안에서 하루 비용이 가장 낮은 조합을 고른다. 없으면 공기량이 가장 가까운 조합을 고른다.

## 평가

검증 40일 x 구성원 5개 = 200 에피소드, 결정적. test 는 쓰지 않는다. 대표는 Park/e35 orig 의 묶음 5개 값을 쓴다.

## 가설 (사전 등록)

- H1. 고른 예측 제어의 검증 공기량이 대표 평균의 ±3% 안이고, 대표 묶음의 하루 비용이 예측 제어보다 낮은 묶음이 5개 중 4개 이상이며 평균도 낮다. 공기량이 ±3% 밖이면 판정하지 않고 "맞춤 실패" 로 적는다

참고 (판정 없음): 예측 제어 대 차단만, ABAC (Park/e43 값).

## RESULT.md 처리 (미리 정함)

대표 방법은 바꾸지 않는다.

- H1 지지: "같은 정보와 같은 공기량에서 대표가 1시간 모델 예측 제어보다 하루 비용이 낮다. 학습 정책이 모델 예측 제어 위에 더하는 몫이 있다" 고 적는다
- H1 기각: "같은 정보의 1시간 모델 예측 제어가 학습 정책 없이 대표만큼 (또는 더 잘) 한다" 고 한계에 적고, 예측 제어가 대표보다 4/5 이상 낮고 평균도 낮으면 대표를 바꿀지는 팀과 정한다 (Park 혼자 정하지 않음)
- 맞춤 실패: 값을 참고로 적고 판정은 하지 않았다고 적는다

## 미리 밝히는 한계

- 예측 제어는 단순한 격자 탐색 (이동 묶음 2 단계, 1시간) 이다. 더 긴 예측 구간이나 연속 최적화는 보지 않는다. 대표에 유리한 쪽이다
- 손잡이는 15 조합에서 고르고 대표는 다시 고르지 않는다. 고르기는 예측 제어에 유리한 쪽이다
- 예측 제어는 대표 차단과 같은 대리 모델 계열을 쓰고, 환경도 같은 계열이다. 모델이 틀린 경우의 비교는 하지 않았다 (Park/e38 참고)
- 대표는 묶음 5개, 예측 제어는 결정적 제어기 하나다. 묶음 5개는 판정 표본이 작다 (4/5 기준). 검증 구간은 e10 부터 반복해서 썼다
