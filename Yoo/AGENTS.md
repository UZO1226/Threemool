# Yoo 후속 실험 지침

루트 AGENTS.md와 CLAUDE.md, RULES 지침을 함께 따른다.

사용자의 2026-11-13 지시: 새 실험을 시작하기 전에 Lee와 Park의 README를 읽고 이미 수행한 실험인지 먼저 확인한다.

1. 최신 origin/main에서 Lee/README.md, Park/README.md와 두 RESULT.md를 읽는다. README가 비었거나 오래됐으면 연결된 분석 요약과 관련 experiments 기록까지 확인한다. 열린 PR도 확인한다.
2. Yoo의 관련 과거 실험도 함께 대조한다. 같은 가설의 결과, 데이터와 환경 차이, 재사용 가능한 근거, 새 실행으로만 답할 질문을 Yoo 문서에 기록한다.
3. 계획만 있고 결과 파일이 없으면 완료 또는 실패로 단정하지 않는다. 다른 데이터에서 실패한 결과를 DARROW에서 같은 결과라는 증거로 쓰지 않는다.
4. 중복 대조가 끝나기 전에는 새 학습, 탐색, 진단 실험을 시작하지 않는다. 기존 결과 읽기는 허용한다. 단순 재실행이 필요하면 재현 목적과 다른 조건을 명시한다.
5. Lee/Park 파일은 읽기만 하고 수정하지 않는다. 팀원에게 메시지를 보내는 권한은 이 지침에 포함되지 않는다.

중복 확인은 새 아이디어를 막는 성능 사전 입증 요구가 아니다. 팀 기록과 다른 변경/질문이 확인되고 사용자가 실행을 지시했다면, 필요한 구현 검사 뒤 실험을 진행한다.
