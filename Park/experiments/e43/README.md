# Park/e43: 공기량을 맞춘 비학습 기준과의 비교 (Kaggle DARROW)

상태: **사전 등록 (2026-11-19).** 가설, 기준, 고르는 규칙은 학습 구간 맞춤과 검증 결과를 보기 전에 정했다. 대표는 바꾸지 않는다.

## 목적

팀 중간점검 (Yoo/analysis/TEAM_RESEARCH_REVIEW_20261117.md) 은 다음을 요구했다.

- 7.1 절: Lee 의 평가 방식 (실제 공기량을 맞춘 비교) 을 Park 제어에 적용해, 이득이 공기 증가나 대표 조합 때문인지 가린다
- 9 절: "같은 조건의 기준선과 단순 제어기를 이기는 이유를 보여 주는 한 장의 표"
- 5.1 절과 Yoo/e68: 현장 표준인 NH4 피드백 폭기 제어 (ABAC) 를 축약 기준선으로 둔다

Park/e36 은 같은 차단에 여러 정책을 붙였지만 공기량이 서로 달라 (79,670 ~ 103,716) 비용을 바로 비교할 수 없었다. 이 실험은 비학습 기준 두 개의 설정을 학습 구간에서 대표의 공기량에 맞춘 뒤, 검증 구간에서 같은 공기량의 비용을 비교한다.

## 기준

| 기준 | 읽는 정보 | 맞추는 손잡이 |
| --- | --- | --- |
| ABAC (NH4 PI, 속도형, Yoo/e68 과 같은 식, `Park/code/baselines_darrow.py`) | 관측 NH4 하나. 대리 모델 없음 | 설정값 1.0 ~ 4.0 (0.1 간격) x Kp (0, 500, 1000, 2000) x Ki (400 ~ 25,600, 1e6) = 992 조합 |
| 차단만 (정책은 언제나 공기 0 제안, 대표 차단, Park/e36 zero 와 같음) | 대표 차단과 같음 (정책보다 많은 정보, 대리 모델) | NH4 여유 P1 의 모든 칸에 delta (0, 0.1, 0.2, 0.3) |
| 참고: 기본 PPO-Lag (Park/e08, 차단 없음) | 관측 11 개 | 정책 공기량 배율 (0.80 ~ 1.00, 0.05 간격), seed 5개 |

## 고르기 (학습 구간 마지막 40일 x 구성원 5개)

1. 대표 (FCSRL 4 x 16 앙상블 + 대표 차단, 구성원이 겹치지 않는 묶음 5개) 의 학습 구간 공기량 평균을 맞출 값으로 한다
2. ABAC: 공기량이 맞출 값의 ±2% 안인 조합 가운데 하루 비용이 가장 낮은 것. 없으면 공기량이 가장 가까운 것. 고른 값이 격자 끝이면 (Kp 최소와 Ki 최대 제외) 한계로 적는다
3. 차단만, PPO-Lag 배율: 공기량이 가장 가까운 값 (같으면 작은 값)

## 평가

검증 40일 x 구성원 5개 = 200 에피소드, 결정적. test 는 쓰지 않는다. 대표 값은 Park/e35 orig 묶음 5개 (82,104, 4.658) 를 그대로 쓴다.

## 가설 (사전 등록)

- H1 (ABAC). 고른 ABAC 의 검증 공기량이 대표 평균의 ±3% 안이고, 대표 묶음의 하루 비용이 ABAC 보다 낮은 묶음이 5개 중 4개 이상이며, 평균도 낮다. 공기량이 ±3% 밖이면 판정하지 않고 "맞춤 실패" 로 적는다
- H2 (차단만). 같은 규칙으로 고른 차단만과 비교한다

참고 (판정 없음): 기본 PPO-Lag 배율, 검증 구간에서 손잡이를 바꾼 곡선 (ABAC 설정값 전체, 차단만 delta 전체) 에서 대표 공기량의 비용을 직선 보간한 값.

## RESULT.md 처리 (미리 정함)

대표 방법은 바꾸지 않는다.

- H1, H2 지지: "같은 공기량에서 대표가 현장 표준 ABAC 와 차단만보다 하루 비용이 낮다" 고 적고, 이 표를 팀 공통 비교의 Park 기준표로 쓴다
- H1 지지, H2 기각: "대표의 이득은 대부분 모델 예측 차단의 몫이고, 같은 공기량에서 정책은 차단만보다 낫지 않다" 고 적는다
- H1 기각: "같은 공기량이면 단순한 NH4 피드백 제어가 대표만큼 한다" 고 한계에 적는다
- 맞춤 실패: 곡선 보간 값을 참고로 적고 판정은 하지 않았다고 적는다

## 미리 밝히는 한계

- ABAC 는 실제 현장 제어기의 축약판이다 (센서와 내부 루프 지연, 공기 변화율 제한 없음). 대리 모델이 공기를 직접 받는다
- ABAC 는 992 조합에서 고르고 대표는 다시 고르지 않는다. 고르기는 ABAC 에 유리한 쪽이다
- 차단만과 대표는 같은 차단을 쓰므로 정보 조건이 같다. ABAC 는 정책보다도 적은 정보를 쓴다
- 대표는 묶음 5개, 기준은 결정적 제어기 하나 (PPO-Lag 는 seed 5개) 다. 묶음 5개는 판정 표본이 작다 (4/5 기준). 검증 구간은 e10 부터 반복해서 썼다
