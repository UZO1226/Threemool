# Park/e30: 회복 계획의 적용 범위 넓히기 (Kaggle DARROW)

상태: **완료 (2026-11-16). 고르기 단계에서 후보 없음, 검증 평가는 하지 않음.** 넓힌 네 후보 모두 학습 구간 평균 비용이 P2 보다 높았다. 고르기 규칙은 결과를 보기 전에 정했다 (커밋 `98ee763`, 아래 그대로).

## 목적

목표는 공기량과 하루 비용을 함께 낮추는 것이다.

- Park/e28 H2 (4 스텝 회복 계획) 는 같은 조합의 e19 차단보다 10개 조합 모두 공기량과 비용이 함께 낮았다. 하지만 보조 가설이라 사전 등록 규칙에 따라 대표가 되지 못했다
- e28 H2 가 공기량을 바꾼 스텝은 0.67% 뿐이다. 공기량 9,000 에서도 다음 스텝 NH4 가 4 를 넘는 스텝 (막을 수 없는 스텝) 에만 썼기 때문이다
- 그 바로 바깥의 스텝 (9,000 이면 겨우 막거나, NH4 가 이미 4 를 넘은 스텝) 에서도 e19 차단은 1 스텝만 보고 공기를 크게 올린다. 이런 스텝까지 4 스텝 비용으로 공기량을 정하면 효과가 커질 수 있다

## 방법

`min_brake.py` 에 `plan_trigger`, `plan_now` 를 더했다. 회복 계획 (H 4, do_lim 1.8, 500 간격, e28 H2 와 같음) 을 쓰는 에피소드를 다음으로 넓힌다. 기본값 (4, 없음) 은 e28 과 같다.

| 후보 | 회복 계획을 쓰는 스텝 |
| --- | --- |
| P2 (e28 H2, 기준) | 9,000 에서의 다음 스텝 예측 NH4 > 4 |
| T38 | 9,000 에서의 다음 스텝 예측 NH4 > 3.8 |
| T35 | 9,000 에서의 다음 스텝 예측 NH4 > 3.5 |
| N4 | P2 이거나 지금 NH4 > 4 |
| N35 | P2 이거나 지금 NH4 > 3.5 |

정책은 e22 와 같은 4 x 16 앙상블이다 (새 학습 없음).

## 고르기 규칙 (결과 전에 기록)

"학습 구간 마지막 40일 (2021-10-01 ~ 11-09) x 구성원 5개, seed 0 ~ 4 의 4개 조합 5개. 넓힌 후보 (T38, T35, N4, N35) 를 같은 조합의 P2 와 짝 비교. 조합 평균 공기량 < P2, 평균 비용 < P2, 둘 다 이긴 조합 최다 (3/5 이상), 같으면 공기량 최소. 없으면 넓히기는 버리고 검증 평가는 하지 않는다 (e28 H2 를 같은 검증 구간으로 다시 판정하지 않는다). P2 는 Park/e28 고르기 값 (73,753, 2.478) 과 같아야 하고, 다르면 코드를 먼저 고친다".

## 해석

- 범위를 조금 넓히면 (T38, N4) 공기량은 거의 같고 비용이 조금 오른다. 많이 넓히면 (T35, N35) 공기량과 비용이 함께 오르고 NH4 위반이 늘어, e19 차단보다도 나빠진다
- 회복 계획은 막을 수 없는 스텝에서만 e19 차단보다 낫다. 막을 수 있는 스텝에서는 e19 차단이 예측 오차에 맞춘 여유로 1 스텝 NH4 를 지키는데, 회복 계획은 여유 없이 4 스텝을 이어 굴린 예측으로 위반 수를 세서 경계 근처 위반을 놓친다. 또 비용이 같으면 NH4 를 빨리 내리는 쪽을 골라 공기를 더 넣는다 (N35 공기량 +11,181)
- e28 H2 의 적용 범위 (공기량 9,000 에서도 다음 NH4 > 4) 가 이미 알맞았다. e28 H2 는 보조 가설 결과로 남고, 대표는 e22 H1 그대로다
