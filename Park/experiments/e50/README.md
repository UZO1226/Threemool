# Park/e50: 한 기여 중심의 주장 지도 (Kaggle DARROW)

상태: **완료 (2026-11-20).** 분류 규칙은 지도를 쓰기 전에 정했다 (사전 등록 커밋 `bc7260d`). 새 학습과 새 평가는 없다. 대표는 바꾸지 않는다.

## 목적

팀 중간점검 (Yoo/analysis/TEAM_RESEARCH_REVIEW_20261117.md) 8절 7번은 "하나의 기여를 중심으로 원고 구성: 주 주장 하나, 대표 비교, 제거 대조, 새 확인, 실패와 한계가 연결됨" 을 요구했고, 8.1 절은 Park 에 "한 페이지 현재 상태" 에 해당하는 정리를 권했다. e1 ~ e49 는 실험 모음으로 흩어져 있어 원고의 주 주장이 무엇이고 어디까지 말할 수 있는지가 한눈에 보이지 않는다. 이 실험은 기존 결과만으로 주장 지도 한 쪽을 만든다.

## 분류 규칙 (사전 등록)

- 주 주장: 사전 등록 판정에서 지지됐고, 겹치지 않는 묶음 단위 판정과 날짜 블록 구간 (Park/e49) 이 모두 같은 방향인 것 하나. 후보가 여럿이면 공기량을 통제한 비교를 우선한다
- 보조 근거: 사전 등록 판정에서 지지된 것 가운데 주 주장의 조건 (모델 오차, 지연, 사건 단위, 새 seed) 을 넓히는 것
- 기여 분리: 차단, 학습 설정, 학습 정책, FCSRL 표현의 몫을 같은 공기량 또는 같은 설정 비교로 나눈 값. 판정 기준을 넘지 못한 것은 "확인되지 않음" 으로 적는다
- 한계와 실패: 사전 등록 판정에서 기각되거나 판정하지 못한 것, 그리고 주 주장을 좁히는 것. 숨기지 않고 주장 옆에 둔다
- 사후 관찰: 판정 없이 결과를 보고 찾은 것. 따로 표시하고 주장의 근거로 쓰지 않는다
- 수치는 Park/RESULT.md 와 각 실험의 results.md 에 이미 있는 값만 쓴다. 새로 계산하거나 다시 고르지 않는다

## 미리 밝히는 한계

- 정리 실험이라 새 증거를 만들지 않는다. 점수를 올리는 것은 정리 자체가 아니라 정리된 근거다
- 모든 결과는 같은 대리 모델 계열의 환경과 반복 사용한 검증 40일에서 나왔다. test 는 쓰지 않았다

## 주장 지도 (한 쪽)

모든 값은 검증 40일 x 구성원 5개, 같은 PROTOCOL v1.1 환경이다. "묶음" 은 구성원이 겹치지 않는 4 x 16 앙상블 묶음 5개다.

### 주 주장

**같은 공기량에서, 대리 모델로 다음 NH4 를 예측해 필요한 만큼만 공기를 올리는 최소 개입 차단과 그 차단을 켠 채 학습한 정책 앙상블 (대표) 은 현장 표준 ABAC 와 차단만보다 하루 위반 비용이 낮다.**

| 근거 | 값 | 판정 단위 |
| --- | --- | --- |
| 대표 대 ABAC (Park/e43) | 82,104 / 4.658 대 82,345 / 5.450, 차이 -0.79 | 묶음 5/5, 사전 등록 지지 |
| 대표 대 차단만 (Park/e43) | 81,934 / 5.120, 차이 -0.46 | 묶음 5/5, 사전 등록 지지 |
| 날짜 블록 구간 (Park/e49) | ABAC -1.249 ~ -0.305, 차단만 -0.752 ~ -0.218 | 5일 블록 다시 뽑기, 사전 등록 지지 |
| 공식 기준선과 (RESULT.md 표) | 기본 PPO-Lag 90,121 / 10.79 대 대표 79,457 / 4.58 | 공기와 비용 함께 낮음 |

### 기여 분리 (같은 공기량 또는 같은 설정)

| 몫 | 비교 | 비용 차이 | 상태 |
| --- | --- | --- | --- |
| 차단 | ABAC 대 차단만 (같은 공기량, e43) | -0.33 | 확인 (ABAC 대비 이득의 약 40%) |
| 학습 정책 (차단 위) | 차단만 대 대표 (같은 공기량, e43, e49) | -0.46 | 확인, 날짜에 고르게 퍼짐 (나은 날 25, 나쁜 날 4) |
| 학습 설정 대 알고리즘 | 같은 설정 PPO-Lag 대 FCSRL (e37) | -0.244 | 확인되지 않음 (2/5) |
| FCSRL 학습 표현 | 무작위 고정 표현 대 FCSRL (e47) | -0.127 | 묶음 5/5 지지, 신뢰구간 0 포함 |
| feasibility 손실 | 동역학 일관성만 대 FCSRL (e47) | -0.164 | 확인되지 않음 (3/5) |
| 회복 계획 (원판) | 계획 없음 대 원판 (e35, e32) | -0.14 | 확인 (새 seed 10/10, 묶음 5/5) |

정리: 대표 이득의 대부분은 차단과 차단을 켠 학습 설정에서 오고, FCSRL 고유의 몫은 작고 (0.1 ~ 0.25) 판정 기준을 일관되게 넘지 못한다. 원고의 주 기여는 "FCSRL" 이 아니라 "예측 차단과 함께 학습한 정책" 이다.

### 보조 근거 (조건을 넓힘, 모두 사전 등록 지지)

- 새 seed (Park/e32): 회복 계획 이득이 새로 학습한 seed 10 ~ 19 의 조합 10개 모두에서 재현
- 측정하지 않는 유입 변수를 모를 때 (Park/e39): 82,283 / 5.068, 기준선보다 5/5 둘 다 낮음
- NH4 분석계 15분 지연 (Park/e46): 82,577 / 5.762, 기준선보다 5/5 둘 다 낮음. 비용 증가 +1.10 으로 같은 설정 PPO-Lag (+3.58) 보다 작음
- 사건 단위 (Park/e45): NH4 위반 사건 0.36 대 ABAC 0.41/일, 5/5
- 차단 모델이 틀릴 때 FCSRL 은 같은 설정 PPO-Lag 보다 덜 무너짐 (Park/e38 H2, +6.57 대 +10.83, 5/5). FCSRL 몫의 가장 강한 근거

### 한계와 실패 (주장 옆에 둠)

- **공기 반응이 틀린 차단 모델에서는 무너진다** (Park/e38 H1 기각: 11.23, 기준선 10.79 보다 나쁨). 여유를 다시 맞추면 7.47 까지만 (e40), 더하기 보정은 오히려 나쁨 (e41), 기울기 학습은 닫힌 고리 교란으로 실패 (e42). 실제 적용에는 공기 반응 방향을 지키는 모델이 먼저 필요하다
- **ABAC 대비 이득은 며칠에 몰린다** (Park/e49 H3 기각): 이득의 65% 가 4일, 나머지 36일에서는 구간이 0 을 포함. NH4 초과 적분은 대표, ABAC, 차단만이 거의 같다 (e45, 2.85 ~ 2.88). 이득의 약 0.48 은 DO 위반에서 온다
- 30분 지연에서는 9.62 로 기준선 10.79 에 가깝다 (e46)
- 같은 정보의 1시간 예측 제어는 대표 공기량에 맞추지 못해 판정하지 못했다 (Park/e48 맞춤 실패, 64,182 / 20.820). "학습 정책이 예측 제어 위에 더하는 몫" 은 열린 질문이다
- 회복 계획의 목적은 문서와 달리 OR 로 계산됐고, 문서대로 합으로 고치면 나빠진다 (Park/e35: 7.86). 대표 값은 모두 OR 원판의 값이다
- 대표 차단은 환경과 같은 대리 모델 계열이다. 차단 검사를 통과한 행동의 위반률 0.00% (e44) 는 거의 정의상 성립한다
- 검증 40일은 e10 부터 반복 사용했고 한 계절 (11 ~ 12월) 이다. 새 날짜나 test 확인은 아직 없다

### 사후 관찰 (근거로 쓰지 않음)

- FCSRL 표현 전체를 쓴 정책은 차단 개입률이 24% 로 무작위 표현, feasibility 손실 없음, PPO-Lag (46 ~ 60%) 보다 낮다 (e47, 5/5). 다음 실험에서 사전 등록할 후보
- 1시간 예측 제어의 실패는 위반 지표 목적이 피할 수 없는 위반 앞에서 최소 공기를 고르기 때문으로 보인다 (e48)
- 남은 NH4 위반의 99.7% 는 최대 공기로도 여유를 못 지키는 스텝이다 (e44). 남은 비용은 제어보다 공정 용량의 문제에 가깝다

## 원고 흐름 제안

1. 문제: 같은 공기량에서 위반을 줄일 수 있는가 (공식 기준선과 ABAC)
2. 방법: 최소 개입 예측 차단 + 차단을 켠 학습 + 앙상블 + 회복 계획 (OR 목적임을 명시)
3. 주 결과: e43 의 같은 공기량 비교와 e49 의 날짜 블록 구간
4. 기여 분리: 위 표. FCSRL 고유 몫은 작다고 적는다
5. 조건 확장: e32, e39, e45, e46, e38 H2
6. 실패와 한계: e38 H1 ~ e42, e49 H3, e48, e35
