# e28 동일 목표 시각의 예측 길이와 시작 상태 대조

2026-11-09 실행 전 계획. e27 후반 오류가 긴 예측과 시간대 중 어느 쪽에 연결되는지 확인한다. 기존 e12는 다른 모델의 하루 전체 분기/실측 주입 진단이며 DO의 다음 실제 값도 주입했다. e26은 현재 모델의 한 스텝/하루 전체 집계였다. 이번에는 e27과 같은 모델에서 목표 날짜와 시각을 맞추고, 시작 시점의 상태만 한 번 주입한 뒤 자율 예측한다. 미래 수질 정답을 매번 넣는 개선 실험이 아니다.

## 고정 대조

- Kaggle Avedore, 내부66일/외부43일, start_multi/short_mse/day_mse seed0,1 가중치 고정. test 사용 및 새 학습 없음.
- 주 비교는 동일 목표13:05~23:55의131개 시점이다. 시작 상태를 실측 NH4/DO로 설정하고1/12/36/72/144전이(5분/1시간/3시간/6시간/12시간) 앞에서 예측한다. 기존01:00 초기화 하루 재생을 함께 보고한다.
- 시간대 비교는 같은1/12/36전이에서04:05~13:00 대13:05~23:55를 보고한다. 날짜는 같지만 시간대별 실제 상태/운전 조건은 다르므로 관찰적 비교다.
- 분기 대조는 동일 후반 목표에서36전이 전의 상태를 기존 하루 예측으로 설정한 뒤, 보정 없음/NH4만 실측/DO만 실측/둘 다 실측을 비교한다. 시작 이후에는 수질 정답을 주입하지 않는다. DO 다음 정답도 주입하지 않는다.
- 모든 대조에서 실제 행동/외생 경로를 재생한다. NH4>4, DO>2 유지. FPR, recall, AUC, NH4 MAE, 정상/위반 판정 수를 기록한다. 부분 시간 구간의 비용MAE는 해당 구간 합계이며 하루 전체 비용MAE와 혼동하지 않는다.

## 판단과 한계

동일 목표에서 짧은 예측으로 recall을 유지/개선하면서 FPR과 NH4 MAE가 두 seed 모두 감소하면 누적 예측 상태/기간의 관여를 지지한다. 짧은 길이에도 후반 성능이 낮으면 시간대 조건이나 국소 전이 오차도 남아 있다. 두 결과는 공존할 수 있고 기여율을 임의로 합산하지 않는다. NH4와 DO의 초기 정보 효과도 상호작용 가능성이 있어 독립 인과 기여율로 해석하지 않는다.

실측 시작 상태가 추가되는 방법들은 그 시작 시점에 관측을 받는 진단이다. 하루01:00부터의 배포 가능한 자율 예측 개선이나 다른 행동의 RL 성과가 아니다. 결과에 따라 실제 관측을 가상 제어 경로에 주입하거나 평가 길이를 줄여 기존 성공 기준을 대체하지 않는다. OMPB 및 새로운 환경 학습은 이번 범위에 없다.

원본 e27 예측 완전일치, e26 한 스텝 판정 수 일치, 예측 상태에서 시작하는36전이 연속 재생 일치, 두 상태 주입과 독립36전이 대조 일치, 시작 이후 수질 정답 교란 불변을 확인한다. 데이터/가중치/소스/기존 캐시 해시는 실행 전후 확인한다. 데이터와 모델 출처는 e27과 같다. 기존 Python, CPU1thread, 새 설치 없음.
