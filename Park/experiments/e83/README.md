# Park/e83: 학습 구간 날짜 블록으로 본 대표 대 차단 위 예측 제어 (Kaggle DARROW)

상태: **사전 등록 (2026-11-26).** 날짜, 설정, 가설, 판정 규칙은 이 실험의 결과를 보기 전에 정했다. 대표는 바꾸지 않는다.

## 목적

Park/e80 은 학습 구간 마지막 40일에서 차단 위 예측 제어가 대표보다 0.3 ~ 0.9 높다는 것을 평균으로 보였다. 이 차이가 날짜 흔들림을 넘는지는 보지 않았다. 이 실험은 Park/e82 와 같은 날짜 블록 판정 (세 갈래) 을 학습 구간 마지막 40일에 적용한다. Park/e82 (검증 구간) 와 나란히 놓으면, 두 구간에서 대표와 예측 제어의 순서가 정말 뒤집히는지 알 수 있다.

## 방법

- 날: 학습 구간 마지막 40일 x 구성원 5개 (Park/e43, e60, e80 과 같음)
- 차단 위 예측 제어 두 설정 (Park/e82 와 같음: 여유 1.2 가중치 1.5, 여유 1.8 가중치 2.0) 과 대표 (FCSRL 4 x 16 + 대표 차단, 묶음 5개) 를 스텝 기록과 함께 돈다. 대표는 학습 구간의 스텝 기록이 없어 다시 돈다. 그 값이 Park/e43 의 학습 구간 값과 같은지 표에 적는다
- 판정 방법은 Park/e82 와 같다 (날짜 짝 차이, 이어진 5일 블록 다시 뽑기 10,000번, seed 0, 95% 구간)

## 평가

학습 구간 마지막 40일 x 구성원 5개 = 200 에피소드, 결정적. test 는 쓰지 않는다.

## 가설 (사전 등록)

방향은 이전 결과에서 정했다 (Park/e60, e80 은 이 날에서 예측 제어가 대표보다 높았다).

- H1. 이 날에서 기본 설정 (여유 1.2) 의 (예측 제어 빼기 대표) 블록 95% 구간이 0 위다 (대표가 낮음)
- H2. 여유 1.8, 가중치 2.0 의 같은 구간이 0 위다
- 판정은 지지 (0 위), 반대 (0 아래), 차이 없음 (0 포함) 의 세 갈래로 적는다

## RESULT.md 처리 (미리 정함)

- 지지: "학습 구간 마지막 40일에서는 날짜 흔들림을 넘어 대표가 차단 위 예측 제어 (그 설정) 보다 낮다" 고 적는다. Park/e82 가 같은 설정에서 반대 방향을 지지하면 "두 구간에서 순서가 뒤집힌다" 고 함께 적는다
- 차이 없음: "학습 구간의 대표 우위는 날짜 흔들림 안에 있다" 고 적고 Park/e80 의 해석을 그만큼 좁힌다
- 반대: "날짜 단위로는 학습 구간에서도 예측 제어가 낮다" 고 적는다

## 미리 밝히는 한계

- 학습 구간은 대표 정책이 학습한 날이라 대표에 유리하다. 이 실험은 그 몫을 가르지 않는다 (Park/e84 에서 학습하지 않는 제어기로 본다)
- 블록 구간은 날짜 흔들림만 담고, 정책 학습의 seed 흔들림은 담지 않는다 (대표는 묶음 5개 평균)
