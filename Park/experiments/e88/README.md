# Park/e88: 예측 제어에서 차단의 몫, 학습 구간 188일 (Kaggle DARROW)

상태: **사전 등록 (2026-11-26).** 공기 가중치, 가설, 판정 규칙은 이 실험의 결과를 보기 전에 정했다. 대표는 바꾸지 않는다.

## 목적

Park/e86 은 ABAC 에서 차단의 몫을 날짜 블록으로 본다. 차단이 이득의 원천이라는 정리가 제어기에 따라 달라지지 않는지 보려면 다른 제어기에서도 같은 몫이 나와야 한다. 검증 40일에서 차단 없는 1시간 예측 제어는 같은 공기량의 대표보다 1.553 높았다 (Park/e57). 이 실험은 같은 예측 제어에 차단을 씌운 것과 씌우지 않은 것을 학습 구간 188일에서 같은 공기량으로 비교한다.

## 방법

- 차단 없는 예측 제어 (`ShortMPC`, NH4 여유 1.2, 1시간): 공기 가중치 0.7, 1.0, 1.4, 2.0 을 학습 구간 188일에서 스텝 기록과 함께 돈다
- 차단 위 예측 제어 기본 (가중치 1.5) 은 Park/e87 의 기록을 쓴다
- 같은 공기량 맞추기: 차단 위 쪽의 전체 공기량을 감싸는 두 가중치의 날짜별 비용을 선형 보간 (Park/e84, e87 과 같음). 감싸는 두 점이 없으면 판정하지 않는다
- 가중치 범위는 검증 40일에서 차단 없는 쪽이 가중치 0.6 ~ 1.0 에서 79,500 ~ 85,200 (Park/e57) 이었고 학습 구간 공기량이 검증보다 10% 안팎 적은 것 (Park/e60) 을 보고 넓게 두었다
- 판정 방법은 Park/e82 와 같다 (세 갈래)

## 평가

학습 구간 188일 x 구성원 5개, 결정적. test 는 쓰지 않는다.

## 가설 (사전 등록)

방향은 Park/e56, e57 (차단 없는 예측 제어가 크게 높음) 과 Park/e70 (차단이 ABAC 를 낮춤) 에서 정했다.

- H1. 학습 구간 188일에서 (차단 위 예측 제어 빼기 같은 공기량의 차단 없는 예측 제어) 하루 비용의 블록 95% 구간이 0 아래다

## RESULT.md 처리 (미리 정함)

- 지지: "차단의 몫은 예측 제어에서도 날짜 블록으로 확인된다" 고 적고, Park/e86 과 함께 "제어기에 따르지 않는 차단의 몫" 으로 적는다
- 차이 없음: "예측 제어에서는 차단의 몫이 날짜 흔들림 안" 이라 적는다
- 반대: "예측 제어에서는 차단이 오히려 높다" 고 적는다

## 미리 밝히는 한계

- 차단 없는 예측 제어는 스스로 NH4 를 내다보므로 차단과 하는 일이 겹친다. 차단의 몫이 ABAC 보다 작게 나올 수 있다
- 예측 제어, 차단, 환경은 같은 대리 모델 계열이다
