# Park/e10: 필요한 만큼만 공기량을 올리는 최소 개입 차단 (Kaggle DARROW)

상태: **완료 (2026-11-10). H1 지지 (4/5), H2 지지 (5/5), H3 지지 안 됨 (0/5).** 같은 공기량에서 비용이 낮아졌지만, 같은 비용에서 공기량을 10% 줄이지는 못했다. 가설과 판정 규칙은 전체 평가 전에 정했고 결과를 본 뒤 바꾸지 않았다.

## 목적

Park/e01 ~ e09 는 차단을 "언제" 거느냐(NH4 규칙, F, 예측기) 를 바꿨고, 차단이 걸리면 공기량은 늘 5,800 Nm3/h 로 올렸다. 그래서 NH4 가 조금만 위험해도 공기를 크게 올려 공기량이 늘었다 (e08: 비용 13.66 에서 6.62, 공기량 +18%). 위험 크기에 따라 올리는 양을 바꾼 비례 차단(e05) 만 BSM1 에서 일관되게 나았다.

이 실험은 "얼마나" 올리느냐를 바꾼다. 대리 모델로 앞을 내다보고, 예측 NH4 를 기준 아래로 유지하는 데 필요한 가장 작은 공기량만큼만 올린다. 같은 수질을 더 적은 공기량으로 지키는지 본다.

## 데이터, 환경, 정책

Park/e08 과 같다 (Kaggle DARROW, Lee 방법의 단조 제약 GBM 대리 모델 구성원 5개, 검증 40일 x 구성원 5개 = 200 에피소드, 결정적 행동). 정책은 **e08 에서 학습한 FCSRL + PPO-Lag 정책 5개(seed 0 ~ 4) 를 다시 학습하지 않고 그대로** 쓴다. test 는 쓰지 않는다.

## 차단 (`Park/code/min_brake.py`)

실행 공기량 = max(정책 공기량, 필요 공기량). 필요 공기량은 0 ~ 9,000 을 250 간격으로 나눈 후보 중 "앞으로 horizon 스텝 동안 예측 NH4 최댓값 <= target" 을 만족하는 가장 작은 값이다 (없으면 9,000).

- 예측에는 관측한 현재 상태, 그 시각의 외부 입력과 구간 배분, 직전 구간 공기량을 쓴다. 미래 외부 입력은 현재 값이 이어진다고 둔다
- **모델 오차를 흉내 내기 위해, 환경이 그 에피소드에 쓰는 구성원을 빼고 나머지 4개 구성원 예측의 평균으로 계산한다.** 환경과 같은 구성원을 쓰는 정답 모델 판은 참고로만 보고한다
- horizon 1 (15분) 에서는 단조 제약 덕분에 조건이 공기량에 대해 단조다. horizon 4 (1시간) 은 DO 를 거치므로 단조가 보장되지 않는다

| 조건 | 설정 (곡선) |
| --- | --- |
| 최소 개입 1스텝 (다른 구성원) | target 2.0, 2.5, 3.0, 3.5, 4.0 |
| 최소 개입 4스텝 (다른 구성원) | target 2.0, 2.5, 3.0, 3.5, 4.0 |
| 최소 개입 1스텝 (정답 모델, 참고) | target 2.0, 2.5, 3.0, 3.5, 4.0 |

비교 기준은 같은 정책의 e08 결과 파일(차단 없음과 NH4 규칙 theta 2.0 ~ 4.0) 이다. 평가가 결정적이므로 차단 없음은 다시 돌려 e08 값과 같은지 확인한다.

## 가설 (사전 등록)

정책 seed 5개 중 3개 이상에서 성립하고 seed 평균도 성립하면 지지로 적는다. 비교 점이 없는 seed 는 성립하지 않은 것으로 센다.

- H1 (주 가설). 최소 개입 1스텝 (다른 구성원) 곡선의 같은 공기량 차이가 같은 seed 의 e08 기준 곡선 대비 음수다. e08 기준 곡선은 그 seed 의 차단 없음과 NH4 규칙 theta 5점, 모두 6점을 공기량 순으로 이은 것이고, 차이는 각 점의 하루 비용에서 같은 공기량의 기준 곡선 비용(선형 보간) 을 뺀 값의 평균이다
- H2. 최소 개입 4스텝 (다른 구성원) 곡선에서 H1 과 같은 비교가 음수다
- H3. 같은 수질에서의 공기량 절감. 그 seed 의 e08 NH4 규칙 theta 3.0 하루 비용을 최소 개입 1스텝 (다른 구성원) 곡선에서 내는 데 필요한 공기량(곡선을 비용 순으로 이은 선형 보간) 이 theta 3.0 공기량보다 10% 이상 적다. 곡선 비용 범위 밖이면 성립하지 않은 것으로 센다. 평균은 감소율의 평균이 10% 이상인지 본다

정답 모델 판은 판정하지 않는다. 가설이 기각되는 결과도 그대로 기록한다.

## 전체 평가 전에 본 값

설계 점검(속도 측정과 동작 확인) 중 seed 0 정책에서 target 3.5 한 점을 봤다. 1스텝: 공기량 88,543, 하루 비용 5.75. 4스텝: 88,466, 5.53. 정답 모델 1스텝에서 다음 스텝 NH4 가 target 을 넘은 비율은 0% 였다 (차단이 뜻대로 동작함). 이 점을 본 뒤 가설과 설정은 바꾸지 않았다.

## 미리 밝히는 한계

- 대리 모델의 예측 정확도가 낮다 (NH4 한 스텝 R2 0.24). 차단에 쓰는 모델과 환경 모델이 같은 방법, 같은 자료로 만든 구성원이라서, 다른 구성원을 써도 실제 처리장의 모델 오차보다 작을 수 있다
- 차단은 그 시각의 외부 입력(유입 성분 포함) 을 안다고 둔다. 관측 11개에 없는 유입 성분 4개도 쓴다
- 앞을 내다보는 방법이라 계산이 많다 (4스텝은 평가 한 번에 약 9분)
- seed 5개, 검증 구간만, 탐색적 실험이다

### 사전 등록 가설 판정

- H1 지지. 1스텝 (다른 구성원) 의 같은 공기량 차이는 평균 -0.33, 음수 seed 4/5 (seed 별 -0.83 ~ +0.88). 비교 점은 seed 마다 2 ~ 4개다.
- H2 지지. 4스텝 (다른 구성원) 은 평균 -2.11, 5/5. seed 2 의 -7.32 를 빼도 4개 seed 가 -0.57 ~ -1.02 다.
- H3 지지 안 됨. e08 theta 3.0 의 비용을 내는 데 필요한 공기량 감소율은 계산된 seed 2개에서 2.2%, 0.1% 였고, 나머지 3개 seed 는 범위 밖이었다. 범위 밖인 이유는 최소 개입 곡선의 가장 느슨한 점(target 4.0) 의 비용조차 theta 3.0 보다 낮았기 때문이다 (seed 1, 3, 4). 판정 규칙대로 성립하지 않은 것으로 센다.

### 사후 관찰 (판정에 쓰지 않음)

- target 3.5 를 e08 theta 3.0 과 seed 별로 대면, 하루 비용은 5개 seed 모두 낮고(평균 6.62 에서 5.46, 17.5% 감소) 공기량은 3개 seed 에서 적다 (평균 -0.6%).
- 최소 개입 곡선은 비용이 약 5.1 ~ 5.5 에서 평평하다. NH4 규칙은 공기를 96,631 까지 늘려도 6.04 에 머문다. 같은 공기를 더 필요한 순간에 쓰기 때문에 도달할 수 있는 비용의 바닥이 낮아졌다.
- 환경과 다른 구성원으로 계산한 결과가 정답 모델 판과 거의 같았다. 이 대리 모델 구성원끼리의 차이 정도에서는 차단이 무너지지 않는다.
- DO 위반은 약 0.5 %p 늘었다. 차단은 NH4 만 보고 DO 상한(2) 은 고려하지 않는다.

### 해석

- 차단이 "얼마나" 올리는지를 필요한 만큼으로 바꾸자, 처음으로 신호를 바꾼 실험들(e01 ~ e06, e08 의 예측기와 비례) 보다 일관된 개선이 나왔다. 같은 공기량에서 비용이 낮다 (H1, H2).
- 개선은 "공기를 아끼는" 쪽보다 "같은 공기로 수질을 더 지키는" 쪽으로 나타났다. 공기량을 크게 줄이려면 정책 자체가 덜 쓰도록 바뀌어야 한다 (e09 와 결합 후보).

### 한계

- 차단 모델과 환경 모델이 같은 방법, 같은 자료의 구성원이다. 실제 처리장의 모델 오차는 더 클 수 있다.
- 차단은 그 시각의 유입 성분을 안다고 둔다.
- 같은 공기량 비교 점이 seed 마다 2 ~ 4개로 적다. 검증 구간만 봤다.
