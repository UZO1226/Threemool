# Park/e23: 새 seed 로 e22 앙상블 재현 (Kaggle DARROW)

상태: **완료 (2026-11-13). H1, H2 지지 안 됨.** 새 seed 5 ~ 8 앙상블은 공기량 82,886, 비용 4.75 로 새 seed 정책 하나의 평균 (84,746, 4.96) 보다 둘 다 낮았지만 seed 별로는 2/5 였고, e19 H1 (seed 0 ~ 4) 평균보다 공기량이 많았다. seed 0 ~ 4 가 공기량이 적은 쪽으로 치우친 묶음이었다. 평균 기준의 앙상블 효과 (공기량 약 2%, 비용 약 3% 감소) 는 재현됐다. 가설과 판정 규칙은 결과를 보기 전에 정했고 (사전 등록 커밋 `a6f86b5`) 결과를 본 뒤 바꾸지 않았다.

## 목적

목표는 공기량과 하루 비용을 함께 낮추는 것이다. Park/e22 의 4 x 16 앙상블 (seed 0 ~ 3) 은 e19 H1 보다 둘 다 낮았지만, seed 0 ~ 4 의 다른 4개 조합에서는 판정이 0 ~ 2/5 였다. 또 e19 H1 기준 정책 (seed 0 ~ 4) 과 앙상블 구성원이 같은 seed 라서 서로 독립이 아니다. 이번에는 한 번도 쓰지 않은 seed 5 ~ 9 로 같은 방법을 처음부터 다시 해서, e22 결과가 seed 운인지 본다.

## 방법 (새로 고르는 설정 없음)

- 기준: seed 5 ~ 9 를 e12 A 설정 (학습 중 차단 target 3.5, 업데이트 66번) 으로 학습한 정책 하나씩 + e19 H1 차단
- 앙상블: seed 5 ~ 8 을 같은 설정으로 업데이트 16번씩 학습해 행동 평균 + e19 H1 차단 (e22 H1 과 같은 방법, 구성원은 새 seed 중 앞 4개)
- seed 9 의 업데이트 16번 정책은 참고 조합에만 쓴다
- 앙상블 합계 업데이트 64번으로 정책 하나 (66번) 보다 학습 예산이 작다

## 조건과 평가

검증 40일 x 구성원 5개 = 200 에피소드를 결정적으로 돈다. test 는 쓰지 않는다. 학습 구간에서 고르는 단계는 없다.

## 가설 (사전 등록)

- H1 (주 가설). 앙상블 (seed 5 ~ 8) 이 새 seed 5 ~ 9 정책 하나 + e19 차단 중 3개 이상보다 공기량과 하루 비용이 둘 다 낮고, 그 평균보다도 둘 다 낮다
- H2. 앙상블 (seed 5 ~ 8) 이 e19 H1 (seed 0 ~ 4) 평균 (80,748, 4.98) 보다 공기량과 하루 비용이 둘 다 낮다

새 seed 4개 조합 5개는 보고만 한다. 가설이 기각되는 결과도 그대로 기록한다.

## 해석

- 새 seed 정책 하나의 공기량은 81,080 ~ 90,671 로 seed 0 ~ 4 (79,258 ~ 82,546) 보다 훨씬 넓게 퍼졌다. seed 0 ~ 4 는 공기량이 적은 쪽으로 치우친 묶음이었다. e12 ~ e22 의 공기량 숫자는 이 치우침을 안고 있다.
- 같은 seed 묶음 안에서 비교하면 앙상블 효과는 두 묶음 모두 같은 방향이다. seed 0 ~ 4: 조합 평균 80,076, 4.79 대 정책 하나 평균 80,748, 4.98. seed 5 ~ 9: 82,675, 4.80 대 84,746, 4.96. 공기량 약 1 ~ 2%, 비용 약 3 ~ 4% 감소다.
- 앙상블은 비용과 그 편차를 꾸준히 줄인다 (새 seed 에서 비용 표준편차 0.27 에서 조합 사이 0.07, 공기량 표준편차 3,564 에서 980). 하지만 seed 사이 차이가 효과보다 커서, 정책 하나 5개와 하나씩 비교하는 판정은 통과하지 못했다.
- 10개 seed 를 합치면 정책 하나 + e19 차단 평균은 공기량 82,747, 비용 4.97 이고, 4 x 16 앙상블 조합 10개 평균은 81,376, 4.80 이다.
- 다음 실험은 seed 10개를 기준으로 판정해 seed 운을 줄인다.
