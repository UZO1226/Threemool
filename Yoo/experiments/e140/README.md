# e140 위험 선택 단독과 Actor 보정 결합의 기간 이동

**앞 기간에서 배율을 정하면, 세 비교 모두 같은 수질 상한을 지키면서 공기를 절약한 시드가 0/5였다.** e139에서 학습한 정책, 공정 모델과 위험 예측기를 고정하고, 배율 선택에 쓴 40일보다 더 뒤로 이동했다. 결합 정책을 개발 기간에서 운전점으로 선택할 수 있었던 시드부터 108일 학습은 3개, 148일 학습은 2개에 그쳤다. 위험 선택 단독의 선택 배율은 모든 시드에서 1이었다. [설계와 근거](REFERENCES_AND_DESIGN.md)

양쪽에 같은 5개 배율을 허용했다. 수질 상한은 같은 시드 위험 선택 단독 원배율의 NH4 위반 분, 초과 적분, DO 위반 분이다. 공기 차이는 결합 빼기 위험 선택 단독이다. 배율을 고를 수 없거나 이후 기간 상한을 넘으면 전체 5개 시드의 성공 수에서 제외했다. 마지막 열은 이후 기간 결과를 알고 고른 기술적 비교다. 해당 기간의 최소 공기를 외삽하지 않았다. 두 겨울 비교는 같은 날짜를 공유한다. ## 미사용 DARROW 자료

제공된 6개 파일을 열어 확인했다. 2022년 3~6월 온라인 평가 파일에는 시간, 유입량, 수온, 구역별 공기량만 있다. 실험실 파일은 유입수 시트 하나이고 동적 유입 파일의 질소 변수도 유입수 성분이다. 반응조 NH4, NO3와 DO 3개가 없어 실측 초기화와 수질 비교를 수행할 수 없다. 15분 기록 96행이 모두 있는 88일의 기록 공기는 팀의 95전이 기준 평균 91,334 Nm³/일이었다. 3월 27일의 90분 공백과 양 끝 불완전 날짜는 이 평균에서 제외했다. 다른 기간 또는 처리장에 대한 독립 검증은 미완료다. [파일별 열, 해시와 입력 범위](data_inventory.json), [대회 원자료](https://www.kaggle.com/competitions/dynamic-modeling-of-wastewater-treatment-process/data)
