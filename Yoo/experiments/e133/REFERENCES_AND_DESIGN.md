# e133 e50 Actor 보정의 새 시드와 추가 PPO 대조

e50은 공기와 비용의 집단 평균이 줄었지만 e111에서 같은 시드의 공동 개선은 1/5였다. 표현 갱신 직후 정책 출력을 보존하는 방식의 이득과, 같은 rollout에서 Actor를 더 최적화한 이득을 구분한다. Lee와 Park README, RESULT와 열린 PR을 확인했다. e29는 Avedore, e30은 다른 DARROW 전이 모델, e113과 e127은 학습 날짜가 다르다. e50 실행 기록은 시드 0~4다. 이들을 새 시드 쌍에 섞지 않는다.

| 설계 결정 | 논문 및 구현 근거 | 적용과 점검 |
| --- | --- | --- |
| 표현 학습과 EMA는 유지 | [원 논문](https://arxiv.org/abs/2405.11718), [공식 구현 d882b91](https://github.com/czp16/FCSRL/tree/d882b91054d52c7a63a18a21f7db67bbbed82b63). [e29 기존 근거](../e29/README.md), [e50 기본 조건](../e50/README.md) | 고정 표현의 EMA 반영 뒤에만 추가 최적화한다. 기본과 Actor 보정은 e50의 기존 학습 코드를 호출한다. |
| 추가 표본 재사용 대조 | Cobbe 등 PPG 알고리즘 1과 3.2절은 정책 출력 보존과 정책 표본 재사용을 구분한다. 저자 구현은 보조 단계에서 저장한 분포와 현재 분포의 KL을 계산한다. [논문](https://proceedings.mlr.press/v139/cobbe21a/cobbe21a.pdf), [ppg.py 7295473](https://github.com/openai/phasic-policy-gradient/blob/7295473f0185c82f9eb9c1e17a373135edd8aacc/phasic_policy_gradient/ppg.py) | PPG 전체를 재현하지 않는다. e29 AblatedFCSRL에서 추가 PPO의 활성 모듈을 Actor로 제한한다. e50 Actor 보정과 같은 입력 분할(2,048 적합, 1,024 점검), Actor 학습률, Adam, 최대 50회, 표현 및 두 가치망 동결이다. Actor 보정은 보존 오차로 후보를 선택하고 PPO는 e29의 KL 한도 내 마지막 후보를 선택한다. 목표와 수락 방식까지 포함한 비교다. 실제 시도 수, 수락 횟수, CPU 시간도 기록한다. FLOP이나 경과 시간이 엄밀히 동일하다는 가정은 두지 않는다. |
| 시드별 공정 비교 | [e111의 짝비교](../e111/README.md), [e59의 초과 강도](../e59/results.md) | e50 학습 188일, 개발 겨울 40일, 모델 5개를 유지한다. 기본 FCSRL, Actor 보정, Actor만 추가 PPO 각각 시드 10~14로 401,280전이(66갱신). 같은 시드는 같은 초기 정책, 날짜 추출 난수 및 구성원 순서를 쓴다. CPU와 원 입력 지문을 맞추고 e113의 수치 동등 GBM 가속을 검산한다. 시험 41일은 사용하지 않는다. |

주 판정은 보정 빼기 각 대조의 같은 시드 차이다. 공기 부피가 감소하고 NH4 위반 시간, NH4 초과 적분과 최대 DO 위반 시간이 모두 비증가할 때 공동 개선이다(부동소수점 오차 허용 1e−8, 공기 0.05 m³ 초과 절감). 두 대조 각각 평균 기준을 만족하고 같은 5개 시드 중 적어도 4개가 두 대조를 모두 통과해야 재현 후보로 둔다. 보조로 e50의 원 기준(기본 대비 비용 감소 4/5, 평균 비용 감소, 공기 증가 2% 이하)과 비용 한도 12 만족 시드 수를 보고한다. 시드 0~4의 기존 결과는 문맥으로만 제시한다. 개발 겨울을 반복 사용하므로 새 계절이나 현장 성능 검증으로 해석하지 않는다.

학습 입력 해시, 열한 개 관측과 비용, 원 추론기와 95개 전이의 일치, 초기 갱신의 기존 e50 로그 및 두 추가 대조의 표본 수와 Critic 불변을 검산한다. 마지막 정책을 원 sklearn으로 다시 평가해 200개 에피소드의 집계와 학습기 최종 지표를 대조한다. 에피소드나 모델 구성원을 독립 시드처럼 세지 않는다.
