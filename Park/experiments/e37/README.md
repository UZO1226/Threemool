# Park/e37: 같은 학습 설정과 같은 차단에서 PPO-Lag 와 FCSRL 비교 (Kaggle DARROW)

상태: **완료 (2026-11-19). H1 기각 (2/5): 같은 학습 설정에서 FCSRL 과 PPO-Lag 는 공기량이 거의 같고 (-213), FCSRL 이 비용이 0.244 낮다 (참고, 판정 없음).** 대표는 바꾸지 않는다. 가설과 판정 규칙은 학습과 검증 결과를 보기 전에 정했다 (커밋 `75ff494`). 고를 설정은 없다.

## 목적

Park/e36 에서 같은 대표 차단을 붙여도 기본 FCSRL (66번 갱신, 학습 중 차단 없음) 은 기본 PPO-Lag 보다 공기량은 적고 비용은 높아, FCSRL 표현이 낫다는 근거가 없었다. 대표의 이득은 학습 설정 (학습 중 차단, 짧은 학습, 앙상블) 에서 나왔다. 그렇다면 PPO-Lag 를 대표와 똑같은 설정으로 학습했을 때도 같은 이득이 나는지가 남은 질문이다. 학습 설정, 학습 예산, 앙상블 방식, 평가 차단이 모두 같고 다른 것은 FCSRL 표현 학습 하나뿐이다 (팀 검토 7.2 절의 "같은 보정의 정책 차이").

## 방법

PPO-Lag 를 seed 0 ~ 19 각각 대표와 같은 명령으로 학습한다 (`train_darrow.py --method ppo --min-brake-target 3.5 --updates 16`, 정책망과 PPO 설정은 FCSRL 과 같음, 389,120 전이 x 4 = 앙상블 하나당 대표와 같은 예산). 구성원이 겹치지 않는 4 x 16 앙상블 묶음 5개 (seed 0 ~ 3, 4 ~ 7, 8 ~ 11, 12 ~ 15, 16 ~ 19) 에 대표 차단 (e19 차단 + e28 원판 회복 계획) 을 붙여 검증 구간에서 평가한다. FCSRL 쪽은 같은 묶음의 Park/e35 orig 값 (대표 방법 그대로) 을 쓴다.

재현 검사: 학습 코드와 가상환경이 대표 학습 때와 같은지 보려고 FCSRL seed 0 을 같은 명령으로 다시 학습해, 학습 끝 평가 값이 `dw_u16_runs/A_s0` 기록과 같은지 확인한다.

## 평가

검증 40일 x 구성원 5개 = 200 에피소드, 결정적. test 는 쓰지 않는다.

## 가설 (사전 등록)

- H1 (주 가설). 같은 학습 설정과 같은 차단에서 FCSRL (대표) 이 같은 묶음의 PPO-Lag 보다 공기량과 하루 비용이 둘 다 낮은 묶음이 5개 중 4개 이상이고, 묶음 5개 평균도 둘 다 낮다

참고 (판정 없음): 반대 방향 (PPO-Lag 가 둘 다 낮은 묶음 수), 짝 차이 평균과 95% 신뢰구간, NH4 위반률과 DO 위반률 차이.

## RESULT.md 처리 (미리 정함)

대표 방법은 이 실험으로 바꾸지 않는다.

- H1 지지: "같은 학습 설정과 같은 차단에서 FCSRL 표현이 PPO-Lag 보다 공기량과 비용을 함께 낮춘다" 고 적는다 (FCSRL 기여의 첫 근거)
- H1 기각이고 PPO-Lag 가 4/5 이상 둘 다 낮고 평균도 낮으면: "같은 설정에서는 PPO-Lag 가 낫다" 고 적고, 대표를 PPO-Lag 판으로 바꿀지는 팀과 정한다 (Park 혼자 정하지 않음)
- 그 밖: "같은 설정에서 FCSRL 과 PPO-Lag 의 차이는 판정 기준을 넘지 않는다" 고 적는다

## 미리 밝히는 한계

- 묶음 5개는 판정 표본이 작다 (4/5 기준)
- 학습 설정 (갱신 16번, 학습 중 차단 target 3.5) 은 FCSRL 로 골랐다 (Park/e12, e20 ~ e22). PPO-Lag 에 더 맞는 설정이 있을 수 있다. 이 실험은 FCSRL 에 맞춘 설정에서의 비교다
- 검증 구간은 e10 부터 반복해서 썼다
- e10 ~ e36 과 같은 대리 모델 한계

- **H1 기각 (2/5).** 평균은 둘 다 FCSRL 이 낮지만 둘 다 낮은 묶음이 2개뿐이다. 반대 방향 (PPO-Lag 가 둘 다 낮음) 은 0/5 다
- 참고 공기량 짝 차이 평균 -213 (95% 신뢰구간 -3,227 ~ +2,802): 차이가 없다고 봐야 한다
- 참고 비용 짝 차이 평균 -0.244 (95% 신뢰구간 -0.479 ~ -0.009): FCSRL 이 5묶음 중 4개에서 낮고 1개에서 같다. 차이는 주로 DO 위반 (-0.22 %p) 에서 온다
- 참고 차단 개입: 같은 설정의 PPO-Lag 는 스텝의 60% 에서 차단이 행동을 바꾼다 (FCSRL 24%)

## 해석

- 사전 등록 처리에 따라 "같은 설정에서 FCSRL 과 PPO-Lag 의 차이는 판정 기준 (공기량과 비용 둘 다, 4/5) 을 넘지 않는다" 고 적는다
- 다만 e36 (기본 학습 설정) 과 그림이 다르다. e36 에서는 FCSRL 이 공기를 덜 쓰고 비용을 더 냈는데 (맞바꿈 위의 다른 점), 같은 학습 설정 (학습 중 차단, 16번 갱신, 4 x 16 앙상블) 에서는 공기량이 같아지고 비용은 FCSRL 이 낮다. 판정 대상은 아니지만, "같은 공기량에서 비용을 낮추는" 대표의 이득 일부가 FCSRL 표현에서 온다는 약한 근거다 (묶음 5개, 신뢰구간 위 끝이 0 에 가깝다)
- 학습 중 차단은 PPO-Lag 의 운전점도 공기를 덜 쓰는 쪽으로 옮긴다 (e36 기본 PPO-Lag 앙상블 103,716 에서 82,317). 공기량 감소의 대부분은 학습 설정과 차단의 몫이다
- PPO-Lag 는 차단 개입이 60% 로 높다. 학습 중 차단에 기대는 정책이 되어, 행동 대부분을 차단이 고친다는 뜻이다. FCSRL 정책은 차단이 받아들이는 행동을 더 자주 낸다
- 학습 설정은 FCSRL 로 골랐으므로 (한계 참고) PPO-Lag 에 맞춘 설정에서는 결과가 다를 수 있다
