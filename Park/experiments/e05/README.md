# Park/e05: 위험에 비례해 미리 폭기를 올리는 차단

상태: **완료 (2026-11-09). H1, H2, H3 모두 지지. 주 가설 H1 의 효과는 작다 (평균 -0.76 %p).** 규칙은 실행 전에 정했고 결과를 본 뒤 바꾸지 않았다.

## 목적

Park/e04 에서 더 정확한 예측기로 차단해도 같은 에너지에서 위반은 1 ~ 2 %p 만 더 줄었다. 원인 후보는 차단이 "위험하면 최대 폭기, 아니면 그대로" 의 켜고 끄기라서, 미리 안 정보를 쓰는 방식이 거칠다는 것이다. 이 실험은 위험 확률이 오를수록 폭기 하한을 조금씩 올리는 방식이 같은 에너지에서 위반을 더 줄이는지 확인한다. 함께, e04 의 약점(비교 곡선의 에너지 폭이 좁음) 을 설정 폭을 넓혀 다시 확인한다.

## 바꾸는 것 한 가지

차단 행동. 예측기와 정책, 환경, 평가는 Park/e04 와 같다.

| 차단 | 규칙 |
| --- | --- |
| 켜고 끄기 (e04) | p >= 기준이면 KLa5 = 240, 아니면 정책 행동 |
| 비례 하한 (이번 확장) | KLa5 = max(정책 KLa5, 240 x min(1, p / c)). 하한이 정책 행동보다 클 때를 개입으로 센다 |

p 는 관측 전체 로지스틱 회귀가 낸 1시간 안 위반 확률이다 (e04 와 같은 입력, 정답, 맞춤 방법. 정책마다 학습 날짜 궤적으로 맞춘다).

## 설정

| 곡선 | 설정 |
| --- | --- |
| 비례 하한 | c = 0.1, 0.25, 0.5, 1.0, 2.0 |
| 켜고 끄기 | 기준 확률 0.02, 0.05, 0.1, 0.2, 0.3, 0.5, 0.7, 0.9, 0.97 |
| NH4 규칙 | theta = 2.0, 2.5, 3.0, 3.5, 4.0, 4.5, 5.0 |

## 비교

- 정책: Park/e02 의 9개 (gamma_F 0.9, 0.97, 0.99 x seed 0, 1, 2). 표현 할인율만 다를 뿐 모두 같은 방식으로 학습한 FCSRL + PPO-Lag 정책이므로, 이번에는 9개 모두를 판정에 쓴다
- 평가: 건기 14일 연속 운전, 후반 7일 (e02 와 같음)
- 같은 에너지 차이: 한 곡선의 각 점에서, 비교 곡선의 점을 에너지 순으로 이은 선형 보간 위반 % 를 뺀다. 비교 곡선 에너지 범위 밖의 점은 뺀다. 정책마다 평균을 낸다. 음수면 앞 곡선이 같은 에너지로 위반을 더 줄였다

## 가설 (사전 등록)

정책 9개 중 6개 이상에서 성립하고 9개 평균도 성립하면 지지로 적는다. 비교 점이 없는 정책은 성립하지 않은 것으로 센다.

- H1 (주 가설). 비례 하한 곡선의 같은 에너지 차이가 켜고 끄기 곡선 대비 음수다
- H2. 비례 하한 곡선의 같은 에너지 차이가 NH4 규칙 곡선 대비 음수다
- H3 (e04 재확인). 켜고 끄기 곡선의 같은 에너지 차이가 NH4 규칙 곡선 대비 음수다

가설이 기각되는 결과도 그대로 기록한다.

## 미리 밝히는 한계

- 예측기는 차단 없는 궤적으로 맞췄다. 차단이 상태 분포를 바꾼다
- 비례 하한의 모양(직선, 상한 240) 은 하나만 본다
- 9개 정책은 seed 3개와 할인율 3개의 조합이라 서로 완전히 독립은 아니다
- 건기, 10 갱신 정책의 탐색적 실험이다

## 실행 명령

```bash
cd Park/experiments/e05
export BSM1_ARCHIVE=<BSM1.zip> WANDB_MODE=disabled OMP_NUM_THREADS=1
for g in 0.9 0.97 0.99; do for s in 0 1 2; do
  python run_e05.py one --gamma $g --seed $s --prepared <결과>/prepared --runs <결과>/runs --out <결과>/e05
done; done
python run_e05.py report --out <결과>/e05 --md results.md
```

정책과 환경은 Park/e02 와 같다. 새 학습은 없다. `Park/code/shield.py` 에 `GradedShield` 를 추가했다. 실행 도중 Mac 이 잠자기에 들어가 약 3시간 멈췄다가 이어서 끝났다. 평가는 결정적이라 결과에는 영향이 없다.

### 해석

- H1: 비례 하한은 9개 정책 모두에서 켜고 끄기보다 같은 에너지로 위반이 적었다. 방향은 일관되지만 크기는 작다 (중앙값 -0.28 %p). 9개 중 5개는 0.3 %p 미만이다. "조금씩 미리 올리기" 가 "최대 폭기" 보다 낫지만 큰 차이는 아니다.
- H2, H3: 위반 예측기로 거는 차단은 NH4 측정값 규칙보다 같은 에너지에서 위반이 약 2 %p 적다 (중앙값). e04 의 약한 결과가 비교 폭을 넓힌 뒤 9개 정책에서 재확인됐다. 평균은 gamma_F 0.97 seed 1 (약 -11 %p) 에 끌려 중앙값보다 크다.
- e01 ~ e05 를 이으면, 순간 위반을 줄이는 데 가장 큰 효과는 "차단을 건다" 는 것 자체이고 (약 45% 에서 20% 대), 차단 신호와 방식을 고치는 효과는 같은 에너지에서 1 ~ 3 %p 수준이다.

### 한계

- c = 2.0 은 하한이 낮아 거의 효과가 없었다 (위반 40.63%). 비례 곡선의 비교 점 4개는 c = 0.1 ~ 1.0 이다.
- 9개 정책은 seed 3개와 할인율 3개 조합이라 완전히 독립이 아니다. seed 1 정책들이 큰 값을 냈다.
- 예측기는 차단 없는 궤적으로 맞췄다. 건기만, 10 갱신 정책의 탐색적 실험이다.
