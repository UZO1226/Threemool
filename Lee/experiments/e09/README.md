# Lee/e09: 실현 가능성 점수를 이용한 이점 벌점 (DARROW 환경)

## 목적

Lee/e08 에서 승수 반응을 높이면 비용은 줄지만 공기량이 함께 늘어(+19.8%) 개선이 아닌 교환이었다. 이번에는 승수 대신
FCSRL 이 이미 학습하는 실현 가능성 점수 F(z)를 정책 갱신에 직접 쓴다. 다음 상태의 F 가 높은(위반에 가까운) 행동의 이점에서
`가중치 x (이점의 rms) x 표준화한 F` 를 뺀다 (`relative` 방식, Lee/e06 에서 쓴 구현). 변경은 이 벌점 하나이고 나머지는
Lee/e07(원래 FCSRL)과 같다. Avedøre(Lee/e06)에서는 가중치 1.0 에서 붕괴했고 0.1, 0.3 은 원래와 차이가 없었다. 이 데이터에서
다시 시험한다.

## 구성

| 항목 | Lee/e07 (원래) | Lee/e09 |
| --- | --- | --- |
| 이점 벌점 가중치 | 없음 | 0.1 과 0.3 |
| 방법 | FCSRL + PPO-Lag | FCSRL + PPO-Lag + 벌점 (`ppolag_fcsrl_fpen`) |
| seed | 0 에서 4 | 0 에서 4 (원래와 짝) |

새 실행은 2 가중치 x 5 seed = 10개. 가중치 0.1, 0.3 은 결과를 보기 전에 정했고 바꾸지 않는다.

## 가설과 판정 기준 (결과를 보기 전에 정함)

- H24 (주). 마지막 모델의 하루 비용이 원래 FCSRL 보다 낮고 한도 만족 에피소드 비율이 높으며 공기량 증가는 5% 이내다.
  공기량이 5% 넘게 늘면 개선이 아니라 교환으로 적는다.
- H25. 선택 모델에서도 같은 방향이다.
- 차이가 seed 간 표준편차보다 작으면 개선이라 단정하지 않는다. p 값은 5개 seed 의 탐색적 Welch 검정이고 보정이 없다.
  결과가 반대여도 그대로 기록한다.
