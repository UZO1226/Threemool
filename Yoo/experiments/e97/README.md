# e97 첫 감량의 공기 절감 예측은 언제 어긋났는가

**e96이 고른 감량의 평균 6시간 절감 예측이 빗나간 구간은 3~6시간이었다.** 감량한 73건 중 첫 1시간에 기본 FCSRL보다 공기를 덜 쓴 건 71건이었다. 이 중 43건은 6시간까지 절감을 유지하지 못했다. 처음 1시간에 절감하지 못한 2건 중 1건은 이후에 절감해 최종 순절감은 29건이었다.

| e96이 선택한 감량의 시간대별 기여 | 감량 전 예상 | 모의 운전 결과 | 결과 빼기 예상 |
| --- | ---: | ---: | ---: |
| 0~1시간 | −32.95 | −42.95 | −10.00 |
| 1~3시간 | +48.88 | +33.93 | −14.95 |
| 3~6시간 | −60.62 | +83.81 | +144.43 |
| 6시간 합계 | −44.69 | +74.79 | +119.48 |

단위는 m³다. 원래 기본 운전 대비 감량 경로의 순공기 차이며 음수가 절감이다. e96의 +74.79 m³와 같은 분모로 비교하기 위해, 미감량 창을 0으로 두고 전체 1,185개 창에서 날짜와 seed를 동일 가중했다. 표의 +144.43 m³는 선택 사례의 평균 오차 기여다. 실제로 개입한 한 건당 수치나 전체 예측 오차의 인과적 기여율은 아니다.

## 감량 전에 구별할 수 있었나

감량 후보 495개에서 각 구간을 감량 직전 관측 11개로 직접 예측했다. 학습 날짜의 구간별 평균을 항상 예측하는 상수 기준과 비교한 제곱오차 감소율은 0~1시간 +1.85%(개선 3/5 seed), 1~3시간 −6.16%(1/5), 3~6시간 −6.37%(2/5)였다. 평균 및 4/5 seed에서 개선된 시간대는 없었다.

- 첫 시간의 절감 방향은 98.3% 맞혔고, 상수 기준도 98.6%였다. 첫 15분에는 직접 감량으로 125 m³가 줄어든다. 첫 시간의 높은 적중률 자체로 상태에 따른 선별 능력을 입증할 수 없다.
- 3~6시간의 방향 적중률은 회귀 53.0%, 상수 기준 56.1%였다. 선택된 정책의 낙관 오차는 특히 이 구간에 집중됐다. seed별 이 구간의 실제 빼기 예측 기여는 각각 +673.88, +34.33, +5.99, 0, +7.95 m³였다. 73건 중 58건이 seed 0에 몰려 평균 크기를 크게 좌우한다. seed 3은 감량 0건이었다.
- 거리 조건을 풀어 후보 595개를 보면 후기 방향 적중률은 53.5%(상수 56.6%)였다. 전체 1,433개 창에서 e96의 76회 선택은 3~6시간 −47.98 m³로 예측됐고 실제 모의 운전에서는 +66.65 m³였다.
- 후속 연구 질문은 **감량 경로에서 1시간 또는 3시간까지 관측한 공기 명령과 수질을 쓰면 남은 3~6시간 공기 차이를 더 잘 예측하는가**다. 같은 후기 표적과 같은 사례로 비교하고, 그때까지 관측할 수 없는 기본 경로의 반사실 상태는 입력에서 제외해야 한다. 예측이 좋아져도 어떤 후속 행동으로 수질을 지키며 절감할 수 있는지는 별도 제어 평가가 필요하다.

## 재현 범위

Kaggle DARROW e50 대리 환경과 e58 기본 FCSRL seed 0~4, e96과 같은 앞 140일 4,253개 비중복 최초 후보, 뒤 48개 학습일의 동일한 평가 창이다. 최초 15분간 500 m³/h 감량 또는 기존 명령을 준 뒤 각 경로는 자기 관측으로 기본 정책을 실행했다. 4, 12, 24스텝의 누적 공기량 차이에서 인접 시점 차분을 구했다. 초기에 측정한 공정 관측 11개로 날짜 가중 표준화 및 Ridge(alpha=1)를 적합했다. 선형 회귀는 동일한 학습 설계에서 표적에 대해 선형이므로 구간별 예측을 합하면 e96의 총량 예측과 같다. 이 실험의 목적은 시간대 진단이며 수질 및 정책 성능은 e96과 같다.

사전 설계 6280522, 실행 코드 1006c3e. Python 3.11, scikit-learn, CPU 단일 스레드, 정책 학습 0스텝. 입력 해시, 창 키와 명령, 학습의 두 경로 6시간 누계, 뒤 날짜의 실제 및 예측 구간 합, e96과 선택 동일성을 확인했다. 저장한 창별 예측 및 경로 차이로 각 날짜의 오차, 방향 적중률, 선택 기여를 별도 반복문으로 검산했다. 기존 정책과 환경이 본 날짜이므로 겨울 또는 실제 공정에서의 효과는 평가하지 않았다.
