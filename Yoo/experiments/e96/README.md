# e96 감량 전 관측으로 6시간 공기와 수질 차이를 각각 예측할 수 있는가

**지표별 선형 회귀로 고른 첫 감량은 공기와 수질의 트레이드오프를 개선하지 못했다.** e93이 제안한 495개 후보 중 예측상 공기를 아끼고 세 수질을 지키는 73개에서 감량했다. 같은 후보의 저장된 결과로 보면 66개에서 세 수질은 지켰고, 29개에서 공기가 줄었으며, 두 조건을 함께 만족한 구간은 24개였다. 같은 날짜에 같은 횟수로 무작위 감량하면 평균 28.69개가 두 조건을 만족한다.

기본 FCSRL 대비 변화다. 주 평가의 비중복 1,185개 창에서 미감량 창도 차이 0으로 포함해 날짜 내 평균 후 날짜와 seed에 동일 가중했다. 두 위반은 15분 스텝 수, NH4 초과 적분은 mg h/L다. 무작위 대조는 같은 날짜의 기존 495개 후보에만 기회를 준다. 무작위 기대 대비 공기를 8.92 m³ 더 썼다. 공동 개선의 기준은 공기 엄격 감소와 세 수질 모두 비악화가 5개 평균과 4/5 seed 이상에서 성립하는 것이다. 실제 선별기는 채택하지 않았다.

- **감량한 뒤의 6시간 순공기 방향을 자주 틀렸다.** 73개 모두 공기가 줄 것으로 예측했지만 실제 대리 경로에서는 29개(39.7%)만 줄었다. 수질 예측을 그대로 두고 공기만 정답으로 대체하면 평균 공기가 절감으로 바뀌었고, 수질만 정답으로 바꾸면 여전히 늘었다. 두 진단은 감량 수와 구간이 달라 오차 원인의 비율을 추정할 수 없다. 공기만 정답인 경우도 평균 DO가 악화되어 공동 채택 기준에 미달했다.
- **어느 지표도 평균적으로 상수 예측의 제곱오차를 줄이지 못했다.** 후보에서 선형 회귀의 6시간 공기 차이 RMSE는 1,602.41 m³, 학습 평균을 그대로 쓰면 1,566.90 m³였다. NH4 위반은 0.819 대 0.784스텝, DO 위반은 0.267 대 0.211스텝, NH4 초과 적분은 0.355 대 0.352 mg h/L였다. 이는 후보별 예측 오차로, 전체 창 평균 제어 효과와 분모가 다르다.
- **감량은 한 seed에 집중됐다.** seed 0에서 58번 감량했고 이 seed의 공기 차이는 +332.61 m³였다. seed 3에서는 0번이었다. 나머지 세 seed도 공기가 늘었다. 거리 조건을 풀어 1,433개 창에서 평가해도 76번 감량, 공기 +55.42 m³, 기본 대비 공동 개선 0/5였다.
- 다음 진단은 같은 초기 관측으로 첫 감량 후 0~1시간, 1~3시간, 3~6시간의 순공기 차이를 따로 예측해 어느 구간에서 방향을 놓치는지 확인하는 것이다. e90은 각 시간대의 실제 절감 추이를 측정했고 e96은 6시간 합계의 예측 오차를 측정했다. 시점별 예측 가능성은 아직 검증하지 않았다.

## 설계와 재현

Kaggle DARROW e50 대리 모델, e58 기본 정책 seed 0~4. 앞 140개 학습일에서 시작 시점이 겹치지 않는 4,253개 창의 B(첫 15분 500 m³/h 감량 후 기본 FCSRL)와 A(계속 기본 FCSRL)를 짝지었다. 각 경로는 자기 관측으로 이후 23회 명령을 낸다. 입력은 감량 직전 공정 관측 11개, 표적은 B와 A의 6시간 누계 차이 네 개다. 날짜 가중 표준화 후 seed별 Ridge(alpha=1, 절편 포함)를 적합했다. 평균 기준선은 해당 seed 학습 날짜의 가중 표적 평균이다. 예측 문턱은 공기 차이 음수, 세 수질 차이 각각 0 이하로 정했고 뒤 48일에 조정하지 않았다. 뒤 날짜는 기존 기본 정책과 환경에는 노출된 개발 자료다. 실제 에너지, 겨울 성과, 하루 연속 운전은 평가하지 않았다.

사전 설계 fd91f42, 실행 e1d62b5. Python 3.11, scikit-learn, CPU 단일 스레드, 정책 및 환경 갱신 0스텝. 자료 해시와 모드별 키, 기본 정책의 감량 전 명령, 단일 출력 회귀 네 개와 예측 동일성, 날짜별 독립 재집계, e93 기본 차이와 e95 최초 감량만의 사후 상한을 검산했다. 미래 측정 벡터를 예측해 행동을 결정하는 원리를 차용했으며 본 구현은 고정한 FCSRL의 감량 선택에 한정된다.
