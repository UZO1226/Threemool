## 질문

e59 는 차단 없이 학습한 Yoo 정책에 Park 의 최소 개입 차단을 실행 시점에만 걸었다. e60 은 Park/e12 A 와 같이 1스텝 target 3.5 차단을 학습 중에도 켠다. 정책은 차단이 지켜 주는 범위에서 공기를 줄이는 법을 배우고, 평가에서는 e19 차단(양방향, 여유 표, 회복 검사, 충돌 조정)과 결합한다. Park 의 같은 환경 대표(e19 H1 80,748 / 4.98, e22 H1 79,633 / 4.68)와 e59 의 정책 없는 모델 제어기를 넘는지 본다.

1. **J1 (Park e19 H1 대비).** PPO-Lag 평균은 공기 1.7% 적고 비용 0.17 낮아 두 평균 모두 Park 단일 정책 대표보다 낮다. 그러나 두 값이 모두 낮은 seed 는 3/5 라 사전 기준 (4/5) 미달이다. FCSRL 은 평균 비용만 낮고 공기는 많다 (1/5). Park 값은 seed 평균이라 짝 비교가 아니다.
2. **J2 (정책 기여).** 학습 중 차단을 쓴 PPO-Lag 는 정책 없는 모델 제어기 (80,003 / 5.41) 보다 공기와 비용이 모두 낮은 seed 가 4/5 로 사전 기준상 기여다. e59 의 차단 없이 학습한 정책은 0/5 였다. FCSRL 은 2/5 로 불확정이다.
3. **J3 (학습 중 차단의 효과).** 같은 seed 의 e59 대비 공기는 PPO 3,406, FCSRL 7,845 m³ 줄었지만 비용은 0.17, 0.28 늘었다. 늘어난 비용은 DO 다 (PPO 1.44 에서 1.56). 공기와 비용이 모두 줄어든 seed 는 각 1/5 다.
4. **J4 (의존).** 10개 모두 마지막 라그랑주 승수가 0 이다. 학습 중 하루 비용이 한도 12 보다 훨씬 낮기 때문이다 (학습 날짜 park_e10 평가 2.6). 차단을 떼면 검증 비용이 33 ~ 40 으로 크다. Park/e12 와 같은 현상이며, 이 정책은 차단과 한 묶음으로만 쓴다.
5. **J5.** NH4 는 모든 조건에서 바닥 (3.2, 최악 날짜 38.2) 이다. 남은 차이는 공기와 DO 의 교환이다.

정리하면 Yoo 파이프라인의 단일 PPO-Lag 정책 + 차단은 Park 단일 정책 대표와 비슷하거나 평균상 조금 나은 위치에 왔고, 처음으로 정책 없는 모델 제어기보다 공기와 비용을 함께 낮췄다. Park 앙상블 대표보다 공기는 적고 비용은 0.13 높다. 승수가 0 이라 학습 중 비용 신호가 정책에 전혀 전달되지 않는 상태이며, 남은 DO 위반을 정책이 줄일 이유가 없다. 다음 후보는 학습 중 비용 한도를 실제로 묶이는 수준으로 낮추거나 (Park/e12 B 의 한도 6 도 묶이지 않았다), 학습 중에도 DO 를 보는 park_e19 차단을 쓰는 것이다. 이번 실험에서는 실행하지 않았다.
