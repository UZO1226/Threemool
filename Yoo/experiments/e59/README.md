# e59: Park 모델 예측 차단을 Yoo 정책에 적용해 정책의 기여를 분리

**2026-11-13 18:25 KST 완료.** 새 학습은 없다. [결과 표](results.md), [요약](summary.json). [사전 조건](protocol.json), [검사 코드](check.py), [평가 코드](shield_eval.py), [실행](run.py), [집계](report.py).

## 왜 이 실험인가

Yoo e30~e58 의 정책 변형(출력 보정, 조건별 제약, NH4 여유 세 종류, prior 제거, 보조 손실)은 모두 e50 환경에서 공기량과 NH4 비용의 한 교환선 위를 움직였다. 같은 환경에서 그 선을 벗어난 결과는 Park 의 실행 시점 최소 개입 차단뿐이다 (Park/e19 H1 80,748 m³, 비용 4.98; Park/e22 H1 79,633, 4.68). 차단은 대리 모델을 실행 시점에 직접 써서 다음 스텝 NH4 를 여유 아래로 유지하는 가장 작은 공기량까지만 올린다.

이 실험은 Park 의 차단을 Yoo 파이프라인에 그대로 옮긴 뒤 두 가지를 묻는다.

1. 차단 아래에서 RL 정책이 무엇을 기여하는가. 공기 0 정책 + 차단은 정책 없이 모델만으로 움직이는 제어기다. 이 값보다 정책 + 차단이 공기량과 비용을 함께 낮추지 못하면, 이 차단 아래에서 정책은 기여가 없다.
2. Yoo 의 기존 정책(모방 prior, FCSRL, Actor 보정, severity)이 차단과 결합했을 때 어디에 놓이는가.

Park/e10 은 차단 없이 학습한 Park e08 FCSRL 정책에 실행 시점 차단을 걸어 90,747 / 5.46 을 얻었고, 차단과 함께 학습한 e12 A 는 84,031 / 5.51 이었다. 정책 없는 모델 제어기 값은 Park 기록에 없다. 이 값이 다음 단계를 가른다.

Park 행의 NH4, DO 비용은 Park 문서의 위반률 x 0.95 로 환산했다. 전체 표와 seed 별 값은 [results.md](results.md) 에 있다.

1. **차단을 걸면 모든 정책이 교환선 아래로 내려간다.** 같은 seed 에서 park_e19 는 합산 비용을 PPO 9.73, FCSRL 6.87 줄였고 공기량 변화는 -0.24 ~ +1.45% 다. 차단 없는 20개 정책의 직선 대비 NH4 잔차는 -4.5 ~ -9.0 이다.
2. **차단 아래에서 NH4 는 바닥에 붙는다.** 모든 조건의 NH4 비용이 3.1 ~ 3.4, 초과 적분 2.73 ~ 2.81, 최악 날짜 38.2 로 거의 같다. Park/e19 진단처럼 공기 9,000 으로도 막을 수 없는 날의 위반이다. 남은 차이는 공기량과 DO 다.
3. **정책의 기여는 DO 와 공기의 교환이다 (J1).** 정책 + park_e19 는 공기 0 + park_e19 보다 비용이 5/5 seed 모두 낮지만 (DO 2.04 에서 1.3 ~ 1.4), 공기는 FCSRL seed 하나만 낮다. 사전 규칙의 "공기와 비용 모두" 기준으로 PPO, Actor 보정, severity 는 기여 없음, FCSRL 은 불확정 (1/5) 이다.
4. **Park 대비 (J4, 우열 아님).** 차단 없이 학습한 Yoo PPO-Lag + park_e19 (82,766 / 4.64) 는 Park e19 H1 (80,748 / 4.98) 보다 비용이 0.34 낮고 공기가 2.5% 많다. Park e22 H1 (79,633 / 4.68) 보다 비용은 0.04 낮고 공기가 3.9% 많다. 공기와 비용을 모두 넘지는 못했다.
5. **다음 단계 규칙.** 공기 0 + park_e19 (80,003 / 5.41) 는 Park e22 H1 을 넘지 못하므로 사전 규칙대로 e60 (학습 중 차단) 으로 간다. Park/e12 에서 학습 중 차단은 같은 차단 아래 공기를 7.4% 줄였다.

차단 없이 학습한 정책은 차단이 대신 지켜 주는 NH4 를 위해 이미 공기를 쓰고 있다. 학습 중 차단은 정책이 그 몫을 차단에 넘기고 공기를 줄이도록 한다. 이것이 e60 의 기대이며 아직 결과는 없다.
