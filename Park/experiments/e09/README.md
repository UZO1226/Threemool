# Park/e09: 학습 중에도 NH4 규칙 차단을 켠 정책 (Kaggle DARROW)

상태: **완료 (2026-11-10). H1 지지 (theta 3.0 에서 공기량이 5개 seed 모두 줄었다), H2 지지 안 됨, H3 지지 (차단을 끄면 크게 나빠진다).** 규칙은 학습 결과를 보기 전에 정했고 결과를 본 뒤 바꾸지 않았다.

## 목적

Park/e08 에서 NH4 규칙 차단(NH4 측정값 >= 3.0 이면 공기량을 최소 5,800 Nm3/h 로) 을 학습이 끝난 정책에 실행 시점에만 걸었더니, 하루 비용은 13.66 에서 6.62 로 줄었지만 공기량이 18% 늘었다. 정책은 차단이 있다는 것을 모르고 학습됐다.

이 실험은 학습 중에도 같은 차단을 켠다. 정책 입장에서 차단은 환경의 일부가 되므로, NH4 가 높은 순간은 차단이 막아 주고 정책은 나머지 시간에 공기를 줄이도록 배울 수 있다. 실행 시점에만 차단을 건 경우보다 같은 공기량에서 비용이 낮아지는지(에너지와 수질 교환이 나아지는지) 를 본다.

## 데이터, 환경, 학습 설정

Park/e08 과 같다 (Kaggle DARROW, Lee 방법의 단조 제약 GBM 대리 모델, 학습 188일, 검증 40일, 한도 12, FCSRL + PPO-Lag, 환경 8개 x 760 스텝 x 66 갱신, seed 0 ~ 4). 다른 점은 `train_darrow.py --brake-theta 3.0` 하나다.

- 수집할 때 정책이 뽑은 행동을 [-1, 1] 로 자른 뒤 차단을 적용한 행동을 환경에 넣는다
- PPO 의 확률비는 정책이 뽑은 행동으로 계산한다 (차단은 환경의 일부)
- 보상, 비용, 라그랑주 승수 갱신, FCSRL 표현 학습(zsa 와 실현 가능성 목표) 은 실제로 넣은 행동과 그 결과를 쓴다
- `--brake-theta` 를 주지 않으면 e08 과 완전히 같다. 1 갱신 시험에서 하루 비용, KL, 실현 가능성 목표 평균이 e08 기록과 같았다

## 평가

검증 40일 x 구성원 5개 = 200 에피소드, 결정적 행동, 마지막 정책. test 는 쓰지 않는다.

- 이 실험의 정책(학습 중 차단, 아래 "학습 차단 정책") 을 차단 없이, 그리고 NH4 규칙 theta 2.0, 2.5, 3.0, 3.5, 4.0 차단으로 평가한다
- 비교 대상은 Park/e08 의 정책(학습 중 차단 없음, "e08 정책") 의 같은 평가값이다. e08 결과 파일을 다시 쓰고 다시 돌리지 않는다

## 가설 (사전 등록)

학습 차단 정책 seed 5개 중 3개 이상에서 성립하고 seed 평균도 성립하면 지지로 적는다. 비교 점이 없는 seed 는 성립하지 않은 것으로 센다.

- H1. theta 3.0 차단을 건 학습 차단 정책의 하루 공기량이 e08 정책 + theta 3.0 의 seed 평균(91,279 Nm3/일) 보다 낮다
- H2 (주 가설). 학습 차단 정책의 theta 곡선(5점) 의 같은 공기량 차이가 e08 기준 곡선 대비 음수다. e08 기준 곡선은 e08 정책의 차단 없음과 theta 5점, 모두 6점의 seed 평균(공기량, 하루 비용) 을 공기량 순으로 이은 것이다. 음수면 같은 공기량에서 학습 차단 정책의 비용이 낮다
- H3. 차단 없이 평가한 학습 차단 정책의 하루 비용이 e08 정책 차단 없음의 seed 평균(13.66) 보다 높다 (정책이 차단에 기대게 되는가. 성립하면 차단을 끄고 쓰면 안 된다는 뜻)

가설이 기각되는 결과도 그대로 기록한다.

## 미리 밝히는 한계

- e08 과 같은 대리 모델 한계 (예측 정확도 낮음, 방향만 단조 제약으로 보장)
- 학습 중 차단은 theta 3.0, 5,800 한 가지만 본다
- 학습 중 비용은 차단이 걸린 결과라서 라그랑주 승수가 e08 보다 작게 유지될 수 있다. 이것이 공기량을 줄이는 경로라고 예상하지만, 원인을 따로 떼어 시험하지는 않는다
- seed 5개, 401,280 전이, 마지막 정책의 탐색적 실험이다

## 실행 결과

전체 표는 [results.md](results.md). 검증 200 에피소드, 마지막 정책, seed 5개 평균.

### 학습 중 상태

학습 중 차단이 걸린 하루 비용은 마지막 갱신에서 3.70 ~ 5.86 으로 한도 12 보다 훨씬 낮았고, 라그랑주 승수는 5개 seed 모두 0 이 됐다. 정책은 비용을 신경 쓰지 않고 공기량만 줄이도록 배웠고, 수집 스텝의 33 ~ 45% 에서 차단이 걸렸다.

### 비교 (theta 3.0 은 학습에 쓴 기준)

| 조건 | 공기량 Nm3/일 | 하루 비용 | NH4 위반 % | 한도 만족 % | 개입 % |
| --- | --- | --- | --- | --- | --- |
| e08 정책, 차단 없음 | 77,266 | 13.66 | 13.34 | 77.2 | 0 |
| e08 정책 + theta 3.0 | 91,279 | 6.62 | 5.04 | 87.1 | 20.2 |
| **학습 차단 정책 + theta 3.0** | **82,971** | **8.04** | 6.46 | 83.9 | 48.5 |
| 학습 차단 정책 + theta 2.0 | 89,125 | 6.68 | 5.59 | 87.2 | 60.1 |
| 학습 차단 정책 + theta 4.0 | 80,563 | 29.71 | 28.99 | 23.0 | 26.1 |
| 학습 차단 정책, 차단 없음 | 81,508 | 52.02 | 52.95 | 12.5 | 0 |
| 실제 운전 재생 | 84,860 | 28.77 | 28.48 | 해당 없음 | 해당 없음 |

### 사전 등록 가설 판정

- H1 지지. theta 3.0 에서 공기량이 5개 seed 모두 e08 의 91,279 보다 낮았다 (평균 -8,308, 9.1% 감소). 대신 하루 비용은 6.62 에서 8.04 로 조금 올랐고 한도 12 안이다.
- H2 지지 안 됨. 5점 곡선 전체의 같은 공기량 차이는 평균 +1.95, 음수 seed 1/5 이다. theta 3.5, 4.0 에서 비용이 크게 오른 점(seed 2, 4 의 theta 4.0 등) 이 평균을 올렸다.
- H3 지지. 차단 없이 쓰면 하루 비용이 5개 seed 모두 e08 정책보다 높았다 (평균 52.02, e08 13.66).

### 사후 관찰 (판정에 쓰지 않음)

학습에 쓴 기준 이하(theta 2.0, 2.5, 3.0) 의 3점만 보면, 같은 공기량 차이가 5개 seed 의 15점 모두 음수였다 (-0.12 ~ -4.06). 즉 학습 때와 같거나 더 엄격한 차단을 걸면 e08 기준 곡선보다 같은 공기량에서 비용이 낮고, 학습 때보다 느슨한 차단을 걸면 크게 나빠진다. 결과를 본 뒤 고른 범위라서 확인 실험이 필요하다.

### 해석

- 학습 중 차단은 정책을 차단과 한 몸으로 만든다. 차단이 NH4 위험을 맡으니 정책은 공기를 줄이고, 라그랑주 승수가 0 으로 떨어져 정책 스스로는 수질을 지키지 않는다 (H3).
- 그래서 학습한 기준 그대로 차단을 함께 쓰면 e08 보다 공기를 9% 덜 쓰는 대신 비용이 조금 높은 교환점이 생긴다. 실제 운전 재생과 비교하면 공기는 2.2% 적고 비용은 28.77 에서 8.04 로 낮다.
- 차단 기준을 학습 때보다 느슨하게 바꾸거나 차단을 끄면 안 된다. 운영에서 차단을 빼는 경우가 있다면 e08 방식(차단 없이 학습) 이 더 안전하다.

### 한계

- 사후 관찰은 결과를 본 뒤 고른 범위다.
- 라그랑주 승수가 0 이라 FCSRL 의 비용 제약 학습이 사실상 꺼졌다. 학습 중 한도를 낮추거나 개입 자체에 벌점을 주는 설계는 시험하지 않았다.
- 학습 중 차단은 theta 3.0 하나만 봤다. 평가는 검증 구간이다.

### 다음 실험 후보

- 학습 중 차단과 함께 개입에 작은 벌점을 주거나 한도를 낮춰, 라그랑주 승수가 살아 있게 한다 (차단을 꺼도 덜 무너지는지).
- 사후 관찰(학습 기준 이하에서 같은 공기량 비용이 낮다) 을 새 seed 로 확인한다.
