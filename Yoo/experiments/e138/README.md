# e138 같은 공기를 옮긴 뒤 정책이 다시 제어하면 NH4가 회복되는가

공급을 한 시간 앞당긴 후 e135 결합 정책이 후속 명령을 다시 정하자, e135 원 운전 대비 하루 평균 공기는 52.57 Nm³ 줄고 NH4 위반은 1.485분 늘었다. 초과 적분도 0.0808 늘었다. 원 일정 대비 공동 개선은 시드 13 한 개였고, 표적 시드 11과 12는 모두 악화해 앞당김을 채택하지 않았다. [사전 설계](REFERENCES_AND_DESIGN.md)

## 정책이 공기를 더 쓴 시각과 덜 쓴 시각

앞당김을 적용한 129개 경로에서 후속 명령을 고정 일정과 15분마다 비교했다. 사건당 하루 평균 증량 합은 4,898.44 Nm³, 감량 합은 5,305.95 Nm³, 순변화는 −407.51 Nm³였다. 129개 사건의 순변화를 전체 1,000개 경로로 나누면 표의 −52.57 Nm³가 된다. 120분에서 관찰을 끊은 NH4 첫 회복은 앞당김 고정 대비 3건이 빨라지고 3건이 늦어졌으며 123건은 같았다. 120분 안에 회복한 사건은 100건에서 99건으로 바뀌었다. [시드별 회복과 증감량](recovery.csv)

두 방향에서 결과가 달라졌으므로 특정 시각의 증감이 항상 낫다고 볼 근거는 부족하다. 이 결과는 사후에 찾은 동일 사건에서 후속 정책 반응의 효과를 가린 것이다. 현장의 관측만으로 미리 해당 사건을 식별할 수 있는지, 다른 계절에서 효과가 반복되는지는 미검증이다.
