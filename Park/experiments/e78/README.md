# Park/e78: 예측 제어 아래 대표 차단의 NH4 여유 (Kaggle DARROW)

상태: **사전 등록 (2026-11-24).** 여유 값, 가설, 판정 규칙은 이 실험의 결과를 보기 전에 정했다. 대표는 바꾸지 않는다.

## 목적

Park/e73 은 이득의 원천을 차단으로 옮겼다. 대표 차단의 NH4 여유 (Park/e15 여유 + 0.1, 예측 표준편차 구간마다 다름) 는 학습 정책 아래에서 정한 값이다. 차단 위 예측 제어는 스스로 NH4 를 내다보고 공기를 넣으므로 (Park/e71 사후 관찰), 차단을 덜 보수적으로 두어도 될 수 있다. Park/e72 와 같은 틀로 차단의 여유만 바꾼다.

## 방법

- 기준: `ShortMPC` (`objective='excess'`, NH4 여유 1.2, 공기 가중치 1.5, 1시간) + 대표 차단. 차단의 NH4 여유 표의 모든 구간에 같은 값을 더한다 (나머지 차단 설정은 그대로)
- 더하는 값 -0.4, -0.2, +0.2. 3번. -0.4 에서는 표준편차가 작은 구간의 여유가 0 아래가 된다 (예측 평균이 4 를 조금 넘어도 통과)
- 비교: Park/e58, e59 의 기본 설정 (더하는 값 0) 곡선에서 같은 공기량의 비용

## 평가

검증 40일 x 구성원 5개 = 200 에피소드, 결정적. test 는 쓰지 않는다.

## 가설 (사전 등록)

- H1. 차단 여유 -0.4 와 -0.2 가운데 하나라도 같은 공기량의 기본 곡선보다 0.05 넘게 낮다
- H2. 차단 여유 +0.2 의 하루 비용이 같은 공기량의 기본 곡선보다 0.05 넘게 높다
- 공기량이 곡선 범위 밖인 점은 그 가설에서 빼고, 모두 밖이면 판정하지 않는다

## RESULT.md 처리 (미리 정함)

- H1 지지: "예측 제어 아래에서는 대표 차단의 NH4 여유를 줄이면 더 낮아진다" 고 적고 그 값을 적는다. 기각: "차단 여유를 줄여도 낫지 않다 (대표 차단 여유가 예측 제어 아래에서도 맞음)" 고 적는다
- H2 지지: "차단 여유를 키우면 높아진다" 고 적는다. 기각: "차단 여유 +0.2 도 비슷하다" 고 적는다

## 미리 밝히는 한계

- H1 은 두 점 가운데 하나만 기준을 넘으면 지지라 여러 번 비교의 몫이 있다
- 차단 여유는 차단의 다른 결정 (회복 계획, 충돌 조정) 과 얽혀 있어 여유만의 효과로 읽기 어렵다. 검증 구간은 e10 부터 반복해서 썼다
