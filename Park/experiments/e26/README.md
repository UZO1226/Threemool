# Park/e26: 4 x 16 앙상블 구성원의 학습률 올리기 (Kaggle DARROW)

상태: **완료 (2026-11-13). 고르기 단계에서 후보 없음, 검증 평가는 하지 않음.** 학습률 6e-4 는 비용이, 1e-3 은 이긴 조합 수가 미리 정한 규칙을 넘지 못했다. 규칙은 결과를 보기 전에 정했다 (2026-11-13 07:27, 아래 그대로).

## 목적

목표는 공기량과 하루 비용을 함께 낮추는 것이다. e24, e25 에서 확인한 점을 합친다.

- 같은 예산에서 공기량과 비용을 함께 낮춘 것은 seed 가 다른 정책의 앙상블 (e22) 뿐이다 (e25 에서 같은 학습의 중간 정책 평균은 효과가 없었다)
- 정책 학습률을 올리면 공기량이 조금 줄었다 (e24, 업데이트 66번 정책)
- 4 x 16 앙상블의 구성원은 업데이트 16번뿐이라 덜 학습된 정도가 가장 크다. 학습률을 올리면 짧은 학습에서 더 많이 배울 것으로 봤다

## 원래 계획에서 바꾼 점

처음 계획은 e26 에서 가장 좋은 방법을 test 구간에서 한 번 확인하는 것이었다. Compare/PROTOCOL.md 는 "평가 구간은 팀 비교 때 한 번만 쓴다" 고 정하므로, Park 실험에서는 test 를 쓰지 않고 이 실험으로 바꿨다.

## 고르기 규칙 (결과 전에 기록)

"4 x 16 앙상블 구성원 학습률 후보 6e-4, 1e-3. 학습 구간 마지막 40일, e19 차단, seed 0 ~ 4 의 4개 조합 5개를 같은 조합의 학습률 3e-4 4 x 16 과 짝 비교. 조합 평균 공기량 < 기준, 평균 비용 < 기준, 둘 다 이긴 조합 최다 (3/5 이상), 같으면 공기량 최소. 없으면 버린다".

e24, e25 에서 seed 3개 고르기가 작은 차이를 가려내지 못해서, 이번에는 조합 5개를 짝 비교하고 3/5 이상을 요구했다. 고른 후보가 있으면 seed 0 ~ 9 의 조합 10개로 검증에서 판정할 계획이었다.

## 해석

- 학습률을 올리면 공기량은 확실히 준다 (e24 도 같은 방향). 하지만 정책이 공기를 더 아끼는 만큼 NH4 위반이 늘어 (6e-4 조합 평균 1.51% 에서 1.70%) 비용이 오르고, 차단 개입도 14% 에서 23 ~ 24% 로 늘었다. 공기량과 비용 사이의 맞바꿈이 정책 쪽에서는 아직 풀리지 않는다.
- 비용을 함께 낮추려면 공기를 줄여도 NH4 가 버틸 때만 줄이는 정보가 정책에 필요하다. 지금 관측 (11개 값) 과 대리 모델로는 NH4 가 바닥 근처라 (중간 점검 원인 1) 여유가 작다.
- e12 ~ e26 의 대표 결과는 e22 H1 (4 x 16 앙상블 + e19 H1 차단) 그대로다.
