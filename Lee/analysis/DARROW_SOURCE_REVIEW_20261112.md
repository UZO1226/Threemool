# DARROW 출처와 해석 보완

이번 목표 작업에서 최신 main에 이미 있는 Yoo/e35의 출처 확인을 추가로
검토했다. 근거는 [기록](../../Yoo/experiments/e35/README.md)과
[원문 해시 및 API 정보](../../Yoo/experiments/e35/source_manifest.json)다.
이번 세션의 같은 공개 읽기 API 재조회는 HTTP 404였으므로 원문 재수집에
성공했다고 주장하지 않는다. 원문 사본은 해당 팀 기록의 서버 경로에 있다.

## 기존 설명에서 바로잡을 점

| 항목 | 출처 기록에 따른 해석 |
| --- | --- |
| 공기 유량 | 문서상 m3/h다. 표준상태 조건이 확인되지 않아 Nm3로 확정하지 않는다 |
| DO와 공기 채널 | DO1/2/3의 직접 대응은 air3/4/5다. air1은 selector, air2는 facultative 구간이다 |
| 온라인 NH4, NO3 | 호기 구간 끝, 최종 침전지 전이다. 최종 방류수 실험실 값과 구별한다 |
| 농도 단위 | 문서상 mg/L다. NH4 표기만으로 질소 환산 기준을 추가 확정하지 않는다 |
| dynamic_influent | 실험실 평균 등을 사용해 생성한 ASM1 입력이다. 온라인 실측 유입 성분이라고 부르지 않는다 |
| DO 상한2, NH4 상한4 | 이 연구의 실험 기준이다. 현장 제어나 법적 방류 기준으로 확정하지 않는다 |

기존 Lee/e07부터 e15까지의 수치는 당시 구현의 역사적 결과로 보존한다.
Nm3 또는 mg N/L 표기는 위 출처 확인으로 참조 조건이나 환산이 검증됐다는
뜻이 아니다. 수치 자체를 바꾸거나 합의된 프로토콜을 개인 브랜치에서
변경하지 않는다. 현재 목표의 새 결과는 m3와 데이터의 mg/L로 해석한다.

기존 기본 모델의 같은 번호 DO/air 단조 대응은 오류였다. 공식 기준의
과거 재현을 위해 원 함수를 조용히 바꾸지 않는다. 새 e16 이후 모델은
세 DO에 대한 모든 공기 채널의 비감소를 사전 가정으로 사용했다. 올바른
직접 대응을 포함하지만 간접 효과까지 강제한 더 강한 가정이며, 실제로
모든 구간이 즉시 같은 방향으로 반응한다는 현장 검증은 아니다.

## 실험실 파일 확인

로컬 원본의 시트와 학습 구간 시작 행만 확인했다. influent 시트에는
COD, BOD5, TKN, Ntot, TSS, Q, effluent에는 이에 NH4와 NOx 등이 있다.
반응조 내부 미생물량이나 모든 구간의 내부 NH4가 온라인 관측되는 자료는
아니다. 측정값의 사용 가능 시간이 확인되지 않아 현재 날짜의 실험실
수치를 실시간 입력으로 추가하지 않는다. 이 확인은 test 평가가 아니다.

## 공정 모델과의 구별

DARROW 공식 [모델링 담당자 인터뷰](https://www.wastewater.ai/holistic-optimisation-of-wastewater-treatment-plants/)는
Tilburg 공정 모델을 만든 뒤 이를 RL과 축약 모델 학습에 사용했다고 설명한다.
이번 경험적 모델은 그 검증된 공정 모델을 확보하거나 재현한 것이 아니다.
관측 운전 재생, 관측 범위에서 벗어난 행동 예측, 실제 공정 제어 효과는
각각 별도의 검증 문제다. 관측 예측 점수만으로 세 가지를 같은 것으로
취급하지 않는다. 추가 모델 가능성을 배제하는 근거로도 쓰지 않는다.
