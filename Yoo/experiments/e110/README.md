# e110 대리 모델이 본 날짜에서는 보정 필요성을 작게 측정하는가

**같은 폭기 사건도 그 날짜를 학습에서 제외하면 보정이 유용하다는 판정이 늘었다. 하지만 바뀐 정답으로 학습해도 겨울 보정 선택은 회복되지 않았다.** 공통 환경은 v1.1을 유지한다. 아래 모델 다섯 개는 날짜 포함 여부를 비교하기 위한 복사본이다. FCSRL 정책과 기록 공기량은 고정했다.

## 같은 폭기 증가 194건을 재생한 결과

DARROW 앞 140일 중 폭기 증가 창이 있는 날은 120일이다. 한 창에서 보정이 유용하다는 뜻은 3시간 NH4 절대오차가 줄고, 1~3시간 NH4 변화 오차 및 3시간 최대 DO 오차도 각각 커지지 않았다는 뜻이다. 비율과 MAE는 각 날짜에 같은 가중치를 주었다.

| 학습 정답을 만든 모델 | 적합 날짜 수 | 유용한 창 | 날짜가중 유용 비율 | 무보정 3시간 NH4 MAE (mg N/L) | 기존 e109 정답과 날짜가중 일치율 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 공통 e50 | 188 | 17/194 | 8.3% | 0.624 | 100% |
| 사건 날짜 포함 | 112 | 16/194 | 8.6% | 0.546 | 88.9% |
| 사건 날짜 제외 | 112 | 28/194 | 15.4% | 0.827 | 87.1% |

포함과 제외 양쪽에서 유용했던 창은 9건이었다. 제외에서만 유용 19건, 포함에서만 유용 7건, 양쪽 모두 유용하지 않은 창은 159건이었다. 날짜가중 차이는 +6.8%p이고 7일 순환 블록의 탐색 95% 구간은 +0.9~+13.5%p였다. 5개 묶음별 유용 수(포함 → 제외)는 4→10, 3→7, 3→4, 2→4, 4→3이다. 보정이 필요하다고 표시되는 빈도는 학습 노출에 민감했다. 학습량을 맞춰도 적합에 들어간 다른 주가 달라지며 해당 모델을 공유하는 창들이 있어, 모든 차이를 한 날짜 포함의 인과 효과로 돌릴 수 없다.

## 새 정답이 겨울까지 도움이 되었는가

예측할 때는 동일한 세 입력(현재 NH4, 직전 1시간 NH4 변화, 현재 유입량)을 사용했다. 앞 140일에서 두 선별기를 적합한 후 뒤 48일과 겨울 40일을 기존 공통 환경의 똑같은 정답으로 평가했다. 유용한 창은 학습 후반 9/48건, 겨울 43/67건이다.

| 선별기 학습 정답 | 학습 후반 AUC | 겨울 AUC | 기본 문턱 0.5 선택, 학습 후반 / 겨울 | 학습 분위수 문턱에서 유용/선택, 학습 후반 / 겨울 |
| --- | ---: | ---: | --- | --- |
| 공통 e50 (e109) | 0.605 | 0.493 | 0 / 0 | 0/1, 4/8 |
| 사건 날짜 포함 | 0.618 | 0.468 | 0 / 0 | 2/5, 2/5 |
| 사건 날짜 제외 | 0.612 | 0.538 | 0 / 0 | 3/8, 2/5 |

날짜를 제외해 만든 정답을 쓰면 겨울의 가능성 순위 AUC는 0.538이고 최고 예측 확률은 0.224였다. 주 문턱에서는 한번도 보정을 켜지 않아 기본 오차와 같았다. 제외 조건의 학습 분위수 문턱(0.206)을 적용하면 겨울 3시간 NH4 MAE는 3.116 → 3.093, 1~3시간 NH4 변화 MAE는 2.043 → 2.025였지만 최대 DO MAE가 0.6302 → 0.6310으로 커졌다. 학습 후반에는 3시간 NH4가 0.841 → 0.858로 악화됐다. 표적 생성 방식을 고쳐도 두 기간 공동 개선 기준은 통과하지 못했다.

## 연구에서의 판단

이 진단은 기록된 공기에 대한 수질 예측에서 대리 모델의 학습 오차를 보정 선별기의 정답으로 사용할 때 생기는 한계를 보여 준다. 이번 날짜 제외는 과거 자료에서 표적을 재구성하기 위한 분할로, 제외 주보다 뒤에 기록된 다른 학습주도 포함할 수 있다. 실제 공기를 다르게 공급했을 때의 반응, 정책의 제어 성능 또는 구현자 숙련도를 평가하지 않았다. 겨울 개발 날짜는 연구 과정에서 반복 사용했다.

이번 0.05 NH4 하락 보정을 팀 공통 환경에 적용할 근거는 부족하다. 연구 본문에서는 공통 v1.1에서의 알고리즘 비교와 실제 공정으로의 일반화 한계를 구분할 수 있다. 기존 e50에서 기본 FCSRL 대비 Actor 보정은 평균 공기량과 비용이 줄었으나 비용 개선은 2/5 seed였다. 평균 공동 개선과 seed별 재현성이 다른 결과라는 점을 함께 보고한다. [공통 환경 비교](../e50/results.md), [공기 감량 효과의 모델 간 전이](../e103/README.md).

## 재현

사전 설계 8cdb2bd, 모델 재생 1db7282, 집계 2c5fde6. scikit-learn 1.9.1의 e30 train_gbm 기본 설정으로 각 복사본에 25개 GBM을 적합했다. 7일 블록 순번을 5로 나눈 나머지로 묶어, 관측의 묶음을 통째로 제외하는 모델 및 다음 묶음을 제외하는 모델에서 같은 기록을 재생했다. 각 구성원의 80% 전이 표본추출과 내부 조기 종료는 해당 복사본의 112일 이내에서만 이루어진다. 보류 날짜를 전달한 val 인자는 적합 뒤 로그 계산에만 사용된다. 최대 상태값도 복사본의 적합일에서 계산한다. 각 모형의 날짜 목록과 두 재생 경로는 서버에 보존했다.

원시 출력은 /home/jio/fcsrl_src/results/e110/main 이다. 원본 e50 자료와 e106 궤적 해시, 전체 창의 날짜, 시각, 실측 일치, 포함/제외 쌍의 분할을 검산했다. 저장한 구성원별 농도로 194쌍의 정답과 기본 NH4 오차를 독립 재계산하고, 두 평가 기간에서 선별기 선택에 따른 세 지표를 날짜별로 다시 집계했다. [사전 설계와 문헌](REFERENCES_AND_DESIGN.md), [전체 결과](summary.json), [선별기 계수](locked.json).
