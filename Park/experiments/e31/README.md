# Park/e31: 최근 예측 오차로 보정한 차단 (Kaggle DARROW)

상태: **완료 (2026-11-16). H1 기각 (6/10 이지만 평균 비용이 낮지 않음).** 대표는 바꾸지 않는다. 고르기 규칙은 결과를 보기 전에 정했고 (커밋 `478b3f7`, 아래 그대로), 가설과 판정 규칙은 검증 결과를 보기 전에 정했다. 설정은 학습 구간만으로 골랐다.

## 목적

목표는 공기량과 하루 비용을 함께 낮추는 것이다. e24 ~ e29 에서 정책이 공기를 더 아끼게 만드는 방법은 검증에서 NH4 위반이 늘어 비용이 올랐다. 차단 쪽에서 예측을 더 정확하게 만들면 두 방향을 함께 얻을 수 있다. 예측이 낮게 치우친 구간에서 공기를 미리 넣으면 NH4 위반이 줄고, 오차 폭이 줄어든 만큼 여유를 줄이면 공기가 준다.

## 진단 (학습 구간 마지막 40일, e22 H1 과 같은 seed 0 ~ 3 앙상블 + e19 차단)

차단의 1 스텝 NH4 예측 (다른 구성원 4개 평균, 실제로 쓴 공기량) 과 실제 NH4 의 차이를 쟀다. 19,000 스텝 중 경계 근처 (예측 3.0 ~ 4.5) 는 10,138 스텝이다.

| 항목 | 값 |
| --- | --- |
| 직전 스텝 오차와의 상관 (전체, 경계 근처) | 0.68, 0.66 |
| 에피소드 평균 오차가 설명하는 오차 분산 | 17% |
| 지수 평균 (lam 0.5) 으로 보정한 경계 근처 오차 표준편차 | 0.067 에서 0.050 |
| 같은 보정의 99% 분위수, 1% 분위수 | 0.172 에서 0.135, -0.159 에서 -0.137 |
| lam 0.8, 0.9, 0.95 의 99% 분위수 | 0.138, 0.144, 0.149 |

지금 차단은 매 스텝 방금 관측한 예측 오차를 쓰지 않는다. 오차는 대부분 몇 스텝 동안 이어지는 치우침이고, 하루 내내 같은 치우침 (환경 구성원 고유의 치우침) 은 일부다.

## 방법

`min_brake.py` 에 `bias`, `margin_scale` 을 더했다. 매 스텝 지난 스텝 예측과 지금 관측 NH4 의 차이 e 로 에피소드마다 b <- lam b + (1 - lam) e 를 갱신하고, 여유 검사 (mu + 여유 <= 4) 의 mu 에 b 를 더한다. 모델 예측 제어의 외란 추정과 같은 방법이다. `margin_scale` 은 e15 여유 표 (+0.1) 에 곱한다. 여러 스텝 예측 (회복 가능성 검사, DO 예측) 은 바꾸지 않는다. 정책은 e22 와 같은 4 x 16 앙상블이다 (새 학습 없음).

| 후보 | lam | 여유 배율 |
| --- | --- | --- |
| B5 | 0.5 | 1.0 |
| B5s8 | 0.5 | 0.8 |
| B8s8 | 0.8 | 0.8 |
| B5s7 | 0.5 | 0.7 |

여유 배율 0.8 은 진단의 99% 분위수 감소 (22%) 에서, 0.7 은 그보다 조금 더 줄인 값이다.

## 고르기 규칙 (결과 전에 기록)

"학습 구간 마지막 40일 (2021-10-01 ~ 11-09) x 구성원 5개, seed 0 ~ 4 의 4개 조합 5개를 같은 조합의 e19 차단 (Park/e26 의 기준값) 과 짝 비교. 조합 평균 공기량 < 기준, 평균 비용 < 기준, 둘 다 이긴 조합 최다 (3/5 이상), 같으면 공기량 최소. 없으면 버린다. 규칙을 통과한 후보 중 평균 비용이 가장 낮은 후보가 고른 후보와 다르면 보조 가설로 함께 검증한다".

## 고르기 결과

학습 구간 마지막 40일 x 구성원 5개, seed 0 ~ 4 의 4개 조합 5개 평균.

| 후보 | 공기량 | 하루 비용 | NH4 위반 % | DO 위반 % | 기준보다 둘 다 낮은 조합 |
| --- | --- | --- | --- | --- | --- |
| 기준 e19 차단 | 73,965 | 2.640 | 1.51 | 1.27 | |
| B5 | 74,166 | 2.562 | 1.53 | 1.17 | 1/5 |
| B5s8 | 73,721 | 2.587 | 1.61 | 1.11 | 2/5 |
| **B8s8 (규칙으로 고름)** | **73,628** | **2.549** | 1.61 | 1.08 | 3/5 |
| B5s7 | 73,573 | 2.641 | 1.63 | 1.15 | 3/5 |

B8s8 만 규칙을 통과했다 (B5s7 은 평균 비용이 기준보다 0.001 높다). 통과한 후보가 하나라 보조 가설은 없다. 보정만 하면 (B5) DO 위반이 줄어 비용은 낮아지지만 공기량이 늘었고, 여유를 함께 줄이면 공기량이 줄었다. 여유를 줄인 후보는 NH4 위반이 조금 늘고 DO 위반이 줄었다.

## 조건과 평가

검증 40일 x 구성원 5개 = 200 에피소드, 결정적. test 는 쓰지 않는다. 판정 단위는 4 x 16 앙상블 조합 10개 (seed 0 ~ 4 의 4개 조합 5개, seed 5 ~ 9 의 4개 조합 5개, 구성원은 Park/e22 `dw_u16_runs`, Park/e23 `dw_new16_runs`) 다. 기준은 같은 조합의 e19 차단 값 (Park/e22, e23 결과, 새로 계산하지 않음) 이다.

참고 조건 (판정에 쓰지 않음): B8s8 에 Park/e28 H2 회복 계획 (H 4, do_lim 1.8) 을 함께 건 값.

## 가설 (사전 등록)

- H1 (주 가설). B8s8 (lam 0.8, 여유 배율 0.8) 이 같은 조합의 e19 차단보다 공기량과 하루 비용이 둘 다 낮은 조합이 10개 중 6개 이상이고, 조합 10개 평균도 둘 다 낮다

짝 차이 평균과 95% 신뢰구간 (조합끼리 독립이 아니라 낙관적) 은 참고로 적는다. 가설이 기각되는 결과도 그대로 기록한다.

## RESULT.md 처리 (미리 정함)

H1 이 지지되면 대표 방법을 "e22 H1 앙상블 + 보정 차단 B8s8" 로 바꾼다 (학습 예산과 정책은 같다). 값은 대표와 같은 구성원인 seed 0 ~ 3 조합 값과 조합 10개 평균을 함께 적는다. 참고 조건은 해석에만 적는다.

## 미리 밝히는 한계

- 환경의 "실제 공정" 은 대리 모델 구성원 하나라, 오차의 일부 (진단에서 17%) 는 그 구성원 고유의 치우침이다. 실제 처리장의 모델 오차는 성질이 다를 수 있다
- 여유 배율은 학습 구간 오차로 정했다. 검증 구간 (겨울) 은 오차 성질이 다를 수 있다
- 보정은 1 스텝 여유 검사에만 쓰고 여러 스텝 예측에는 쓰지 않는다
- e10 ~ e30 과 같은 대리 모델 한계

## 결과

전체 표는 [results.md](results.md).

| 조건 (조합 10개 평균) | 공기량 Nm3/일 | 하루 비용 | NH4 위반 % | DO 위반 % | 기준보다 둘 다 낮은 조합 |
| --- | --- | --- | --- | --- | --- |
| 기준 4 x 16 + e19 차단 | 81,375 | 4.80 | 3.44 | 1.61 | |
| H1 4 x 16 + 보정 차단 B8s8 | 81,062 | 4.80 | 3.42 | 1.63 | 6/10 |
| 참고: B8s8 + e28 4 스텝 회복 계획 | 80,738 | 4.68 | 3.55 | 1.38 | 9/10 |
| (비교) e28 H2: e19 차단 + 회복 계획 | 81,063 | 4.65 | 3.56 | 1.33 | 10/10 |

- H1 기각. 둘 다 낮은 조합은 6/10 으로 기준을 넘었지만, 평균 비용이 낮지 않았다 (짝 차이 +0.003, 95% 신뢰구간 -0.039 ~ +0.044). 공기량은 10개 중 9개에서 줄었다 (짝 차이 -314, -448 ~ -179)
- 보정과 여유 축소는 공기량을 조금 줄이지만, 검증 구간에서는 비용을 낮추지 못했다. 학습 구간 고르기 (3/5) 부터 효과가 약했다
- 참고 조건 (판정에 쓰지 않음): 회복 계획과 함께 쓰면 9/10 이 둘 다 낮았다. e28 H2 와 비교하면 공기량은 325 적고 비용은 0.03 많아, 보정 차단을 더해도 e28 H2 보다 낫다고 하기 어렵다
