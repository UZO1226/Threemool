# Park/e85: e82 ~ e84 를 반영한 주장 지도 갱신과 판정 방식 정리 (Kaggle DARROW)

상태: **완료 (2026-11-26). 대표 교체 제안을 (3) 에서 (1) 대표 유지로 고침, 날짜 블록 세 갈래 판정을 기본 판정으로 정함.** 사전 등록 커밋 `39add59` (main 병합 #255). 갱신 규칙은 e82 ~ e84 의 결과를 보기 전에 정했다. 새 학습과 새 평가는 없다 (정리 실험이라 실행 코드가 없다). 대표는 바꾸지 않는다.

## 목적

Park/e81 은 차단 위 예측 제어가 대표보다 낮다는 결론이 검증 40일에서만 나왔다고 보고 대표 교체 제안을 (3) 으로 되돌렸다. e82 ~ e84 는 날짜 블록 판정 (세 갈래) 으로 두 구간의 순서와 학습한 날의 이점을 본다. 이 실험은 그 결과를 주장 지도에 넣고, Park 의 판정 방식을 정리한다.

## 갱신 규칙 (사전 등록, e82 ~ e84 결과 보기 전)

- 분류 규칙은 Park/e73, e81 과 같다. 수치는 각 실험의 README, results.md 에 있는 값만 쓴다. 바뀐 곳에 **(갱신)** 을 붙인다
- 판정 방식: e82 부터 쓴 날짜 블록 세 갈래 판정 (지지, 반대, 차이 없음) 을 Park 의 기본 판정으로 적는다. e74 ~ e80 의 점 하나 0.05 기준 판정은 지우지 않고 "점 판정" 으로 표시한다
- 대표 교체 제안 (팀 결정, Park 혼자 바꾸지 않음):
  - e82 H1 이 "차이 없음" 또는 "반대" 면: 검증 구간에서도 날짜 흔들림을 넘는 예측 제어 이득이 없으므로 제안을 "(1) 대표를 그대로 두기" 로 고친다
  - e82 H1 이 지지이고, e83 H1 이 지지가 아니거나 e84 해석 규칙이 "학습한 날의 이점" 이면: 학습 구간의 대표 우위가 날짜 흔들림 안이거나 학습 이점으로 설명되므로 제안을 "(2) 대표를 차단 + 예측 제어로 바꾸기 (test 확인은 팀과 협의)" 로 되돌린다
  - 그 밖에는 (3) 을 유지한다
- e79 의 공기와 비용 동시 감소 점: e82 H2 가 지지면 보조 근거에, 아니면 한계와 실패 칸에 둔다
- e84 해석 규칙의 결과 (학습한 날의 이점, 날짜에 따른 예측 제어 약화, 가르지 못함) 는 한계 칸의 날짜 항목에 그대로 적는다
- 주 주장 (차단이 이득의 원천, 다시 고른 ABAC 와 차단만보다 낮음) 은 e82 ~ e84 가 그 판정을 직접 다루지 않으므로 유지한다

## 미리 밝히는 한계

- 정리 실험이라 새 증거를 만들지 않는다
- 모든 결과는 같은 대리 모델 계열의 환경이다. test 는 쓰지 않았다

## 규칙 적용

- 판정 방식: 날짜 블록 세 갈래 판정을 Park 의 기본 판정으로 적는다. e74 ~ e80 의 판정은 "점 판정" 으로 표시한다
- 대표 교체 제안: e82 H1 이 "차이 없음" (-0.233, 구간 -0.550 ~ +0.010) 이다. 규칙의 첫 갈래에 따라 제안을 "(1) 대표를 그대로 두기" 로 고친다
- e79 의 공기와 비용 동시 감소 점: e82 H2 가 "차이 없음" (-0.313, 구간 -0.906 ~ +0.171) 이다. 한계와 실패 칸에 둔다
- e84 해석 규칙의 결과: "가르지 못함". 한계 칸의 날짜 항목에 적는다
- 주 주장: 유지한다

## 갱신한 주장 지도 (한 쪽)

Park/e73, e81 의 지도에서 바뀐 곳만 적는다. 나머지는 [Park/e73](../e73/README.md), [Park/e81](../e81/README.md) 과 같다.

### 판정 방식 (갱신)

**(갱신)** e82 부터 Park 의 기본 판정은 같은 날끼리 짝지은 하루 비용 차이의 날짜 블록 95% 구간 (이어진 5일 원형 이동 블록, 10,000번, seed 0) 으로 "지지 / 반대 / 차이 없음" 세 갈래를 가르는 것이다. 이전의 묶음 5/5 판정과 점 하나 0.05 기준 판정은 날짜 흔들림을 담지 않는다. e74 ~ e80 의 판정은 "점 판정" 으로, e59 ~ e67 의 묶음 판정은 "묶음 판정" 으로 읽는다.

### 주 주장 (문장 유지, 단서 고침)

**같은 공기량에서, 대리 모델로 다음 NH4 를 예측해 필요한 만큼만 공기를 올리는 최소 개입 차단을 씌운 제어 (대표는 그 차단을 켠 채 학습한 정책 앙상블) 는 현장 표준 ABAC 와 차단만보다 하루 위반 비용이 낮다. 이득의 원천은 차단이다.**

**(갱신)** 차단 위의 제어기끼리 (학습 정책, 1시간 예측 제어) 의 차이는 검증 40일 (e82) 과 학습 구간 40일 (e83) 모두 날짜 흔들림 안이다. 평균의 방향은 구간마다 반대다 (검증 -0.233, 학습 구간 +0.935, 예측 제어 빼기 대표).

### 기여 분리 (갱신한 줄만)

| 몫 | 비교 | 차이 | 상태 |
| --- | --- | --- | --- |
| **(갱신)** 학습 정책 대 예측 제어 (같은 차단, 날짜 블록) | 대표 대 차단 위 예측 제어 기본, 검증 (e82) 과 학습 구간 (e83) | -0.233 (-0.550 ~ +0.010), +0.935 (-0.086 ~ +2.452) | 둘 다 차이 없음. 묶음 판정 (e59, e66, e67) 은 날짜 흔들림을 담지 않음 |
| **(갱신)** 예측 제어 대 차단 + ABAC (같은 차단, 같은 공기량, 날짜 블록) | e84 | 검증 -0.178 (-0.432 ~ -0.008), 학습 구간 +0.712 (-0.402 ~ +2.231) | 검증은 0 아래 (참고 비교, 판정 없음), 학습 구간은 차이 없음 (H1) |
| **(갱신)** 학습 정책 대 차단 + ABAC (같은 차단, 같은 공기량, 날짜 블록) | e84 | 검증 +0.053 (-0.144 ~ +0.251), 학습 구간 -0.194 (-0.602 ~ +0.199) | 둘 다 차이 없음 |

정리 (갱신): 같은 차단 위에서 학습 정책, 1시간 예측 제어, ABAC 의 차이는 날짜 블록으로 보면 대부분 날짜 흔들림 안이다. 날짜 흔들림을 넘은 것은 검증 40일의 예측 제어 대 차단 + ABAC (-0.178) 하나이고, 그것도 참고 비교다. 차단이 이득의 원천이고 차단 위 제어기의 선택은 부차적이라는 Park/e73 의 정리가 날짜 블록 판정으로 더 강해졌다.

### 한계와 실패 (더한 항목)

- **(갱신)** 대표보다 공기와 비용을 함께 줄인 차단 위 예측 제어 점 (e79, 80,374 / 4.345) 은 날짜 블록으로 차이 없음이다 (e82 H2, -0.313, 구간 -0.906 ~ +0.171). 학습 구간에서도 차이 없음 (e83 H2)
- **(갱신)** 학습 구간의 대표 우위가 학습한 날의 이점인지, 날짜에 따른 예측 제어 약화인지는 가르지 못했다 (e84). 학습 구간 40일의 날짜 흔들림 (블록 구간 폭 0.8 ~ 3.0) 이 검증 구간 (0.4 ~ 1.1) 보다 커서 40일로는 이 크기의 차이를 가르기 어렵다
- **(갱신)** 묶음 5/5 판정과 점 판정은 날짜 흔들림을 담지 않는다. Park 의 이전 지지 판정 가운데 날짜 블록으로 다시 본 것은 대표 대 ABAC (e49), 대표 대 다시 고른 ABAC (e64), 대표 대 차단 위 예측 제어 (e64, e82, e83) 다

## 팀 결정 사항 (Park 혼자 정하지 않음)

- **(갱신) 대표 교체 (Park 제안: 선택지 (1) 대표 유지):** 사전 등록 갱신 규칙에 따라, 검증 구간에서도 날짜 흔들림을 넘는 예측 제어 이득이 없으므로 (e82 H1 차이 없음) 제안을 "(1) 대표를 그대로 두기" 로 고친다. 원고에는 "차단 위 제어기 (학습 정책, 예측 제어) 의 차이는 날짜 흔들림 안" 을 주 주장 옆에 적는다
- Park 의 모든 실험은 지금 대표 (FCSRL 4 x 16 + 대표 차단) 를 계속 쓴다
