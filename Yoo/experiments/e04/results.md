검증 운전 기록의 호기 중 DO < 0.7 비율은 30.1%다. 정책의 비율과 차이가 크지만 이것만으로 분포 밖임을 판정하지 않는다.

제약 방법 30개 모두 전체 검증 평균 비용이 15를 넘었다. 기존 무작위 10에피소드의 선택 검증과 전체 검증은 다른 결과를 준다. 낮은 비용의 에피소드 표본을 기준으로 모델을 선택한 영향과 날짜별 차이를 분리해야 한다.

Q 잔차는 Q 평균에서 동일 정책의 12스텝 할인 비용과 끝 상태 Q를 뺀 값이다. 양수는 이 목표보다 높게 추정한 것이다. FCSRL에서 일관된 큰 음의 편향은 보이지 않았지만 bootstrap된 값이라 실제 공정 비용의 과소평가를 반증하지 않는다. PPO에는 critic 앙상블이 없으며 결정적 평균 행동과 학습 정책도 다르다.

## 환경 모델의 불확실성

| 변수 | 한 스텝 MAE | 평균 sigma | sigma와 절대 오차 상관 | k=1 상한 포함률 |
| --- | --- | --- | --- | --- |
| nh4 | 0.148 | 0.020 | -0.011 | 58.3% |
| do | 0.179 | 0.027 | 0.179 | 74.1% |

위 포함률은 실제 다음 값이 앙상블 평균 + sigma 이내인 비율이다. 정규성 또는 확률적 보장은 가정하지 않는다. NH4 sigma는 이 검증 자료에서 오차 크기를 거의 구분하지 못한다. k만 높이는 불확실성 벌점의 본 학습은 진행하지 않는다.

## 설정과 테스트

- 같은 seed의 두 실제 학습이 일치하지 않아 원인을 추적했다. warmup의 Box 행동 샘플링 난수가 고정되지 않았다. 수정 후 같은 seed의 두 20회 갱신 실행에서 모든 저장된 모델 tensor, 검증 지표 및 PID 기록이 정확히 일치했다.


- 단위 테스트 6개 통과. 진단용 trace를 켜고 꺼도 배치 평가 결과가 정확히 같았다. 실제 데이터 2에피소드의 순차 및 배치 평가 비용도 같았다.
- PID에 비용 100을 100회, 비용 10을 100회 입력한 인위적 스트레스 시험에서 적분값은 8000으로 남았고 lambda는 상한 0.75 및 5에 각각 붙었다. 이는 적분 누적 가능성의 예시이며 과거 실행의 내부 적분값을 복원한 결과는 아니다.
- 이번 수정은 잘못된 입력 및 결과 덮어쓰기를 거부하며 e03의 유효한 기본 학습 수식을 바꾸지 않는다.

## 다음 작은 비교 실행

고정 전체 검증으로 FCSRL의 학습 한도 15와 12를 비교한다. 이는 보수성 민감도 대조 실험이며 새로운 확장 성능을 주장하는 실험이 아니다. 두 방법 모두 승수 상한 5, 기존 PID 계수, 기존 네트워크, 환경 벌점 0이다. seed 0과 1, 5 epoch x 2500 gradient step으로 약 40만 전이를 수집한다. 검증은 매 epoch 215에피소드이며 최종 평가는 val만 사용한다. test 구간은 읽어 평가하지 않는다.

보고 한도는 두 방법 모두 15로 고정한다. 학습 한도 12는 추가 보수성 20%를 주는 사전 정의 대조군이다. 비교 결과를 보고 임계값을 계속 바꾸지 않는다. 검증 구간 자체는 이미 사용된 자료이므로 결과는 탐색적이다.

선택 규칙은 원본 트레이너를 유지한다. 한도를 만족한 모델이 없으면 마지막 모델이 남으므로, 이 경우 선택 모델을 제약 만족 모델로 부르지 않는다. 마지막 모델도 따로 보관한다.
