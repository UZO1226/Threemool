# Lee/e11 결과: 승수 반응 8배 효과도 새 seed 에서 재현되지 않았다

5개 실행 모두 정상 종료. 비교 기준 원래 FCSRL 은 Lee/e10 의 새 seed 5 에서 9. "합친 10개"는 seed 0 에서 4 (e07, e08)와 새 seed 5 에서 9 를 합친 것이다. 원자료는 `summary_new_seeds.json`, `summary_10seeds.json`.

## 가설 판정

- **H28 (새 seed 선택 모델에서 비용이 낮고 한도 만족 seed 가 같거나 많음)**: **기각**. 비용이 더 높고(+12%) 한도 만족 seed 도 5/5에서 4/5로 줄었다.
- **H29 (합친 10개 선택 모델 비용의 짝 차이가 음수인 seed 7개 이상)**: **기각**. 5/10 이고 평균 차이는 -0.10 으로 사실상 0 이다. 마지막 모델은 7/10 이지만 평균 차이가 편차보다 훨씬 작다(p=0.61).

## 결론

e08 의 "승수 8배가 비용을 줄인다"는 seed 0 에서 4 의 결과였고 새 seed 에서 사라졌다. 10개 seed 로 보면 선택 모델은 원래 FCSRL 과 구별되지 않는다. 마지막 모델의 한도 만족 seed 가 2/10 에서 6/10 으로 늘어난 점만 남지만, 평균 비용 차이는 편차 안이라 개선으로 보지 않는다.
e08 결과를 포함해 seed 5개 비교는 우연에 크게 흔들린다는 것이 e10 과 e11 로 두 번 확인되었다.
