# e54 날짜 분할 불확실성 신호 선별

2026-11-12 완료. e54의 새 불확실성 앙상블이 실제 위험을 더 잘 구분하는지 확인한 대조다. 새 정책 성능 실험이나 반복 예측 상태 모델 교체가 아니다. [전체 결과](results.md), [원 수치](results.json), [고정한 기준](protocol.json).

## 다음 작업으로 선택한 이유

e52/e53은 안전 여유를 더하면 NH4가 줄지만 공기량이 늘며, 불확실성 여유의 추가 이득은 FCSRL 일부 seed에서만 나타났다. e54는 날짜 묶음 하나씩을 제외한 NH4 예측기 5개로 불확실성을 계산한다. 전이 모델은 그대로다. 모델 간 차이가 커지는 것만으로 실측 위험 정보가 좋아졌다고 판단할 수 없으므로 탐지율과 거짓양성률을 함께 확인한다.

불확실성의 보정이 모델 기반 RL에서 별도 검증 대상이라는 점은 [Malik 등, ICML 2019](https://proceedings.mlr.press/v97/malik19a.html)에서도 다룬다. [MOPO, NeurIPS 2020](https://proceedings.nips.cc/paper/2020/hash/a322852ce0df73e204b7e67cbbef0d0a-Abstract.html)는 불확실성에 따른 보수적 목적을 사용하지만, 그 논문의 보장이나 알고리즘을 현재 PPO 비용 여유에 그대로 적용했다고 주장하지 않는다.

이 선별 결과는 날짜 분할 신호를 다음 FCSRL 학습 후보로 확대할 근거가 있는지를 바꾼다. 이전 e38/e41의 이력/증강이나 e42의 전문가 분리를 다시 학습하지 않았고, 임계값 또는 kappa를 재탐색하지 않았다.

## 실행 순서와 한계

후보 결과를 읽기 전에 선별 기준과 코드를 커밋 `1520d20`으로 고정했다. 후보 생성 자체는 다른 작업 공간에서 이미 진행 중이었다. 생성 완료를 확인했을 때 클로드가 별도 e54 본학습 6개도 시작한 상태였다. 따라서 이 검사를 실제로 그 학습을 차단한 사전 관문이라고 부르지 않는다. 그 실행을 중복 생성하거나 중단하지 않았다.

기존 신호는 e35 앙상블의 SD에 kappa 10을 곱한다. 새 신호는 e54 build가 학습 날짜에서 비용 5.62를 맞추도록 고정한 kappa 5.5를 그대로 쓴다. 비교 구간은 동일한 train188일과 개발 val40일이다. test41일은 평가하지 않는다. val은 여러 실험에서 사용한 개발 자료이므로 독립 확증이 아니다.

각 날짜의 기록 행동으로 전이를 재생하며 모든 판정 방법이 완전히 같은 예측 NH4 경로와 관측 정답을 쓴다. 바뀌는 것은 비용에 더하는 여유뿐이다. 임의의 정책 행동에 대응하는 실제 수질을 관측한 실험이 아니다.

날짜 묶음 제외 방식은 각 학습 날짜를 구성원 하나만 보지 않는 방식이다. 나머지 네 구성원은 그 날짜를 보았으므로 학습 날짜의 앙상블 전체를 out-of-fold 예측이라고 부르지 않는다. 학습 날짜는 비용 강도 맞춤에만 쓰고 신호 품질의 주 비교는 별도 val40일에서 한다.

## 고정한 판단

- 기존 신호와 후보의 학습 날짜 비용이 실제 기록 비용에서 각각 0.1 이내여야 한다.
- 검증 FPR은 증가하지 않고 탐지율은 감소하지 않으며 둘 중 하나는 엄격하게 개선돼야 탐색 선별을 통과한다.
- paired 날짜 블록 bootstrap은 7일, 2000회, RNG 20261112다. 모델 구성원을 독립 데이터로 세지 않는다.
- 95% 구간도 두 개선 방향 안에 남는지는 별도 신뢰도 표시로만 보고한다.
- 미통과면 불확실성 품질 개선을 근거로 후보를 채택하거나 kappa 탐색을 확대하지 않는다. 진행 중인 정책 학습의 성공 또는 실패를 이 선별만으로 확정하지 않는다.

학습 비용 맞춤은 통과했지만 탐지/FPR 동시 개선은 미통과다. 후보는 원 신호보다 진양성이 4개 줄고 거짓양성이 99개 늘었다. 이 개수에는 같은 관측 날짜의 모델 구성원 5개 경로가 포함되며 독립 사건 수로 해석하지 않는다.

FPR 차이 +0.6302%p의 탐색 95% 구간은 [-0.0989,+1.3021], 탐지율 차이 -0.1216%p는 [-0.6516,+0.3154]다. 모두 0을 포함하므로 통계적으로 확정된 악화라고 주장하지 않는다. 현재 근거로는 신호 품질 개선을 확인하지 못했다.

절대 오차와 SD의 상관은 조금 커졌지만 실제로 놓친 NH4 위반을 더 잘 찾지는 못했다. 이 차이는 위험의 방향을 구분하지 않는 불확실성 크기와 안전 비용용 신호를 구별해야 함을 보여준다. 신호가 모든 정책 상태에서 쓸모 없다는 증명이나 FCSRL 자체 실패라는 결론은 아니다.

## 결정

이번 날짜 분할 불확실성은 이 탐색 선별 기준으로 채택하지 않는다. 원래의 NH4 과대예측 편향과 자기 예측 누적 상태를 바꾸지 않으므로, 이 변경을 환경 정확도 개선으로 설명하지 않는다.

이미 다른 작업 공간에서 실행 중인 e54 정책 학습은 별도 근거로 남긴다. 결과가 나오면 공기량, NH4, DO와 초과 적분, 최악 날짜를 기존 정책과 비교해야 하며, 신호 검사가 미통과라는 이유로 그 결과를 버리거나 반대로 공기량 증가를 숨기지 않는다. 이 작업에서는 학습을 추가하지 않았다.
