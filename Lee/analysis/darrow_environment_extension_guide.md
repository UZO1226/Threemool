# DARROW 환경과 확장 실험 읽는 법

DARROW 데이터는 실제 처리장의 운전 기록이다. 에이전트가 실제 처리장을
조작하는 것은 아니다. 기록으로 학습한 환경 모델 안에서 공기량을 조절한다.

| 구성 요소 | 역할 | 코드 |
| --- | --- | --- |
| 데이터 준비 | 15분 간격 기록을 날짜 순으로 학습, 검증, 평가에 나눈다 | code/darrow/prep_darrow.py |
| 환경 모델 | 현재 수질과 공기량으로 다음 수질을 계산한다 | code/darrow/surrogate_dw.py |
| 제어 환경 | 상태, 행동, 보상, 비용과 하루 종료를 정의한다 | code/darrow/env_dw.py |
| 에이전트 학습 | 공기량 결정 방법을 반복해서 개선한다 | code/darrow/train_dw.py |

## 왜 환경부터 확인했는가

운전 연습용 환경이 잘못된 결과를 알려주면 에이전트도 잘못 배울 수 있다.
15분 뒤 한 번 예측하는 정확도와, 예측을 이어 붙여 하루를 계산하는 정확도는
다르다. 기존 모델은 한 번의 예측에서는 현재 수질이 그대로 유지된다는 단순
기준보다 NH4 오차가 작았지만, 하루 연속 예측에서는 오히려 오차가 컸다.

Lee/e14에서는 수질 변화량 대신 다음 수질을 직접 예측하는 후보를 학습했다.
선택된 후보는 기존 모델보다 하루 연속 NH4 평균 절대 오차를 약 22퍼센트
줄였다. 하지만 NH4 위반을 과대 예측하고 DO 위반을 과소 예측하는 문제가
남아 있다. 예측 오차 감소와 실제 공정의 안전성 입증은 별개다.

## 이번 확장은 무엇인가

Lee/e15의 확장은 학습할 때 어려운 날을 더 자주 연습하게 만드는 것이다.
학습 구간의 188일 가운데 NH4 위반이 많은 47일을 고르고, 전체 연습의
절반을 이 날들에 배정한다. 나머지 절반은 다른 141일에서 고른다.
검증 날짜를 골라 학습시키거나 미래 정답을 에이전트에 제공하지 않는다.

기본 FCSRL과 확장 기법은 같은 환경 모델, 같은 보상과 비용, 같은 학습량,
같은 seed 5개로 비교한다. 바뀐 것은 학습 날짜를 고르는 확률이다.
여기서 FCSRL은 우리 폐수처리 환경에 적용한 FCSRL과 PPO-Lag의 결합이며,
원 논문의 실험 환경이나 발표된 점수를 재현했다는 뜻은 아니다.

## 결과에서 확인할 것

1. 공기량은 얼마나 달라졌는가. 이것은 실제 전기 사용량이 아니다.
2. NH4 위반이 줄었는가.
3. DO 상한 초과가 늘지는 않았는가.
4. seed를 바꾸거나 환경 모델을 바꿔도 같은 경향인가.

비용은 NH4 위반과 DO 상한 초과를 각각 1씩 더한 점수다. 합계만 낮아져도
NH4 위반은 늘 수 있으므로 두 항목을 따로 읽는다. 기준값은 실험 설정이며
법적 방류 기준이라고 해석하지 않는다. 공기량은 95개의 15분 전이에 대한
23.75시간 합계다. 전체 폐수처리 성능이나 하루 전력량과 같지 않다.

환경 모델 선택과 이번 비교에는 검증 구간을 사용한다. 최종 평가 구간은
팀 공통 비교를 위해 남겨둔다. 이번 기록은 개인 탐색 실험이며 공통 평가
조건을 바꾸거나 팀의 공식 결과를 채택하는 작업은 아니다.
