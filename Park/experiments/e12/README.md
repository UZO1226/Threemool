# Park/e12: 학습 중에도 최소 개입 차단을 켠 정책 (Kaggle DARROW)

상태: **완료 (2026-11-10). 목표였던 "공기량과 비용을 함께 낮추기" 를 e08 차단 기준으로 달성 (H2 지지, A 와 B 모두 5/5).** e10 기준의 강한 가설(H3) 은 평균 비용 5.51 대 5.46 으로 지지 안 됨, 곡선 전체 비교(H1) 도 지지 안 됨. 가설과 판정 규칙은 학습 결과를 보기 전에 정했고 결과를 본 뒤 바꾸지 않았다.

## 목적

e12 부터 Park 실험의 목표는 **공기량(전기) 을 줄이면서 하루 비용도 함께 낮추는 것** 이다 (사용자 결정, 2026-11-10). 지금까지는 둘을 맞바꿨다.

| 기준 (seed 5개 평균) | 공기량 Nm3/일 | 하루 비용 |
| --- | --- | --- |
| e08 정책 + NH4 규칙 theta 3.0 (Park/e08) | 91,279 | 6.62 |
| e08 정책 + 최소 개입 1스텝 target 3.5 (Park/e10) | 90,747 | 5.46 |
| NH4 규칙을 켜고 학습한 정책 + theta 3.0 (Park/e09) | 82,971 | 8.04 |

e09 에서 학습 중 차단은 공기량을 9% 줄였지만 비용이 올랐고, e10 에서 최소 개입 차단은 같은 공기량에서 비용을 낮췄지만 공기량은 줄이지 못했다. 이 실험은 둘을 합쳐, 최소 개입 차단을 학습 중에도 켠다.

e09 에서는 학습 중 비용이 한도 12 보다 훨씬 낮아 라그랑주 승수가 0 이 되었고, 정책이 수질을 스스로 지키지 않게 됐다. 그래서 학습 비용 한도를 6 으로 낮춘 조건도 함께 본다.

## 공통 평가 조건

`Compare/PROTOCOL.md` v1 을 따른다 (데이터, 분할, 대리 모델, 관측, 행동, 보상, NH4 와 DO 비용, 하루 한도 12, 학습 예산, seed, 검증 200 에피소드). 조건 B 의 학습 비용 한도 6 은 확장 기법의 학습 설정이며, 평가의 비용 정의와 한도 12 는 v1 그대로다. v1 이 요구하는 대로 NH4 위반률과 DO 위반률을 따로 적고, 한도 만족은 에피소드 비율과 seed 평균 비용 <= 12 여부로 함께 본다.

## 조건

데이터, 환경, 학습 설정은 Park/e08 과 같다 (FCSRL + PPO-Lag, 환경 8개 x 760 스텝 x 66 갱신, seed 0 ~ 4). 학습 중 차단은 `min_brake.py` 의 최소 개입 1스텝, 다른 구성원, target 3.5 다 (e10 의 대표 설정). 학습 중 처리 방식은 e09 와 같다 (PPO 확률비는 정책이 뽑은 행동, 보상, 비용, 표현 학습은 실제로 넣은 행동).

| 조건 | 명령 인자 | 학습 비용 한도 |
| --- | --- | --- |
| A | `--min-brake-target 3.5` | 12 |
| B | `--min-brake-target 3.5 --cost-limit 6` | 6 |

`train_darrow.py` 를 바꾼 뒤 `--brake-theta 3.0` 1 갱신 시험이 e09 기록과 같았다.

## 평가

검증 40일 x 구성원 5개 = 200 에피소드, 결정적 행동, 마지막 정책. 각 정책을 차단 없이, 그리고 최소 개입 1스텝 (다른 구성원) target 2.0, 2.5, 3.0, 3.5, 4.0 으로 평가한다. test 는 쓰지 않는다.

## 가설 (사전 등록)

조건 A 와 B 에 각각 같은 가설을 판정한다 (A 가 주 조건). seed 5개 중 3개 이상에서 성립하고 seed 평균도 성립하면 지지로 적는다. 비교 점이 없는 seed 는 성립하지 않은 것으로 센다.

- H1 (주 가설, 더 나은 교환). 최소 개입 곡선(5점) 의 같은 공기량 차이가 기준 곡선 대비 음수다. 기준 곡선은 e08 정책의 차단 없음과 e10 최소 개입 1스텝 5점, 모두 6점의 seed 평균(공기량, 하루 비용) 을 공기량 순으로 이은 것이다
- H2 (둘 다 낮다, e08 차단 기준). target 3.5 에서 공기량 < 91,279 이고 동시에 하루 비용 < 6.62 다. seed 별로 두 조건이 모두 맞아야 성립이고, 평균도 두 조건을 모두 맞아야 한다
- H3 (둘 다 낮다, e10 기준, 강한 가설). target 3.5 에서 공기량 < 90,747 이고 동시에 하루 비용 < 5.46 이다. 판정 방식은 H2 와 같다

차단 없이 평가한 비용(정책이 차단에 기대는 정도) 과 학습 마지막 라그랑주 승수는 보고만 한다. 가설이 기각되는 결과도 그대로 기록한다.

## 미리 밝히는 한계

- e10 과 같은 대리 모델 한계 (예측 정확도 낮음, 차단 모델과 환경 모델이 같은 방법의 구성원, 그 시각의 유입 성분을 안다고 둠)
- 학습 중 차단 target 은 3.5 하나, 낮춘 한도는 6 하나만 본다
- 기준값은 e08 정책 seed 5개의 평균이다. 이 실험의 seed 와 짝지어 비교하지 않는다
- seed 5개, 401,280 전이, 마지막 정책의 탐색적 실험이다

## 실행 명령

```bash
export OMP_NUM_THREADS=1 WANDB_MODE=disabled
cd Park/code
for s in 0 1 2 3 4; do
  python train_darrow.py --method fcsrl --seed $s --data ../data/darrow/darrow_15min.pkl --surrogate ../data/darrow/darrow_surrogate_gbm.pkl --out <결과>/dw_minbrake_runs/A_s$s --min-brake-target 3.5
  python train_darrow.py --method fcsrl --seed $s --data ../data/darrow/darrow_15min.pkl --surrogate ../data/darrow/darrow_surrogate_gbm.pkl --out <결과>/dw_minbrake_runs/B_s$s --min-brake-target 3.5 --cost-limit 6
done
cd ../experiments/e12
for c in A B; do for s in 0 1 2 3 4; do python run_e12.py one --cond $c --seed $s --data ../../data/darrow/darrow_15min.pkl --surrogate ../../data/darrow/darrow_surrogate_gbm.pkl --runs <결과>/dw_minbrake_runs --out <결과>/e12; done; done
python run_e12.py report --out <결과>/e12 --runs <결과>/dw_minbrake_runs --e10 <결과>/e10 --md results.md
```

## 실행 결과

전체 표는 [results.md](results.md). 검증 200 에피소드, 마지막 정책, seed 5개 평균.

### 학습 중 상태

두 조건 모두 학습 중 하루 비용이 마지막 갱신에서 2.16 ~ 4.42 로 한도(12 또는 6) 보다 낮았고, 라그랑주 승수는 10개 정책 모두 0 이었다. 조건 B 의 한도 6 도 한 번도 묶이지 않아, seed 1, 3, 4 는 A 와 B 의 학습이 완전히 같았다 (같은 seed, 승수가 계속 0). A 와 B 는 사실상 같은 조건이다.

### 사전 등록 가설 판정

| 가설 | 조건 A | 조건 B |
| --- | --- | --- |
| H1 같은 공기량 차이 < 0 | 평균 0.00, 1/5, 지지 안 됨 | 평균 -0.24, 2/5, 지지 안 됨 |
| H2 공기량 < 91,279 이고 비용 < 6.62 | 84,031, 5.51, **5/5, 지지** | 83,940, 5.51, **5/5, 지지** |
| H3 공기량 < 90,747 이고 비용 < 5.46 | 84,031, 5.51, 3/5, 지지 안 됨 | 83,940, 5.51, 4/5, 지지 안 됨 |

- H2: 5개 seed 모두 e08 차단보다 공기량이 적고(평균 7.9% 감소) 비용도 낮다 (6.62 에서 5.51).
- H3: 공기량은 5개 seed 모두 e10 보다 적지만(평균 7.4% 감소), 비용은 평균 5.51 로 e10 의 5.46 보다 0.05 높다. 규칙상 평균이 두 조건을 모두 맞아야 하므로 지지하지 않는다.
- H1: target 2.0 ~ 3.0 은 e10 곡선과 비슷하거나 조금 나쁘고, target 4.0 은 크게 나쁘다 (16.85). 학습에 쓴 target 3.5 한 점만 기준 곡선보다 크게 낮다. 곡선 전체로는 더 나은 교환이라고 할 수 없다.

### 해석

- 학습에 쓴 설정(target 3.5) 그대로 차단을 함께 쓰면, e10 과 비용은 거의 같고(5.51 대 5.46) 공기량은 7.4% 적다. 실제 운전 재생과 비교하면 공기량은 1% 적고 비용은 28.77 에서 5.51 이다. Park 실험 중 처음으로 e08 차단 기준에서 공기량과 비용이 함께 낮아졌다.
- e09 와 같은 의존이 생긴다. 라그랑주 승수가 0 이 되어 정책은 공기 절약만 배우고, 차단을 끄면 비용이 34.44, 학습보다 느슨한 target 4.0 이면 16.85 다. 이 정책은 학습 때와 같은 차단과 한 몸으로만 써야 한다.
- 학습 한도를 6 으로 낮춰도 학습 비용이 그보다 낮아 효과가 없었다. 정책이 스스로 수질을 지키게 하려면 한도를 학습 비용(약 2 ~ 4) 보다 낮추거나 개입 자체에 비용을 줘야 한다.

### 한계

- 기준값은 e08 정책 seed 5개의 평균이다. 이 실험의 seed 와 짝지은 비교가 아니다.
- e10 과 같은 대리 모델 한계가 있다. 평가는 검증 구간이다.
- 조건 B 는 의도와 달리 A 와 거의 같아, 학습 한도의 효과는 시험되지 않았다.

### 다음 실험 후보

- 학습 중 차단의 target 을 3.0 이나 2.5 로 낮춰 학습해, 같은 비용에서 공기량이 더 줄어드는지, 또는 같은 공기량에서 비용이 더 낮아지는지 본다 (H3 의 비용 0.05 차이를 넘기기).
- 개입에 작은 비용을 줘 라그랑주 승수가 살아 있게 하고, 차단을 꺼도 덜 무너지는 정책을 만든다.
