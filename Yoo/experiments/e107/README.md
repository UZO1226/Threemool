# e107 폭기 변경 전 수질 관측과 NH4 하락 판별

**현재 NH4 농도에는 이후 하락을 구분하는 정보가 있었다. 직전 1시간의 NH4 추세와 현재 유입량을 더한 이득은 두 기간에 재현되지 않았다.** 세 변수를 함께 쓴 규칙은 겨울 폭기 증가 67건 전부에 보정을 켰다. 학습 뒤 48일에서도 48건 중 47건을 선택했다. 공통 대리 환경을 바꾸거나 정책 평가로 넘어가는 기준은 충족하지 못했다.

## 실측 하락을 예측했는가

목표는 기록된 큰 폭기 변화 뒤 1시간부터 3시간까지 NH4가 0.1 mg N/L 넘게 내려가는 사건이다. 증가와 감소에 구분해서 DARROW 학습 앞 140일에 적합한 로지스틱 회귀를 고정했다. Brier는 예측 확률과 실제 0 또는 1 사이의 평균제곱오차로 작을수록 좋다. AUC는 실제 하락 창을 더 높게 평가하는 순위 지표로 0.5가 무작위 수준이다. 두 지표 모두 날짜에 같은 가중치를 주었다.

| 기간, 폭기 | 실측 하락/전체 | Brier 학습 빈도 | Brier 현재 농도 | Brier 농도+추세+유입 | AUC 농도만 / 세 변수 | 세 변수 선택 | TPR / FPR |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 학습 뒤 48일 증가 | 26/48 | 0.249 | 0.220 | 0.251 | 0.743 / 0.741 | 47/48 | 100.0% / 96.6% |
| 겨울 40일 증가 | 53/67 | 0.182 | 0.158 | 0.150 | 0.704 / 0.702 | 67/67 | 100.0% / 100.0% |
| 학습 뒤 48일 감소 | 17/48 | 0.269 | 0.257 | 0.227 | 0.747 / 0.735 | 2/48 | 5.7% / 0.0% |
| 겨울 40일 감소 | 8/65 | 0.083 | 0.067 | 0.086 | 0.801 / 0.807 | 4/65 | 38.9% / 3.3% |

증가 창의 Brier 차이(세 변수 빼기 농도만)는 학습 뒤 48일 +0.031, 7일 블록 탐색 95% 구간 [−0.019, +0.087], 겨울 −0.008 [−0.053, +0.054]였다. 감소 창에서는 학습 후반에 개선됐지만 겨울에는 악화됐다. 겨울 감소 표본의 실제 하락은 8건뿐이다. 확률 순위와 0.5 문턱에서 실제로 선택한 창 수는 구분해서 볼 필요가 있다. 한 가지 변수를 추가한 두 대조까지 포함한 값은 [수치 파일](summary.json)에 있다.

## 보정을 골라 적용하면 예측 오차가 줄었는가

해당 창 전체에서 세 변수 하락 확률이 0.5 이상일 때만 e106의 0.05 보정 궤적을 사용했다. 모든 조건은 같은 공기와 유입 기록을 재생한다. 아래는 날짜 동일 가중 MAE이며 각 셀은 기본 / 항상 보정 / 선택 보정 순이다.

| 기간, 폭기 | 1~3시간 NH4 변화 (mg N/L) | 3시간 NH4 (mg N/L) | 3시간 최대 DO (mg O₂/L) |
| --- | ---: | ---: | ---: |
| 학습 뒤 48일 증가 | 0.858 / 0.872 / 0.871 | 0.841 / 0.894 / 0.891 | 0.188 / 0.174 / 0.174 |
| 겨울 40일 증가 | 2.043 / 1.841 / 1.841 | 3.116 / 2.776 / 2.776 | 0.630 / 0.608 / 0.608 |
| 학습 뒤 48일 감소 | 0.449 / 0.417 / 0.449 | 0.506 / 0.483 / 0.504 | 0.126 / 0.127 / 0.126 |
| 겨울 40일 감소 | 1.756 / 1.863 / 1.757 | 1.772 / 1.904 / 1.767 | 0.296 / 0.287 / 0.295 |

겨울 감소 창에서는 65건 중 61건에서 기본 모델을 사용해 항상 보정할 때 생기던 3시간 NH4 악화를 피했다. 그러나 1~3시간 변화 오차는 기본보다 소폭 늘었고, 겨울 증가에서는 항상 보정한 것과 동일했다. 학습 뒤 48일의 증가 창에서도 두 NH4 오차가 기본보다 컸다. 이 결과는 특정 선형 판별식과 고정 문턱을 사용한 기록 예측에 한정된다. 정책이 공기를 바꿨을 때의 효과나 실제 공기 절감은 측정하지 않았다.

다음으로는 기존 두 예측 궤적만으로, 결과를 미리 알고 창마다 보정 여부를 고를 때 얻을 수 있는 이득부터 계산할 수 있다. 그 여지가 크면 학습 표적을 실측 하락 여부에서 기본 모델의 예측 오차가 줄어드는지로 바꿀 근거가 생긴다. 여러 수질 지표를 함께 지키며 얻을 수 있는 여지가 작다면 이 보정의 문턱을 더 조절할 이유도 줄어든다.
