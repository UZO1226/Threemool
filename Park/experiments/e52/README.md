# Park/e52: 연속 목적 (초과량) 의 짧은 예측 구간 모델 예측 제어와의 비교 (Kaggle DARROW)

상태: **완료 (2026-11-21). H1 판정 안 함 (맞춤 실패, 검증 공기량 차이 -3.1%).** 가설, 기준, 고르는 규칙은 학습 구간 맞춤과 검증 결과를 보기 전에 정했다 (사전 등록 커밋 `4d76c60`). 대표는 바꾸지 않는다.

## 목적

팀 중간점검 (Yoo/analysis/TEAM_RESEARCH_REVIEW_20261117.md) 6.2 절은 "동일 정보의 짧은 horizon 제어" 와의 분리를 요구했다. Park/e48 은 위반 지표 (0/1) 를 목적으로 쓴 1시간 예측 제어가 대표 공기량에 맞춰지지 않아 판정하지 못했다 (맞춤 실패). 사후 진단으로는 1시간 안에 위반을 피할 수 없으면 모든 후보의 위반 항이 같아져 공기가 가장 적은 후보를 고른다.

이 실험은 같은 제어기에서 목적만 초과량 (연속) 으로 바꿔 e48 의 열린 질문 "같은 정보와 같은 공기량에서 학습 정책이 모델 예측 제어 위에 더하는 몫이 있는가" 를 다시 본다. 기준을 바꾸는 것이므로 새로 사전 등록한다.

## 기준: 초과량 예측 제어 (`Park/code/mpc_darrow.py`, `objective='excess'`)

- 정보, 예측 구간 (4 스텝, 1시간), 후보 (u0 500 간격, u1 1,500 간격) 는 Park/e48 과 같다
- 목적: 4 스텝 동안 [max(NH4 + 여유 - 4, 0) + max(구간 DO 최댓값 - 1.8, 0) + 공기 가중치 x 공기량 / 9,000] 의 합. 피할 수 없는 위반 앞에서도 공기를 더 넣으면 목적이 줄어든다
- 손잡이: NH4 여유 (0, 0.4, 0.8, 1.2, 1.6) x 공기 가중치 (0.01, 0.05, 0.2, 1), 20 조합
- 격자 범위를 정하려고 학습 구간 2일로 미리 돌려 봤다 (여유 0.2 에서 가중치 0.01 이 공기량 66,500, 1 이 62,413). 공기량을 움직이는 손잡이는 여유라서 여유를 1.6 까지 넓혔다. 검증 구간은 보지 않았다

## 고르기 (학습 구간 마지막 40일 x 구성원 5개)

Park/e43, e48 과 같은 규칙이다. 대표의 학습 구간 공기량 (73,345) 의 ±2% 안에서 하루 비용이 가장 낮은 조합을 고른다. 없으면 공기량이 가장 가까운 조합을 고른다.

## 평가

검증 40일 x 구성원 5개 = 200 에피소드, 결정적. test 는 쓰지 않는다. 대표는 Park/e35 orig 의 묶음 5개 값을 쓴다.

## 가설 (사전 등록)

- H1. 고른 예측 제어의 검증 공기량이 대표 평균의 ±3% 안이고, 대표 묶음의 하루 비용이 예측 제어보다 낮은 묶음이 5개 중 4개 이상이며 평균도 낮다. 공기량이 ±3% 밖이면 판정하지 않고 "맞춤 실패" 로 적는다

참고 (판정 없음): 예측 제어 대 차단만, ABAC (Park/e43 값), Park/e48 지표 목적과의 차이.

## RESULT.md 처리 (미리 정함)

대표 방법은 바꾸지 않는다.

- H1 지지: "같은 정보와 같은 공기량에서 대표가 1시간 초과량 예측 제어보다 하루 비용이 낮다. 학습 정책이 모델 예측 제어 위에 더하는 몫이 있다" 고 적는다
- H1 기각: "같은 정보의 1시간 예측 제어가 학습 정책 없이 대표만큼 (또는 더 잘) 한다" 고 한계에 적고, 예측 제어가 대표보다 4/5 이상 낮고 평균도 낮으면 대표를 바꿀지는 팀과 정한다 (Park 혼자 정하지 않음)
- 맞춤 실패: 값을 참고로 적고 판정은 하지 않았다고 적는다

## 미리 밝히는 한계

- 예측 제어는 단순한 격자 탐색 (이동 묶음 2 단계, 1시간) 이다. 더 긴 예측 구간이나 연속 최적화는 보지 않는다
- 손잡이는 20 조합에서 고르고 대표는 다시 고르지 않는다. 고르기는 예측 제어에 유리한 쪽이다
- 예측 제어는 대표 차단과 같은 대리 모델 계열을 쓰고 환경도 같은 계열이다
- 대표는 묶음 5개, 예측 제어는 결정적 제어기 하나다. 검증 구간은 e10 부터 반복해서 썼다

## 결과

- H1: 검증 공기량 차이가 -3.1% 로 사전 등록 허용폭 (±3%) 을 넘어 **판정하지 않았다 (맞춤 실패)**. 참고로 대표 비용은 5개 묶음 모두 예측 제어보다 낮고, 평균 차이는 -2.067 (95% 신뢰구간 -2.136 ~ -1.998) 이다
- 참고: 초과량 목적은 지표 목적 (Park/e48) 의 맞춤 실패를 크게 줄였다 (공기량 차이 -21.8% 에서 -3.1%, 비용 20.820 에서 6.725)

## 해석

- 사전 등록 처리에 따라 값을 참고로 적고 판정은 하지 않았다고 적는다. "같은 정보와 같은 공기량에서 학습 정책이 예측 제어 위에 더하는 몫" 은 이번에도 판정되지 않았다
- 사후 관찰 (판정 없음): 예측 제어의 하루 비용은 학습 구간 3.285 에서 검증 6.725 로, NH4 위반은 2.43% 에서 6.52% 로 크게 올랐다. 같은 학습 구간에서 고른 ABAC (4.000 에서 5.450) 보다 오름폭이 크다. 공기량 차이 3.1% 만으로 설명하기 어려운 크기라, 1시간 예측 제어는 학습 구간에 맞춘 손잡이가 검증 구간으로 덜 옮겨 가는 것으로 보인다 (확인하지 않음)
- 사후 관찰 (판정 없음): 예측 제어의 검증 공기량 79,564 는 차단만 곡선 (Park/e43, 79,670 ~ 86,369) 의 최소 공기 점과 비슷한데, 비용은 차단만보다 1.6 높다
