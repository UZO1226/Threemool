# e39: 학습과 분리한 날짜로 DARROW NH4 위험 판정 보정

## 가설과 사전 조건

e38은 NH4 이력 입력으로 오차/FPR/위험 순위가 개선됐지만 고정 농도 판정의 탐지율이 떨어졌다. 검증 정답으로 판정점을 고른 사후 결과 대신, 모델 학습에 쓰지 않은 날짜로 보정해도 개선이 유지되는지 확인한다. DARROW만 사용하고 공기/NH4/DO 동시 개선 목적을 유지한다.

- 기존 train188일의 앞140일은 전이 모델 학습, 뒤48일은 보정, 기존 val40일은 최종 이번 대조 평가에 사용한다. 반복 사용한 개발val이며 독립 최종test라고 부르지 않는다. test41일은 평가하지 않는다.
- NH4뿐 아니라 NO3/DO 모델과clipping 상한도140일로 다시 학습한다. 같은140일로 기존24입력모델25개와 NH4이력44입력모델5개를 맞춘다. 이력유무 비교의다른20개 상태 모델은 공유한다. e38의188일 모델 수치와 직접 성능 증감을 비교하지 않는다.
- 데이터 준비는 e30 그대로며 online 결측 대체는 없었다. 전이 입력은실제 구간 공기량을 사용해188일로 정한 구간배분중앙값을 쓰지 않는다. 보조 유입은원래보간한합성자료로 유지한다. 모든 예측은기록된미래행동/외생입력을 재생하는조건부예측이다.
- 보정용48일에서 각 모델의95전이 자기반복 NH4 예측값을 입력, 실측NH4>4 여부를 정답으로 isotonic 단조 확률 보정을 학습한다. 모델 구성원은독립seed표본으로 해석하지 않는다. 보정은판정확률만바꾸며 농도상태나후속전이를바꾸지않는다.
- 주 판정점은보정자료에서탐지율80%이상을달성하는가장높은확률경계(해당범위최소FPR)다. 별도보조판정은FPR10%이하에서최대탐지율이다. 두 규칙을미리고정하고검증결과로유리한프로필을고르지않는다.
- 보정기와판정점을저장/해시고정한뒤val을평가한다. 4조건은기존/이력각각보정전/후다. 보정전은예측NH4>4, 보정후는고정확률경계다. 실제위반기준NH4>4와비용한도는유지한다.
- 검증에서실제달성한탐지율은다를수있으므로이를동일탐지율비교라고부르지않는다. 두모델의보정된주조건에서이력의탐지율이낮지않고FPR이높지않으며하나이상개선되는지, 목표80%도달여부를함께보고한다. 날짜7일블록bootstrap2000회는탐색적불확실성으로보고한다.
- e37고정구간중공기감소후실제NH4가0.1mg/L넘게상승한구간의위반탐지도15/60/180분별공개한다. 미래상승여부는평가부분집합에만사용하며보정/모델입력에는쓰지않는다. 정상/위반표본이없는조건은해당지표를미정의로보고한다.
- DO는보정하지않는다. 모델간DO예측/탐지는보고하되보정만으로DO문제가해결됐다고주장하지않는다. 농도예측오차와반응궤적은보정전후같다. 새RL학습/채택은없다.

### 주 비교: 보정에서 탐지율80%를 목표로 고정한 판정

| 조건 | 검증 NH4 탐지율 % | 검증 FPR % | 평균 예측 위반 표본 수 (실측16.45) |
| --- | --- | --- | --- |
| 기존 모델 | 90.09 | 67.03 | 67.47 |
| 기존 + 보정 | 97.45 | 93.63 | 89.58 |
| 이력 모델 | 35.41 | 13.14 | 16.145 |
| 이력 + 보정 | 73.65 | 43.81 | 46.53 |

이력 보정은탐지율을올렸지만FPR도늘렸다. 기존보정보다FPR은낮으나탐지율도낮아두지표동시우위가아니다. 보정의80%목표도검증에서는달성하지못했다. 모델이예측한평균위반수16.145가실측16.45와가깝다는것도위반시점을정확히맞혔다는뜻이아니다.

주 프로필의보정구간탐지율은기존95.76%,이력80.81%였다. 두모델의실제달성탐지율이달라동일탐지율비교로부르지않는다. 확률값의동점때문에기존모델은80%를조금넘는지점대신크게넘는지점을선택했다.

보조FPR10%조건은두모델모두경보없음(탐지율0/FPR0)이었다. 잘못된안전성공으로세지않는다. 비용한도와판정규칙을사후완화하지않았다.

### 왜 실패했는지 확인된 단서

| 구간 | NH4 실측 위반률 | 평균 수온 | NH4 위반이 있는 날짜 |
| --- | --- | --- | --- |
| 모델 학습140일 | 5.71% | 20.10℃ | 67/140 |
| 보정48일 | 6.51% | 18.59℃ | 17/48 |
| 검증40일 | 17.32% | 15.96℃ | 37/40 |

보정과검증의위반빈도/운전조건이달랐다. 이차이가실패의얼마를설명하는지인과적으로분해한것은아니지만, 한구간의판정규칙이뒤기간에도그대로맞을거라고가정할수없음을보여준다.

이력모델의단조보정은예측점수를20가지확률로묶었다. 가장높은확률묶음만경보해도보정자료FPR10.0774%로고정10%를넘어, 그다음선택지는경보없음이었다. **원래연속점수를그대로사용하면같은보정자료에서FPR9.998%,탐지율61.08%가가능했다.** 이사후점검은보정함수의동점이보조실패에기여했음을보여주며, 해당연속점수판정점을검증에적용하거나성공조건으로채택하지않았다. 따라서 "FPR10%에서탐지는원천적으로불가능하다"고결론내리지않는다.

### 변화하지 않은 한계

보정은위험판정만바꿔물리농도예측과기록공기량은같다. 검증NH4 MAE는기존5.838,이력2.043이고위반판정보정전후변하지않는다. DO탐지율은두모델모두0%다. 이력의DO1 MAE0.2557은기존0.2481보다높고DO FPR도1.555%→1.565%로소폭높다. 모든환경/제어지표를개선한결과가아니다.

검증의원예측점수AUC는기존0.635,이력0.700으로이력정보는여전히유용한후보지만, 낮은오차나높은순위점수만으로현재보정기를채택하지않는다. 보정 후AUC는기존0.624,이력0.699다.

## 다음 결정

1. 이번isotonic보정기와판정점은채택하지않는다. 기존환경을덮어쓰거나새RL학습을시작하지않았다. DARROW공기/NH4/DO동시개선은미달성이다.
2. 이력정보와원래연속위험점수는보존한다. 다음최소대조후보는같은보정날짜에서연속점수를보존해판정점을선택하는방식이다. 확률보정의동점문제와예측정보자체의한계를분리할수있고추가환경학습은필요없다. 이번주평가결과를해당사후대조로대체하지않는다.
3. 단순판정규칙이기간변화에도유지되는지는별도문제다. 그뒤필요하다면시간블록교차예측으로보정자료의운전조건범위를넓히는대조를검토한다. 판정법변경과학습/보정분할변경을한번에섞지않는다.
4. 이런판정보정은공기감소후NH4상승예측이나DO검출을자동해결하지않는다. 제어정책의모든지표개선은그문제까지확인한뒤평가해야한다. 위후속대조는아직실행하지않았다.
