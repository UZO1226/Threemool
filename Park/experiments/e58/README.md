# Park/e58: 같은 차단 위의 예측 제어와의 같은 공기량 비교 (Kaggle DARROW)

상태: **완료 (2026-11-21). H1 기각 (대표가 낮은 묶음 0/5, 곡선 범위 밖 3개).** 손잡이 값, 곡선 규칙, 가설은 검증 구간을 돌리기 전에 정했다 (사전 등록 커밋 `0fc85ff`). 대표는 바꾸지 않는다.

## 목적

Park/e55 주장 지도에서 대표 이득의 대부분 (0.46) 은 "차단 위에서 학습한 정책" 의 몫이다. 그런데 그 몫이 학습 때문인지, 차단 위에 무엇이든 계획하는 제어기를 올리면 생기는 것인지는 Park/e48, e52 의 맞춤 실패로 판정하지 못했다. 이 실험은 학습 정책 자리에 1시간 예측 제어를 넣고 대표와 같은 차단을 씌워, "차단 위의 학습 정책" 과 "차단 위의 계획기" 를 같은 공기량에서 비교한다. 공기량은 Park/e56 과 같은 검증 구간 곡선으로 맞춘다. 이 문제를 푸는 세 가지 길 (e56 곡선, e57 직접 맞춤, e58 같은 차단 위의 예측 제어) 가운데 하나다.

## 방법

- 기준: `ShortMPC` (`objective='excess'`, NH4 여유 1.2, 1시간, 후보는 e52 와 같음) 의 행동에 대표 차단 (`MinAirBrake(dyn, 3.5, 1, 'others', **BRAKE)`, Park/e38 의 BRAKE) 을 씌운다. 정책만 바뀌고 차단, 정보, 대리 모델은 대표와 같다
- 공기 가중치: 1.5, 1.0, 0.7, 0.5, 0.35, 0.2, 0.1 (7개)
- 곡선과 판정 규칙은 Park/e56 과 같다 (지배되는 점을 빼고 선형 보간, 범위 밖 묶음은 "대표가 낮지 않음")
- 손잡이 범위는 학습 구간 4일 (마지막 40일에서 10일 간격) 사전 점검으로 정했다 (차단을 씌운 NH4 여유 1.2 에서 공기 가중치 0.2, 1.0, 3.0 의 공기량 87,038, 80,231, 65,631). 검증 구간은 보지 않았다
- 대표는 Park/e35 orig 의 묶음 5개 값을 쓴다

## 이 비교가 누구에게 유리한가

e56 과 같이 예측 제어는 검증 구간에서 손잡이를 바꿔 곡선을 만들고 대표는 다시 고르지 않으므로 예측 제어에 유리하다.

## 평가

검증 40일 x 구성원 5개 = 200 에피소드, 결정적. test 는 쓰지 않는다.

## 가설 (사전 등록)

- H1. 대표 묶음 5개 모두 공기량이 곡선 범위 안이고, 대표의 하루 비용이 같은 공기량의 "차단 + 예측 제어" 곡선 비용보다 낮은 묶음이 5개 중 4개 이상이며 평균도 낮다

참고 (판정 없음): 차단 개입률, 차단만과 ABAC 의 공기량에서의 곡선 비용, Park/e56 의 차단 없는 곡선과의 차이.

## RESULT.md 처리 (미리 정함)

대표 방법은 바꾸지 않는다.

- H1 지지: "같은 차단 위에서 학습 정책이 1시간 예측 제어보다 같은 공기량에서 하루 비용이 낮다. 차단 위 학습 정책의 몫은 계획기로 대신되지 않는다" 고 적는다
- H1 기각: "같은 차단 위에서는 1시간 예측 제어가 학습 정책만큼 한다" 고 한계에 적고, 기여 분리의 "학습 정책 0.46" 을 "차단 위의 제어기 0.46" 으로 고친다. 예측 제어가 4/5 이상 낮으면 대표를 바꿀지는 팀과 정한다

## 미리 밝히는 한계

- 곡선은 7개 점의 선형 보간이다
- 예측 제어의 NH4 여유는 차단이 없는 Park/e52 에서 고른 값이다. 차단 위에서는 다른 여유가 더 나을 수 있다
- 예측 제어와 차단은 같은 대리 모델 계열을 쓰고 환경도 같은 계열이다. 검증 구간은 e10 부터 반복해서 썼다

## 해석

- 사전 등록 처리에 따라 "같은 차단 위에서는 1시간 예측 제어가 학습 정책만큼 한다" 고 한계에 적고, 기여 분리의 "학습 정책 0.46" 을 "차단 위의 제어기 0.46" 으로 고친다. 예측 제어가 대표보다 낮다고 판정된 묶음은 2개뿐이라 (3개는 범위 밖) 사전 등록 규칙의 "4/5 이상 낮음" 에는 닿지 않아 대표 교체를 팀에 올리는 조건은 아니다. 다만 공기량이 같은 점에서 0.23 낮다는 참고 결과는 함께 알린다
- Park/e56 (차단 없는 예측 제어에는 대표가 1.6 낮음) 과 합치면, 대표 이득의 큰 부분은 "학습" 이 아니라 "대표 차단" 과 "그 위에서 공기를 덜 쓰려는 제어기" 의 조합에서 온다. 학습 정책이 같은 차단 위의 1시간 계획기보다 낫다는 근거는 없다
- 사후 관찰 (판정 없음): 차단 위 예측 제어는 공기 가중치를 1.5 까지 올려도 공기량이 82,000 아래로 내려가지 않고, 가중치 1.0 ~ 0.35 에서 비용이 거의 변하지 않는다. 차단이 NH4 쪽을 지키므로 예측 제어의 여유 1.2 가 공기를 과하게 넣는 것으로 보인다. 더 작은 여유나 더 큰 가중치에서 대표 공기량 아래까지 곡선을 늘리면 나머지 3개 묶음도 판정할 수 있다 (다음 후보)
