# e84 기존 FCSRL 실행 방식 조합의 공기 절감 상한

e81~83의 고정 보정은 기본 FCSRL 대비 공기와 세 수질 지표 공동 개선 0/5였다. 완벽한 선택이라도 불가능한지, 최초 증량과 후속 회수 중 어느 결정에 개선 여지가 있는지 검사한다. 이 실험은 이미 본 겨울 개발 궤적의 사후 상한을 계산한다. 미래를 보지 않는 제어기의 성능으로 해석할 수 없다.

| 결정 | 근거 | 적용 및 검산 |
| --- | --- | --- |
| 고정 방식과 사례별 최선의 선택 비교 | Bischl 등, ASlib 4절 및 각주 5,6의 virtual best solver와 single best solver. [원문](https://ada.liacs.nl/papers/BisEtAl15.pdf) | 기존 정책 실행 4개의 같은 에피소드 결과만 사용한다. 수질 제약을 공유하므로 전 기간 조건은 사례별 독립 최솟값 대신 결합 최적화한다. |
| 이산 실행 하나 선택 | [SciPy 1.17.1 공식 구현](https://github.com/scipy/scipy/blob/v1.17.1/scipy/optimize/_milp.py), milp의 integrality, bounds, LinearConstraint, HiGHS 반환 상태 및 mip_dual_bound. | seed별로 합산 공기를 최소화한다. 원시 궤적으로 해의 모든 지표 재계산, 이중 경계와 정수해 대조, 작은 사례 완전열거 검산. 불가능 또는 정밀도 미달을 구분한다. |
| 중복 대조 | main c723568의 Lee/Park README와 RESULT, Lee 후속 ACTIVE_GOAL, Yoo/e75, e82, e83. 열린 PR 없음. | e75는 ABAC 대비 CEM으로 새 행동열을 찾았고 e82는 회수 전에 관측한 변수로 판별했다. 여기서는 동결 FCSRL 실행 경로의 선택 가능 집합만 바꾼다. |

- 겨울 40일, 5개 GBM 구성원, seed 0~4. 같은 시작 상태, 구성원, 외생 시계열의 저장된 95전이 경로만 사용한다. 선택 A는 pulse, recover, limited 중 하나, 선택 B는 A에 base를 추가한다. pulse는 e81 규칙에 따라 적격이면 최초 증량 후 기본 정책을 따르고 recover는 회수를 허용하며 limited는 e83 상승 제한을 추가한다. base는 최초 증량을 생략한 경로다. 하루 중 다른 경로의 스텝을 짜깁기하지 않는다.
- 각각 세 가지 정보 및 수질 조건을 고정한다. (1) 모의 에피소드별로 자유롭게 고르고 겨울 평균 수질 제약, (2) 같은 날짜의 5개 모델에 같은 실행 방식을 고르고 겨울 평균 수질 제약, (3) 날짜별 같은 방식을 고르며 매 날짜의 모델 평균 수질 세 지표를 각각 기본 이하로 유지한다. 세 지표는 NH4 초과 스텝 수, DO 초과 스텝 수, NH4 초과 농도 적분이다. (3)은 날짜마다 허용 가능한 최소 공기를 직접 열거한다. 하루라도 불가능하면 40일 해는 불가능이다. B는 기본 경로를 포함하므로 항상 가능하다.
- 고정 base 대비 하루 절감 m³와 %, 3개 수질 차이, 악화된 날짜 수(날짜별 모델 평균 세 지표 중 하나라도 증가), 5개 seed를 보고한다. 제약 허용오차는 지표 평균 1e-8, 공기 절감도 그보다 커야 개선이다. 최적화는 실제 0을 우변으로 쓰고 수치 검산에만 오차를 허용한다. 최적성이 확인되면 상한, 종료 한계가 있으면 가능한 해와 검증된 경계를 분리해서 보고한다. 불가능한 seed를 빼고 5개 평균을 내지 않는다.
- A와 B의 차이는 처음부터 증량을 생략하는 선택지를 추가한 한계 가치다. (1)과 (2)는 구성원별 선택의 낙관성, (2)와 (3)은 날짜 사이 수질 상쇄에 대한 의존도를 나타낸다. 대리 모델 밖, 다른 제어 입력, 미사용 날짜의 상한이 아니다. 새 FCSRL 학습과 시험 평가는 없다.
