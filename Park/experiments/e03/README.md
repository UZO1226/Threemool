# Park/e03: F 조기 경보의 학습 표본 밖 확인과 단순 예측기 비교

상태: **완료 (2026-11-09). H1 지지, H2 와 H3 지지 안 됨.** 아래 규칙은 실행 전에 정했고 결과를 본 뒤 바꾸지 않았다.

## 목적

Park/e02 에서 F 는 위반 1시간 전 경보 AUROC 약 0.99 로 NH4 측정값(약 0.73) 을 크게 앞섰다. 그러나 (1) F 가 학습한 날짜에서 잰 값이고, (2) BSM1 건기 유입은 하루 주기가 뚜렷해서 시각과 유입만으로도 위반 시점을 맞힐 수 있다. 이 실험은 두 가지를 확인한다.

1. 학습에 쓰지 않은 구간(평가 구간 건기, 우기) 에서도 F 의 조기 경보가 유지되는가
2. 같은 관측을 쓰는 단순 예측기보다 F 가 나은가

## 바꾸는 것

새로 학습하지 않는다. Park/e02 의 정책 9개 (gamma_F 0.9, 0.97, 0.99 x seed 0, 1, 2) 를 그대로 쓰고, 평가 방법만 바꾼다.

## 자료

| 이름 | 내용 | 쓰임 |
| --- | --- | --- |
| 학습 날짜 | 건기 0 ~ 6일, 각 날 시작 상태에서 하루씩, 차단 없음 (e02 와 같음) | 단순 예측기 맞춤 |
| 평가 건기 | 공통 시작 상태에서 건기 14일 연속 운전, 후반 7일 (스텝 2017 ~ 4032), 차단 없음 | 주 판정 |
| 평가 우기 | 같은 방식, 우기 유입 | 보조 (판정하지 않고 보고) |

모든 자료는 같은 정책이 스스로 만든 궤적이다.

## 정답과 점수

- 대상 스텝: 현재 스텝이 위반이 아닌 스텝. 평가 자료는 후반 7일 안에서 t+H 가 운전 끝을 넘지 않는 스텝
- 정답: t+1 ~ t+H 안에 위반 스텝이 있는가. 주 판정 H = 12 (1시간), 보조 H = 24
- 점수 4가지
  - F: F(s_t, a_t)
  - NH4: 현재 NH4 측정값 (관측 0번)
  - 시각과 유입: 로지스틱 회귀. 입력은 하루 중 시각의 sin, cos (1, 2, 3배 주기, 6개) 와 유입 부유물, 유입 NH4, 유입 유량 (관측 5, 6, 7번). 모두 9개
  - 관측 전체: 로지스틱 회귀. 입력은 관측 11개 전체와 위 2, 3배 주기 sin, cos 4개. 모두 15개
- 로지스틱 회귀는 seed 와 gamma_F 마다, 그 정책의 학습 날짜 자료(같은 정답 정의, H 별) 로 맞춘다. 입력은 학습 날짜 평균과 표준편차로 표준화하고 L2 계수 1e-3 으로 뉴턴법 50회 맞춘다. 평가 자료로는 맞추지 않는다
- 지표: AUROC

## 가설 (사전 등록)

주 판정은 팀 기준 설정과 같은 gamma_F = 0.9 정책에서, 평가 건기 H = 12 로 한다. 각 가설은 seed 3개 중 2개 이상에서 성립하고 seed 평균도 성립하면 지지로 적는다. gamma_F 0.97, 0.99, 우기, H = 24 는 같은 표로 보고만 한다.

- H1. 평가 건기에서 F 의 AUROC 가 NH4 측정값보다 높다 (학습 표본 밖에서도 e02 결과가 유지된다)
- H2 (주 가설). F 의 AUROC 가 시각과 유입 로지스틱 회귀보다 높다 (F 가 하루 주기 이상의 정보를 쓴다)
- H3. F 의 AUROC 가 관측 전체 로지스틱 회귀보다 높다 (F 가 같은 입력의 선형 예측기보다 낫다)

가설이 기각되는 결과도 그대로 기록한다.

## 미리 밝히는 한계

- 평가 건기는 학습 날짜와 다른 날짜지만 같은 건기 유입 파일의 후반부다. 날씨 종류가 바뀌는 확인은 우기뿐이며 우기는 판정하지 않는다
- F 는 정책 학습 중 표현과 함께 학습됐고, 로지스틱 회귀는 학습 날짜 하루 7개로 맞췄다. 맞추는 자료의 양이 다르다
- 위반을 미리 알아채는 것과 막는 것은 다르다. 이 실험은 예측만 본다

## 실행 명령

```bash
cd Park/experiments/e03
export BSM1_ARCHIVE=<BSM1.zip> WANDB_MODE=disabled OMP_NUM_THREADS=1
for g in 0.9 0.97 0.99; do for s in 0 1 2; do
  python run_e03.py one --gamma $g --seed $s --prepared <결과>/prepared --runs <결과>/runs --out <결과>/e03
done; done
python run_e03.py report --out <결과>/e03 --md results.md
```

정책과 환경은 Park/e02 와 같다. 새 학습은 없다.

## 실행 결과

전체 표는 [results.md](results.md). 1시간 조기 경보 AUROC, seed 평균:

| 자료 | gamma_F | F | NH4 측정값 | 시각과 유입 | 관측 전체 |
| --- | --- | --- | --- | --- | --- |
| 학습 날짜 | 0.9 | 0.990 | 0.728 | 0.989 | 1.000 |
| 평가 건기 | 0.9 | 0.937 | 0.784 | 0.957 | 0.998 |
| 평가 건기 | 0.97 | 0.953 | 0.800 | 0.948 | 0.997 |
| 평가 건기 | 0.99 | 0.945 | 0.803 | 0.939 | 0.996 |
| 평가 우기 | 0.9 | 0.830 | 0.770 | 0.817 | 0.906 |

### 사전 등록 가설 판정 (gamma_F 0.9, 평가 건기, H = 12)

- H1 지지. F 0.937 대 NH4 측정값 0.784, 세 seed 모두 F 가 높다. 학습 표본 밖에서도 F 는 현재 NH4 보다 위반을 미리 알아챈다.
- H2 지지 안 됨. 시각과 유입만 쓰는 로지스틱 회귀가 0.957 로 F 보다 높았다 (F 가 높은 seed 1/3).
- H3 지지 안 됨. 관측 전체 로지스틱 회귀가 0.998 로 세 seed 모두 F 보다 높았다.

### 해석

- e02 에서 본 F 의 조기 경보 능력은 대부분 하루 주기와 유입 정보로 설명된다. 같은 관측을 쓰는 선형 예측기가 F 보다 정확하다. 이 조건에서 FCSRL 의 feasibility 점수는 위반 예측기로서 고유한 이점을 보이지 않았다.
- 학습 표본 밖으로 가면 F 가 단순 예측기보다 더 많이 떨어진다 (건기 0.990 에서 0.937, 우기 0.830). seed 2 는 건기에서 0.855 로 낮았다.
- 그래서 e02 의 같은 에너지 비교에서 F 차단이 NH4 규칙보다 나았던 것도, 더 정확한 예측기로 차단하면 더 커질 수 있는 효과로 보인다. 이 추측은 아직 시험하지 않았다.

### 한계

- 로지스틱 회귀는 매 정책의 학습 날짜 궤적으로 맞췄고, 평가 구간은 같은 정책이 만든 궤적이다. 위반 시점이 정책에 따라 달라도 같은 정책 안의 비교라 공정하지만, 결과는 이 BSM1 건기 유입처럼 주기가 뚜렷한 조건에 묶인다.
- F 는 10 갱신 동안 표현과 함께 학습됐다. 더 오래 학습하면 달라질 수 있다.
- 우기는 판정하지 않았다. 우기에서도 관측 전체 회귀가 가장 높았다 (0.906).

### 다음 실험 후보

- 관측 전체 로지스틱 회귀를 차단 신호로 써서, F 차단과 같은 에너지에서 비교한다. 예측 정확도 차이가 실제 위반 감소로 이어지는지 확인한다.
