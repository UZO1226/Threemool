# e38: DARROW NH4 전이에 직전1시간 수질 이력 추가

## 가설과 고정 조건

e37에서 NH4 반응 크기의 재현이 부족했고 공기 변화 전 수질 추세도 크게 달랐다. 현재 상태만으로 부족한 시간 정보를 추가하면 NH4 반복 예측이 개선되는지 한 조건만 대조한다. 이것은 원인으로 확정된 사실이 아니라 후보 가설이다. DARROW만 사용하며 FCSRL 적용/확장의 큰 방향은 유지한다.

변경은 NH4 GBM의 입력에15/30/45/60분 전 NH4, NO3, DO1~3을 추가하는 것이다. 24개 기존 입력에20개를 더해44개다. NH4 모델5개만 재학습하고 NO3/DO 모델, clipping 상한, 기록 행동/외생 입력과 모든 정책은 고정한다. NH4 공기량 단조 제약은 유지하고 추가 이력에는 단조 제약을 걸지 않는다. 후보 파일은 이력 어댑터가 필요한 별도 형식이며 기존 환경에 자동 대입하지 않는다.

## 사전 평가 원칙

- train188일의 모든95전이를 사용해 기존과 동일한 표본 수, 구성원별80%추출, GBM 설정과 조기종료 난수를 유지한다. 기존 NH4 입력24개로 재학습해 원 모델 예측이 정확히 재현되는지도 확인한다. 외부 val로 튜닝하지 않는다.
- 날짜 초반에 없는 이력은 그날 첫 상태를 반복한다. 학습과 초기화 모두 같은 규칙이다. 최근 이력부터 오래된 순서로 정렬한다.
- val40일에서1스텝 실측 이력 예측, 주 평가인 첫 시각 초기화95전이, 보조 평가인 첫1시간 관측 후91전이를 구분한다. 서로 다른 길이의 수치를 직접 비교하지 않는다. 보조 평가의 미래 관측을 주 평가에 넣지 않는다.
- e37의132개 공기 변화 구간도 그대로 재평가한다. 시작 전 이력만 실측으로 주고 반복 예측 중에는 자신이 예측한 상태로 이력을 갱신한다.
- 모델 교체 후보의 점추정 선별 기준은 주 평가 NH4 MAE 감소, NH4 recall 비감소/FPR 비증가, DO1~3 MAE 비증가와 DO recall 비감소/FPR 비증가, 공기 증가/감소 양쪽15/60/180분 NH4 반응 MAE 비증가다. 작은 상충도 숨기지 않도록 허용폭0의 보수적 선별을 사용하며, 미통과가 실용적 무가치의 증명은 아니다. 날짜7일 블록 불확실성도 공개한다. 사후 기준을 완화하지 않는다.
- 선별을 통과해도 인과적 제어 효과나 공기/NH4/DO 동시 개선 성공이 입증되는 것은 아니다. 정책 학습과test41일 평가는 하지 않는다. reward와 연구 제약도 변경하지 않는다.

자료/기본 환경은 e30 준비 자료와 e35 수정 환경이다. 원본 준비/체크포인트는 변경하지 않는다. 정확한 코드 커밋, 입력 및 후보 SHA256은 manifest.json, 조건은 protocol.json에 저장한다. CPU1스레드와 기존 Python3.10/cu130 가상환경을 사용한다.
