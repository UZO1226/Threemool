# Park/e49: 날짜 블록을 고려한 불확실성 (Kaggle DARROW)

상태: **사전 등록 (2026-11-20).** 가설과 판정 규칙은 날짜 블록 계산을 하기 전에 정했다. 새 학습과 새 평가는 없고 Park/e44, e45 의 스텝 기록만 다시 셈한다. 대표는 바꾸지 않는다.

## 목적

팀 중간점검 (Yoo/analysis/TEAM_RESEARCH_REVIEW_20261117.md) 8절의 통계 계획은 "정책 학습 seed, 평가 날짜, 모델 구성원, 앙상블 조합의 단위를 구분" 하고 "날짜 일반화 불확실성은 날짜 블록을 고려해 별도로 평가" 하라고 했다.

Park 의 지금까지 신뢰구간 (Park/e35 ~ e47) 은 앙상블 묶음 5개의 t 구간이다. 이 구간은 같은 검증 40일을 고정하고 학습 seed 의 흔들림만 본다. 날짜가 바뀌면 이득이 얼마나 흔들리는지는 보지 않았다. Park/e45 는 대표 비용의 71% 가 4일에 몰려 있다고 보고했으므로 (이 실험 전에 본 값), 날짜 단위 불확실성이 더 클 수 있다.

## 방법

- 자료: 대표 (FCSRL 4 x 16 + 대표 차단, 묶음 5개, Park/e44 스텝 기록), Park/e43 이 고른 ABAC 와 차단만, 기본 PPO-Lag 와 FCSRL (차단 없음, seed 5개) (Park/e45 스텝 기록). 모두 검증 40일 x 구성원 5개
- 날짜마다 구성원 5개 평균 하루 비용과 공기량을 낸다 (대표는 묶음 5개도 평균). 대표와 기준을 날짜 단위로 짝지어 뺀다
- 날짜 블록 구간: 검증 40일 (2021-11-10 ~ 12-19, 끊김 없음) 을 이어진 5일 블록으로 원형 이동 블록 다시 뽑기 10,000번 (seed 0), 날짜 평균 차이의 95% 백분위 구간. 블록 길이 5일은 공정 부하의 자기상관을 며칠 단위로 보고 미리 정했다
- 참고로 날짜를 하나씩 독립으로 뽑은 구간과 기존 묶음 단위 t 구간을 함께 적는다

## 가설 (사전 등록)

- H1. 대표 빼기 ABAC 의 날짜 평균 하루 비용 차이의 블록 95% 구간 상한이 0 보다 작다
- H2. 대표 빼기 차단만에 대해 같은 규칙
- H3 (이득이 며칠에만 몰려 있는가). 대표의 ABAC 대비 이득이 가장 큰 4일 (10%) 을 뺀 36일에서도 대표 빼기 ABAC 의 평균이 0 보다 작고 블록 95% 구간 상한이 0 보다 작다

참고 (판정 없음): 기본 PPO-Lag, FCSRL 과의 같은 비교, 공기량 차이의 블록 구간, 대표가 나은 날 수, 이득이 큰 4일의 몫, 날짜별 비용 표.

## RESULT.md 처리 (미리 정함)

대표 방법은 바꾸지 않는다.

- H1, H2 지지: "대표의 기준 대비 비용 이득은 검증 날짜를 다시 뽑아도 0 을 넘지 않는다 (날짜 블록 구간)" 고 적는다. 기각된 쪽은 "날짜 불확실성을 넣으면 이득이 확인되지 않는다" 고 한계에 적는다
- H3 지지: "이득은 특정 며칠에만 의존하지 않는다". 기각: "ABAC 대비 이득의 상당 부분이 몇몇 어려운 날에서 나온다" 고 한계에 적는다

## 미리 밝히는 한계

- 검증 40일은 한 계절 (11 ~ 12월) 의 한 구간이다. 블록 다시 뽑기는 이 구간 안의 흔들림만 보고 다른 계절이나 새 날짜를 대신하지 않는다. 새 날짜가 없다는 사실을 그대로 적는다
- 블록 8개로 만든 구간은 거칠다. 블록 길이를 바꿔 보는 감도 분석은 하지 않는다 (결과를 보고 길이를 고르지 않으려고)
- 기준 ABAC 와 차단만은 Park/e43 이 학습 구간에서 고른 설정 하나다. 대표의 묶음 흔들림과 날짜 흔들림을 한 구간에 합치지 않고 날짜만 다시 뽑는다
- 검증 구간은 e10 부터 반복해서 썼다
