# Park/e27: 정책 앙상블의 의견 차이에 맞춘 NH4 여유 (Kaggle DARROW)

상태: **완료 (2026-11-13). 고르기 단계에서 후보 없음, 검증 평가는 하지 않음.** 다섯 후보 모두 학습 구간에서 공기량과 비용을 함께 낮추지 못했다 (둘 다 이긴 조합 0 ~ 1/5). 규칙은 결과를 보기 전에 정했다 (2026-11-13 09:59, 아래 그대로).

## 목적

목표는 공기량과 하루 비용을 함께 낮추는 것이다. e23 ~ e26 에서 알게 된 점을 이용한다.

- seed 가 다른 정책 앙상블은 평균적으로 공기량과 비용을 함께 낮춘다 (e23)
- 정책을 바꿔 공기를 줄이면 NH4 위반이 늘어 비용이 오른다 (e24, e26)

그래서 정책은 그대로 두고 차단 쪽을 바꾼다. 구성원 4개의 공기량이 크게 갈리는 순간은 정책이 확신하지 못하는 상황으로 보고 NH4 여유를 키우고, 의견이 같은 순간에는 여유를 줄여 공기를 아낀다. 학습을 새로 하지 않는다.

## 방법

`min_brake.py` 에 두 가지를 더했다.

- `EnsemblePolicy`: 구성원 행동을 평균하고 (e20 ~ e23 과 같음) 구성원 공기량의 표준편차 (Nm3/h) 를 남긴다
- `DisagreementBrake`: 표준편차가 hi 이상이면 e19 H1 차단의 NH4 여유에 up 을 더하고, lo 이하면 down 을 뺀다. 여유가 쓰이는 모든 곳 (기본 필요 공기량, DO 충돌 때 줄인 여유) 에 더한다

확인: 여유를 바꾸지 않으면 (up = down = 0) 기존 e19 H1 차단과 학습 구간 결과가 소수점까지 같았다 (seed 0 ~ 3 앙상블, 73,654.388, 2.695).

lo = 620, hi = 1,200 Nm3/h 는 학습 구간 마지막 40일, seed 0 ~ 3 앙상블의 표준편차 25%, 75% 분위수다 (중앙값 860).

## 고르기 규칙 (결과 전에 기록)

"후보 (up, down) = A (0.1, 0.1), B (0.2, 0.1), C (0.1, 0.2), D (0, 0.2), E (0.2, 0). 학습 구간 마지막 40일, seed 0 ~ 4 의 4개 조합 5개를 같은 조합의 e19 차단 (Park/e26 의 기준값) 과 짝 비교. 조합 평균 공기량 < 기준, 평균 비용 < 기준, 둘 다 이긴 조합 최다 (3/5 이상), 같으면 공기량 최소. 없으면 버린다". 고른 후보가 있으면 조합 10개 (seed 0 ~ 4, 5 ~ 9) 로 검증에서 판정할 계획이었다.

## 해석

- 여유를 키우는 쪽 (E) 은 공기량만 늘고 비용은 그대로였다. 의견이 갈리는 순간에 NH4 위반이 몰려 있지 않다는 뜻이다.
- 여유를 줄이는 쪽 (D, C) 은 공기량을 조금 줄였지만 NH4 위반이 늘어 비용이 올랐다. e24, e26 과 같은 맞바꿈이 차단 쪽에서도 나타났다.
- 정책 구성원의 의견 차이는 NH4 위험을 알려 주는 신호가 아니었다. 정책은 공기량을 정하는데, 위험은 대리 모델의 NH4 예측 쪽에 있다. e15 ~ e19 의 여유는 대리 모델 구성원 사이의 차이를 쓰는데, 이것이 더 직접적인 신호다.
- e23 ~ e27 을 합치면, 같은 학습 예산과 지금의 대리 모델 안에서 공기량과 비용을 함께 낮추는 쪽은 seed 가 다른 정책 앙상블 (e22) 뿐이다. 남은 맞바꿈은 정책이나 차단 설정보다 NH4 가 바닥 근처라는 조건에서 오는 것으로 본다.
