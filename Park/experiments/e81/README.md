# Park/e81: e74 ~ e80 을 반영한 주장 지도 갱신 (Kaggle DARROW)

상태: **완료 (2026-11-26). 대표 교체 제안을 (2) 에서 (3) 으로 되돌림, 설정 손잡이는 지금 기본값이 대체로 맞음.** 사전 등록 커밋 `9309442` (main 병합 #250). 갱신 규칙은 지도를 고치기 전에 정했다. 새 학습과 새 평가는 없다 (정리 실험이라 실행 코드가 없다). 대표는 바꾸지 않는다.

## 목적

Park/e73 은 이득의 원천을 차단으로 옮기고, 팀 결정 사항의 Park 제안을 "(2) 대표를 차단 + 예측 제어로 바꾸기" 로 고쳤다. 그 뒤 차단 위 예측 제어의 설정 손잡이 (e74 예측 구간 곡선, e75 후보 간격, e76 NH4 여유, e77 DO 한도, e78 차단 여유, e79 여유 1.8 곡선) 와, 고를 때 쓰지 않은 날에서의 다시 보기 (e80) 가 끝났다. 이 실험은 그 결과를 주장 지도에 넣고 팀 결정 사항을 고친다.

## 갱신 규칙 (사전 등록)

e74 ~ e80 의 결과는 이미 알고 있다. 이 규칙은 결과를 예측하는 가설이 아니라, 알려진 결과를 어느 칸에 어떻게 넣을지를 미리 고정하는 것이다.

- 분류 규칙은 Park/e50, e55, e65, e73 과 같다. 수치는 Park/RESULT.md 와 각 실험의 README, results.md 에 이미 있는 값만 쓴다. Park/e73 지도의 항목은 지우지 않고 바뀐 곳에 **(갱신)** 을 붙인다
- 주 주장의 비교 (대표가 다시 고른 ABAC 와 차단만보다 낮음) 와 이득의 원천 (차단) 은 e74 ~ e80 이 그 판정을 직접 다루지 않았으면 유지한다
- 설정 손잡이 (e74 ~ e79): 지지된 결과는 기여 분리 표의 "차단 위 예측 제어 설정" 줄에, 기각된 결과는 "지금 기본값이 맞음" 으로 같은 줄에 둔다. 검증 구간에서 고르고 검증 구간에서 판정한 결과는 모두 "검증 구간에서만" 으로 표시한다
- 대표 교체 근거: 고를 때 쓰지 않은 날에서 차단 위 예측 제어가 대표보다 낮다는 판정 (e80 H1) 이 기각되고, 같은 날의 여유 1.2 결과 (Park/e60) 도 대표보다 높으면, 팀 결정 사항의 Park 제안을 "(2)" 에서 "(3) 검증 구간과 겹치지 않는 날에서 다시 비교한 뒤 정하기" 로 되돌린다. e80 H1 이 지지되면 (2) 를 유지하고 근거를 더한다. 어느 경우에도 Park 혼자 대표를 바꾸지 않는다
- 공기와 비용 동시 감소 (e79 H3): e80 H1 이 기각되면 보조 근거가 아니라 한계와 실패 칸에 "검증 구간에서만" 으로 둔다
- 판정하지 못한 것 (e74 H1) 은 한계와 실패 칸에 둔다

## 미리 밝히는 한계

- 정리 실험이라 새 증거를 만들지 않는다
- e80 을 뺀 모든 결과는 같은 대리 모델 계열의 환경과 반복 사용한 검증 40일에서 나왔다. test 는 쓰지 않았다

## 규칙 적용

- 주 주장의 비교와 이득의 원천: e74 ~ e80 은 대표 대 다시 고른 ABAC, 대표 대 차단만, 차단 없는 ABAC 대 차단 + ABAC 의 판정을 다루지 않았다. 유지한다
- 설정 손잡이: e75, e77, e78 은 기각되어 "지금 기본값이 맞음" 으로, e74 H2, e76 H1, e79 H1 은 지지되어 "검증 구간에서만" 으로 기여 분리 표에 둔다
- 대표 교체 근거: e80 H1 이 기각됐고 (고를 때 쓰지 않은 날에서 여유 1.8 점 4개 모두 대표보다 0.3 ~ 0.9 높음), 같은 날의 여유 1.2 (Park/e60) 도 대표 공기량 근처에서 2.83 ~ 3.54 로 대표 (2.605) 보다 높다. Park 제안을 (3) 으로 되돌린다
- 공기와 비용 동시 감소 (e79 H3): e80 H1 이 기각됐다. 한계와 실패 칸에 "검증 구간에서만" 으로 둔다
- e74 H1 (판정 못 함): 한계와 실패 칸에 둔다

## 갱신한 주장 지도 (한 쪽)

Park/e73 의 지도에서 바뀐 곳만 적는다. 나머지 (주 주장의 근거 표, 보조 근거, 사후 관찰) 는 [Park/e73](../e73/README.md) 과 같다. 값은 따로 적지 않으면 검증 40일 x 구성원 5개, 같은 PROTOCOL v1.1 환경이다.

### 주 주장 (문장 유지, 단서 더함)

**같은 공기량에서, 대리 모델로 다음 NH4 를 예측해 필요한 만큼만 공기를 올리는 최소 개입 차단을 씌운 제어 (대표는 그 차단을 켠 채 학습한 정책 앙상블) 는 현장 표준 ABAC 와 차단만보다 하루 위반 비용이 낮다. 이득의 원천은 차단이다.**

**(갱신)** Park/e73 의 "차단 위의 제어기는 학습 정책, 1시간 예측 제어, ABAC 어느 것이어도 비슷하거나 낫다" 는 검증 40일에서만 확인됐다. 학습 구간 마지막 40일에서는 차단 위 예측 제어가 여유 1.2 (Park/e60) 와 1.8 (Park/e80) 모두 대표보다 높다. 이 날은 대표 정책이 학습한 날이라 대표에 유리하고, 그 몫과 날짜의 차이를 아직 가르지 못했다.

### 한계와 실패 (더한 항목)

- **(갱신)** 차단 위 예측 제어가 대표보다 낮다는 결론 (e59, e66, e67) 과 대표보다 공기와 비용을 함께 줄이는 점 (e79 H3, 80,374 / 4.345) 은 검증 40일에서만 나왔다. 고를 때 쓰지 않은 학습 구간 40일에서는 대표보다 높다 (e60, e80)
- **(갱신)** 2시간 예측 구간 곡선은 한 점이 나머지를 지배해 곡선 대 곡선 판정을 하지 못했다 (e74 H1)
- **(갱신)** 같은 방법의 이웃한 설정 사이 비용이 0.1 가까이 오르내린다 (e74, e79). 학습 구간에서는 그 폭이 더 크다 (e60, e80). 점 하나의 0.05 ~ 0.1 차이는 근거로 약하다

## 팀 결정 사항 (Park 혼자 정하지 않음)

- **(갱신) 대표 교체 (Park 제안: 선택지 (3) 으로 되돌림):** Park/e73 은 공정한 두 비교 (e66, e67) 를 근거로 "(2) 대표를 차단 + 예측 제어로 바꾸기" 를 제안했다. 그런데 그 비교는 모두 검증 40일에서 했고, 고를 때 쓰지 않은 학습 구간 40일에서는 차단 위 예측 제어가 대표보다 높다 (e60, e80). 사전 등록 갱신 규칙에 따라 제안을 "(3) 검증 구간과 겹치지 않는 날에서 다시 비교한 뒤 정하기" 로 되돌린다
- 결정 전까지 Park 의 모든 실험은 지금 대표 (FCSRL 4 x 16 + 대표 차단) 를 계속 쓴다
