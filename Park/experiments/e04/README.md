# Park/e04: 단순 위반 예측기로 거는 안전 차단

상태: **완료 (2026-11-09). 사전 규칙상 H1, H2 지지. 다만 근거가 약하다 (아래 해석).** 규칙은 실행 전에 정했고 결과를 본 뒤 바꾸지 않았다.

## 목적

Park/e03 에서 관측 전체를 쓰는 로지스틱 회귀가 F 보다 위반을 더 정확히 미리 맞혔다 (평가 건기 1시간 AUROC 0.998 대 0.937). 이 실험은 더 정확한 예측기로 차단하면 같은 에너지에서 위반이 실제로 더 줄어드는지 확인한다. 예측이 정확해도 공정이 늦게 반응하면 차이가 작을 수 있다.

## 바꾸는 것 한 가지

차단 신호. F(s, a) 대신 로지스틱 회귀가 낸 위반 확률을 쓴다. 차단 규칙(확률 >= 기준이면 최대 폭기 KLa5 = 240) 과 정책, 환경, 평가는 Park/e02 와 같다.

## 예측기

- 입력: Park/e03 의 "관측 전체" 와 같다 (관측 11개와 하루 중 시각 2, 3배 주기 sin, cos 4개, 모두 15개)
- 정답: t+1 ~ t+12 (1시간) 안에 위반 스텝이 있는가. 차단은 위반 중인 순간에도 판단해야 하므로, e03 과 달리 **현재 위반 중인 스텝도 포함** 해서 맞춘다
- 맞춤: 정책마다 그 정책의 학습 날짜(건기 0 ~ 6일, 차단 없음) 궤적으로 맞춘다. 표준화, L2 1e-3, 뉴턴법 50회 (e03 과 같은 코드). 평가 구간으로는 맞추지 않는다
- 기준 확률: 0.1, 0.2, 0.3, 0.5, 0.7

## 비교

- 정책: Park/e02 의 9개 (gamma_F 0.9, 0.97, 0.99 x seed 0, 1, 2). 주 판정은 gamma_F 0.9
- 평가: 건기 14일 연속 운전, 후반 7일 (e02 와 같음)
- 비교 곡선: 같은 정책의 F 차단 (tau 0.3, 0.5, 0.7, 0.9) 과 NH4 규칙 차단 (theta 3.0, 3.5, 4.0, 4.5). 두 곡선은 Park/e02 의 결과를 그대로 쓴다. 평가가 결정적이라 다시 돌려도 같다
- 같은 에너지 차이: 예측기 차단 각 점에서, 비교 곡선의 4점을 에너지 순으로 이은 선형 보간 위반 % 를 뺀다. 비교 곡선 에너지 범위 밖의 점은 뺀다. 음수면 예측기 차단이 같은 에너지로 위반을 더 줄였다

## 가설 (사전 등록)

gamma_F 0.9 정책에서, seed 3개 중 2개 이상에서 성립하고 seed 평균도 성립하면 지지로 적는다. 0.97, 0.99 는 보고만 한다.

- H1 (주 가설). 예측기 차단의 같은 에너지 차이가 F 차단 곡선 대비 음수다
- H2. 예측기 차단의 같은 에너지 차이가 NH4 규칙 곡선 대비 음수다

가설이 기각되는 결과도 그대로 기록한다. 비교 가능한 점이 없는 seed 는 성립하지 않은 것으로 센다.

## 미리 밝히는 한계

- 예측기는 차단 없는 궤적으로 맞췄다. 차단이 걸리면 상태 분포가 바뀐다 (F 도 같다)
- 건기, 10 갱신 정책, seed 3개의 탐색적 실험이다
- 하루 주기가 뚜렷한 BSM1 건기 유입에 묶인 결과다

## 실행 명령

```bash
cd Park/experiments/e04
export BSM1_ARCHIVE=<BSM1.zip> WANDB_MODE=disabled OMP_NUM_THREADS=1
for g in 0.9 0.97 0.99; do for s in 0 1 2; do
  python run_e04.py one --gamma $g --seed $s --prepared <결과>/prepared --runs <결과>/runs --out <결과>/e04
done; done
python run_e04.py report --out <결과>/e04 --e02 <결과>/e02 --md results.md
```

정책, 환경, F 와 NH4 규칙 곡선은 Park/e02 와 같다. 새 학습은 없다. `Park/code/shield.py` 에 `PredictorShield` 를 추가했다.

### 해석

- 방향은 "더 정확한 예측기로 차단하면 같은 에너지에서 위반이 조금 더 준다" 쪽이지만 근거가 약하다.
  - H1 의 seed 2 는 예측기 차단 점이 모두 F 곡선의 에너지 범위 밖이라 비교하지 못했다. seed 1 은 비교 점이 1개뿐이다. F 곡선은 에너지 폭이 30 ~ 60 kWh/day 로 좁다.
  - H2 의 seed 2 는 예측기가 오히려 NH4 규칙보다 0.55 %p 나빴다.
  - 차이 크기(1 ~ 2 %p) 는 seed 사이 위반 편차(약 2 ~ 8 %p) 보다 작다.
- 보고만 하는 gamma_F 0.97, 0.99 정책에서는 대부분 음수였지만 0.99 seed 1 은 F 대비 +2.48 %p 였다. 0.97 seed 1 의 -11 %p 는 곡선 끝의 보간에서 나온 값이라 크기를 믿기 어렵다.
- e03 에서 예측 정확도 차이(AUROC 0.998 대 0.937) 는 컸지만, 차단 효과 차이는 작았다. 최대 폭기를 넣어도 NH4 가 내려가는 데 시간이 걸려, 미리 아는 것만으로는 막을 수 있는 위반이 한정된다.

### 한계

- 같은 에너지 비교는 비교 곡선의 에너지 범위가 좁으면 점이 빠지거나 끝에서 보간 오차가 커진다. 다음에는 비교 곡선의 설정 폭을 넓히거나 같은 개입 비율 비교를 함께 봐야 한다.
- 예측기와 F 모두 차단 없는 궤적으로 맞췄다. 10 갱신, seed 3개, 건기만 본 탐색적 실험이다.

### 다음 실험 후보

- 비교 곡선 설정 폭을 넓혀(예: F tau 0.05 ~ 0.95, theta 2.0 ~ 5.0) 같은 에너지 비교의 점을 늘린다.
- 차단 행동을 최대 폭기 대신 더 이른 시점의 중간 폭기로 바꿔, 미리 아는 정보를 더 잘 쓰는지 본다.
