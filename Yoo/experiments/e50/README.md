### 판정

- H1 Yoo 확장: **지지 안 됨**. FCSRL + Actor 보정은 평균 비용(10.32 대 11.34)과 공기량(−5.73%)이 FCSRL + PPO-Lag 보다 낮지만, seed 짝 비교에서 비용이 낮은 seed 가 2/5 로 기준 4/5 에 못 미친다. FCSRL + PPO-Lag 는 seed 0, 3, 4 에서 공기를 더 써서(90,890 ~ 96,158) 비용을 5.8 ~ 7.0 까지 낮췄고, Actor 보정은 그 seed 들에서 공기를 6 ~ 12% 덜 쓰는 대신 비용이 2.0 ~ 5.4 높다. 즉 같은 비용에서 공기가 적다고 말할 수 없다
- Q2 모델 민감도: 순위가 **다르다**. e30 (1.7.2 모델) 은 PPO-Lag 11.45 < Actor 보정 13.68 < FCSRL 16.58 이었고, e50 (1.9.1 기준 모델) 은 Actor 보정 10.32 < FCSRL 11.34 < PPO-Lag 14.37 이다. Yoo 의 이전 방법 순위 주장은 대리 모델 버전에 민감하므로, e30 의 순위를 방법 우열로 쓰지 않는다
- seed 편차가 크다. FCSRL + PPO-Lag 의 비용 표준편차는 6.29 로 평균의 절반을 넘는다. Actor 보정의 비용 표준편차는 2.57 로 FCSRL 보다 작지만 PPO-Lag 의 2.01 보다 크다. 평균 비용 한도 이하 seed 는 4/5 로 가장 많다. 판정 기준이 아니라 관찰로만 적는다
