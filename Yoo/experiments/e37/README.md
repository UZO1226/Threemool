# e37: DARROW 공기량 변화 구간의 모델 반응 대조

## 목적과 사전 범위

목표는 DARROW에서 공기량, NH4 위반, DO 위반의 동시 개선이다. e36에서는 기존 정책의 성과가 환경 수정에 의존했고 모든 지표를 안정적으로 개선한 확장을 확인하지 못했다. 새 알고리즘 학습 전, 공기량이 변한 실제 운전을 수정 환경이 어느 정도 재현하는지 판정한다. 다른 데이터는 사용하지 않는다.

현재 공기와 수질의 관계는 기존 제어기의 피드백과 외부 부하를 포함한다. 따라서 이 실험은 관측된 운전 경로의 조건부 예측 검사이며 공기 변화의 인과 효과를 식별하는 실험이 아니다. 물리적 수질 한도를 새로 정하거나 환경 사용을 자동 승인하지 않는다.

## 사전 고정

- e30 train188일의 15분 총 공기 변화 절댓값90분위수(최소500m³/h)를 큰 변화 기준으로 고정한다. 안정 구간은 train25분위수와100 중 작은 값 이하로 정한다.
- 첫1시간 이력과 이후3시간 기록이 같은 날짜에 있는 시작점만 쓴다. 큰 변화는 날짜별 시간 순서대로 선택하고 다음3시간 안의 중복 시작을 제외한다. 이후 행동이 유지되는지를 보고 표본을 고르지 않는다. 이는 지속 계단 입력 실험이 아니다.
- val40일에서15분,60분,180분 후 NH4/NO3/DO1~3 변화량을 확인한다. 실제 시작 상태와 직전 구간 공기량에서 출발해 미래 기록 행동/외생 입력만 재생한다. 미래 실측 수질은 모델 입력에 넣지 않는다. 모델5개 구성원의 개별 오차와 평균 예측 오차를 구분한다.
- 변화 전 상태5개, 직전1시간 추세5개, 현재 외생 입력9개, 이전 총 공기량과 구간 비율5개로 안정 구간을 매칭한다. 현재 변경 공기량과 미래 수질은 매칭에 쓰지 않는다. train IQR로 표준화하고 다른 날짜의 가장 가까운 안정 구간 하나를 고른다. 중복 사용은 허용하고 고유 구간 수를 보고한다.
- 허용 RMS 거리는 train 변화 구간과 안정 구간 간 최근접 거리90분위수로 고정한다. 각 변수 차이도1 IQR 이하여야 한다. 이 거리 기준은 데이터의 조건 유사성 검사이며 인과적 공통 지지의 증명이 아니다. 30쌍/10날짜 미만이면 사전 정한 기술적 자료 충분성 기준에 미달로 표시한다.
- 방향은 NH4/NO3 ±0.1mg/L, DO ±0.05mg/L 안을 유지로 분류한다. 이는 진단용 구분이며 센서 정확도나 법적 한도가 아니다. 변화 없는 상태 유지 예측을 기준으로 MAE를 비교하고 방향별 결과도 공개한다.
- 최대 변화 시점은3시간 경로 내 기술적 극값이다. 공기량의 인과적 지연시간으로 해석하지 않는다. 경계에서 최대가 나는 비율도 보고한다.
- 날짜7일 순환 블록 bootstrap2000회는 개발 자료의 탐색적 구간이다. 다중 비교 중 유리한 구간만 선택하지 않는다. NH4/DO에서 상태 유지 예측보다 나쁘거나 조건이 비슷한 자료가 부족하면 새 RL 성과/안전성 주장을 보류한다. 반대로 예측 개선만으로 제어 효과가 입증되지는 않는다.

프로토콜과 입력 SHA256은 검증 평가 전에 저장한다. 새 환경/정책 학습과 test41일 평가는 없다. 기존 수정 환경은 e35의 corrected_surrogate.pkl이다. 준비 자료 출처/분할은 [e30](../e30/README.md), 수정 근거는 [e35](../e35/README.md)를 따른다.


### NH4 반응의 크기를 충분히 재현하지 못했다

아래는 공기 변화 이후 관측된 경로의 평균 농도 변화다. 같은 구간의 기록된 공기/외생 입력을 모델에 재생한 예측과 비교하며, 공기량만의 인과 효과가 아니다.

| 구간 | 경과 시간 | 실제 NH4 변화 mg/L | 모델 NH4 변화 mg/L |
| --- | --- | --- | --- |
| 공기 증가 | 1시간 | -1.468 | +0.106 |
| 공기 증가 | 3시간 | -3.142 | -0.152 |
| 공기 감소 | 1시간 | +0.236 | +0.168 |
| 공기 감소 | 3시간 | +2.114 | +0.697 |

전체132구간의 NH4 MAE는15분0.298,1시간1.280,3시간2.635였다. 현재 농도 유지 기준은0.297,1.302,2.856이고, 세 시간 모두 차이의 탐색95%구간이0을 포함했다. 뚜렷한 개선을 입증하지 못했으며 동등성을 증명한 것은 아니다.

반면 DO1의1시간 MAE는0.561→0.274, DO2는0.663→0.310으로 상태 유지 기준보다 낮았다. 방향/센서/시간대별 차이가 있으므로 모든 모델을 버릴 근거는 아니다. 공기 증가 구간3시간에서는 DO1/DO3이 상태 유지 기준보다 나빴다는 결과도 공개했다.

### 조건이 비슷한 비교 자료가 제한적이었다

주 사전 매칭은4쌍/4날짜(모두 공기 증가)로,30쌍/10날짜 기준에 미달했다. 가까운 후보 하나만 검사한 방식이 지나치게 제한적인지 확인하기 위해 사후 모든 후보를 검색하면 같은1 IQR 조건에서9개 변화 구간이 대응됐다. 최대 차이를2/3 IQR로 넓히면41/85개로 늘었다. 따라서 "데이터에 비교 가능한 구간이 전혀 없다"고 결론짓지 않는다. 넓은 기준을 사후 성공 조건으로 채택하지도 않는다.

공기 증가 전 NH4 평균은4.572, 직전1시간에는평균1.321 상승했다. 감소 전에는1.089, 직전1시간에는1.245 하락했다. 기존 운전 피드백/상태 추세와 행동 선택이 얽혀 있다. 이는 공기량의 순수한 인과 효과를 추정하려면 추가 가정/근거가 필요하다는 단서이며, 미관측 교란이 해소됐다는 증거가 아니다.

극값 시간도 차이가 있었지만3시간 창의 경계에 걸리는 사례가 있어 실제 공정 지연시간으로 해석하지 않는다.

## 이번 결과로 바뀌는 다음 결정

1. 현재 모델이 공기 절감에 따른 NH4 변화를 믿을 만하게 평가한다고 주장할 근거가 부족하다. 새 RL 본 학습과 확장 성공 채택은 보류한다. 매칭 기준을 넓히거나 비용 한도를 완화해서 통과시키지 않는다.
2. 짧은 시간의 DO1/DO2 예측에는 유용한 부분이 있다. 모든 환경을 다시 만드는 대신 NH4 전이의 이력 누락을 다음 제한적 개선 후보로 삼는다. 현재 전이 입력에는 과거 수질 이력이 없고, 행동 변경 구간의 사전 추세는 크게 달랐다. 이력 누락이 원인이라고 확정한 것은 아니다.
3. 다음 대조는 DARROW에서 NH4 예측에 직전1시간 수질 이력을 추가한 조건 하나와 현재 모델을 같은 학습/검증 날짜로 비교하는 것이다. DO모델, 행동/보상/제약과 FCSRL 구조는 고정한다. 반복 예측에서는 실제 미래 이력 대신 자기 예측 이력을 갱신해야 한다. NH4 반응 재현/위반 분류/장기 재생을 함께 보고 DO 악화가 없는지도 확인한다. 예측 MAE만 내려가면 성공으로 채택하지 않는다.
4. 과거 다른 데이터의 이력 실험은 DARROW에서 이 방법이 효과가 있다는 근거로 사용하지 않는다. 이번 결과는 모든 제어 지표 개선을 위한 환경 병목 후보를 좁힌 것이며, 아직 공기/NH4/DO 동시 개선을 달성한 것은 아니다. 후속 모델 학습은 이번 작업에서 실행하지 않았다.
