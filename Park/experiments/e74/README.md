# Park/e74: 2시간 예측 구간 곡선과 1시간 곡선의 비교 (Kaggle DARROW)

상태: **사전 등록 (2026-11-24).** 공기 가중치, 비교 규칙, 가설은 새 점을 돌리기 전에 정했다. 대표는 바꾸지 않는다.

## 목적

Park/e72 는 차단 위 예측 제어의 예측 구간을 2시간으로 늘리면 같은 공기량의 1시간 곡선보다 0.075 낮다는 것을 점 하나로 보였다. 점 하나는 우연일 수 있다. 이 실험은 2시간 예측 구간에도 공기 가중치 곡선을 만들어 1시간 곡선과 곡선 대 곡선으로 비교한다 (Park/e67 과 같은 방식).

## 방법

- 기준: `ShortMPC` (`objective='excess'`, NH4 여유 1.2, `H=8`) + 대표 차단
- 새로 돌리는 공기 가중치: 1.0, 2.0, 2.5. Park/e72 의 가중치 1.5 점 (87,120 / 4.330) 과 합친 4개 점에서 지배되지 않는 점으로 2시간 곡선을 만든다
- 1시간 곡선은 Park/e58, e59 의 11개 점 곡선이다
- 겹치는 공기량 범위를 21개 점으로 나눠 (2시간 곡선 빼기 1시간 곡선) 의 평균을 낸다 (Park/e67 의 `mean_gap`)
- 가중치 범위는 Park/e72 의 2시간 점이 1시간보다 공기를 더 쓴 것 (87,120 대 82,238) 을 보고, 대표 공기량 근처까지 내려오도록 큰 가중치 쪽으로 정했다

## 평가

검증 40일 x 구성원 5개 = 200 에피소드, 결정적. test 는 쓰지 않는다.

## 가설 (사전 등록)

- H1. 겹치는 범위에서 2시간 곡선이 1시간 곡선보다 평균 0.05 넘게 낮다
- H2. 2시간 점 4개 가운데 3개 이상이 같은 공기량의 1시간 곡선보다 낮다 (범위 밖 점은 "낮지 않음")

## RESULT.md 처리 (미리 정함)

- H1 지지: "2시간 예측 구간은 곡선 대 곡선으로도 1시간보다 낮다" 고 적고, 차단 위 예측 제어의 기본 예측 구간 후보로 2시간을 적는다
- H1 기각: "2시간 예측 구간의 이득은 곡선으로 보면 0.05 를 넘지 않는다" 고 적고 Park/e72 H1 을 "점 하나에서만" 으로 좁힌다
- H2 는 H1 과 함께 점 단위 일관성으로 적는다

## 미리 밝히는 한계

- 곡선은 검증 구간에서 만든 것이고 두 곡선 모두 같은 조건이다. 곡선은 선형 보간이다
- 2시간 예측 구간은 계산이 1시간의 약 2배다 (Park/e63 기준 1시간 213 ms). 검증 구간은 e10 부터 반복해서 썼다
