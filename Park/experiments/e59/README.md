# Park/e59: 같은 차단 위의 예측 제어 곡선을 대표 공기량 아래로 늘린 비교 (Kaggle DARROW)

상태: **사전 등록 (2026-11-21).** 더할 손잡이 값, 곡선 규칙, 가설은 새 점을 돌리기 전에 정했다. 대표는 바꾸지 않는다.

## 목적

Park/e58 은 대표와 같은 차단을 씌운 1시간 예측 제어의 검증 구간 곡선이 82,238 ~ 96,097 이라, 공기를 더 적게 쓰는 대표 묶음 3개 (79,457, 80,552, 81,791) 를 곡선 범위 밖으로 두고 "대표가 낮지 않음" 으로 셌다. 범위 안 2개에서는 예측 제어가 낮았다 (H1 기각). 이 실험은 공기 가중치가 큰 점을 더해 곡선을 대표 공기량 아래까지 늘리고, 묶음 5개를 모두 실제 곡선과 비교한다.

## 방법

- 기준은 Park/e58 과 같다: `ShortMPC` (`objective='excess'`, NH4 여유 1.2, 1시간) + 대표 차단 (`MinAirBrake(dyn, 3.5, 1, 'others', **BRAKE)`)
- 새로 돌리는 공기 가중치: 2.0, 2.5, 3.0, 4.0. Park/e58 의 7개 점과 합친 11개 점으로 곡선을 만든다
- 곡선과 판정 규칙은 Park/e56, e58 과 같다 (지배되는 점을 빼고 선형 보간, 범위 밖 묶음은 "대표가 낮지 않음")
- 범위는 Park/e58 의 학습 구간 4일 사전 점검 (공기 가중치 3.0 에서 65,631) 과 e58 의 검증 점 (1.5 에서 82,238) 을 보고 정했다. 새 점의 검증 값은 보지 않았다
- 대표는 Park/e35 orig 의 묶음 5개 값을 쓴다

## 평가

검증 40일 x 구성원 5개 = 200 에피소드, 결정적. test 는 쓰지 않는다.

## 가설 (사전 등록)

- H1. 대표 묶음 5개 모두 공기량이 11개 점 곡선의 범위 안이고, 대표의 하루 비용이 같은 공기량의 "차단 + 예측 제어" 곡선 비용보다 낮은 묶음이 5개 중 4개 이상이며 평균도 낮다
- H2 (반대 방향, 대표 교체 검토 조건). 5개 묶음 모두 범위 안이고, 곡선 비용이 대표보다 낮은 묶음이 4개 이상이며 평균도 낮다

## RESULT.md 처리 (미리 정함)

대표 방법은 이 실험만으로 바꾸지 않는다.

- H1 지지: "곡선을 늘리면 같은 공기량에서 대표가 차단 위 예측 제어보다 낮다" 고 적고 Park/e58 의 결론을 고친다
- H2 지지: "같은 차단 위에서 1시간 예측 제어가 묶음 4/5 이상 대표보다 낮다" 고 적고, 사전 등록 규칙 (Park/e58) 에 따라 대표를 바꿀지 팀에 올린다. 공정한 비교는 학습 구간에서 고른 Park/e60 으로 본다
- 둘 다 아님: "같은 차단 위에서 학습 정책과 1시간 예측 제어는 같은 공기량에서 비슷하다" 고 적는다

## 미리 밝히는 한계

- 예측 제어는 검증 구간에서 곡선을 만들어 유리하다. 곡선은 선형 보간이다
- 손잡이는 공기 가중치 하나만 바꾼다
- 예측 제어와 차단은 같은 대리 모델 계열을 쓰고 환경도 같은 계열이다. 검증 구간은 e10 부터 반복해서 썼다
