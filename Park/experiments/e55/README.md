# Park/e55: e51 ~ e54 를 반영한 주장 지도 갱신 (Kaggle DARROW)

상태: **완료 (2026-11-21).** 갱신 규칙은 지도를 고치기 전에 정했다 (사전 등록 커밋 `0efaac4`). 새 학습과 새 평가는 없다. 대표는 바꾸지 않는다.

## 목적

Park/e50 은 e1 ~ e49 로 주장 지도 한 쪽을 만들었다. 그 뒤 e51 (새 seed 블록), e52 (초과량 예측 제어), e53 (지연 보정), e54 (넓힌 ABAC 격자) 가 끝났고, 그중 e53 과 e54 는 주 주장의 크기와 범위를 바꾼다. 팀 중간점검 (Yoo/analysis/TEAM_RESEARCH_REVIEW_20261117.md) 8절 7번의 "주 주장 하나에 대표 비교, 제거 대조, 새 확인, 실패와 한계가 연결됨" 을 최신 결과로 유지하려고 지도를 갱신한다.

## 갱신 규칙 (사전 등록)

e51 ~ e54 의 결과는 이미 알고 있다. 이 규칙은 결과를 예측하는 가설이 아니라, 알려진 결과를 어느 칸에 어떻게 넣을지를 미리 고정하는 것이다.

- 분류 규칙은 Park/e50 과 같다 (주 주장, 보조 근거, 기여 분리, 한계와 실패, 사후 관찰)
- 기준 교체: Park/e54 사전 등록 처리에 따라 주 주장의 ABAC 는 다시 고른 ABAC (설정값 3.2, Kp 4,000, Ki 1,600) 로 바꾼다. e43 ABAC 값은 지우지 않고 옆에 둔다
- 주 주장 유지 조건: 다시 고른 ABAC 대비 묶음 판정이 사전 등록 지지이면 주 주장 문장을 유지하고 크기만 고친다. 날짜 블록 구간 (Park/e49) 은 e43 ABAC 기준이므로 새 기준에서는 "다시 계산하지 않음" 으로 적는다
- 기여 분리: 차단의 몫은 새 기준 (다시 고른 ABAC 대 차단만) 의 차이로 고치되, 두 방법의 공기량이 다르면 그 차이를 함께 적고 "같은 공기량 아님" 으로 표시한다. 새로 보간하거나 계산하지 않는다
- 사전 등록 판정에서 지지된 사후 관찰 (e47 의 차단 개입률이 e51 H3 로 확인됨) 은 사후 관찰에서 기여 분리 또는 보조 근거로 옮기되, 비용 차이가 아니라 개입률의 차이임을 적는다
- 지연 (e46, e53): 보정한 대표가 기준선보다 둘 다 낮으면 보조 근거에, 보정한 ABAC 가 보정한 대표보다 낮으면 그 사실을 한계에 둔다
- 판정하지 못한 것 (e51 H2, e52 맞춤 실패) 은 한계와 실패 칸에 둔다
- 수치는 Park/RESULT.md 와 각 실험의 README, results.md 에 이미 있는 값만 쓴다

## 미리 밝히는 한계

- 정리 실험이라 새 증거를 만들지 않는다
- 모든 결과는 같은 대리 모델 계열의 환경과 반복 사용한 검증 40일에서 나왔다. test 는 쓰지 않았다

## 갱신한 주장 지도 (한 쪽)

모든 값은 검증 40일 x 구성원 5개, 같은 PROTOCOL v1.1 환경이다. "묶음" 은 구성원이 겹치지 않는 4 x 16 앙상블 묶음이다. Park/e50 에서 바뀐 곳은 **(갱신)** 으로 표시했다.

### 주 주장 (문장 유지, 크기 갱신)

**같은 공기량에서, 대리 모델로 다음 NH4 를 예측해 필요한 만큼만 공기를 올리는 최소 개입 차단과 그 차단을 켠 채 학습한 정책 앙상블 (대표) 은 현장 표준 ABAC 와 차단만보다 하루 위반 비용이 낮다.**

| 근거 | 값 | 판정 단위 |
| --- | --- | --- |
| **(갱신)** 대표 대 다시 고른 ABAC (Park/e54) | 82,104 / 4.658 대 80,673 / 5.195, 차이 -0.537 (-0.606 ~ -0.468) | 묶음 5/5, 사전 등록 지지 |
| 대표 대 e43 ABAC (Park/e43, 옛 기준) | 82,345 / 5.450, 차이 -0.79 | 묶음 5/5, 사전 등록 지지 |
| 대표 대 차단만 (Park/e43) | 81,934 / 5.120, 차이 -0.46 | 묶음 5/5, 사전 등록 지지 |
| 날짜 블록 구간 (Park/e49) | e43 ABAC -1.249 ~ -0.305, 차단만 -0.752 ~ -0.218 | 다시 고른 ABAC 기준으로는 다시 계산하지 않음 |
| **(갱신)** 새 seed 블록 (Park/e51) | seed 20 ~ 35 묶음 4개 평균 81,268 / 4.734 | 기준선보다 4/4 둘 다 낮음, 사전 등록 지지 |
| 공식 기준선과 (RESULT.md 표) | 기본 PPO-Lag 90,121 / 10.79 대 대표 79,457 / 4.58 | 공기와 비용 함께 낮음 |

### 기여 분리 (갱신)

| 몫 | 비교 | 차이 | 상태 |
| --- | --- | --- | --- |
| **(갱신)** 차단 | 다시 고른 ABAC 대 차단만 (e54, e43) | 비용 -0.075, 공기량 +1,261 | 같은 공기량 아님. 다듬은 ABAC 와 차단만은 거의 같다 |
| 차단 (옛 기준) | e43 ABAC 대 차단만 (같은 공기량, e43) | -0.33 | 확인 |
| 학습 정책 (차단 위) | 차단만 대 대표 (같은 공기량, e43, e49) | -0.46 | 확인, 날짜에 고르게 퍼짐 (나은 날 25, 나쁜 날 4) |
| 학습 설정 대 알고리즘 | 같은 설정 PPO-Lag 대 FCSRL (e37) | -0.244 | 확인되지 않음 (2/5) |
| FCSRL 학습 표현 (비용) | 무작위 고정 표현 대 FCSRL (e47, e51) | -0.127 (e47), -0.149 (e51) | 두 번 모두 신뢰구간 0 포함 |
| **(갱신)** FCSRL 학습 표현 (차단 개입률) | 무작위 고정 표현 대 FCSRL (e51) | 44.5% 대 23.9%, 차이 -20.6 %p (-34.8 ~ -6.5) | 새 seed 4/4, 사전 등록 지지 (e47 사후 관찰을 확인) |
| feasibility 손실 | 동역학 일관성만 대 FCSRL (e47) | -0.164 | 확인되지 않음 (3/5) |
| 회복 계획 (원판) | 계획 없음 대 원판 (e35, e32) | -0.14 | 확인 (새 seed 10/10, 묶음 5/5) |

정리 (갱신): 다듬은 현장 표준 ABAC 대비 대표의 이득은 0.54 이고, 그 대부분은 차단 위에서 학습한 정책의 몫 (0.46) 이다. 차단만으로 얻는 몫은 ABAC 를 다듬으면 거의 사라진다. FCSRL 표현은 비용 차이로는 확인되지 않고, 차단에 덜 기대는 정책을 만든다는 것 (개입률 절반) 이 확인됐다. 원고의 주 기여는 "예측 차단을 켠 채 학습한 정책" 이고, FCSRL 은 "차단 개입을 줄이는 표현" 으로 적는다.

### 보조 근거 (조건을 넓힘, 모두 사전 등록 지지)

- 새 seed (Park/e32): 회복 계획 이득이 seed 10 ~ 19 의 조합 10개 모두에서 재현
- **(갱신)** 새 seed 블록 (Park/e51): seed 20 ~ 35 에서 기준선 대비 이득 4/4 재현
- 측정하지 않는 유입 변수를 모를 때 (Park/e39): 82,283 / 5.068, 기준선보다 5/5 둘 다 낮음
- NH4 분석계 15분 지연 (Park/e46): 82,577 / 5.762, 기준선보다 5/5 둘 다 낮음
- **(갱신)** NH4 분석계 30분 지연에 보정을 붙일 때 (Park/e53): 9.623 에서 7.104 로 5/5 낮아지고 기준선보다 5/5 둘 다 낮음
- 사건 단위 (Park/e45): NH4 위반 사건 0.36 대 ABAC 0.41/일, 5/5
- 차단 모델이 틀릴 때 FCSRL 은 같은 설정 PPO-Lag 보다 덜 무너짐 (Park/e38 H2, +6.57 대 +10.83, 5/5)

### 한계와 실패 (주장 옆에 둠)

- 공기 반응이 틀린 차단 모델에서는 무너진다 (Park/e38 H1 기각, e40 ~ e42 로도 회복 못함)
- ABAC 대비 이득은 며칠에 몰린다 (Park/e49 H3 기각, e43 ABAC 기준). 이득의 약 0.48 은 DO 위반에서 온다 (e45)
- **(갱신)** 지연이 있으면 ABAC 가 따라온다 (Park/e53): 같은 보정을 붙인 ABAC 는 30분 지연에서 5.560 으로 보정한 대표 (7.104) 보다 낮고, 15분 지연에서도 차이가 0.23 으로 준다. 주 주장은 "분석계 지연이 없을 때" 로 범위를 좁혀 적는다
- **(갱신)** 다시 고른 ABAC 는 대표보다 공기를 1.7% 덜 쓴다 (Park/e54). 같은 공기량이면 0.54 는 약간 과대일 수 있다
- **(갱신)** 같은 정보의 1시간 예측 제어와의 비교는 두 번 모두 맞춤 실패로 판정하지 못했다 (Park/e48 지표 목적 -21.8%, Park/e52 초과량 목적 -3.1%). e52 에서 대표 비용은 5/5 낮지만 (79,564 / 6.725, 참고) "학습 정책이 예측 제어 위에 더하는 몫" 은 여전히 판정되지 않았다
- **(갱신)** 새 seed 블록의 같은 공기량 판정은 묶음 하나가 차단만 곡선 범위 밖이라 하지 않았다 (Park/e51 H2)
- 회복 계획의 목적은 문서와 달리 OR 로 계산됐다 (Park/e35). 대표 값은 모두 OR 원판의 값이다
- 대표 차단은 환경과 같은 대리 모델 계열이다. 보정 (e53) 과 예측 제어 (e52) 도 같은 계열이다
- 검증 40일은 e10 부터 반복 사용했고 한 계절 (11 ~ 12월) 이다. 새 날짜나 test 확인은 아직 없다

### 사후 관찰 (근거로 쓰지 않음)

- 대표만 지연 보정에서 덜 회복하는 것은 차단 여유가 지연 없는 1 스텝 예측 오차에 맞춰져 있기 때문으로 보인다 (e53)
- 1시간 예측 제어는 학습 구간 비용 3.285 에서 검증 6.725 로 크게 올라, 학습 구간에 맞춘 손잡이가 덜 옮겨 가는 것으로 보인다 (e52)
- 남은 NH4 위반의 99.7% 는 최대 공기로도 여유를 못 지키는 스텝이다 (e44)

## 원고 흐름 제안 (갱신)

1. 문제: 같은 공기량에서 위반을 줄일 수 있는가 (공식 기준선과 다듬은 ABAC)
2. 방법: 최소 개입 예측 차단 + 차단을 켠 학습 + 앙상블 + 회복 계획 (OR 목적임을 명시)
3. 주 결과: e54 의 다듬은 ABAC 대비 비교, e43 의 차단만 대비 비교, e49 의 날짜 블록 구간, e51 의 새 seed 확인
4. 기여 분리: 위 표. 이득은 주로 차단 위의 학습 정책, FCSRL 은 개입률을 줄인다
5. 조건 확장: e32, e39, e45, e46, e53, e38 H2
6. 실패와 한계: e38 H1 ~ e42, e49 H3, e53 의 보정 ABAC, e48 과 e52 맞춤 실패, e35
