# Park/e61: 차단 모델이 틀릴 때 대표와 차단 위 예측 제어의 비교 (Kaggle DARROW)

상태: **사전 등록 (2026-11-21).** 가설과 판정 규칙은 Park/e60 의 검증 결과와 이 실험의 결과를 보기 전에 정했다. 대표는 바꾸지 않는다.

## 목적

Park/e58 은 같은 차단 위에서 1시간 예측 제어가 학습 정책만큼 한다는 것을 보였다. 그렇다면 학습 정책은 어디에서 쓸모가 있는가. Park/e38 H2 는 차단 모델이 틀릴 때 FCSRL 대표가 같은 설정의 PPO-Lag 보다 덜 무너진다는 것을 보였다 (+6.57 대 +10.83). 예측 제어는 매 스텝 그 틀린 모델로 계획하므로 모델 오차에 더 민감할 수 있다. 이 실험은 차단 모델이 틀릴 때 대표가 차단 위 예측 제어보다 덜 무너지는지 본다.

## 방법

- 조건은 Park/e38 과 같다. 환경은 GBM 대리 모델 그대로, 차단의 예측만 (1 - w) x GBM + w x MLP (Park/e38 의 MLP 대리 모델) 로 바꾼다. w = 0.5 가 주 판정, w = 1.0 은 참고
- 차단 위 예측 제어는 Park/e60 이 학습 구간에서 고른 설정 (NH4 여유, 공기 가중치) 이다. 예측 제어의 계획도 차단과 같은 틀린 예측을 쓴다 (같은 정보)
- 대표 값은 Park/e38 (w = 0.5, 1.0, 묶음 5개) 과 Park/e35 orig (w = 0) 를 쓰고, 예측 제어의 w = 0 값은 Park/e60 검증 값을 쓴다

## 평가

검증 40일 x 구성원 5개 = 200 에피소드, 결정적. test 는 쓰지 않는다.

## 가설 (사전 등록)

- H1. w = 0.5 에서 대표 묶음의 비용 증가 (w = 0.5 빼기 w = 0) 가 차단 위 예측 제어의 증가보다 작은 묶음이 5개 중 4개 이상이고 평균도 작다
- H2. w = 0.5 에서 대표 묶음의 하루 비용이 차단 위 예측 제어보다 낮은 묶음이 4개 이상이고 평균도 낮다

## RESULT.md 처리 (미리 정함)

- H1 지지: "차단 모델이 틀릴 때 학습 정책은 차단 위 예측 제어보다 덜 나빠진다" 고 적는다. H2 도 지지면 "모델이 틀릴 때는 학습 정책이 낮다" 고 함께 적는다
- H1 기각: "모델이 틀릴 때도 학습 정책이 예측 제어보다 견고하다는 근거는 없다" 고 적는다

## 미리 밝히는 한계

- 모델 오차는 MLP 대리 모델 한 종류만 본다. Park/e38 의 한계 (공기 반응이 틀린 모델에서는 대표도 기준선보다 나쁨) 는 그대로다
- 공기량은 맞추지 않는다 (같은 고른 설정을 그대로 씀). 공기량 차이는 함께 적는다
- 검증 구간은 e10 부터 반복해서 썼다
