# Park/e02: 더 먼 미래를 보는 feasibility 점수

상태: **완료 (2026-11-09). H2, H3 지지, H1 지지 안 됨.** 아래 규칙은 학습 전에 정했고 결과를 본 뒤 바꾸지 않았다.

## 목적

Park/e01 에서 F 차단은 단순 NH4 규칙보다 낫지 않았다. 원인 후보는 feasibility discount 0.9 가 약 50분 앞만 봐서, F 가 위반이 시작된 뒤에야 올라가는 것이다. 이 실험은 discount 를 늘려 F 가 위반을 **미리** 알아채는지 확인한다.

## 바꾸는 것 한 가지

FCSRL 의 feasibility discount (gamma_F). 나머지(환경, 이진 비용, 한도 72, PPO, 표현 학습 구조, 학습량 10 갱신, seed 0 ~ 2) 는 e01 과 같다.

| gamma_F | 위반이 k 스텝 뒤일 때 F = gamma_F^k 가 0.5 가 되는 k | 대략의 시야 |
| --- | --- | --- |
| 0.9 (e01 정책 재사용) | 6.6 | 33분 |
| 0.97 | 22.8 | 1.9시간 |
| 0.99 | 69.0 | 5.7시간 |

gamma_F 는 F 학습 목표와 그 목표로 학습되는 표현에 모두 영향을 주므로, gamma_F 마다 정책을 새로 학습한다. 따라서 정책도 달라진다 (아래 한계 참고).

## 주 지표: 위반 조기 경보 (A0)

e01 에서는 위반이 이미 진행 중인 스텝까지 정답에 넣어 현재 NH4 만으로도 AUROC 0.99 가 나왔다. 이번에는 **아직 위반이 아닌 순간** 만 본다.

- 자료: 각 정책을 학습 날짜(건기 0 ~ 6일)에서 차단 없이 하루씩 돌린 궤적
- 대상 스텝: 현재 스텝 t 가 위반 스텝이 아닌 경우만
- 정답: t+1 ~ t+H 안에 위반 스텝이 처음 생기는가. H = 12 (1시간), 24 (2시간). 하루 끝 H 스텝은 뺀다
- 점수: F(s_t, a_t), 그리고 비교용으로 현재 NH4 측정값(관측 0번)
- 지표: AUROC

## 보조 지표: 같은 에너지에서의 위반 (A1)

e01 의 개입 비율 맞춤이 평가 구간에서 깨졌으므로, 이번에는 한 점을 맞추지 않고 곡선으로 비교한다.

- 각 정책에 F 차단 tau = 0.3, 0.5, 0.7, 0.9 와 NH4 규칙 차단 theta = 3.0, 3.5, 4.0, 4.5 를 붙여 건기 평가 (14일, 후반 7일)
- NH4 규칙의 (에너지, 순간 위반 %) 4점을 에너지 순으로 잇는 선형 보간으로, F 차단 각 점과 같은 에너지에서의 규칙 위반 % 를 구한다. 규칙 곡선 에너지 범위 밖의 F 점은 비교에서 뺀다
- 차이 = F 위반 % 에서 보간한 규칙 위반 % 를 뺀 값. 음수면 F 가 같은 에너지로 위반을 더 줄였다

## 가설 (사전 등록)

- H1. 조기 경보 AUROC (H = 12) 에서 F 는 gamma_F 가 클수록 높아진다 (0.9 < 0.97 < 0.99 의 seed 평균).
- H2 (주 가설). gamma_F = 0.97 또는 0.99 의 F 는 조기 경보 AUROC (H = 12) 에서 같은 정책의 NH4 측정값보다 높다. seed 3개 중 2개 이상에서 높고 seed 평균도 높으면 지지로 적는다.
- H3. gamma_F = 0.97 또는 0.99 에서, 비교 가능한 F 차단 점의 평균 차이(위 정의) 가 음수다. seed 3개 중 2개 이상에서 음수이고 seed 평균도 음수면 지지로 적는다.

0.97 과 0.99 중 하나라도 기준을 넘으면 지지로 적되, 어느 쪽인지 밝힌다. 가설이 기각되는 결과도 그대로 기록한다.

| 선택 | 마지막 정책만 쓴다 |

## 미리 밝히는 한계

- gamma_F 를 바꾸면 표현과 정책이 함께 바뀐다. 조기 경보 지표는 각 정책 자신의 궤적에서 재므로, 정책 차이가 정답 분포를 바꿀 수 있다. NH4 측정값과의 비교는 같은 궤적 안에서 하므로 공정하다.
- 위반을 막을 수 있는지는 공정의 응답 속도에 달려 있다. 미리 알아채도 최대 폭기로 막지 못하는 위반이 있다 (최대 폭기만으로도 건기 위반 15.8%).
- 10 갱신, seed 3개의 탐색적 실험이다.

## 실행 명령

```bash
cd Park/code
export BSM1_ARCHIVE=<BSM1.zip> WANDB_MODE=disabled OMP_NUM_THREADS=1
for g in 0.97 0.99; do for s in 0 1 2; do
  python train.py --method fcsrl --seed $s --updates 10 --feasibility-discount $g --prepared <결과>/prepared --out <결과>/runs/fcsrl_g${g}_s$s
done; done
cd ../experiments/e02
for g in 0.9 0.97 0.99; do for s in 0 1 2; do
  python run_e02.py one --gamma $g --seed $s --prepared <결과>/prepared --runs <결과>/runs --out <결과>/e02
done; done
python run_e02.py report --out <결과>/e02 --md results.md
```

gamma_F 0.9 정책은 Park/e01 에서 학습한 것이다. 환경은 Park/e01 과 같다.

### 사전 등록 가설 판정

- H1 지지 안 됨. 1시간 조기 경보 AUROC 가 0.990, 0.995, 0.986 으로 gamma_F 를 키워도 꾸준히 오르지 않았다. 0.9 에서도 이미 0.99 다.
- H2 지지 (0.97, 0.99 모두). 세 seed 모두 F 가 NH4 측정값보다 높았다 (1시간 약 0.99 대 0.73, 2시간 약 0.99 대 0.45).
- H3 지지 (0.97, 0.99 모두). 같은 에너지에서 F 차단의 위반이 NH4 규칙보다 모든 seed 에서 낮았다. 차이는 0.4 ~ 2.3 %p 로 작다. 사전 등록 대상은 아니지만 0.9 에서도 같은 방향이었다.

### 해석

- Park/e01 의 결론("F 는 NH4 측정값과 거의 같은 신호") 은 위반 진행 중인 스텝을 섞은 지표 때문이었다. 위반 전 스텝만 보면 F 는 NH4 측정값이 놓치는 다가오는 위반을 알아챈다.
- 그 원인은 discount 가 아니었다. 0.9 에서도 F 의 조기 경보는 이미 높았다.
- e01 의 사후 분석(에너지당 위반 감소에서 F 가 규칙보다 낮음) 은 차단 없음 한 점과의 직선 비교였다. 이번 곡선 비교에서는 같은 에너지에서 F 가 조금 나았다. 사후 분석 결과는 근거로 쓰지 않는다.

### 한계 (결과를 보고 확인한 것)

- 조기 경보는 학습 날짜(건기 0 ~ 6일) 에서 쟀다. F 는 같은 날짜의 궤적으로 학습됐으므로 학습 표본 안의 성능이다. 평가 구간이나 우기에서 다시 재야 한다.
- BSM1 건기 유입은 하루 주기가 뚜렷하고, 관측에 시각(sin, cos) 과 유입 유량, 유입 NH4 가 있다. F 의 높은 AUROC 가 "언제 위반이 오는지" 를 시각과 유입으로 외운 결과일 수 있다. 시각과 유입만 쓰는 단순 예측기를 비교군으로 넣어야 F 의 기여를 말할 수 있다. 현재 NH4 측정값은 이 경우 약한 비교군이다.
- 같은 에너지 비교의 차이(1 ~ 2 %p) 는 seed 사이 편차(약 3 ~ 4 %p) 보다 작다. 같은 정책 안의 짝 비교라서 방향은 일관되지만 크기는 작다.
- 10 갱신, seed 3개, 건기만 본 탐색적 실험이다.
