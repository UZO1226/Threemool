# e109 폭기 증가 전 관측으로 NH4 예측 보정의 이득을 직접 학습

**기본 환경을 유지한다.** NH4 하락 대신 보정이 실제로 유용했던 창을 학습시켜도, 문턱 0.5에서 학습 후반과 겨울 모두 선택이 0건이었다. 겨울에서는 유용한 창에 높은 점수를 주는 능력도 AUC 0.493이었다. 공통 FCSRL 제어기의 공기량을 바꾼 실험은 아니다.

## 무엇을 바꿨나

두 분류기는 같은 학습 날짜, 폭기 증가 창, 세 입력(현재 NH4, 직전 1시간 NH4 변화, 현재 유입량), 날짜 가중, L2 로지스틱과 문턱을 사용했다. e107은 실측 NH4 하락을 학습했고 e109는 같은 기록에서 e106의 0.05 보정이 기본보다 3시간 NH4 절대오차를 줄이고, 1~3시간 NH4 변화 및 3시간 최대 DO 절대오차를 각각 키우지 않았는지를 학습했다. 각 창에는 하나의 3시간 경로를 선택한다. 평가일의 미래 실측은 정답 및 오차 계산에만 사용한다.

| 폭기 증가 창 | 학습 앞 140일 | 학습 후반 48일 | 겨울 개발 40일 |
| --- | ---: | ---: | ---: |
| 유용한 창 / 전체 | 17/194 | 9/48 | 43/67 |
| 날짜 동일 가중 유용 비율 | 8.3% | 20.6% | 67.1% |
| e109 예측 확률 범위 | 적합 구간 | 0.015~0.147 | 0.013~0.206 |
| 유용 창에 대한 AUROC, e107 / e109 | 적합 구간 | 0.421 / 0.605 | 0.464 / 0.493 |
| Brier 손실, 학습 빈도 상수 / e109 | 적합 구간 | 0.179 / 0.181 | 0.566 / 0.563 |

학습에서 기간을 옮길수록 유용 창의 비율이 크게 달라졌다. 겨울의 직접 표적 확률은 실제 빈도보다 전반적으로 낮았고, 순위도 무작위 수준에 가까웠다. 이번 결과는 표적의 빈도 변화만으로 설명된다고 단정할 수 없다. 유용성은 단일 고정 보정과 세 오차 조건에 의존하며, e50이 이미 학습한 날짜의 예측 오차로 분류기의 학습 표적을 만들었다. 이 점과 계절 및 유입 조건의 변화는 이 비교에서 분리하지 못했다.

## 실제로 어떤 창을 골랐나

각 셀의 세 오차는 차례로 3시간 NH4 농도, 1~3시간 NH4 변화, 3시간 최대 DO의 날짜 동일 가중 MAE다. NH4는 mg N/L, DO는 mg O₂/L다. 선택 중 유용 창은 해당 창에서 세 오차 조건이 모두 성립한 횟수다.

| 선택 규칙 | 학습 후반 유용/선택 | 학습 후반 세 오차 | 겨울 유용/선택 | 겨울 세 오차 |
| --- | ---: | --- | ---: | --- |
| 기본 | 0/0 | 0.84149 / 0.85759 / 0.18781 | 0/0 | 3.11568 / 2.04250 / 0.63018 |
| 항상 보정 | 9/48 | 0.89433 / 0.87180 / 0.17430 | 43/67 | 2.77585 / 1.84139 / 0.60771 |
| 하락 표적 0.5 (정정 e107) | 5/32 | 0.85130 / 0.84350 / 0.18403 | 43/66 | 2.79186 / 1.85000 / 0.60712 |
| 유용 표적 0.5 (e109) | 0/0 | 0.84149 / 0.85759 / 0.18781 | 0/0 | 3.11568 / 2.04250 / 0.63018 |
| 하락 표적 학습 분위수 | 0/2 | 0.85293 / 0.85421 / 0.18751 | 5/11 | 3.08027 / 2.01624 / 0.62785 |
| 유용 표적 학습 분위수 | 0/1 | 0.83554 / 0.85442 / 0.18783 | 4/8 | 3.07902 / 2.02359 / 0.62789 |
| e108 사후 선택 | 9/9 | 0.78455 / 0.83556 / 0.17708 | 43/43 | 2.79351 / 1.84883 / 0.61052 |

주 비교에서 기본 대비 3시간 NH4 오차 감소는 양 기간 모두 0이고, 탐색 95% 구간도 [0, 0]이었다. 선택 경로가 전부 같아서 나온 값이다. 하락 표적 대비 직접 표적의 같은 오차 감소는 학습 후반 +0.010 [−0.039, +0.070], 겨울 −0.324 [−0.471, −0.164] mg N/L였다. 구간은 날짜 7일씩 2000회 순환 재표집했다.

보조 문턱은 학습 유용 빈도 8.3%만큼 높은 점수를 선택하도록 앞 140일에서 정했다. 고정 문턱은 e107 0.8471, e109 0.1224였다. 이 설정의 e109는 겨울 8건 중 유용 4건을 찾았고 세 평균 오차가 모두 줄었다. 학습 후반에는 선택한 1건에서 최대 DO 오차가 소폭 커졌다(기간 평균 0.18781 → 0.18783). 주 문턱과 보조 문턱 어느 쪽도 두 기간의 공동 기준을 통과하지 못했다. 학습 날짜로 문턱을 고정했으므로 평가 날짜에서 두 모델의 선택 횟수는 달라질 수 있다.

## 다음 판단과 범위

같은 겨울 기록을 보고 문턱을 더 맞추는 것보다 먼저 확인할 점은 학습용 유용성 표적이 평가 때와 같은 방식으로 만들어졌는지다. 가능하면 날짜를 나눠 해당 날짜를 학습에서 뺀 대리 모델로 보정 전후 오차를 계산하고, 기존 학습 표적의 빈도와 일치도를 비교하는 것이 다음 진단이다. 여기서 빈도가 달라져도 실제 겨울 순위가 회복되는지는 별도 검증이 필요하다. DARROW 기록 행동과 증가 창의 환경 예측 실험이므로 FCSRL의 실제 공기 절감이나 한계에 관한 결론은 없다.
