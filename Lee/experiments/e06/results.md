## 가설 판정

| 가설 | 결과 |
| --- | --- |
| H18. 벌점이 원래 FCSRL 의 하루 비용을 줄인다 (공기량 +3% 이내) | **기각.** 선택 모델 비용은 0.1 에서 +3.5%, 0.3 에서 +3.8%, 1.0 에서 +131.8% 로 오히려 높고, 공기량은 +11% 에서 +60% 늘었다 |
| H19. 가중치가 클수록 비용이 더 줄고 공기량이 는다 | 공기량이 느는 것은 맞다(+11, +17, +60%). 비용은 줄지 않고 늘었다. 1.0 에서는 학습이 무너졌다 |
| H20. 마지막 모델에서도 같은 방향이다 | **일관성 없음.** 0.1 만 비용이 -6.0% 로 낮고(p=0.50, 한도 만족 seed 2/5 에서 3/5), 0.3 은 +4.6% 로 높다. 둘 다 표준편차보다 작은 차이다 |

## 해석

- **원래 FCSRL 대비 개선은 없다.** 가장 안전하게 보이는 0.1 도 선택 모델에서 비용이 3.5% 높고 공기량은
  11% 더 쓴다. 마지막 모델의 -6.0% 는 표준편차(2.26)보다 작고 p=0.50 이라 우연과 구분되지 않는다.
- **가중치 1.0 은 학습을 무너뜨렸다.** 벌점이 기본 이점과 같은 크기가 되어 정책을 지배했고, 비용 한도를 넘는
  정도가 커서 승수가 14 까지 올랐다. DO 위반이 5.7%(마지막 모델 17.3%)로 늘었으므로 공기를 과하게 넣는
  쪽으로 밀렸다. 이 방향이 원인이라고 이 자료만으로 확정할 수는 없다. 벌점이 높은 feasibility 상태로
  가는 행동을 억제하는데, 그 억제가 과폭기로 나타났다는 해석이 가능하다.
- 벌점이 행동에서 안전한 쪽으로 일관되게 작용했다고 볼 근거는 없다. 공기량 증가는 확실하지만 비용 감소는
  없으므로 안전과 에너지의 좋은 교환도 아니다.
- 참고: 원래 FCSRL 은 PPO-Lag 보다 공기량이 선택 모델 기준 22.5% 적고(33,745 대 43,564, p=0.025)
  비용은 비슷하다. Yoo/e06 과 같은 방향이다.
- Lee/e05 (BSM1)에서 가중치 0.3 이 보인 개선은 이 데이터에서는 재현되지 않았다. 환경과 설계가 달라서
  직접 비교할 수는 없지만, e05 의 개선이 한 seed 에 의존했다는 판단과 일치한다.

## 한계

- 대리 모델 위의 결과이고 실제 공정이 아니다. 대리 모델은 NH4 위반을 실제보다 낮게 예측한다 (Yoo 확인).
- 검증 구간에서 모델을 고르고 같은 구간을 보고하므로 선택 편향이 있다. 마지막 모델을 함께 보고했고 test
  구간은 쓰지 않았다.
- 학습 404,096 전이는 수렴을 보장하지 않는다. seed 5개의 탐색적 비교이며 Welch 검정에 다중 비교 보정이 없다.
  유의하지 않다는 것이 효과가 없다는 증명은 아니다.
- 이 기기에서 Yoo 의 결과가 완전히 같게 재현되지는 않았다 (위 재현 검사).
- 비용이 0, 1, 2 값이라 feasibility 의 "계속 안전할 확률" 해석(명제 4.1)이 엄밀하게 성립하지 않는다.

## 재현

```bash
python -u Lee/code/avedore/prep.py --raw <데이터>/aved_raw.csv --out <데이터>/aved_5min.pkl
python -u Lee/experiments/e06/run_av.py --data <데이터>/aved_5min.pkl --model <데이터>/surrogate.json \
  --upstream <원본 FCSRL> --out <결과>/e06_runs --parallel 5 --jobs <방법:seed 25개>
python -u Lee/experiments/e06/report_av.py --runs <결과>/e06_runs --out Lee/experiments/e06
```

실행 커밋과 입력 해시는 [summary.json](summary.json) 의 `code_commit`, `data_sha256`, `surrogate_sha256` 에
있다. 체크포인트와 전체 로그는 저장소 밖 `IoT_project2/results/e06_runs/` 에 있고, 중단된 첫 시도의 로그는
`e06_runs_attempt1_crashed/` 에 보관했다.
