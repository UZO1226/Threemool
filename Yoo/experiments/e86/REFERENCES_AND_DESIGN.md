# e86 기존 FCSRL 위험 점수의 예측 표적 대조

e85의 감량 위험 순위가 약했던 이유를 좁힌다. 같은 후보에서 기존 점수가 학습 방식에 맞춘 위반 변화는 구별하지만 누적 NH4 악화는 구별하지 못하는지, 또는 기본 명령에서의 절대 위험만 구별하는지 확인한다.

뒤 48개 학습 날짜 내 e85 적격 후보 전체를 쓴다. 날짜마다 총 가중치 1, seed별 요약과 5개 seed 단순평균. 날짜, 시각, 대리 모델 구성원을 독립 반복으로 간주하지 않는다. 겨울 및 시험일을 열지 않는다.

- 주 진단은 행동 점수 차이(감량 빼기 원 명령)로 끝 상태 추정값을 포함한 할인 최대 비용 증가(차이 > 1e-8)를 구별하는 날짜 가중 AUC다. 해당 seed에서 양성과 비양성 날짜가 각각 5개 이상이고 AUC ≥ 0.60이면 통과다. 4/5 이상 통과하고 관측 비용만 사용한 할인 최대 비용에서도 같은 기준을 통과할 때 표적 차이 설명을 지지한다. 끝값 사용 여부에 따라 결과가 다르거나 양성 날짜가 부족하면 각각 구분해 기록한다.
- 보조 대조는 같은 구간에서 끝값 없는 합산 할인 최대, NH4 단독 할인 최대, 합산 위반 횟수, NH4 위반 횟수, e85의 NH4 횟수 또는 초과 적분 악화다. 방향별 건수와 날짜 수를 남긴다. 대부분 동률일 수 있어서 단순 정답률로 비교하지 않는다. 각 AUC의 양성 정의가 다르므로 차이를 인과 효과로 해석하지 않는다.
- 절대 위험은 기본 행동 점수로 원 명령 경로의 6시간 내 합산 위반 발생을 구별하는 AUC다. 같은 지원 날짜 및 AUC 기준을 쓴다. 이는 행동 간 차이를 예측하거나 수질을 개선하는지와 별개의 질문이다. 외부 검증이나 감량 정책 채택에 쓰지 않는다.
