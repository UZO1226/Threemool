# Yoo/e18: BSM1 DO 설정값 제어와 같은 출발점 시험

## 목적

e17 의 네 가지 문제를 고친 설정이 실제로 학습되는지 짧게 확인한다. 이 시험을 통과하면 e19 에서 5-seed 본 실험을 한다.

| e17 의 문제 | e18 의 처리 |
| --- | --- |
| 행동이 KLa5 직접 조절이라 탐색이 어렵고 운전 범위를 벗어나기 쉽다 | 행동을 5번 조 DO 설정값(0.5 ~ 3.0 mg/L)으로 바꾸고, 원본 BSM1 DO PI 가 1분마다 추종한다 |
| 방법마다 초기 정책이 달라 학습 효과와 초기화 차이가 섞였다 | 정책 평균 마지막 층을 0, 편향을 설정값 2.0 으로 둔다. 모든 방법이 DO PI 와 같은 정책에서 출발한다 |
| 경사 clipping 비율 77 ~ 92% | 가치망 출력 척도 `value_scale = 100` (하루 반환값 규모). 정책과 가치망 clipping 비율을 따로 기록한다 |
| 평균 NH4 4 mg/L 한도가 느슨해 lambda 가 0 근처 | 한도를 학습 날짜에서 DO PI 가 낸 평균 비용으로 둔다. "DO PI 와 같은 평균 NH4 에서 에너지를 줄이는" 문제다 |

초과 시간 제약은 쓰지 않았다. 최대 폭기(고정 KLa 240)도 건기 초과 시간이 15.2% 라 DO PI(16.4%)와 차이가 작고, 막을 수 없는 부하 정점에서 폭기를 포기하는 정책을 부추길 수 있다. 초과 시간은 보조 지표로 보고한다.

## 환경과 기준 제어 (`setpoint_env.py`, `abac.py`, `prepare.py`)

- e16 정상상태에서 건기 14일을 DO PI(설정값 2)로 운전한 상태를 평가 시작 상태로 쓴다
- 학습은 그 상태에서 이어지는 건기 0 ~ 6일의 하루 시작 snapshot(PI 적분 포함)에서 하루씩 reset 한다
- 평가는 e17 과 같다. 평가 시작 상태에서 14일 연속 운전하고 후반 7일을 집계한다. 건기와 우기(우기는 학습에 쓰지 않음)
- 관측 12차원: e16 관측에서 직전 KLa 를 직전 설정값으로 바꾸고 현재 KLa 를 덧붙였다
- 보상 −폭기 에너지 / 기본 폭기 에너지, 비용은 e17 과 같은 유량 가중 NH4 부하
- 상수 설정값 2.0 의 결과가 e17 DO PI 기준과 소수점 넷째 자리까지 같음을 확인했다 (건기 3,717.76 kWh/일, NH4 2.5671)

학습 날짜(건기 0 ~ 6일, 하루 reset)에서 잰 기준:

| 제어 | 폭기 kWh/일 | 유량 가중 NH4 | NH4 > 4 시간 |
| --- | --- | --- | --- |
| DO PI 설정값 2.0 (출발점, 한도 기준) | 3,716.3 | 2.420 | 16.38% |
| 고정 설정값 1.5 | 3,598.4 | 2.545 | 17.35% |
| 고정 설정값 2.5 | 3,836.4 | 2.345 | 15.86% |
| ABAC 최선 (평균 NH4 가 DO PI 이하인 조합 중 최소 에너지) | 3,813.5 | 2.394 | 16.00% |

- 비용 한도는 174.234 (평균 NH4 2.420 mg/L 에 해당)
- 고정 설정값 0.75 ~ 3.0 의 결과는 볼록한 경계를 이룬다 (`constant_setpoint_frontier.json`). 설정값을 올릴수록 수질 개선 폭이 줄어든다
- ABAC 격자 30개(NH4 목표 1.0 ~ 3.0, Kp 0.25 ~ 1.0, Ti 1 ~ 3시간)는 모두 이 경계보다 나빴다. 방류 NH4 피드백만으로는 반응이 늦다. 그래서 RL 이 넘어야 할 기준은 ABAC 가 아니라 고정 설정값 경계다

## 학습 설정 (`train.py`)

| 항목 | 값 |
| --- | --- |
| 방법 | PPO-Lag, FCSRL + PPO-Lag (e05 의 원본 표현 손실 결합) |
| seed | 0, 1 |
| 학습량 | 60회 갱신 x 5,760전이 = 345,600전이 (4환경 x 1,440전이, 갱신마다 하루 20개) |
| PPO | e17 과 같다. actor 3e-4, critic 1e-3, gamma .99, GAE .95, clip .2, 10 epoch, batch 512, KL .02, 경사 clip .5 |
| 초기 log std | −1.2 (행동 단위 0.30, 설정값 약 0.38 mg/L) |
| PID | e17 과 같은 단위 환산 (계수 x 15 / 한도), lambda 상한 20 |
| 저장 | 10회 갱신마다 가중치, 마지막 정책으로 평가. 중간 모델 선택 없음 |

## 판정 기준 (결과를 보기 전에 정함)

e18 은 설정 확인 단계다. 아래를 모두 만족하면 e19 본 실험으로 간다.

1. 같은 출발점: 학습 전 결정적 정책의 학습 날짜 비용이 DO PI 와 같다 (코드에서 assert)
2. 학습 안정성: NaN 없음, 정책 clipping 비율 중앙값 50% 미만, 가치망 clipping 비율 중앙값 20% 미만
3. 제약 작동: 마지막 10회 갱신의 lambda 가 0 도 아니고 상한 20 에도 붙지 않는다
4. 학습 효과: 마지막 정책이 학습 날짜에서 평균 NH4 2.420 이하(5% 여유, 2.541 이하)를 지키면서 DO PI 보다 폭기 에너지가 적거나, 같은 에너지에서 고정 설정값 경계보다 NH4 가 낮다. seed 2개 중 하나 이상

4번이 하나도 안 되면 본 실험 대신 원인(탐색 잡음, 관측, 학습량)을 먼저 본다.

마지막 정책은 학습 날짜에서 에너지를 2.4 ~ 7.2% 줄였지만, 이는 설정값을 그냥 낮춘 것과 같은 효과다(평균 설정값 1.1 ~ 1.7). 14일 연속 평가에서도 같은 경향이다.

e17 대비 경사 문제는 원인을 확인했다. 가치망 clipping 이 0% 가 되어, e17 의 77 ~ 92% 는 가치망 목표 규모(하루 반환값 약 100) 때문이었다.

### 원인 확인 (사전 규칙에 따라 본 실험 전에 수행)

1. 제약 미달: PID 계수를 e17 방식(15 / 한도)으로 환산하면 상대 오차에 대한 반응이 e03 과 같은데, e03 은 218회 갱신, 이번은 60회였다. lambda 가 아직 오르는 중에 학습이 끝났다
2. 경계 미달: 5번 조만 제어하는 구조에서는 단순한 동적 규칙도 경계를 거의 넘지 못한다. 학습 날짜에서 시각별 일정(설정값 = a + b cos(하루 위상 − φ))과 유입 부하 비례 규칙 45개를 시험했고, 가장 좋은 것이 경계 대비 −1.13% 였다. 시간대별 배분으로 얻을 수 있는 이득 자체가 1% 안팎이라, 탐색 잡음이 있는 짧은 학습으로는 찾기 어렵다
3. 제어 범위: 3, 4번 조가 KLa 240(최대)으로 고정이라 폭기 에너지 대부분을 정책이 바꿀 수 없다. 5번 조 DO PI 를 둔 채 3, 4번 조 KLa 만 240 에서 80 으로 낮추면 에너지가 3,716 에서 2,291 kWh/일로, NH4 가 2.42 에서 6.85 로 바뀐다. 5번 조만으로는 약 500 kWh 폭이다. 4번 조 평균 DO 는 2.68 로 과포기다

3, 4, 5번 조 모두를 같은 설정값의 DO PI 로 제어하는 구조에서 같은 확인을 했다 (학습 날짜, 하루 예열 뒤 집계).

| 구조 | 고정 설정값 2.0 의 폭기 kWh/일 | NH4 | 단순 동적 규칙의 경계 대비 최선 |
| --- | --- | --- | --- |
| 5번 조만 DO PI (e18 본 시험) | 3,716.3 | 2.420 | −1.13% (시각별 일정) |
| 3, 4, 5번 조 DO PI | 3,460.6 | 2.481 | −3.09% (유입 부하 비례) |

3, 4, 5번 조 DO PI 는 RL 없이도 비슷한 NH4 에서 에너지가 약 7% 적다. 따라서 이후 비교 기준은 이 구조의 고정 설정값이어야 한다. 동적 배분의 여지도 약 3배로 커진다.
