# e77 현재 폭기량을 바꿨을 때의 한 시간 수질 차이

2026-11-23 완료. 공기를 아낄 수 있는 시점을 구별하는 신호는 5개 정책 모두에서 관찰됐다. 추가 폭기가 NH4를 낮추는 시점은 모든 정책에서 분류 기준에 미달해 두 방향을 함께 쓰는 보조망 학습은 보류했다. [계산 전 설계](REFERENCES_AND_DESIGN.md), [수치와 입력 해시](summary.json).

학습 188일 안에서 실측 상태를 시작점으로 썼다. 앞 140일에서 관측 범위와 분류기를 정하고 뒤 48일에 판정했다. 후보 공기량 차이와 범위 조건을 만족한 시점은 각각 718/3,080개와 305/1,056개다. 결과의 분모는 적격 시점이다. 두 행동의 첫 15분만 바꾸고 이후 45분 동안 각 e58 기본 FCSRL이 피드백으로 결정했다. 저공기 유리는 1시간 총공기 25 m³ 이상 감소 및 NH4 위반 수, 초과 적분과 DO 위반 수 비악화다. 고공기 유용은 NH4 개선과 DO 비악화다. 모델 5개 중 4개 이상이 같은 방향에 동의한 표적을 기존 관측 11개로 구별했다.

양 방향 각각 정밀도와 재현율 60% 이상 등 사전 조건을 충족한 정책은 0/5였다(진행 기준 4/5). 저공기 유리 표적 자체의 비율도 74.8~77.4%라서 정밀도는 이 비율과 함께 읽어야 한다. 저공기 유리로 잘못 분류한 경우는 seed별 2~10개이며 그중 고공기 유용 표적은 0~2개다. 한 시간 이후의 누적 수질, 하루 전체 공기 절감률, 분류기로 매번 개입했을 때의 상태 분포는 이 진단 범위 밖이다.

기록 공기가 500 Nm³/h 이상 증가한 36개 창(25일)에서 1시간 뒤 NH4 평균절대오차는 모델 0.589, 현재 농도 유지 1.385 mg/L였다. 감소한 36개 창(26일)에서는 각각 0.364, 0.554였다. 기존 정책과 모델이 이미 학습한 날짜에서 기록 행동을 재생한 값이다. 실제 공기를 다르게 넣었을 때의 수질은 관측할 수 없었다. 구성원들은 같은 데이터와 모델 제약을 공유한다. 겨울 외부 성능은 별도 검증이 필요하다.
