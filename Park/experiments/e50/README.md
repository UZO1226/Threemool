# Park/e50: 한 기여 중심의 주장 지도 (Kaggle DARROW)

상태: **사전 등록 (2026-11-20).** 분류 규칙은 지도를 쓰기 전에 정했다. 새 학습과 새 평가는 없다. 대표는 바꾸지 않는다.

## 목적

팀 중간점검 (Yoo/analysis/TEAM_RESEARCH_REVIEW_20261117.md) 8절 7번은 "하나의 기여를 중심으로 원고 구성: 주 주장 하나, 대표 비교, 제거 대조, 새 확인, 실패와 한계가 연결됨" 을 요구했고, 8.1 절은 Park 에 "한 페이지 현재 상태" 에 해당하는 정리를 권했다. e1 ~ e49 는 실험 모음으로 흩어져 있어 원고의 주 주장이 무엇이고 어디까지 말할 수 있는지가 한눈에 보이지 않는다. 이 실험은 기존 결과만으로 주장 지도 한 쪽을 만든다.

## 분류 규칙 (사전 등록)

- 주 주장: 사전 등록 판정에서 지지됐고, 겹치지 않는 묶음 단위 판정과 날짜 블록 구간 (Park/e49) 이 모두 같은 방향인 것 하나. 후보가 여럿이면 공기량을 통제한 비교를 우선한다
- 보조 근거: 사전 등록 판정에서 지지된 것 가운데 주 주장의 조건 (모델 오차, 지연, 사건 단위, 새 seed) 을 넓히는 것
- 기여 분리: 차단, 학습 설정, 학습 정책, FCSRL 표현의 몫을 같은 공기량 또는 같은 설정 비교로 나눈 값. 판정 기준을 넘지 못한 것은 "확인되지 않음" 으로 적는다
- 한계와 실패: 사전 등록 판정에서 기각되거나 판정하지 못한 것, 그리고 주 주장을 좁히는 것. 숨기지 않고 주장 옆에 둔다
- 사후 관찰: 판정 없이 결과를 보고 찾은 것. 따로 표시하고 주장의 근거로 쓰지 않는다
- 수치는 Park/RESULT.md 와 각 실험의 results.md 에 이미 있는 값만 쓴다. 새로 계산하거나 다시 고르지 않는다

## 미리 밝히는 한계

- 정리 실험이라 새 증거를 만들지 않는다. 점수를 올리는 것은 정리 자체가 아니라 정리된 근거다
- 모든 결과는 같은 대리 모델 계열의 환경과 반복 사용한 검증 40일에서 나왔다. test 는 쓰지 않았다
