# e141 위험 선택기가 명령을 바꿀 조건에서 한 시간 NH4 검산

**폭기를 늘리고 위험 선택기가 개입할 조건에서 실제 NH4 문턱 통과 26건 중 8건을 검출했고, 최초 통과 시점까지 맞은 것은 3건이었다.** 폭기 증가 뒤 60분 농도 예측은 초기 농도를 그대로 쓰는 기준을 평균적으로 개선하지 못했다. 다만 개입이 적은 조건에서도 틀렸고 실제 공기 감소 구간에서는 유지 기준보다 오차가 작았다. 겨울 기록 운전에서 관측된 결론이다. [사전 설계](REFERENCES_AND_DESIGN.md)

## 15분 단위 기록 공기 재생

e104의 비중복 창 132건에서 실측 시작 상태와 직전 공기로 e135의 위험 선택 단독 FCSRL 시드 5개를 각각 호출했다. 선택기가 원 Actor의 명령을 바꾼 시드가 3개 이상이면 개입 다수로 분류했다. 공정 모델에는 각 시드가 제안한 새 행동 대신 현장에서 실행한 구역별 실제 공기량을 넣었다. 예측은 다섯 구성원 평균 농도 경로다. 아래 농도와 MAE는 날짜 내 평균 후 날짜에 같은 비중을 두었다. 문턱은 NH4가 4 mg N/L보다 높은 상태로 바뀌거나 그 상태에서 회복하는 최초 시점이며 사건 수는 원래 창 수로 셌다.

| 기록 공기 | 개입 다수 | 창 / 날짜 | 실측 / 예측 NH4 변화 | 모델 / 농도 유지 MAE (mg N/L) | 검출 / 실제 통과 | 정확한 시점 / 검출 | 오경보 |
| --- | --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 증가 | 예 | 51 / 35 | −1.324 / +0.099 | 1.530 / 1.513 | 8 / 26 | 3 / 8 | 2 |
| 증가 | 아니오 | 16 / 14 | −1.303 / +0.350 | 1.878 / 1.577 | 0 / 1 | 해당 없음 | 0 |
| 감소 | 예 | 32 / 21 | +0.087 / +0.254 | 0.978 / 1.175 | 1 / 3 | 1 / 1 | 0 |
| 감소 | 아니오 | 33 / 24 | +0.311 / +0.162 | 0.620 / 0.710 | 0 / 0 | 해당 없음 | 0 |

증가하며 개입 다수인 51건에서 실측 통과 26건 중 22건은 4 초과에서 회복했고, 4건은 4 초과로 진입했다. 모형은 18건을 놓쳤고 실측 통과가 없던 25건 중 2건에 오경보를 냈다. 농도 유지는 모든 창에서 통과를 예측하지 않아 검출 0건, 오경보 0건이다. 60분 종점 변화 부호가 맞은 비율은 이 조건에서 날짜 가중 57.6%였다. 평균 변화 부호가 반대여도 모든 개별 창의 부호가 반대인 것은 아니다. [조건별 수치](summary.csv)

## 개입 조건에 오차가 집중됐는가

폭기 증가에서 모델 MAE와 농도 유지 MAE의 차이는 개입 다수 +0.017, 소수 +0.301 mg N/L다. 개입 다수에 실제 문턱 사건이 많이 있었으나 개입 소수의 실제 사건은 1건뿐이라 검출률의 집단 차이를 판단하기 어렵다. 초기 NH4, 수온, 유입량, 공기 변화 크기와 방향을 함께 구분한 뒤 양 집단이 모두 남은 증량 층은 4개였다(다수 13건, 소수 5건). 감량은 6개 층(12건, 22건)이었다. 동일 운전 조건의 두 집단을 충분히 비교했다는 근거가 약하다. [조건별 겹침](strata.csv)

개입 다수 증량 51건 중 선택 명령이 실제 공기와 가까운 시드가 과반이었던 창은 1건이었다(후보 간격의 절반인 ±281.25 Nm³/h). 감량 다수도 32건 중 1건이었다. 따라서 현장 운전이 위험 선택기와 같은 행동을 했다면 어떤 수질이 됐을지는 이 결과에서 읽을 수 없다. 모형이 실제로 받은 공기에도 회복 시점을 자주 놓친다는 점은 확인했다. 수질을 예측할 때 어느 정도 신뢰를 둘 수 있는지를 보여주는 진단이다.

## 받은 피드백의 판단

1. e139의 10~11월 실측 / 재생은 NH4 95.25 / 529.65분, DO 127.88 / 35.70분이다. e104의 겨울 증량 한 시간 변화는 −1.295 / +0.122 mg N/L였다. 이 두 실험은 다른 학습 기간의 공정 모델을 쓴다. 재생 오차가 확실해도 정책 순위가 뒤집힌 원인은 정해지지 않는다. [e139](../e139/README.md), [e104](../e104/README.md)
2. e139에서 보정된 Actor에 위험 선택을 더해 세 수질 조건을 충족한 시드는 같은 공기 범위에서 5/5, 4/5였다. 위험 선택 위에 Actor 보정을 더하면 0/5, 1/5였다. 위험 선택은 보존할 근거가 있고 Actor 보정의 우선순위는 낮다. e140을 완료한 결과, 배율을 이전 기간에서 고정하면 세 수질을 지키면서 공기를 절약한 시드는 세 비교 각각 0/5였다. 이번 논문의 Actor 보정 추가 튜닝을 마무리할 근거다. [구성별 비교](../e139/README.md), [고정 배율 기간 이동](../e140/README.md)
3. Park/e86에서 검증 40일의 같은 ABAC에 차단을 붙이면 비용 차이는 −0.570(날짜 블록 95% 구간 −0.960~−0.260), 공기 차이는 −71 Nm³/일(−660~+566)이었다. Lee식 위험 선택과의 직접 비교는 이 실험에 없다. Park 차단은 원 코드에서 현재 구역 배분, 직전 구역 유량, 추가 외생 정보와 환경 구성원 번호(나머지 4개로 예측)를 사용한다. Lee식은 정책 관측과 주변 행동 5개로 한 시간 NH4 및 DO 위반률을 추정한다. 비교하려면 기본 정책, 접근 가능한 정보, 행동 후보와 공기 배율 선택 예산을 맞추고, 수정한 Park 차단과 원형의 결과를 구분해야 한다. [Park/e86](../../../Park/experiments/e86/results.md), [차단 구현](../../../Park/code/min_brake.py), [Lee/e63](../../../Lee/experiments/e63/trust_policy.py)
4. 다음 공정 모델 후보는 증량 시 실제 한 시간의 NH4 회복을 더 잘 잡고 감량 시 오차와 문턱 오경보를 늘리지 않는지 시험할 가치가 있다. e106에서 증량을 개선한 보정은 감량을 악화시켰고, e109에서는 유용 구간 탐지기가 고정 문턱에서 작동하지 않았다. 자료가 더 필요하다면 실제 수질 센서와 실행 공기가 짝지어진 새 기간, 특히 정책 후보와 기록 행동이 가까운 증량 사건이 우선이다. [e106](../e106/README.md), [e109](../e109/README.md)
