# e35: 원출처 확인과 DO 직접 폭기 구간 오류 수정

2026-11-10. e34 후속 작업의 첫 단계로 원출처를 확인했고, DO 센서에 대응하는 공기 입력을 잘못 지정한 오류를 발견했다. **대응 오류는 수정했지만 환경 정확도 문제가 해결되지는 않았다.** 이번 실험은 환경의 DO 모델15개 재학습이며 RL 정책은 새로 학습하지 않았다.

## 원출처에서 확인한 내용

[Kaggle 대회 데이터 설명](https://www.kaggle.com/competitions/dynamic-modeling-of-wastewater-treatment-process/data)의 공식 공개 API로 설명 본문과 공정도를 읽었다. 브라우저 검색 도구로 본문이 보이지 않았지만 `competitions.PageService/ListPages`의 읽기 요청으로 확인했다. 대회56933, 페이지250695의 재현 정보와 원문 SHA256은 [source_manifest.json](source_manifest.json)에 있다. 원문과 공정도는 `/home/jio/fcsrl_src/results/e35/sources/`에 보존했다.

| 원본 변수 | 설명에서 확인한 역할 | 문서상 단위 |
| --- | --- | --- |
| Q_air_1 | aerobic selector조의 공기 유량 | m³/h |
| Q_air_2 | facultative조의 공기 유량 | m³/h |
| Q_air_3, Q_air_4, Q_air_5 | 호기조1, 2, 3의 공기 유량 | m³/h |
| DO_1, DO_2, DO_3 | 호기조1, 2, 3의 DO 센서 | mg/L |
| NH4, NO3 | 호기 구간 끝의 농도, 최종 침전지 전 | mg/L |
| Q_inf | 처리장 전체 유입 유량 | m³/h |

- 공기 유량의 m³/h 단위를 확인했다. Nm³/h의 표준상태 조건은 명시되지 않아 N을 붙이지 않는다. e34의 단위 미확인 상태를 이 근거로 갱신한다.
- 원문은 NH4/NO3 단위를 mg/L로 적는다. 이 표기만으로 질소 환산 기준을 추가 확정하지 않는다. 온라인 NH4와 실험실 최종 방류수 NH4는 구별한다.
- 실제 폭기는 NH4와 DO의 cascade 제어다. 원문에는 이 연구의 DO 상한2나 평균 위반 허용6이라는 기준이 없다. 기준 방향을 반전하거나 한도를 완화하지 않았다.
- dynamic_influent의 성분은 실험실 평균값 등을 사용하는 생성기로 만든 ASM1 입력이다. 온라인 실측 유입 성분으로 부르면 안 된다. 이를 실시간 제어 입력으로 가정하는 연구에는 별도의 가용성 검증이 필요하다.
- 원문은2021년10월 이후 lab의 계산 유량이 신뢰하기 어렵다고 경고한다. 현재 코드는 온라인 Q_inf를 사용하므로 이 항목은 바꿀 필요가 없다.
- 그림은3개 병렬 처리 라인 중 생물학적 처리 흐름을 설명한다. 파일의5개 공기 채널 합을 처리장 전체 송풍기의 전력이나 전체 공기량으로 확대 해석하지 않는다.

## 발견한 오류

기존 `e30/surrogate_dw.py:monotone_constraints`는 DO1/2/3에 대해 같은 번호인 air1/2/3의 증가 방향을 강제했다. 실제 직접 대응은 air3/4/5다. 현재와 직전 공기 입력 모두 동일하게 잘못 지정되어 있었다.

| 목표 | 기존 양의 단조 제약 | 수정한 양의 단조 제약 | 24차원 입력의 수정 위치(0부터) |
| --- | --- | --- | --- |
| DO1 | 현재/직전 air1 | 현재/직전 air3 | 16, 21 |
| DO2 | 현재/직전 air2 | 현재/직전 air4 | 17, 22 |
| DO3 | 현재/직전 air3 | 현재/직전 air5 | 18, 23 |

센서값 자체나 CSV 열을 서로 바꿔 읽은 오류는 아니다. GBM 학습에 적용한 물리 사전 제약의 대상 열이 틀렸다. 모든 공기 열은 원래부터 입력에 있었기 때문에 기존 모델이 실제 대응 열을 전혀 못 본 것도 아니다. 기존 `diagnose.py`도 같은 잘못된 열을 검사해 통과했으므로, 그 통과가 올바른 구간 대응을 증명하지 못했다.

`mapping.py`는 원출처의 변수 이름으로 대응을 정의하고 알려진 입력 위치16/21,17/22,18/23과 독립 검산한다. 과거 재현을 위해 e30 코드는 보존했고 새 모델은 e35 경로에 따로 만들었다. 향후 새 환경에는 이 수정 대응을 사용한다. 과거 e30/e31/e33 정책 성과는 잘못된 DO 제약을 가진 대리 환경에서의 역사적 결과로 표시한다.

직접 구간에서 공기가 늘면 DO 변화량이 비감소하도록 하는 것은 기존의 모델 사전 가정이다. 대응을 고쳤다고 관측자료만으로 즉시 반응의 인과성이 검증되거나 모든 운전 조건에서 같은 반응이 보장되는 것은 아니다.

## 한 요소만 바꾼 대조

- 같은 e30 준비 데이터, 시간순 학습188일과 개발 검증40일, 구성원5개를 사용했다. test41일은 평가하지 않았다.
- DO1/2/3 모델15개만 위 대응으로 재학습했다. NH4/NO3 모델10개는 저장된 가중치를 그대로 유지했다.
- 각 모델의 추출 표본, random_state, 트리 설정, train 내부 조기 종료, clipping 상한을 유지했다. 조기 종료 반복 수는 고친 제약으로 학습하면서 달라질 수 있다.
- 기존 DO1 구성원0을 기존 설정으로 재학습해 원 체크포인트의 검증 예측을 정확히 재현하는지도 확인했다.
- RL 관측, 보상, 평균 한도, 액션, discount, 초기 모방 정책은 수정하지 않았다. 기록 행동을 그대로 넣고 환경만 비교했다.

DO1과DO3의 연속 재생 MAE는 감소했고 날짜별 차이의 bootstrap95%구간도0 미포함이다. DO2 차이의 구간은0을 포함한다. 반면 NH4 MAE는0.470 증가했고 구간[0.197,0.766]으로 악화했다. 날짜 사이 상관이나 검증자료 반복 사용을 모두 해결한 최종 통계 검증은 아니다.

원출처 대응 구간의 현재/직전 유량을 함께0.75배와1.25배로 바꾸는 단일 전이 진단에서, 기존 모델은 DO1의 경우 구성원별 약41~64% 표본에서 방향이 반대였다. 수정 후 같은 검사에서 세 DO와 모든 구성원의 역방향 비율은0이다. 이것은 강제한 구조의 확인이며 현실 반응 정확도 증명이 아니다.

한 스텝 DO 변화량의 R²는 오히려 감소했다(DO1 .210→.071, DO2 .508→.355, DO3 .127→-.024). 따라서 올바른 대상 열에 단조 제약을 넣는 일과 관측자료 예측 점수를 높이는 일은 같지 않았다. 제어 피드백, 시간 정렬, 지연과 자료 분포의 영향은 아직 분리하지 못했다.

**잘못된 대응으로 돌아가 점수만 높이지 않는다. 동시에 수정 모델을 신뢰할 수 있는 제어 환경으로 채택하지도 않는다.** DO 평균 오차 개선과 NH4/분류 성능 악화가 함께 남아 있어 다음 RL 본 실험은 보류한다. 공기량 절감은 이번 실험의 결과가 아니다. 모든 조건에서 기록 행동이 같았다.

## DO에서 NH4로 전달되는 영향 진단

`feedback_probe.py`는 재학습 없이 DO1, DO2, DO3 모델을 하나씩 교체해 NH4 재생에 미치는 영향을 비교한다. 추가로 매 시점의 DO 입력만 실측값으로 넣는 진단을 수행한다. 이 실측 입력은 미래 관측을 사용하는 평가용 oracle이며 실시간 정책의 성과로 해석하지 않는다. 결과는 `feedback_probe.json`에 보존한다. 개별 교체 효과는 상호작용 때문에 합산 분해로 해석하지 않는다.

| 교체 조건 | NH4 재생 MAE | NH4 거짓양성률 |
| --- | --- | --- |
| 기존 DO3개 유지 | 2.383 | 22.40% |
| DO1만 수정 | 2.683 | 26.66% |
| DO2만 수정 | 2.335 | 21.83% |
| DO3만 수정 | 2.634 | 27.31% |
| DO3개 모두 수정 | 2.853 | 29.66% |
| 매 시점 DO만 실측 입력(oracle) | 5.173 | 62.75% |

이 모델에서는 DO1 또는DO3의 교체가 NH4 오차를 증가시키고 DO2만 교체하면 조금 감소했다. DO를 실측으로 입력한 경우 기존/수정 모델의 NH4와 NO3 궤적이 정확히 같아졌다. 따라서 NH4 모델의 가중치 변화가 아니라 DO의 반복 입력 경로를 통해 차이가 전달됐음을 확인했다.

그러나 실측 DO를 넣어도 NH4 오차는 오히려 더 커졌다. 이는 DO 평균 오차만 줄이면 결합된 NH4 장기 예측도 개선된다는 가정이 성립하지 않음을 보여준다. 실제 DO 센서가 나쁘다는 뜻이 아니며, 기존 예측 오차끼리 일부 상쇄됐을 가능성을 포함해 NH4/NO3의 자기 반복 전이를 별도로 진단해야 한다. 이 진단만으로 실제 공정의 인과적 주원인을 확정하지 않는다.

다음 한 단계는 수정한 구간 대응을 유지한 상태에서 NH4 자신의 반복 입력, NO3 입력, 실제 시각의 공기 입력 정렬과 지연을 분리하는 것이다. 실측 DO를 사용하는 oracle을 배포 정책 입력으로 전용하지 않는다. 관측 확장이나 PPO/FCSRL 재학습은 그 진단 뒤에 판단한다.
