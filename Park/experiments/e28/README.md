# Park/e28: 막을 수 없는 NH4 위반 구간의 회복 계획 (Kaggle DARROW)

상태: **완료 (2026-11-15). H1 기각, H2 지지.** 가설과 판정 규칙은 검증 결과를 보기 전에 정했다 (사전 등록 커밋 `2a0f542`, 아래 그대로). 설정은 학습 구간만으로 골랐다.

## 목적

목표는 공기량과 하루 비용을 함께 낮추는 것이다. e23 ~ e27 에서 정책이나 차단 여유를 바꾸는 방법은 공기량과 비용을 맞바꿀 뿐이었다. 이번에는 비용이 어디서 나오는지부터 나눠 봤다.

## 진단 (학습 구간 마지막 40일, e22 H1 과 같은 seed 0 ~ 3 앙상블 + e19 차단)

| 항목 | 값 |
| --- | --- |
| 비용이 0 인 에피소드 | 73.5% |
| 비용 상위 10% 에피소드가 낸 비용 | 전체의 78% |
| 첫 NH4 > 4 로 시작한 에피소드 | 7.5%, 비용은 전체의 61% |
| NH4 위반 스텝 중 직전 NH4 가 이미 4 를 넘은 비율 | 92% |
| 공기량 9,000 에서도 다음 NH4 > 4 로 예측된 스텝 (막을 수 없는 스텝) | 1.56%, NH4 위반 1.515 회/일 중 1.39 회/일 |
| 막을 수 없는 스텝에서 차단이 더한 공기량 | 1,259 Nm3/일 (차단이 더한 공기량의 34%) |
| 막을 수 없는 스텝의 DO 위반 | 0.28 회/일 |

비용 대부분은 NH4 가 이미 높은 소수의 날에서 나온다. 그런 스텝에서 e19 차단은 필요 공기량을 찾지 못해 공기량을 9,000 까지 올리고, 그 때문에 DO 위반이 함께 생긴다 (비용 78 인 에피소드는 NH4 위반 38, DO 위반 40). 이때는 NH4 위반을 막을 수 없으므로, 공기량을 정하는 기준은 "앞으로 몇 스텝 동안의 비용 합" 이어야 한다.

Park/e16 의 futile 은 같은 스텝에서 다음 스텝 DO 만 보고 공기량을 낮췄다가, NH4 가 늦게 내려와 NH4 위반이 늘었다. 이번에는 여러 스텝 앞의 NH4 와 DO 비용을 함께 세고, 비용이 같으면 NH4 를 더 빨리 내리는 쪽을 고른다.

## 방법

`min_brake.py` 의 `plan=(H, do_lim, step)`. e19 H1 차단 계산을 모두 마친 뒤, 공기량 9,000 에서도 다음 스텝 예측 NH4 (다른 구성원 4개 평균) 가 4 를 넘는 에피소드에서만 다음을 한다.

- 후보: 0 ~ 9,000 을 500 간격으로 나눈 공기량. 후보마다 H 스텝 동안 그 공기량을 유지한다 (외부 입력 지속 예측, 다른 구성원 평균)
- 예측 비용 = (NH4 > 4 인 스텝 수) + (구간 DO 최댓값 > do_lim 인 스텝 수)
  - **정정 (2026-11-18, Park/e35):** 코드는 두 bool 배열을 더해 OR 로 계산했다. 실제 예측 비용은 "NH4 > 4 이거나 구간 DO 최댓값 > do_lim 인 스텝 수" 다 (한 스텝에 두 위반이 함께여도 1). 이 README 의 모든 결과는 이 실제 계산으로 얻은 값이다. 문서대로 합으로 고친 수정판은 검증에서 비용이 4.66 에서 7.86 으로 나빠졌다 ([e35](../e35/README.md))
- 예측 비용이 가장 작은 후보, 같으면 H 스텝 뒤 예측 NH4 가 낮은 후보, 그것도 같으면 공기량이 작은 후보

그 밖의 스텝은 e19 H1 차단과 같다. 정책은 e22 와 같은 4 x 16 앙상블이다 (새 학습 없음).

## 설정 고르기 (학습 구간만)

후보 (H, do_lim): P1 (4, 2.0), P2 (4, 1.8), P3 (8, 2.0), P4 (8, 1.8). 학습 구간 마지막 40일 (2021-10-01 ~ 11-09) x 구성원 5개, seed 0 ~ 4 의 4개 조합 5개를 같은 조합의 e19 차단 (Park/e26 의 기준값) 과 짝 비교.

규칙 (결과 전에 기록): "조합 평균 공기량 < 기준, 평균 비용 < 기준, 둘 다 이긴 조합 최다 (3/5 이상), 같으면 공기량 최소. 없으면 버린다".

| 후보 | 공기량 | 하루 비용 | 기준보다 둘 다 낮은 조합 |
| --- | --- | --- | --- |
| 기준 e19 차단 | 73,965 | 2.64 | |
| P1 (4, 2.0) | 73,749 | 2.49 | 5/5 |
| P2 (4, 1.8) | 73,753 | 2.48 | 5/5 |
| P3 (8, 2.0) | 73,674 | 2.61 | 4/5 |
| **P4 (8, 1.8) (규칙으로 고름)** | **73,726** | **2.55** | 5/5 |

P1, P2, P4 가 5/5 로 같아 공기량이 가장 적은 P4 를 골랐다. P2 는 비용을 가장 많이 낮춰서 보조 가설로 함께 본다. (고르기 결과 파일은 디스크가 가득 차 저장되지 않았고, 값은 실행 로그에서 옮겼다.)

## 조건과 평가

검증 40일 x 구성원 5개 = 200 에피소드, 결정적. test 는 쓰지 않는다. 판정 단위는 4 x 16 앙상블 조합 10개 (seed 0 ~ 4 의 4개 조합 5개, seed 5 ~ 9 의 4개 조합 5개, 구성원은 Park/e22 `dw_u16_runs`, Park/e23 `dw_new16_runs`) 다. 기준은 같은 조합의 e19 차단 값 (Park/e22, e23 결과, 새로 계산하지 않음) 이다. 같은 조합끼리 짝을 지어 비교하므로 seed 운의 영향을 줄인다.

## 가설 (사전 등록)

- H1 (주 가설). P4 (H 8, do_lim 1.8) 가 같은 조합의 e19 차단보다 공기량과 하루 비용이 둘 다 낮은 조합이 10개 중 6개 이상이고, 조합 10개 평균도 둘 다 낮다
- H2. P2 (H 4, do_lim 1.8) 가 같은 판정을 통과한다

짝 차이 평균과 95% 신뢰구간 (조합끼리 독립이 아니라 낙관적) 은 참고로 적는다. 가설이 기각되는 결과도 그대로 기록한다.

## RESULT.md 처리 (미리 정함)

H1 이 지지되면 대표 방법을 "e22 H1 + 회복 계획 P4" 로 바꾸고, 값은 대표 결과와 같은 구성원인 seed 0 ~ 3 조합 값과 조합 10개 평균을 함께 적는다. H2 만 지지되면 대표는 바꾸지 않고 해석에 적는다.

## 미리 밝히는 한계

- 회복 계획은 대리 모델을 8 스텝 (2시간) 이어 굴린다. 이어 굴린 예측은 오차가 쌓인다 (Lee/e14, e21)
- 막을 수 없는 스텝은 대리 모델 예측으로 정한다. 실제 공정에서는 다를 수 있다
- 검증 구간은 첫 NH4 가 높은 날이 학습 구간보다 많아 (Lee 분석) 효과 크기가 다를 수 있다
- e10 ~ e27 과 같은 대리 모델 한계

## 결과

전체 표는 [results.md](results.md).

| 조건 (조합 10개 평균) | 공기량 Nm3/일 | 하루 비용 | NH4 위반 % | DO 위반 % | 한도 12 만족 % | 둘 다 낮은 조합 |
| --- | --- | --- | --- | --- | --- | --- |
| 기준 e19 차단 | 81,375 | 4.80 | 3.44 | 1.61 | 88.8 | |
| H1 P4 (H 8, do_lim 1.8) | 80,752 | 4.85 | 3.74 | 1.36 | 89.1 | 1/10 |
| H2 P2 (H 4, do_lim 1.8) | 81,063 | 4.65 | 3.56 | 1.33 | 89.5 | 10/10 |

- H1 기각. 공기량은 모든 조합에서 줄었지만 (짝 차이 평균 -624), 비용이 9개 조합에서 올랐다 (+0.052). NH4 위반이 3.44% 에서 3.74% 로 늘어 DO 위반 감소를 넘었다. 8 스텝 이어 굴린 예측이 NH4 가 내려오는 속도를 낙관해 공기를 너무 일찍 줄인 것으로 보인다 (미리 밝힌 한계 1)
- H2 지지. 10개 조합 모두 공기량과 비용이 함께 낮았다. 짝 차이 평균 공기량 -312 (95% 신뢰구간 -386 ~ -238), 비용 -0.147 (-0.165 ~ -0.128). 조합끼리 독립이 아니라 신뢰구간은 낙관적이다. 계획이 공기량을 바꾼 스텝은 0.67% 뿐이다
- seed 0 ~ 3 조합 (대표와 같은 구성원): H2 는 공기량 79,457, 비용 4.58, NH4 3.52%, DO 1.31%, 한도 만족 89.5% (대표 e22 H1 은 79,633, 4.68)
- 학습 구간 규칙은 P4 를 골랐지만 검증에서는 P2 만 통과했다. 학습 구간에서 공기량 차이 (P4 73,726, P2 73,753) 가 아주 작아 공기량 순 동률 깨기가 사실상 무작위였다
- 처리: 사전 등록대로 H2 만 지지되어 대표 방법은 바꾸지 않고 RESULT.md 해석에 적는다
