# e99 공기 절감량을 잘못 예측한 이유

**감량 직전에는 감량 뒤 다시 쓸 공기를 적게 예상한 영향이 컸다. 3시간 뒤에는 감량하지 않았을 때 썼을 공기를 크게 예상한 영향도 커졌다.** e96에서 고른 73회의 후기(3~6시간) 공기량은 기본 FCSRL보다 평균 60.62 m³ 적을 것으로 예상했지만, 두 대리 경로를 끝까지 따라가면 83.81 m³ 더 썼다. 두 값 모두 선택하지 않은 창을 0으로 포함한 1,185개 창에서 날짜별로 평균한 뒤 seed에 같은 비중을 준 값이다.

| 절감을 과대예측하게 한 항목 | 감량 직전 | 1시간 관측 후 | 3시간 관측 후 |
| --- | ---: | ---: | ---: |
| 감량한 경로의 후속 공기를 적게 예상한 기여 (m³) | +126.12 | +130.08 | +98.26 |
| 기본 경로의 후속 공기를 많이 예상한 기여 (m³) | +18.31 | +24.97 | +77.34 |
| 합계 (m³) | +144.43 | +155.05 | +175.60 |

최초 오차 중 87%가 감량 경로에서 왔다. 3시간 정보를 쓰면 이 경로의 기여는 27.86 m³ 줄지만, 기본 경로의 기여가 59.03 m³ 증가한다. 이는 선택된 사례에서의 예측 편향을 분해한 값이다. 어떤 센서나 정책 구성요소가 후속 명령을 일으켰는지는 이 계산으로 특정할 수 없다.

## 공기량 자체를 더 잘 맞혔는데도 절감량은 왜 틀렸나

거리 조건 안의 감량 후보 495개에서 감량 직전과 3시간 뒤를 비교하면 기본 경로의 RMSE는 5,140에서 3,807 m³로, 감량 경로의 RMSE는 5,127에서 3,777 m³로 줄었다. 두 경로의 공통 오차는 차이를 계산할 때 사라진다. 처음에는 두 경로 제곱오차 합의 93.14%가 이렇게 상쇄됐고 3시간에는 87.24%만 상쇄됐다. 남은 절감량 오차(RMSE)는 1,803에서 1,826 m³로 늘었다. 같은 입력으로 각 경로를 따로 적합한 뒤 뺀 값은 e98의 절감량 직접 예측과 모든 창에서 1e−7 m³ 이내로 일치했다.

**결과의 적용 범위가 좁다.** 선택 73회 중 58회가 seed 0이었고 seed 3은 선택이 없었다. 거리 조건을 풀면 후보는 595개, 선택은 76개가 되고, 감량 직전의 전체 창 평균 기여는 기본 경로 +61.33 m³, 감량 경로 +53.30 m³로 순서가 바뀐다. 선택 집합과 날짜별 평균의 분모가 모두 달라진다. 두 분석에서 공통으로 재현된 현상은 추가 관측이 각 경로의 공기량을 더 잘 예측해도 두 경로의 차이는 개선되지 않았다는 것이다.

후속 실험은 처음 감량을 결정하는 시점에 집중할 수 있다. 앞 140일 안에서 연속 날짜 블록을 나누고, 적합에 쓰지 않은 블록에서 절감 예측이 빗나가는 정도를 측정한다. 그 오차를 감안하고도 절감이 예상될 때만 첫 감량을 허용하는 규칙 하나를 고정해 기존 규칙과 비교하는 방안이다. 평가에는 절감량, NH4와 DO 악화, 선택 횟수, 같은 횟수만 감량한 대조가 필요하다. 감량을 거의 선택하지 않아 생긴 겉보기 개선을 구분하기 위해서다. 이미 여러 번 본 뒤 48일은 개발 평가로 해석한다.
