# Lee/e11: 승수 반응 8배 효과를 새 seed 로 확인 (DARROW 환경)

## 목적

Lee/e08 에서 승수 반응 8배는 선택 모델 비용 -13%(p=0.30), 한도 만족 seed 4/5에서 5/5, 공기량 +7.3% 였고 마지막 모델은 비용 -36%, 공기량 +19.8% 였다.
Lee/e10 에서 이점 벌점 0.1 의 이득이 새 seed 에서 재현되지 않았으므로, 같은 방식으로 8배를 **새 seed 5 에서 9** 로 확인한다.
비교 대상 원래 FCSRL 은 Lee/e10 이 같은 새 seed 로 이미 돌렸다. 새 실행은 승수 8배 x 5 seed = 5개이고 나머지 설정은 e07, e08 과 같다.

## 가설과 판정 기준 (결과를 보기 전에 정함)

- H28. 새 seed 의 선택 모델에서 8배가 원래 FCSRL 보다 비용이 낮고 한도 만족 seed 수가 같거나 많다.
- H29. e08 과 합친 10개 seed 에서 선택 모델 비용의 seed 별 짝 차이가 음수인 seed 가 7개 이상이다(부호 확인용).
- 공기량이 원래보다 5% 넘게 늘면 개선이 아니라 교환으로 적는다. 차이가 표준편차보다 작으면 개선이라 단정하지 않는다. 결과가 반대여도 기록한다.

## 한계

Lee/e08 과 같다(대리 모델 정확도 낮음, 승수 8배 하나, 탐색적 p 값).
