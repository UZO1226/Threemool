# e53: e52 의 대조, 불확실성 없이 NH4 문턱만 고정 여유로 낮춘 학습

2026-11-12 시작. Yoo 개인 탐색이며 공통 평가 조건과 공식 채택을 바꾸지 않는다. test 구간 사용 없음.

## 동기

Yoo/e52 에서 학습 중 NH4 비용을 `NH4 + 10 x 구성원 표준편차 > 4` 로 바꾸자 검증 NH4 가 줄었지만 공기량이 늘었다. 이 효과가 "모델 구성원이 엇갈리는 상태를 피함" 때문인지, 단지 "NH4 목표를 전반적으로 더 엄격하게 둠" 때문인지 e52 만으로는 가를 수 없다. 같은 강도의 고정 여유와 비교해 불확실성 정보 자체의 기여를 본다.

## 바꾼 것 (하나)

e52 의 상태별 여유 `kappa x std` 를 고정 여유 `delta` 로 바꾼다.

    학습 NH4 비용 = 1[ NH4_next(선택 구성원) + delta > 4 ]

전이, 보상, DO 비용, 한도 6 / 6, 관측(e44 padded 16개), 에이전트, 수집과 갱신, 평가(여유 없이 원래 비용)는 e52 와 같다. smoke 에서 delta 0, FCSRL seed 0 의 처음 두 갱신 학습 기록이 e52 kappa 0 smoke (e44 와 같음을 확인한 것) 와 모든 항목이 같았다.

### delta 정하기 (학습 날짜만 사용, 정책 학습 전)

e52 의 kappa 와 같은 규칙이다. 기록 운전 재생의 여유 포함 NH4 비용이 학습 날짜 실제 기록 NH4 위반 5.62 와 같아지는 값을 0.01 간격으로 찾았다.

| delta | 0 | 0.20 | 0.30 | 0.40 | **0.45** | 0.50 | 0.60 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 학습 날짜 재생 NH4 비용 | 4.51 | 4.92 | 5.16 | 5.44 | **5.62** | 5.82 | 6.37 |
| (참고) 검증 날짜 재생 NH4 비용 | 33.47 | 35.03 | 36.23 | 37.55 | 38.29 | 39.02 | 40.62 |

delta = 0.45 로 고정한다. 학습 날짜에서는 e52 kappa 10 과 같은 강도(5.62)다. 참고로 기록 운전 재생의 검증 날짜에서는 고정 여유(38.29)가 kappa 10 (37.72) 보다 조금 더 엄격하다. 즉 기록 운전에서는 구성원 불일치 여유가 검증 날짜에 더 몰리지 않는다. 학습 중 구성원 표준편차가 평균 0.03 mg/L 안팎이라 kappa 10 의 평균 여유는 약 0.3 으로, 0.45 보다 작고 상태마다 다르다.

## 판정 (결과를 보기 전에 정함)

방법마다 따로 본다. 주 비교는 seed 짝 차이 (kappa 10 − delta 0.45).

- H1 불확실성 정보 기여: 아래 둘 중 하나면 지지
  - NH4 경로: 검증 NH4 가 seed 3개 중 2개 이상에서 낮고 평균도 낮으며, 평균 검증 공기량 차이가 +2% 이하
  - 공기량 경로: 검증 공기량이 seed 2개 이상에서 낮고 평균 −2% 이하이며, 평균 검증 NH4 가 높지 않음
- 둘 다 아니면 "e52 효과는 고정 문턱 낮춤으로 설명되며 불확실성 정보의 추가 기여는 확인되지 않음" 으로 적는다
- H2 (보조): 일반화 격차(검증 NH4 − 학습 NH4)가 kappa 10 에서 평균적으로 더 작다
- 부가: 각 조건의 검증 두 한도 충족 seed 수, 학습 공기량, NH4 초과 적분, 최악 날짜 NH4 를 함께 적는다. kappa 0 대비 변화도 참고로 적는다

seed 3개 탐색이라 검정은 하지 않는다. delta 는 하나만 시험하며 결과를 보고 다른 값을 고르지 않는다.

사전 규칙상 FCSRL 은 지지로 적지만 seed 하나에 기댄 경계 결과다. 두 방법을 함께 보면 **e52 효과의 대부분은 NH4 문턱을 고정으로 낮춰도 재현된다.** kappa 0 대비 고정 여유도 공기량을 비슷하게 늘리며(PPO-Lag +6.5%, FCSRL +16.0%) 검증 NH4 를 비슷하게 낮추고(PPO-Lag 9.34 → 5.84, FCSRL 19.23 → 6.08), 검증 두 한도 충족 seed 도 같은 2/3 이다.

### 관찰

- 고정 여유와 불일치 여유는 학습 날짜에서 거의 같은 지점에 도착했다 (학습 공기량 70,156 ~ 72,532, 학습 NH4 2.3 ~ 2.7). 같은 강도로 맞춘 두 여유가 정책을 비슷한 보수 수준으로 옮겼다는 뜻이다
- FCSRL 에서 불일치 여유가 나은 점은 seed 간 안정성이다: 검증 NH4 5.26 ± 0.76 대 6.08 ± 1.27, 검증 DO 0.68 ± 0.32 대 1.82 ± 1.36. 고정 여유 seed 2 는 공기 99,687 로 가장 많이 쓰고도 DO 3.74 로 흔들렸다. seed 3개라 안정성 차이를 일반화하지 않는다
- 기록 운전 재생에서도 검증 날짜의 여유 효과가 고정 여유 쪽이 조금 더 컸다 (README 의 delta 표). 불일치 여유가 모르는 날짜에 여유를 자동으로 몰아준다는 근거는 이번 자료에서 찾지 못했다. 구성원 5개가 같은 자료의 부분 표본으로 학습돼 서로 비슷하고 (평균 표준편차 0.03 mg/L), 검증 날짜의 실제 오차를 반영하지 못하는 것으로 보인다

### 결론과 다음

- e52 의 "검증 NH4 감소, 공기량 증가" 는 주로 NH4 목표를 엄격하게 둔 효과다. 불확실성 정보의 추가 기여는 FCSRL 에서 경계 수준으로만 보이고 PPO-Lag 에서는 없다
- 두 여유 모두 공기를 더 쓰는 보수화라 채택하지 않는다
- 불확실성 쪽을 계속한다면 구성원을 날짜 단위로 나눠 학습해 불일치가 날짜 밖 오차를 반영하게 하는 것이 먼저다. 공기량을 늘리지 않고 NH4 를 낮추는 것이 목표라면 여유 조정보다 다른 방향이 필요하다
