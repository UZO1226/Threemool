# Park/e89: 대표 대 공식 기준선 PPO-Lag, 공기와 비용을 날짜 블록으로 (검증) (Kaggle DARROW)

상태: **사전 등록 (2026-11-26).** 가설과 판정 규칙은 이 실험의 결과를 보기 전에 정했다. 대표는 바꾸지 않는다.

## 목적

Park 의 연구 목표는 공기와 비용을 함께 줄이는 것이다 (Park/e12 부터). 공식 표에서 대표 (79,457 / 4.58, 묶음 5개 평균 82,104 / 4.658) 는 기본 PPO-Lag (90,121 / 10.79) 보다 공기와 비용이 모두 낮지만, 이 비교는 평균값이고 날짜 블록 판정이 없다. Park/e85 부터 날짜 블록 세 갈래 판정을 기본으로 정했으므로, 목표의 핵심 비교를 같은 방식으로 판정한다.

## 방법

- PPO-Lag: 공식 표와 같은 seed 0 ~ 4 (차단 없음, `dw_ppo16_runs`) 를 검증 40일에서 스텝 기록과 함께 돈다. 다시 돈 평균이 공식 표 값과 같은지 표에 적는다
- 대표: Park/e44 의 스텝 기록 (묶음 5개)
- 날짜마다 구성원 평균을 내고 (대표는 묶음 5개, PPO-Lag 는 seed 5개도 평균) (대표 빼기 PPO-Lag) 를 날짜 단위로 짝짓는다. 하루 비용과 하루 공기량 각각 Park/e82 와 같은 블록 95% 구간
- 공식 표의 비교 방식 (앙상블 대표 대 seed 평균 기준선) 을 그대로 따른다

## 평가

검증 40일 x 구성원 5개, 결정적. test 는 쓰지 않는다.
