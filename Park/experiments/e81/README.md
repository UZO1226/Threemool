# Park/e81: e74 ~ e80 을 반영한 주장 지도 갱신 (Kaggle DARROW)

상태: **사전 등록 (2026-11-26).** 갱신 규칙은 지도를 고치기 전에 정했다. 새 학습과 새 평가는 없다 (정리 실험이라 실행 코드가 없다). 대표는 바꾸지 않는다.

## 목적

Park/e73 은 이득의 원천을 차단으로 옮기고, 팀 결정 사항의 Park 제안을 "(2) 대표를 차단 + 예측 제어로 바꾸기" 로 고쳤다. 그 뒤 차단 위 예측 제어의 설정 손잡이 (e74 예측 구간 곡선, e75 후보 간격, e76 NH4 여유, e77 DO 한도, e78 차단 여유, e79 여유 1.8 곡선) 와, 고를 때 쓰지 않은 날에서의 다시 보기 (e80) 가 끝났다. 이 실험은 그 결과를 주장 지도에 넣고 팀 결정 사항을 고친다.

## 갱신 규칙 (사전 등록)

e74 ~ e80 의 결과는 이미 알고 있다. 이 규칙은 결과를 예측하는 가설이 아니라, 알려진 결과를 어느 칸에 어떻게 넣을지를 미리 고정하는 것이다.

- 분류 규칙은 Park/e50, e55, e65, e73 과 같다. 수치는 Park/RESULT.md 와 각 실험의 README, results.md 에 이미 있는 값만 쓴다. Park/e73 지도의 항목은 지우지 않고 바뀐 곳에 **(갱신)** 을 붙인다
- 주 주장의 비교 (대표가 다시 고른 ABAC 와 차단만보다 낮음) 와 이득의 원천 (차단) 은 e74 ~ e80 이 그 판정을 직접 다루지 않았으면 유지한다
- 설정 손잡이 (e74 ~ e79): 지지된 결과는 기여 분리 표의 "차단 위 예측 제어 설정" 줄에, 기각된 결과는 "지금 기본값이 맞음" 으로 같은 줄에 둔다. 검증 구간에서 고르고 검증 구간에서 판정한 결과는 모두 "검증 구간에서만" 으로 표시한다
- 대표 교체 근거: 고를 때 쓰지 않은 날에서 차단 위 예측 제어가 대표보다 낮다는 판정 (e80 H1) 이 기각되고, 같은 날의 여유 1.2 결과 (Park/e60) 도 대표보다 높으면, 팀 결정 사항의 Park 제안을 "(2)" 에서 "(3) 검증 구간과 겹치지 않는 날에서 다시 비교한 뒤 정하기" 로 되돌린다. e80 H1 이 지지되면 (2) 를 유지하고 근거를 더한다. 어느 경우에도 Park 혼자 대표를 바꾸지 않는다
- 공기와 비용 동시 감소 (e79 H3): e80 H1 이 기각되면 보조 근거가 아니라 한계와 실패 칸에 "검증 구간에서만" 으로 둔다
- 판정하지 못한 것 (e74 H1) 은 한계와 실패 칸에 둔다

## 미리 밝히는 한계

- 정리 실험이라 새 증거를 만들지 않는다
- e80 을 뺀 모든 결과는 같은 대리 모델 계열의 환경과 반복 사용한 검증 40일에서 나왔다. test 는 쓰지 않았다
