## 사전에 고정한 보정 시험

기존 한 스텝 학습과 하루 자기 회귀 사용의 차이를 줄일 수 있는지 확인한다. [Benechehab 등 (2024)](https://arxiv.org/abs/2402.03146)의 연속 예측 손실 원리를 참고한다. 해당 논문의 공식 구현을 가져왔다고 주장하지 않으며, 기존 numpy 대리 모델과 같은 식을 PyTorch로 구현했다. 논문 전체 실험이나 하이퍼파라미터 탐색의 재현은 아니다.

세 군은 기존 모델, 한 스텝 결합 추가 학습, 12스텝 결합 추가 학습이다. 두 학습군 모두 DO 예측을 NH4 입력으로 사용하며 DO와 NH4를 함께 갱신한다. 차이는 매 스텝 실측 상태로 재시작하는지, 12스텝 동안 예측 상태를 이어 쓰는지다. 따라서 기존 모델 대비 결합 학습 변화와 다중 스텝의 추가 효과를 구분한다.

| 항목 | 고정값 |
| --- | --- |
| 초기 모델 | e02 MLP 구성원 5개 각각의 기존 가중치 |
| 구조 | 기존 입력 및 출력, ReLU 64 x 2, 정규화 유지 |
| 데이터 | 기존 train 330일, 같은 날 안의 연속 12전이, 5분 간격 검증 |
| 손실 | NH4, DO 상태 오차를 train 상태 표준편차로 나눈 제곱의 평균, 12시점 균등 가중 |
| 학습량 | 구성원별 300갱신, batch 128, 마지막 가중치 고정 사용 |
| 최적화 | Adam, lr 0.0001, weight decay 0.00001, gradient clip 1 |
| 난수 | 구성원별 9000 + 구성원 번호, 두 군의 날짜와 창 샘플 순서 동일 |
| 장치 | CPU 1 thread, 기존 venv 사용. GPU가 다른 작업에 사용 중이라 점유하지 않음 |
| 평가 | train 및 val, 재시작 간격 1, 12, 36, 287, 구성원별 전체와 저온 및 범위 내 날짜 |

새 학습에서는 val로 gradient, 조기 종료 또는 checkpoint 선택을 하지 않는다. 단 초기 e02 모델이 val로 선택되었고 여러 분석에 val을 재사용했으므로 독립 검증 성능이라고 해석하지 않는다. test는 읽어 평가하거나 학습에 사용하지 않는다. 5개 구성원은 독립 실험 seed 5개의 대체물이 아니다.

장기 NH4 오차, DO 오차, 실측 하루 비용과의 차이, 저온 집단 성능을 함께 본다. 비용이 작아지는 것을 개선으로 세지 않는다. 이번 단일 설정을 확인한 뒤 유리한 결과를 찾기 위한 추가 탐색을 하지 않는다. 모델 보정으로 수온 관측 범위 밖의 정확성이나 행동 변경의 인과 효과가 보장되지는 않는다. 기존 환경 모델을 덮어쓰지 않고, RL 재학습은 이 시험에서 수행하지 않는다.

## 무엇을 해결해야 하는가

확인된 문제는 두 가지다. 학습과 검증의 운전 조건이 다르고, 기존 모델의 NH4 연속 예측이 위반 비용을 크게 과소평가한다. 두 현상이 정책 실패의 단독 원인이라는 인과 결론은 아니다. 표현 고정이나 평균 농도 MSE 개선만으로 모두 해결되지 않은 점까지 확인했다.

다음 모델 점검의 통과 기준은 단순한 NH4 MAE가 아니라 날짜별 NH4 및 DO 임계값 초과의 재현성이다. 기존 입력에서 누락된 시간 이력이나 부하가 위반 지속시간 오차를 설명하는지 학습 구간 안에서 먼저 확인해야 한다. 이는 아직 검증하지 않은 가설이다. 저온 관측 범위 밖의 문제는 해당 조건 자료나 독립적인 공정 근거가 필요하며, 온도 자르기나 구성원 삭제로 해소된다고 취급하지 않는다. 이후 환경을 교정하면 PPO, FCSRL 및 확장 후보를 동일한 새 환경에서 다시 비교해야 한다. 기존 환경 성능과 섞지 않는다.

FCSRL 원본 표현 학습을 적용하는 큰 가지는 유지한다. e09 자체는 대리 환경의 신뢰성 진단이며 확장의 성공 근거가 아니다. [저자 후속 보고](https://abenechehab.github.io/publications/) 역시 예측 오차 개선이 정책 성능 개선으로 그대로 이어지지는 않았다고 보고하므로 두 판정을 구분한다.
