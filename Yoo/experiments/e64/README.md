## 질문

e63 의 배분 정책은 사전 판정상 두 모델에서 개선이었지만 실행 구간 공기의 약 20% 가 train 99% 분위수를 넘었다. 또 모든 평가가 매일 자정 기록 상태로 되돌리는 방식이라 NH4 비용의 큰 몫이 시작 상태에서 왔다 (e62). e64 는 e63 정책 20개를 그대로 두고 (1) 구간 공기를 99% 분위수로 자른 실행과 (2) 검증 40일을 이어 붙인 연속 평가로 다시 잰다.

## 조건

- 실행 상한: 차단까지 정한 뒤 구간 공기를 [331, 1131, 2220, 2712, 2173] m³/h 이하로 자르고 잘린 양은 총 공기에서 뺀다. 두 조건에 똑같이 적용한다.
- 연속 평가: 구성원별로 검증 40일을 날짜 순서로 잇는다. 둘째 날부터 시작 상태와 직전 공기를 전날 마지막 값으로 넘긴다. 데이터에 없는 23:57 에서 다음 날 00:12 로 가는 한 스텝은 건너뛴다.
- 평가 88개: 일별 상한 (두 모델) 과 연속 (DO 수정 모델, 상한 없음과 있음) 각각 정책 20개, 기록 운전과 공기 0 + park_e19 기준선.

값은 공기량 m³/23.75h / 합산 비용, seed 5 평균, park_e19 차단.

1. **J1 상한: 배분 이득은 범위 밖 구간에서 나오지 않는다.** 상한을 걸면 배분 정책의 비용이 조금 오르지만 (PPO 2.88 에서 3.06) 총 공기만 정책도 함께 변해, 짝 비교는 DO 수정 모델에서 두 방법 모두 5/5 로 유지됐다. 상한으로 잘린 스텝은 배분 정책 19 ~ 22%, 총 공기만 정책 32 ~ 36% 로, 범위 이탈은 차단이 총 공기를 올리는 데서 생긴다는 e63 의 사후 확인과 같다.
2. **공통 모델 상한에서 FCSRL 은 사전 기준 미달.** 두 평균은 모두 낮지만 (공기 -3,326, 비용 -1.39) seed 1 과 4 에서 공기가 늘어 3/5 다. 규칙대로 '이득 없음' 으로 적는다. PPO-Lag 는 5/5 로 유지됐다.
3. **J2 연속 평가: 이득이 더 뚜렷하다.** 날짜를 이으면 시작 이월이 사라져 모든 차단 정책의 비용이 크게 내려가고, 배분 PPO-Lag 는 55,626 m³, 비용 0.83 (NH4 0.38, DO 0.45) 이다. 짝 비교는 두 방법, 상한 유무 모두 5/5 다.
4. **연속 평가의 기록 운전 재생은 기준으로 쓰기 어렵다.** 기록 공기를 40일 이어 넣으면 비용이 77 로 일별 (31.9) 보다 크게 나빠진다. 피드백 없는 장기 재생에서 대리 모델 오차가 쌓이기 때문으로 보이며, 차단이 매 스텝 상태를 보고 공기를 정하는 정책 평가와 성격이 다르다. 연속 평가는 정책끼리의 비교로만 쓴다.

## e66 test 최종 평가의 주 구성 (사전 규칙)

규칙은 'DO 수정 모델 일별 상한 평가가 이득 유지이면 배분 구성' 이었다. 두 방법 모두 이득 유지이므로 e66 의 주 구성은 **총 공기 + 배분 정책 + park_e19 차단 + 실행 상한** 이다. e66 은 두 조건과 두 방법을 모두 평가하되 이 구성을 주 비교로 쓴다.
