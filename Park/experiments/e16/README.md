# Park/e16: DO 여유와 헛수고 방지를 더한 차단 (Kaggle DARROW)

상태: **사전 등록 (2026-11-11).** 가설과 판정 규칙은 검증 결과를 보기 전에 정했다. 설정은 학습 구간만으로 골랐다.

## 목적

목표는 공기량과 하루 비용을 함께 낮추는 것이다. Park/e15 에서 NH4 여유를 줄이면 공기량은 줄지만 NH4 위반이 늘어 비용이 올랐다. 이번에는 비용의 다른 절반인 DO 위반을 줄여, NH4 여유를 줄인 만큼 늘어난 비용을 메운다.

## 학습 구간 진단 (e12 A seed 0 정책 + e14 양방향 차단 3.5, 학습 40일 x 구성원 5개)

- DO 위반의 59% 는 NH4 때문에 차단이 공기량을 올린 스텝이고, 그중 많은 수가 공기량 9,000 이었다. 공기량 9,000 에서도 다음 스텝 NH4 위반을 못 막는 스텝에서는 공기를 최대로 넣어도 NH4 비용은 그대로 받고, DO 비용과 전기만 늘어난다.
- DO 위반의 47% 는 예측 DO 가 2 이하(중앙값 1.98) 였는데 실제로 넘었다. trim 이 DO 를 2 에 딱 맞춰 내려서 예측 오차로 넘는다.
- 차단이 올린 공기 때문에 DO 가 넘는 충돌 스텝에서만 NH4 여유를 줄이는 방법은 충돌이 전체의 0.3% 뿐이라 효과가 거의 없었다.
- 정책 공기량을 위에서 자르면 오히려 공기량이 늘었다 (정책이 미리 넣는 공기가 나중의 큰 개입을 줄인다).

## 차단 (`min_brake.py`, trim=True 에 더함)

- do_limit: trim 이 공기량을 내릴 때 쓰는 예측 DO 기준을 2 대신 1.9 또는 1.8 로 둔다
- futile: 공기량 9,000 에서도 예측 NH4 (다른 구성원 평균) 가 4 를 넘는데 차단이 공기량을 올린 경우, 정책 공기량 이상에서 예측 DO <= 2 인 가장 큰 격자 값까지만 올린다 (없으면 정책 공기량)
- NH4 여유: 고정 target 3.5 (fix) 또는 e15 여유 표 + 0.1 (p1, e15 의 adapt_plus 와 같음)

## 설정 고르기 (학습 구간만)

e12 A 정책 seed 5개, 학습 구간 40일(4일 간격) x 구성원 5개로 10개 설정을 돌렸다. 규칙은 결과를 보기 전에 정했다: "평균 비용이 한 방향 3.5 보다 0.1 이상 낮은 설정 중 평균 공기량이 가장 적은 것".

| 설정 | 공기량 | 하루 비용 | 둘 다 낮은 seed |
| --- | --- | --- | --- |
| 한 방향 3.5 (e12) | 72,298 | 2.951 | |
| trim 3.5 (e14) | 72,332 | 2.585 | 2/5 |
| fix + do 1.9 + futile | 72,264 | 2.427 | 2/5 |
| fix + do 1.8 + futile | 72,368 | 2.399 | 3/5 |
| **p1 + do 1.9 + futile (규칙으로 고름)** | **69,066** | **2.787** | 2/5 |
| p1 + do 1.8 + futile | 69,087 | 2.654 | 4/5 |
| p2 + do 1.9 + futile | 70,234 | 2.603 | 3/5 |
| p2 + do 1.8 + futile | 70,318 | 2.543 | 3/5 |
| p3 + do 1.9 + futile | 71,834 | 2.615 | 2/5 |
| p3 + do 1.8 + futile | 71,914 | 2.541 | 2/5 |

(p2, p3 은 e15 여유 표 + 0.2, + 0.3)

## 조건과 평가

학습 없음. e12 A 정책 seed 0 ~ 4 에 차단만 바꿔, 검증 40일 x 구성원 5개 = 200 에피소드를 결정적으로 돈다. e14, e15 에서 학습 중 차단을 바꿔도 바꿔 끼운 것보다 낫지 않았으므로 이번에는 학습하지 않는다. trim_3.5 (e14) 도 함께 보고한다. test 는 쓰지 않는다.

## 가설 (사전 등록)

비교 기준은 같은 seed 의 e12 A 정책 + 한 방향 target 3.5 (seed 평균 84,031, 5.51) 다. seed 5개 중 3개 이상에서 공기량과 하루 비용이 둘 다 기준보다 낮고, seed 평균도 둘 다 낮으면 지지로 적는다.

- H1 (주 가설). p1 + do 1.9 + futile (규칙으로 고른 설정)
- H2. p1 + do 1.8 + futile
- H3. fix + do 1.8 + futile

NH4 와 DO 위반률, 헛수고 방지가 작동한 스텝 비율은 보고만 한다. 가설이 기각되는 결과도 그대로 기록한다.

## 미리 밝히는 한계

- 학습 구간에서 고른 설정이 검증 구간(겨울, NH4 높음) 에서도 같은 순서일지는 모른다
- futile 은 NH4 회복을 늦출 수 있다
- e10 ~ e15 와 같은 대리 모델 한계 (차단 모델과 환경 모델이 같은 방법의 구성원, 그 시각의 유입 성분을 안다고 둠)
- 정책은 e12 A 5개뿐이다
