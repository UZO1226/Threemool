# Park/e15: 예측 불확실성에 맞춘 NH4 여유 (Kaggle DARROW)

상태: **사전 등록 (2026-11-11).** 가설과 판정 규칙은 학습 결과와 검증 결과를 보기 전에 정했다. 여유 표는 학습 구간만으로 정했다.

## 목적

목표는 공기량과 하루 비용을 함께 낮추는 것이다. Park/e14 의 양방향 차단은 DO 위반을 줄여 비용을 낮췄지만 공기량은 그대로였다. 공기량 대부분은 NH4 를 지키는 데 쓰이므로, 이번에는 NH4 쪽 여유를 줄인다.

지금 차단은 예측 NH4 <= 3.5 를 지킨다. 한도 4 보다 0.5 낮은 여유다. e12 A seed 0 정책을 검증 구간에서 진단했다 (판정에 쓰지 않음).

| 차단 target | NH4 위반 % | 위반 원인 |
| --- | --- | --- |
| 3.5 | 3.29 | 100% 가 공기량 9,000 으로도 못 막는 스텝 (차단으로 줄일 수 없음) |
| 4.0 | 17.32 | 13.46 %p 는 막을 수 있었는데 예측이 평균 0.055 낮아 넘음. 한번 넘으면 이어짐 |

학습 구간 기록 운전 재생에서 1스텝 NH4 예측 오차(환경 구성원 값 빼기 다른 구성원 4개 평균) 는 95% 가 0.047 이하이고, 다른 구성원 사이 표준편차 sigma 와 상관이 있다 (|오차| 와 상관 0.62). 여유 0.5 는 대부분의 스텝에서 필요 이상이다. 그래서 sigma 가 작을 때는 여유를 줄이고 클 때만 크게 둔다.

## 공통 평가 조건

`Compare/PROTOCOL.md` v1 을 따른다 (데이터, 분할, 대리 모델, 관측, 행동, 보상, NH4 와 DO 비용, 하루 한도 12, 학습 예산, seed, 검증 200 에피소드). NH4 위반률과 DO 위반률을 따로 적고, 한도 만족은 에피소드 비율과 seed 평균 비용 <= 12 여부로 함께 본다.

## 불확실성 여유 차단 (`min_brake.py` 의 `margins`, `E15_MARGINS`)

후보 공기량마다 다른 구성원 4개의 1스텝 NH4 예측 평균 mu 와 표준편차 sigma 를 구하고, mu + 여유(sigma) <= 4 인 가장 작은 공기량을 필요 공기량 r 로 둔다. 나머지는 e14 의 양방향 차단과 같다 (정책 공기량 < r 이면 r 로 올림, DO 가 넘칠 것 같으면 r 이상에서 내림).

여유 표는 학습 구간 188일 x 구성원 5개 기록 운전 재생에서, 경계 근처(mu 3.0 ~ 4.5) 스텝의 예측 오차 99% 분위수를 sigma 칸별로 구해 올림했다.

| sigma | 여유 (adapt) | 실제 목표 NH4 | 여유 + 0.1 (adapt_plus) |
| --- | --- | --- | --- |
| < 0.05 | 0.13 | 3.87 | 0.23 |
| 0.05 ~ 0.1 | 0.23 | 3.77 | 0.33 |
| 0.1 ~ 0.2 | 0.38 | 3.62 | 0.48 |
| >= 0.2 | 0.47 | 3.53 | 0.57 |

모든 칸의 여유를 0.5 로 두면 고정 target 3.5 와 결과가 같았다 (학습 구간 8일 시험).

## 조건

| 조건 | 내용 |
| --- | --- |
| A | e12 A 와 같은 학습 설정에서, 학습 중 차단을 양방향 + 여유 표(adapt) 로 바꿔 학습 (`--min-brake-target 3.5 --brake-trim --adaptive-margin`) |
| E | 학습 없음. e12 A 정책에 차단만 바꿔 평가 |

각 정책을 차단 없이, 양방향 고정 target 3.5 (trim_3.5, e14), 양방향 고정 target 3.85 (trim_3.85, 여유 크기만 줄인 대조), adapt, adapt_plus 로 평가한다. 검증 40일 x 구성원 5개 = 200 에피소드, 결정적 행동, 마지막 정책. test 는 쓰지 않는다.

## 가설 (사전 등록)

비교 기준은 같은 seed 의 e12 A 정책 + 한 방향 target 3.5 (seed 평균 84,031, 5.51) 다. seed 5개 중 3개 이상에서 공기량과 하루 비용이 둘 다 기준보다 낮고, seed 평균도 둘 다 낮으면 지지로 적는다.

- H1 (주 가설). A + adapt
- H2. E + adapt
- H3. E + adapt_plus

trim_3.85 대조, e14 E (양방향 3.5, 84,001, 5.27) 와의 비교, NH4 와 DO 위반률, 학습 마지막 라그랑주 승수, 차단 없음 비용은 보고만 한다. 가설이 기각되는 결과도 그대로 기록한다.

## 미리 밝히는 한계

- 공기량 9,000 으로도 못 막는 NH4 위반(약 3.3%) 은 이 방법으로 줄일 수 없다. 공기량을 줄이면서 비용이 늘지 않는 것이 현실적인 목표다
- 여유 표는 기록 운전 상태에서 정했다. 정책이 만드는 상태에서는 오차 분포가 다를 수 있다
- e10 ~ e14 와 같은 대리 모델 한계 (차단 모델과 환경 모델이 같은 방법의 구성원, 그 시각의 유입 성분을 안다고 둠)
- seed 5개, 401,280 전이, 마지막 정책의 탐색적 실험이다

