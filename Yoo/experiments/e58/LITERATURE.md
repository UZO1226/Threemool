# e58 논문 검토와 구현 대응

2026-11-13, 본 학습 전 검토. 특정 새 아키텍처를 그대로 재현하는 실험이 아니다. FCSRL에 연속 NH4 초과 크기라는 보조 목표를 추가하는 적용 및 제한적 확장이다.

## 실제로 읽은 방법과 결과

**FCSRL (ICML 2024).** [원문](https://arxiv.org/pdf/2405.11718) 4.1~4.3절, 5.5절, 부록 B.3과 원본 `train_encoder`를 확인했다. dynamics와 feasibility 표현 손실을 함께 학습하고 EMA 표현을 정책/가치망에 전달한다. 원 관측 연결과 feasibility 손실 제거 대조에서 성능 저하를 보고했다. 부록은 고정 표현의 선형 회귀도 사용한다. 따라서 e57의 probe 자체를 새 방법으로 주장하지 않는다. 원 논문의 이진 비용 전제에 대한 안전 확률 해석을 현재 합산 비용0/1/2에 그대로 적용하지 않는다.

**UNREAL (Jaderberg 등).** [원문](https://arxiv.org/pdf/1611.05397) 3.2~3.4절, 4.1절, 부록 B를 읽었다. 최근 관측3개의 공유 CNN 특징을 합쳐 128 ReLU와 3분류 head로 다음 보상의 부호를 예측한다. 최근2,000개 경험에서 0/비0 보상을 균형 표집하고 가중치1의 교차 엔트로피를 쓴다. 이 head는 행동 출력에 직접 쓰지 않는다. A3C에 보상 예측, 가치 재학습, pixel control을 더한 전체 구성은 Labyrinth 평균 human-normalized 점수54%에서87%를 보고했다. 이 수치는 보조망 하나의 효과가 아니다. 단순 입력 복원은 최종 성능을 악화시키기도 했다. MSE는 가능한 대안으로 언급되지만 이 논문의 보상 예측 주 실험은 분류였다.

**Adapting Auxiliary Losses Using Gradient Similarity (Du 등, 2020 개정본).** [원문](https://arxiv.org/pdf/1812.02224) 3절과 4.3~4.4절을 읽었다. 공유 파라미터의 주/보조 경사 방향으로 보조 업데이트를 조절했다. 관련 없는 교사의 증류가 방해되는 gridworld/Atari에서 단순 합산보다 개선했지만, 교사가 같은 문제의 좋은 정책이면 단순 합산보다 나쁜 경우도 있었다. 이를 보조 손실이 항상 유리하지 않다는 근거로 사용한다. 이번에는 경사 cosine/norm 비율만 기록하며 적응 가중치나 경사 투영은 도입하지 않는다. FCSRL 표현 손실의 경사 정렬이 정책 안전 보장이라는 뜻도 아니다.

## 논문에서 가져오는 것과 우리가 바꾸는 것

| 항목 | e58 적용 |
| --- | --- |
| FCSRL 본체 | Encoder, dynamics/feasibility 손실, EMA, 원 관측 연결, PPO/PID, 기존 prior 유지 |
| 보조 학습 연결 | 온라인 상태-행동 잠재값 zsa에서 별도 head를 학습, 추론 시 head 미사용 |
| 예측 목표 | 보상 부호 대신 다음4전이(한 시간) NH4 초과 농도 평균/4. 폐수처리 적용에서 정한 목표이며 논문이 검증한 설정 아님 |
| head 크기 | 64→64 Tanh→1. 기존 FCSRL z64와 회귀 출력에 맞춘 선택. UNREAL의 CNN/LSTM/128/3분류를 재현한 것이 아님 |
| 희소한 초과 표본 | 같은 minibatch의 유효한 양수/0 목표 손실 평균을 각각 구해 같은 비중으로 합침. 표본을 다시 뽑는 UNREAL 방식과 구현은 다르지만 보조 목적의 그룹 균형을 옮김 |
| 빈 그룹 | 한 그룹만 있으면 그 그룹 평균. 모든 창이 무효이면 보조 손실0. 전체 하루 날짜 경계를 넘는 미래 창 제외 |
| 가중치와 단위 | 초과 평균을 임계값4 mg/L로 나눠 무차원화, 보조 가중치1을 고정. 단위 변경으로 손실 크기가 달라지므로 UNREAL의 가중치1과 동등한 세기라고 주장하지 않음 |
| PPO 분포 | PPO minibatch, 정책 비용과 PID에는 균형 가중치를 적용하지 않음. 예측 head 출력은 확률이나 무편향 수질 예측으로 사용하지 않음 |
| 추가하지 않는 구성 | A3C, CNN/LSTM, 경험 재생, pixel control, 정책 위험 벌점, 실행 차단, 경사 투영 |

균형 MSE는 이번 보조 학습 정의의 일부다. 현재 세 조건만으로 head와 균형화의 개별 기여를 분리했다고 주장하지 않는다. 보조 경사를 끊은 대조군은 head 계산/학습과 Encoder에 전달되는 추가 지도 신호를 구별한다. 벽시계 비용이 정확히 같은 대조는 아니며 실제 시간을 함께 기록한다.

## 검증 방법

기본 FCSRL, 보조망 추가, 보조 경사 차단을 같은 장치/예산/seed로 새로 학습한다. 보조 예측 손실 감소만으로 성공이라 부르지 않고, 원 공기량/NH4/DO 지표와 초과 적분, 최악 날짜를 비교한다. 개발 val을 보고 목표나 가중치를 바꾸지 않는다. 환경 오류와 실제 현장의 반사실 행동 효과는 이 보조망이 해결했다고 주장하지 않는다.
