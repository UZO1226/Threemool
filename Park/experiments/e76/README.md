# Park/e76: 차단 위 예측 제어의 NH4 여유 (Kaggle DARROW)

상태: **완료 (2026-11-26). H1 지지 (여유 0.9 -0.069), H2 기각 (여유 1.8 은 오히려 -0.221).** 사전 등록 커밋 `9e81203` (main 병합 #239). 여유 값, 가설, 판정 규칙은 이 실험의 결과를 보기 전에 정했다. 대표는 바꾸지 않는다.

## 목적

차단 위 예측 제어의 NH4 여유 1.2 는 Park/e52 가 차단 없이 고른 값이다. 차단이 NH4 한도를 지키는데도 예측 제어가 여유 1.2 로 공기를 넉넉히 넣는다면, 차단 위에서는 더 작은 여유가 맞을 수 있다 (Park/e58 사후 관찰). 반대로 여유를 키우면 차단이 할 일을 예측 제어가 미리 한다. Park/e72 와 같은 틀로 여유만 바꾼다.

## 방법

- 기준: `ShortMPC` (`objective='excess'`, 공기 가중치 1.5, 1시간) + 대표 차단. 예측 제어의 NH4 여유만 바꾼다 (차단의 여유는 그대로)
- 여유 0.6, 0.9, 1.5, 1.8. 4번
- 비교: Park/e58, e59 의 기본 설정 (여유 1.2) 곡선에서 같은 공기량의 비용

## 평가

검증 40일 x 구성원 5개 = 200 에피소드, 결정적. test 는 쓰지 않는다.

## 가설 (사전 등록)

- H1. 여유 0.6 과 0.9 가운데 하나라도 같은 공기량의 기본 곡선보다 0.05 넘게 낮다
- H2. 여유 1.5 와 1.8 가운데 하나라도 같은 공기량의 기본 곡선보다 0.05 넘게 높다
- 공기량이 곡선 범위 밖인 점은 그 가설에서 빼고, 모두 밖이면 판정하지 않는다

## RESULT.md 처리 (미리 정함)

- H1 지지: "차단 위에서는 예측 제어의 NH4 여유를 1.2 보다 줄이면 더 낮아진다" 고 적고 그 값을 적는다. 기각: "여유를 줄여도 낫지 않다" 고 적는다
- H2 지지: "여유를 키우면 높아진다" 고 적는다. 기각: "여유 1.5 ~ 1.8 도 같은 공기량에서 비슷하다" 고 적는다

## 미리 밝히는 한계

- 두 가설 모두 두 점 가운데 하나만 기준을 넘으면 지지라 여러 번 비교의 몫이 있다
- 공기 가중치는 다시 맞추지 않아 공기량이 달라진다 (곡선 비교로 다룸). 검증 구간은 e10 부터 반복해서 썼다

## 결과

전체 표는 [results.md](results.md). 대표 차단 위 초과량 예측 제어, 공기 가중치 1.5, 1시간. 예측 제어의 NH4 여유만 바꿈.

## 해석

- 사전 등록 처리에 따라 "차단 위에서는 예측 제어의 NH4 여유를 1.2 보다 줄이면 더 낮아진다 (여유 0.9 에서 -0.069)" 고 적는다
- H2 기각의 처리 문구는 "여유 1.5 ~ 1.8 도 같은 공기량에서 비슷하다" 였지만, 1.8 은 비슷한 것이 아니라 0.221 낮다. 문구 그대로 적되 1.8 이 낮았다는 것을 함께 적는다
- 여유를 줄여도 (0.9) 키워도 (1.8) 기본 곡선보다 낮아, 여유의 방향만으로 비용이 정해지지 않는다. H1 의 이득 0.069 는 Park/e74 에서 본 이웃 설정 사이 흔들림 (0.1 가까이) 보다 작으므로 "여유를 줄이는 쪽이 낫다" 는 약한 근거다
- 사후 관찰 (판정 없음): 여유 1.8 점 (84,332 / 4.195) 은 지금까지의 차단 위 예측 제어 가운데 대표 공기량 근처에서 가장 낮다. 대표 (82,104 / 4.658) 보다 공기 2.7% 많고 0.463 낮다. DO 위반 (1.00%) 과 차단 개입 (4.4%) 이 가장 적다. 점 하나라 이 값을 다시 확인하려면 1.8 근처에 곡선을 만드는 실험이 따로 필요하다 (사전 등록 밖)
- 여유는 공기 가중치를 다시 맞추지 않아 공기량이 75,986 에서 84,332 로 움직였다. 비교는 같은 공기량의 곡선 값으로 했다
