# e50, e52 결과 검산과 원인 분석

2026-11-12. FCSRL 적용과 제한된 확장의 결과를 해석하기 위한 사후 분석이다. 새 알고리즘이나 학습 실험이 아니다. [상세 결과](results.md), [수치 JSON](analysis.json).

## 핵심 판단

- e50 Actor 보정은 평균 공기량 5.73%, 평균 합산 비용 8.97% 감소지만 비용 개선 seed는 2/5다. 이득이 큰 seed 1 또는 2를 제외하면 평균 비용 차이는 각각 +0.699, +0.487로 악화한다.
- NH4 초과 농도의 시간 적분은 4.460에서 5.195 mg h/L로 16.48% 증가했다. 각 seed의 최악 날짜 NH4 위반 횟수는 5/5 seed에서 증가했고, 그 값의 seed 평균은 49.72에서 56.72로 증가했다. Actor 보정을 우선 채택 후보로 보던 판단을 유보한다.
- 비용 함수는 NH4가 4를 조금 넘든 크게 넘든 한 스텝 위반으로 센다. 위반 빈도 개선이 초과 정도 개선을 보장하지 않는다는 것이 이번 결과로 확인됐다. 이것이 악화의 유일한 원인이라고 입증한 것은 아니다.
- e52 FCSRL은 seed 평균으로 검증 40일 모두에서 NH4 비용이 낮아지고, 공기량도 40일 모두에서 늘었다. 평균 공기량 +15.13%이며 단순한 특정 날짜 이상치로 설명되지 않는다.
- e52 FCSRL의 양의 추가 공기량 중 기준 정책 NH4가 3 이하인 시각이 40.15%, 3 초과 4 이하가 50.58%다. 기준 정책 불일치 상위 사분위에는 양의 추가량 21.15%가 속한다. 불확실성이 큰 구간에 추가 공급이 집중됐다는 증거는 없지만, 이것만으로 낭비라고 단정하지 않는다.
- e52 PPO도 평균 NH4 위반 횟수는 감소했지만 NH4 초과 적분은 4.718에서 5.119로 증가했다. 빈도와 심각도는 두 실험 모두 따로 평가해야 한다.

## 범위와 재현

- e50 최종 정책 15개는 Python 3.11, scikit-learn 1.9.1 환경과 e50 준비물로 평가한다. 원래 관측 11개, 합산 비용 한도 12를 유지한다.
- e52 비교 정책 12개는 Python 3.10, scikit-learn 1.7.2 환경과 e35 수정 모델로 평가한다. 관측 padded 16개, NH4와 DO 한도 각각 6을 유지한다. kappa 0의 seed 0, 1은 e44 최종 체크포인트다.
- 두 실험의 절대 수치를 직접 비교하지 않는다. 각 실험 안에서 같은 seed, 날짜, 구성원으로 대응 비교한다.
- 각 정책은 검증 40일과 모델 구성원 5개, 95전이로 평가한다. 200개 에피소드는 200개의 독립 날짜나 실제 공정이 아니다.
- 원 pickle에서 train과 val 행만 추출하는 e45 함수를 사용한다. test 행은 평가하지 않는다. 정책 학습, 정규화 갱신, 모델 재학습은 없다.
- 상태, 행동 전 상태, 공기량 시계열을 저장한다. e52는 학습 코드와 동일한 원시 NH4 변화량 예측 5개의 표준편차도 저장한다.
- 정책 파라미터 지문을 전후 비교하고, 입력과 원 결과, 소스 파일 SHA256을 전후 검산한다. 원본 결과는 덮어쓰지 않는다.

## 집계식 수정

평균 공기량 변화율은 `100 * (mean(candidate_air) / mean(baseline_air) - 1)`로 계산한다. seed별 변화율 평균은 별도 설명 통계로 남긴다. e50의 공기량 증가 2% 조건과 e52의 증가 5% 조건, 세 평균 감소 판정에 적용한다.

수정 전에는 기준 공기량 [100, 10, 10], 후보 [110, 9, 9]에서 실제 평균이 6.67% 늘었는데도 평균 변화율을 -3.33%로 보아 감소 판정이 가능했다. 이는 인공 반례이며 실제 실험 수치가 아니다. e50과 e52 각각의 회귀 검사를 통과했다. 실제 결과의 미채택 판정은 수정 전후 동일하다.

## 해석 제한

기준 정책과 후보 정책은 같은 날짜를 시작해도 이후 상태가 달라진다. 기준 정책의 행동 전 NH4와 표준편차로 묶은 공기량 차이는 대응 시계열의 기술 통계이며, 같은 상태에서 공기량만 바꾼 인과 실험이 아니다. 추가 공기의 비중은 음의 차이를 제외한 양의 추가량을 분모로 한다. 순 공기량 증가는 추가량에서 감소량을 뺀 값이다.

현재 NH4가 낮을 때의 추가 공기는 미래 위반을 예방할 수 있으므로 낭비라고 단정하지 않는다. 모델 불일치는 실측 예측 오차가 아니다. 표준편차 사분위 경계는 검증 시계열을 설명하기 위한 값으로만 쓰며 정책이나 kappa 선택에 쓰지 않는다.

Actor 보정의 출력 KL 감소는 보정 목적의 달성을 보여줄 뿐, 최종 제어 성능 개선의 인과 증거가 아니다. 날짜별 분석도 같은 검증 40일을 재사용한 결과이며 독립 시험을 대체하지 않는다.

## 다음 작업

클로드가 e53에서 고정 여유 delta=0.45 대조를 이미 실행하고 있음을 확인했다. 중복 학습은 시작하지 않았다. e53 결과로 e52의 이득이 상태별 불확실성 활용인지 단순한 비용 보수화인지 비교하되, 학습 데이터에서 추가 비용을 맞춘 절차와 같은 환경, seed, 예산을 먼저 검산한다.

Actor 보정과 불확실성 비용은 아직 결합하지 않는다. Actor 보정은 seed별 상충이 남아 있으며, 추가 최적화 계산량 대조 없이 FCSRL 고유의 확장 이득이라고 확정하지 않는다. 두 확장 모두 최종 채택하지 않는다.
