# e54: 날짜 묶음을 빼고 학습한 앙상블의 불일치로 NH4 제약에 여유를 두는 학습

2026-11-12 시작. Yoo 개인 탐색이며 공통 평가 조건과 공식 채택을 바꾸지 않는다. test 구간 사용 없음.

## 동기

Yoo/e53 에서 e52 (전이 모델 구성원 불일치 여유) 의 효과 대부분이 같은 강도의 고정 여유로 재현됐다. 전이 모델의 구성원 5개는 같은 188일에서 행을 80% 씩 뽑아 학습해 서로 비슷하고 (학습 중 평균 표준편차 0.03 mg/L), 학습 날짜 밖의 오차를 반영하지 못한다고 봤다. 구성원마다 서로 다른 날짜 묶음을 못 보게 학습하면 불일치가 "처음 보는 날" 의 오차를 더 잘 반영하는지, 그리고 그 여유가 고정 여유보다 나은지 본다.

## 바꾼 것 (하나)

여유를 계산하는 앙상블만 바꾼다. 상태 전이는 e35 수정 모델 그대로다.

    학습 NH4 비용 = 1[ NH4_next(선택 구성원) + kappa x std_m(날짜 분할 NH4 앙상블 5개의 한 스텝 변화량 예측) > 4 ]

- 날짜 분할 앙상블 (`build.py`): 학습 188일을 날짜순 5묶음 (37 ~ 38일) 으로 나누고 구성원 m 은 묶음 m 을 뺀 150 ~ 151일의 모든 행으로 NH4 변화량 GBM 을 학습한다. 하이퍼파라미터와 단조 제약은 e35 수정 모델의 NH4 구성원과 같다
- 전이, 보상, DO 비용, 한도 6 / 6, 관측(e44 padded 16개), 에이전트, 수집과 갱신, 평가(여유 없이 원래 비용)는 e52, e53 과 같다
- smoke 에서 kappa 0, FCSRL seed 0 의 처음 두 갱신 학습 기록이 e53 delta 0 smoke (e44 와 같음을 확인한 것) 와 모든 항목이 같았다

## 정책 학습 전 점검 (`check.json`)

한 스텝 NH4 변화량 예측에서 구성원 표준편차와 구성원 평균 절대 오차를 비교했다.

| 앙상블 | 학습 날짜 표준편차 | 검증 날짜 표준편차 | 검증 / 학습 | 검증 날짜 표준편차와 절대 오차 순위 상관 | 검증 날짜 표준편차 상위 10% 행의 오차 / 나머지 |
| --- | --- | --- | --- | --- | --- |
| 전이 모델 구성원 (e52) | 0.022 | 0.041 | 1.88 | 0.37 | 0.436 / 0.261 |
| 날짜 분할 (e54) | 0.033 | 0.075 | 2.27 | 0.40 | 0.461 / 0.261 |

- 날짜 분할 불일치는 더 크고 검증 날짜에 조금 더 몰리며 오차와의 상관도 조금 높다
- 날짜 밖 오차는 실제로 있다. 학습 날짜의 각 묶음에서, 그 묶음을 못 본 구성원의 절대 오차는 0.148, 같은 행에서 그 묶음을 본 구성원 4개 평균의 오차는 0.114 다

### kappa 정하기 (학습 날짜만 사용)

e52, e53 과 같은 규칙이다. 기록 운전 재생의 여유 포함 NH4 비용이 학습 날짜 실제 기록 NH4 위반 5.62 와 같아지는 값을 선형 보간하고 0.5 단위로 반올림했다.

| kappa | 0 | 5 | **5.5** | 10 | 15 | 20 |
| --- | --- | --- | --- | --- | --- | --- |
| 학습 날짜 재생 NH4 비용 | 4.51 | 5.51 | **5.65** | 6.79 | 8.30 | 9.94 |
| (참고) 검증 날짜 재생 NH4 비용 | 33.47 | 37.57 | 38.20 | 42.17 | 46.31 | 50.82 |

kappa = 5.5 로 고정한다. 참고로 같은 강도에서 기록 운전 재생의 검증 날짜 여유 효과는 날짜 분할 38.20, 고정 여유 38.29, e52 37.72 로 셋이 거의 같다. 즉 기록 운전이 지나가는 상태에서는 날짜 분할 불일치도 검증 날짜에 고정 여유보다 여유를 더 주지 않는다. 정책이 기록 운전과 다른 상태로 갈 때도 같은지가 이 실험에서 확인할 부분이며, 결과가 e53 과 비슷하게 나올 가능성이 있다는 점을 미리 적어 둔다.

## 실험 구성

PPO-Lag, FCSRL + PPO-Lag 각 seed 0, 1, 2 새로 학습. 비교 대상은 e53 (고정 여유 0.45), e52 (전이 구성원 불일치 kappa 10), kappa 0 기준 (e52 와 같은 출처). 각 401,280 전이, 마지막 정책, 검증 40일과 학습 188일을 구성원 5개로 결정적 평가. 학습 환경은 e30 준비물과 e35 수정 모델 (scikit-learn 1.7.2, `/home/jio/fcsrl_src/.venv`).

## 판정 (결과를 보기 전에 정함)

방법마다 따로 본다. 주 비교는 seed 짝 차이 (e54 − e53 고정 여유), 규칙은 e53 과 같다.

- H1 날짜 분할 불확실성의 기여: 아래 둘 중 하나면 지지
  - NH4 경로: 검증 NH4 가 seed 3개 중 2개 이상에서 낮고 평균도 낮으며, 평균 검증 공기량 차이가 +2% 이하
  - 공기량 경로: 검증 공기량이 seed 2개 이상에서 낮고 평균 −2% 이하이며, 평균 검증 NH4 가 높지 않음
- 보조: 같은 규칙으로 e54 − e52 를 적고, 일반화 격차(검증 NH4 − 학습 NH4)가 더 작은지 적는다
- kappa 0 대비 공기량 평균 증가가 +5% 를 넘으면 H1 이 지지돼도 e52 와 같은 "공기를 더 쓰는 보수화" 로 적는다. 공기량, NH4, DO 세 평균이 kappa 0 대비 모두 낮아질 때만 전체 개선으로 적는다

seed 3개 탐색이라 검정은 하지 않는다. 분할 방식과 kappa 는 하나만 시험하며 결과를 보고 바꾸지 않는다.
