# Park/e24: 정책 학습률을 올려 덜 학습된 정책 보완 (Kaggle DARROW)

상태: **사전 등록 (2026-11-13).** 가설과 판정 규칙은 검증 결과를 보기 전에 정했다. 설정은 학습 구간만으로 골랐다.

## 목적

목표는 공기량과 하루 비용을 함께 낮추는 것이다. e12 ~ e23 중간 점검 ([../../analysis/e12_e22_중간점검.md](../../analysis/e12_e22_중간점검.md)) 에서 찾은 원인 두 가지를 보완한다.

- 공기를 아끼는 힘은 정책에서 나오는데, 정책이 덜 학습됐다. 업데이트마다 KL 이 약 0.007 로 목표 0.02 보다 훨씬 작고, e21, e22 에서 학습을 더 할수록 공기량이 줄었다. 그래서 같은 학습 예산 (업데이트 66번) 에서 한 번에 더 많이 배우게 한다.
- seed 운이 크다 (e23). 그래서 판정을 seed 10개로 한다.

## 설정 고르기 (학습 구간만)

후보: 정책 학습률 6e-4, 1e-3 (기본 3e-4), 업데이트마다 같은 자료를 도는 횟수 20 (기본 10). 나머지는 e12 A 와 같다 (학습 중 차단 target 3.5, 업데이트 66번).

평가 구간은 학습 구간 마지막 40일 (2021-10-01 ~ 11-09) x 구성원 5개, e19 H1 차단. e12 ~ e22 에서 쓴 4일 간격 40일은 여름이 많아 검증 구간 (겨울) 과 순서가 자주 달랐다. 마지막 40일로 e17 ~ e22 를 다시 매겨 보니 검증 순서와 더 잘 맞아서 이번부터 이것을 쓴다 (다시 매긴 것은 이미 나온 결과라 고르는 데 쓰지 않았다).

규칙 (결과 전에 기록): "seed 0, 1, 2. 기준은 같은 seed 의 e12 A + e19 차단. 평균 공기량과 평균 비용이 기준보다 낮고, 둘 다 이긴 seed 가 가장 많은 것 (2/3 이상, 같으면 공기량이 적은 것). 없으면 버린다".

| 후보 | 공기량 | 하루 비용 | 기준보다 둘 다 낮은 seed |
| --- | --- | --- | --- |
| 기준 e12 A (학습률 3e-4) | 74,447 | 3.58 | |
| **학습률 6e-4 (규칙으로 고름)** | **73,220** | **3.38** | 2/3 |
| 학습률 1e-3 | 73,357 | 3.40 | 1/3 |
| 자료 20번 돌기 | 79,811 | 3.55 | 0/3 |

## 방법

`train_darrow.py --actor-lr 6e-4` 로 seed 0 ~ 9 를 학습한다 (나머지는 e12 A 와 같음, 업데이트 66번이라 PROTOCOL v1 예산 안). seed 0 ~ 2 는 고르기 단계에서 같은 명령으로 학습한 정책을 그대로 쓴다. 평가는 e19 H1 차단을 건 정책 하나다.

기준은 같은 seed 의 e12 A 정책 + e19 H1 차단이다. seed 0 ~ 4 는 Park/e19 결과, seed 5 ~ 9 는 Park/e23 결과 (새로 계산하지 않음).

## 조건과 평가

검증 40일 x 구성원 5개 = 200 에피소드를 결정적으로 돈다. test 는 쓰지 않는다.

## 가설 (사전 등록)

- H1 (주 가설). 학습률 6e-4 가 같은 seed 기준보다 공기량과 하루 비용이 둘 다 낮은 seed 가 10개 중 6개 이상이고, seed 10개 평균도 둘 다 낮다
- H2. 학습률 6e-4 의 seed 10개 평균이 4 x 16 앙상블 조합 10개 평균 (seed 0 ~ 4 와 5 ~ 9 의 조합, 공기량 81,376, 비용 4.80) 보다 둘 다 낮다

가설이 기각되는 결과도 그대로 기록한다.

## RESULT.md 처리 (미리 정함)

H1 과 H2 가 모두 지지되면 대표 방법을 "학습률 6e-4 정책 하나 + e19 H1 차단" 으로 바꾸고 seed 10개 평균을 적는다. 그렇지 않으면 대표 결과 (e22 H1) 는 바꾸지 않고 해석에만 적는다.

## 미리 밝히는 한계

- 고르기 단계는 seed 3개, 학습 구간 40일뿐이다
- 학습률 하나만 바꿨다. 학습률을 올리면 학습이 불안정해질 수 있어 seed 사이 편차도 함께 적는다
- e10 ~ e23 과 같은 대리 모델 한계
