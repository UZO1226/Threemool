# Park/e80: 고를 때 쓰지 않은 날에서 다시 본 예측 제어 NH4 여유 1.8 (Kaggle DARROW)

상태: **사전 등록 (2026-11-26).** 날짜, 공기 가중치, 가설, 판정 규칙은 이 실험의 결과를 보기 전에 정했다. 대표는 바꾸지 않는다.

## 목적

Park/e79 에서 NH4 여유 1.8, 공기 가중치 2.0 의 차단 위 예측 제어 (80,374 / 4.345) 는 대표 (82,104 / 4.658) 보다 공기와 비용을 함께 줄였다. 그런데 여유 1.8 은 검증 구간 결과 (Park/e76) 를 보고 고른 값이고, 판정도 같은 검증 구간에서 했다. 이 실험은 고를 때 쓰지 않은 날 (학습 구간 마지막 40일) 에서 같은 비교를 다시 한다. 같은 날의 대표 (Park/e43) 와 여유 1.2 격자 (Park/e60) 는 이미 있다. 학습 구간에서는 Park/e60 에서 대표가 예측 제어보다 낮게 나온 적이 있어, 결과가 뒤집힐 수 있는 시험이다.

## 방법

- 날: 학습 구간 마지막 40일 x 구성원 5개 = 200 에피소드 (Park/e43, e60 과 같음). 정책은 이 날로 학습했지만 예측 제어의 여유 1.8 은 이 날을 보지 않고 골랐다
- 기준: `ShortMPC` (`objective='excess'`, NH4 여유 1.8, 1시간) + 대표 차단
- 공기 가중치: 1.0, 1.5, 2.0, 2.5. 학습 구간은 검증보다 공기량이 10% 안팎 적으므로 (Park/e60) 검증에서 쓴 범위를 그대로 쓴다
- 비교 1: 대표 (FCSRL 4 x 16 + 대표 차단, 묶음 5개, Park/e43 학습 구간 값)
- 비교 2: 여유 1.2 곡선 (Park/e60 격자의 여유 1.2, 공기 가중치 0.7, 1.0, 1.5, 2.0 의 지배되지 않는 점, 선형 보간)

## 평가

학습 구간 마지막 40일 x 구성원 5개 = 200 에피소드, 결정적. test 는 쓰지 않는다.

## 가설 (사전 등록)

- H1. 여유 1.8 점 가운데 하나라도 공기량이 대표 평균 이하이고, 하루 비용이 대표 평균보다 0.05 넘게 낮고, 대표 묶음 5개 가운데 4개 이상보다 비용이 낮다
- H2. 여유 1.2 곡선 범위 안의 여유 1.8 점들의 (점 비용 빼기 같은 공기량의 여유 1.2 곡선 비용) 평균이 -0.05 보다 낮다. 범위 안 점이 없으면 판정하지 않는다

## RESULT.md 처리 (미리 정함)

- H1 지지: "대표보다 공기와 비용을 함께 줄이는 차단 위 예측 제어 (여유 1.8) 가 고를 때 쓰지 않은 날에서도 나온다" 고 적고 그 점을 적는다. Park/e73 의 대표 교체 제안 (팀 결정) 에 근거로 더한다. 기각: "Park/e79 의 공기와 비용 동시 감소는 검증 구간에서만 보였다" 고 적는다
- H2 지지: "여유 1.8 이 1.2 보다 낮은 것은 다른 날에서도 이어진다" 고 적는다. 기각: "여유 1.8 의 이득은 검증 구간에서만 보였다" 고 적고 Park/e79 H1 을 그만큼 좁힌다

## 미리 밝히는 한계

- 학습 구간은 대표 정책이 학습한 날이라 대표에 유리할 수 있다. 그래도 H1 이 지지되면 더 강한 근거가 되고, 기각되면 그 몫을 함께 적는다
- Park/e60 격자 비용은 공기 가중치를 따라 고르지 않게 오르내린다 (예: 여유 1.2 에서 2.375 ~ 3.625). 곡선 비교는 흔들림이 크다
- 대표 값은 Park/e43 에서 돌린 것을 다시 읽는다. 같은 차단, 같은 날, 결정적이다
