# Park/e36: 같은 차단에서 정책 기여 분리 (Kaggle DARROW)

상태: **완료 (2026-11-18). H1 기각 (0/5): 같은 차단에서 FCSRL 은 PPO-Lag 보다 공기를 13% 덜 쓰지만 비용이 0.41 높다.** 대표는 바꾸지 않는다. 가설과 판정 규칙은 검증 결과를 보기 전에 정했다 (커밋 `5e7e62c`). 새 학습과 고를 설정은 없다.

## 목적

팀 검토 (Yoo/analysis/TEAM_RESEARCH_REVIEW_20261117.md 6.2 절, 7.1 절) 는 Park 대표 방법의 개선 상당 부분이 FCSRL 보다 모델 예측 차단의 성과로 보인다고 지적했다. 이 실험은 대표 차단 (e19 차단 + e28 원판 회복 계획) 을 그대로 두고 정책만 바꿔, 다음을 나눠 본다.

1. 정책이 없어도 차단만으로 얼마나 되는가 (정책 없음, 고정 규칙)
2. 같은 차단에서 FCSRL 표현 학습이 PPO-Lag 보다 나은가 (같은 학습 설정, 같은 seed)
3. 대표 방법의 추가 요소 (학습 중 차단, 짧은 학습, 앙상블) 가 어디서 이득을 내는가

## 조건

검증 40일 x 구성원 5개 = 200 에피소드, 결정적. test 는 쓰지 않는다. 모든 조건에 대표 차단을 똑같이 붙인다.

| 조건 | 정책 | 학습 |
| --- | --- | --- |
| zero | 언제나 공기 0 을 제안 (차단이 모두 정함) | 없음 |
| rec | 언제나 학습 구간 기록 총 공기량 평균 3,774 Nm3/h 를 제안 | 없음 |
| ppo_s0 ~ s4 | Park/e08 PPO-Lag (`dw_runs/ppo_s*`) | 66번 갱신, 학습 중 차단 없음 |
| fcsrl_s0 ~ s4 | Park/e08 FCSRL (`dw_runs/fcsrl_s*`) | 66번 갱신, 학습 중 차단 없음, PPO 와 같은 설정 |
| ppo_ens, fcsrl_ens | 위 seed 0 ~ 3 의 행동 평균 | 위와 같음 |
| 대표 (새로 계산하지 않음) | Park/e22 4 x 16 앙상블 seed 0 ~ 3 (`dw_u16_runs`) | 16번 갱신 x 4, 학습 중 e12 차단 |

대표 값은 e35 의 orig seed 0 ~ 3 (79,457, 4.585) 과 겹치지 않는 묶음 5개 평균 (82,104, 4.658) 을 쓴다.

## 가설 (사전 등록)

- H1 (주 가설). 같은 대표 차단에서 FCSRL 단일 정책이 같은 seed 의 PPO-Lag 단일 정책보다 공기량과 하루 비용이 둘 다 낮은 seed 가 5개 중 4개 이상이고, seed 5개 평균도 둘 다 낮다

참고 (판정 없음, 미리 정한 비교):

- 정책 기여: 대표와 FCSRL 앙상블이 zero, rec 보다 비용이 낮은가
- 앙상블 기여: ppo_ens, fcsrl_ens 대 같은 방법 단일 평균
- 학습 설정 기여: 대표 대 fcsrl_ens (학습 중 차단과 짧은 학습, 같은 seed 0 ~ 3)

## RESULT.md 처리 (미리 정함)

대표 방법은 바꾸지 않는다. 결과는 "기여 분리" 로 RESULT.md 해석에 적는다. H1 이 기각되면 "같은 차단에서는 FCSRL 표현이 PPO-Lag 보다 낫다는 근거가 없다" 고 적고, 대표의 이득을 차단과 학습 설정의 몫으로 설명한다.

## 정보 접근 (검토 4.4 절)

| 요소 | 읽는 정보 | 대리 모델 호출 |
| --- | --- | --- |
| 정책 (PPO-Lag, FCSRL) | 관측 11 개: 상태 5 개 (NH4, NO3, DO 3 구역), 유입량, 수온, 시각 sin, cos, 유입 NH4, 직전 총 공기량 | 없음 |
| 대표 차단 | 관측 + 정책이 못 보는 유입 변수 4 개 (inf_s_nd, inf_x_nd, inf_s_s, inf_x_s), 지금 구간 배분 (frac), 직전 구간 공기량, 환경이 쓰는 구성원 번호 (그 구성원을 빼려고) | 매 스텝 격자 37 개 x 다른 구성원 4 개, 회복 검사 3 스텝, 회복 계획 4 스텝 x 19 후보 |

차단은 정책보다 많은 정보를 읽고 환경과 같은 대리 모델 계열을 쓴다. 따라서 차단의 이득은 "정확한 모델이 있을 때" 의 값이며, 실제 처리장에서의 이득은 아니다.

## 미리 밝히는 한계

- PPO-Lag 와 FCSRL 은 seed 5 개다. 판정 표본이 작다
- 기본 정책 (66번 갱신, 학습 중 차단 없음) 과 대표 (16번 x 4, 학습 중 차단) 는 학습 설정이 여러 가지 다르다. 학습 설정 기여는 한 덩어리로만 본다
- 검증 구간은 e10 부터 반복해서 썼다
- e10 ~ e35 와 같은 대리 모델 한계

## 결과

전체 표는 [results.md](results.md). 검증 40일 x 구성원 5개, 모든 조건에 대표 차단.

| 정책 (+ 대표 차단) | 공기량 Nm3/일 | 하루 비용 | NH4 위반 % | DO 위반 % | 개입 % |
| --- | --- | --- | --- | --- | --- |
| 정책 없음 (차단만) | 79,670 | 5.245 | 3.65 | 1.87 | 77.3 |
| 고정 규칙 (3,774 Nm3/h) | 96,912 | 4.655 | 3.65 | 1.25 | 13.8 |
| PPO-Lag 단일 평균 (seed 0 ~ 4) | 102,377 | 4.103 | 3.39 | 0.93 | 5.1 |
| FCSRL 단일 평균 (seed 0 ~ 4) | 89,261 | 4.511 | 3.46 | 1.29 | 11.0 |
| PPO-Lag 앙상블 (seed 0 ~ 3) | 103,716 | 4.050 | 3.35 | 0.92 | 5.2 |
| FCSRL 앙상블 (seed 0 ~ 3) | 90,749 | 4.405 | 3.40 | 1.24 | 4.5 |
| 대표 (e22 4 x 16 앙상블 seed 0 ~ 3, e35 값) | 79,457 | 4.585 | 3.52 | 1.31 | |
| 대표, 겹치지 않는 묶음 5개 평균 (e35 값) | 82,104 | 4.658 | 3.58 | 1.32 | |

- **H1 기각 (0/5).** 같은 차단에서 FCSRL 은 모든 seed 에서 PPO-Lag 보다 공기량이 적지만 (짝 차이 -13,116) 비용이 높다 (+0.408). 어느 쪽도 다른 쪽을 두 지표 모두에서 이기지 못한다. 비용 차이는 주로 DO 위반 (+0.35 %p) 에서 온다
- 정책 기여: 차단만 쓰면 공기량은 대표와 비슷하지만 (79,670 대 79,457) 비용이 5.245 로 대표 (4.585) 보다 0.66 높다. 같은 공기량에서 학습한 정책이 비용을 13% 줄인다. 차단만 쓰면 매 스텝 77% 를 차단이 정해, DO 위반이 1.87% 로 가장 많다
- 고정 규칙은 공기를 많이 쓰고 (96,912) 비용도 대표와 비슷하다 (4.655). FCSRL 앙상블은 고정 규칙보다 공기량과 비용이 둘 다 낮다. PPO-Lag 는 공기를 더 써서 비용을 낮춘다
- 앙상블 기여: 같은 방법의 단일 평균보다 비용이 조금 낮다 (PPO -0.053, FCSRL -0.106). 공기량은 조금 는다
- 학습 설정 기여: 대표는 같은 seed 0 ~ 3 의 FCSRL 앙상블보다 공기량이 11,292 적고 비용은 0.18 높다. 학습 중 차단과 짧은 학습은 "공기를 덜 쓰는 쪽" 으로 운전점을 옮긴다

## 해석

- 같은 차단 아래 PPO-Lag, FCSRL, 대표는 공기량과 비용의 맞바꿈 위의 서로 다른 점이다. PPO-Lag 는 공기를 많이 넣어 비용을 낮추고, FCSRL 과 대표는 공기를 덜 넣는 대신 비용을 조금 더 낸다. "FCSRL 표현이 같은 차단에서 PPO-Lag 보다 낫다" 는 근거는 없다
- 학습한 정책은 분명히 기여한다. 같은 공기량에서 차단만 쓸 때보다 비용이 0.66 낮다. 차단은 1 스텝 필요량만 넣으므로, 앞으로의 부하에 대비한 완충 (e33 진단) 은 정책이 만든다
- Park 대표 방법의 독자적 이득은 "같은 공기량에서 비용을 낮추는 것" 으로 말하는 것이 맞다. PPO-Lag + 같은 차단이 비용만 보면 더 낮으므로, 비용 최소만을 목표로 하면 대표가 가장 좋은 선택은 아니다. 연구 목표 (공기량과 비용을 함께) 에서는 대표가 차단만 쓰는 경우를 두 지표 모두에서 이기는 유일한 조건이다 (대표 seed 0 ~ 3 기준. 묶음 5개 평균 82,104 는 차단만보다 공기량이 많다)
- 차단은 정책보다 많은 정보 (정책이 못 보는 유입 변수 4 개, 구간 배분, 환경 계열 모델) 를 쓴다. 차단 몫의 이득은 정확한 모델이 있을 때의 값이다
