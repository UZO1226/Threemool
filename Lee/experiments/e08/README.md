# Lee/e08: 라그랑주 승수의 반응 속도를 높이는 확장 (DARROW 환경)

## 목적

원래 FCSRL(Lee/e07)이 제약을 못 지키는 약점을 겨냥한다. Lee/e06 (Avedøre)에서 원래 FCSRL 의 마지막 모델은 5개 중
2개만 비용 한도를 지켰고, Yoo 는 BSM1 에서 승수 PID 반응을 높이는 것이 제약 준수에 결정적이었다고 기록했다
(Yoo/e20, e21: 반응 5배에서 8배). 같은 아이디어를 이 데이터에서 FCSRL + PPO-Lag 에 적용한다.

변경은 승수(lambda)를 갱신하는 PID 의 이득(kp, ki, kd)에 곱하는 배율 하나다. 표현 학습, 정책, 환경은 그대로다.
Lee/e07 의 기본 이득은 (0.02, 0.005, 0.01) 이고 배율은 1 이다.

## 구성

| 항목 | Lee/e07 (원래) | Lee/e08 |
| --- | --- | --- |
| PID 이득 배율 | 1 | 3 과 8 |
| 방법 | FCSRL + PPO-Lag | FCSRL + PPO-Lag |
| seed | 0 에서 4 | 0 에서 4 (원래와 짝을 이룸) |

나머지(데이터, 환경, 한도 12, 학습량, 평가, 선택 규칙)는 Lee/e07 과 모두 같다. 새 실행은 2 배율 x 5 seed = 10개다.
배율 3 과 8 은 결과를 보기 전에 정했고 바꾸지 않는다. 두 값을 모두 보고한다.

## 가설과 판정 기준 (결과를 보기 전에 정함)

- H21 (주 가설). 배율을 높이면 마지막 모델의 하루 비용이 원래 FCSRL 보다 낮아지고 한도 만족 에피소드 비율이 높아진다.
  단 공기량이 원래 FCSRL 보다 5% 넘게 늘면 개선이 아니라 에너지와 안전의 교환으로 적는다.
- H22. 선택 모델(검증 한도 만족 중 보상 최대)에서도 같은 방향이다.
- H23. 배율이 클수록(8) 승수가 더 빨리 오르고 학습 중 비용이 한도에 더 가깝다. 단 과도하게 흔들려 학습이 불안정해지지는 않는다
  (승수가 상한 20 에 붙거나 비용이 진동하면 불안정으로 적는다).

차이가 seed 간 표준편차보다 작으면 개선이라 단정하지 않는다. p 값은 seed 5개의 탐색적 Welch 검정이며 보정이 없다.
seed 가 같으므로 seed 별 짝 비교를 함께 적는다. 결과가 반대여도 그대로 기록한다.

## 실행

```bash
python -u Lee/experiments/e07/run_dw.py --data <데이터>/darrow_15min.pkl --surrogate <데이터>/darrow_surrogate_gbm.pkl \
  --limit 12 --upstream <원본 FCSRL 경로> --out <결과>/e08_runs --parallel 6 \
  --jobs ppolag_fcsrl#3:0 ppolag_fcsrl#8:0 ... (배율 2 x seed 5)
```

## 미리 밝히는 한계

- Lee/e07 과 같다 (대리 모델 정확도가 낮고 실제 공정이 아님, 검증 구간 분포 차이, 데이터 적음).
- 단일 하이퍼파라미터(승수 반응)의 조정이라 새 알고리즘이 아니다. FCSRL 표현 학습을 바꾸지 않는다.
- 승수 반응을 높이면 한도를 지키려고 에너지를 더 쓰는 쪽으로 움직일 수 있다. 그 경우 개선이 아니라 교환으로 적는다.
