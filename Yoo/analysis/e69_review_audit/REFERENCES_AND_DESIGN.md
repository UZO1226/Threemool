e68의 제약 미달이 제한된 학습 예산에서도 계속되는지 확인하는 기존 e69를 활용한다. FCSRL과 같은 망의 고정 무작위 표현 PPO 모두 seed 0~9, 250회에서 500회로 늘린다. 비용, 환경, 한도, 네트워크와 평가를 유지한다. 수렴하지 않았다는 단정 대신 추가 학습으로 개선되는지 묻는다. 500회에서도 실패하면 그 예산에서 미달했다고만 결론 낸다.

## 팀 중복 확인

main c325d97의 Lee/Park README, RESULT 및 Park/e34를 확인했다. Lee 최신 원격 e077ba3의 e76은 DO 변화량 예측을 계획한 것이며 완료 결과가 아니다. Park/e34는 DO 예측 오차 차단으로 주 가설 실패다. 이들은 같은 비용에서 FCSRL과 고정 표현 대조군의250/500회 비교와 다르다. 그러나 로컬 Yoo 브랜치 yoo/e69-longer-training, 커밋86f543c가 바로 그 실험을 이미 수행 중이다. 따라서 새 실행을 만들지 않는다.

## 데이터와 판정

입력13차원과 총공기 행동, cap 적용 후 실제 공기량, dev146일/val40일, stochastic3회 평균은 기존 정의를 유지한다. 비용은 누적 NH4가380을 넘은 뒤의 스텝 수이며 한도.3이다. dev는 학습과 조정에 쓰였고 val도 연구 전반에서 반복 사용됐다. holdout42일은 과거 정책 및 대리 모델 학습 자료이며 독립 미노출 시험이 아니다. test41일은 e66에서 사용됐다. 이번 감사는 데이터 파일을 역직렬화하거나 정책 평가를 새로 실행하지 않는다.

기존 H1~H3 판정은 보존한다. 단, H1의 상대 우위가 절대 한도 충족을 뜻하지 않는다. ABAC 효율 우위 주장은 같은 평가 분포에서 한도 충족 여부와 NH4 초과량을 먼저 보여야 한다. 성공한 날만 골라 계산한 공기량은 서로 다른 날짜 집합일 수 있어 단독 우위 근거로 쓰지 않는다. seed10개가 정책 반복 단위이며 모델5개와 평가 난수3개를 독립 학습 seed로 세지 않는다.

## 실행 후 감사

audit.py는 manifest 해시, 명령의500회 고정, 시작된 실행의 e68 접두부 모든 수치(벽시계 seconds 제외)를 비교한다. 250회 미만은 부분 일치로 표시하고 전체 재현으로 세지 않는다. 길이가 짧은 zip 비교를 통과로 오인하지 않는다. 로그 일치는 저장되지 않은 전체 가중치의 비트 일치를 입증하지 않는다. e68 최종 파일은 optimizer/PID/RNG를 모두 담은 재개 파일이 아니지만 e69는 처음부터 같은 seed로 재실행하므로 초기화된 optimizer에 최종 가중치만 넣는 문제는 없다.

실행 중 소스는 수정하지 않는다. 기존 report69.py의 재현 검사는 cost/air만 보고 길이 검증이 없어 별도 감사로 보완한다. 이후 모든 실행이 끝났을 때 같은 감사 스크립트로 다시 확인한다. 이 감사가 실패하면 학습량만의 효과로 해석하지 않는다.
