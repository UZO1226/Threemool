# Lee/e12: 학습 비용 한도에 여유를 두기 (DARROW 환경)

## 목적

원래 FCSRL 은 학습에서는 한도 12 를 맞추지만 검증 구간(겨울)에서는 같은 정책의 비용이 훨씬 높다(기록된 운전도 학습 12.17, 검증 28.77).
학습 분포와 검증 분포의 차이를 학습 때 미리 반영하려고, **학습과 모델 선택에서 쓰는 비용 한도만 12 에서 8 로 낮춘다**.
보고 기준은 계속 12 다(비용이 12 이하인 seed 수, 평균 비용). 변경은 이 한도 하나이고 나머지는 Lee/e07 과 같다.
원래 FCSRL 은 Lee/e07, e10 의 seed 0 에서 9 (한도 12)를 그대로 쓴다. 새 실행은 seed 0 에서 9, 10개.

## 가설과 판정 기준 (결과를 보기 전에 정함)

- H30 (주). 선택 모델과 마지막 모델 모두 10개 seed 평균 비용이 원래보다 낮고 비용 12 이하인 seed 수가 원래(선택 9/10, 마지막 2/10)보다 많거나 같다.
  공기량이 5% 넘게 늘면 개선이 아니라 교환으로 적는다.
- H31. 비용의 seed 별 짝 차이가 음수인 seed 가 마지막 모델에서 7개 이상이다.
- 차이가 표준편차보다 작으면 개선이라 단정하지 않는다. 결과가 반대여도 기록한다.

## 읽는 법의 주의

- 이 실험의 metrics.json 안 "한도 만족 에피소드 %" 는 한도 8 기준이라 원래(12 기준)와 비교하지 않는다. 비용과 공기량, 비용 12 이하 seed 수로 비교한다.
- 학습 중 모델 선택도 한도 8 기준(8 만족 중 보상 최대, 없으면 최소 비용)이라 선택 규칙이 함께 달라진다. 한도 여유의 일부로 보고 분리하지 않는다.
