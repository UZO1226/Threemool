# e133 DARROW 공통 환경에서 Actor 보정 재검증

e50에서 FCSRL 표현을 갱신한 직후 Actor 출력을 원래 값에 가깝게 맞추자 평균 공기와 비용이 모두 감소했다. e111에서 같은 시드가 두 수치를 함께 낮춘 경우는 1/5였다. e133은 새로운 학습 시드에서 이 결과가 반복되는지, 같은 표본으로 Actor를 더 학습하는 것만으로도 같은 효과가 생기는지 확인한다. [e50](../e50/README.md), [e111](../e111/README.md), [실행 전 판정 기준 및 문헌](REFERENCES_AND_DESIGN.md)

## 결과

**2026년 11월 25일 22시 15분 완료. Actor 보정은 기본 FCSRL보다 평균 공기량을 10.56% 줄였지만 NH4 위반 시간이 102.09분 늘었다.** 같은 시드에서 공기 감소와 세 수질 조건을 동시에 만족한 경우는 기본 대비 0/5, 추가 PPO 대비 0/5였다.

겨울 개발 40일, 날짜별 GBM 5개를 같은 가중치로 평가한 뒤 학습 시드 5개의 평균과 표본 표준편차를 냈다. 한도 충족은 각 시드의 평균 비용이 12 이하인 경우다.

- **기본 대비.** 보정은 평균 공기 9,493 Nm³와 DO 위반 12.27분을 줄였다. NH4 초과 적분은 2.20 mg h/L, 합산 비용은 5.99 증가했다. 비용이 감소한 시드는 2/5로 e50의 원 판정 기준에도 미달했다. 시드 10에서는 공기 5,133 Nm³와 NH4 위반 6.75분이 함께 줄었으나 DO 위반이 1.35분 늘었다. 시드 11, 12에서는 각각 공기 29,480, 9,401 Nm³를 절약했지만 NH4 위반이 242분, 235분 늘었다.
- **같은 예산의 추가 PPO 대비.** 보정은 평균 NH4 위반을 43.43분, NH4 초과 적분을 10.97 mg h/L 줄였고 공기를 3,389 Nm³(4.40%) 더 썼다. 시드별 편차가 컸다. 추가 PPO의 시드 13에서는 공기 52,530 Nm³와 NH4 위반 562.58분이 함께 관측됐다. 출력 보존 방식이 단순 추가 최적화보다 평균 NH4 악화를 완화했지만, 같은 공기량에서의 수질 이득을 측정한 비교는 아니다.
- **보정 자체는 작동했다.** 330개 추가 단계에서 표현 갱신 전 정책과의 점검 표본 평균 KL은 보정 전 0.001428에서 보정 후 0.000069로 줄었다. 보정과 추가 PPO 모두 16,500회 갱신을 시도했고, 후보를 채택한 단계는 각각 330/330, 324/330이었다. 추가 단계에 든 CPU 시간은 다섯 시드 합계 767초, 380초였다. 보정이 출력을 보존하는 효과와 하루 운전 성과를 구분할 수 있다.
- **기존 결과와의 관계.** 기존 시드 0~4에서는 기본 대비 평균 공기 −5.73%, 비용 −1.02였고 이번 시드에서는 공기 −10.56%, 비용 +5.99였다. 평균 공기 절감의 방향은 반복됐고 비용의 방향은 바뀌었다. 개발 겨울을 다시 쓴 결과이므로 재현성 판단은 이 대리 환경과 학습 시드 범위에 해당한다. 이 결과를 근거로 Actor 보정을 트레이드오프 개선 기법으로 채택하지 않는다.

## 방법

세 방법 모두 DARROW 공통 대리 환경 v1.1에서 공기 공급률 하나를 결정한다. 환경은 총 공급률을 기록 비율로 폭기 구역 5개에 배분한다. 표의 총 공기는 정책이 낸 공급률(Nm³/h)을 15분 간격으로 적분한 부피(Nm³)다. 하루 기록의 첫 관측에서 시작해 95번 전이하므로 표의 부피와 위반 시간은 23시간 45분 기준이다. NH4는 4 mg/L 초과, DO는 세 구역 중 최댓값이 2 mg/L 초과이면 해당 구간 15분을 센다. 비용은 두 위반 구간 수의 합이다. NH4 초과 적분은 초과 농도에 0.25시간을 곱해 더한다.

| 조건 | 표현 갱신 직후 수행하는 추가 단계 |
| --- | --- |
| 기본 FCSRL | 추가 최적화 없음 |
| Actor 보정 | 같은 관측에서 표현 갱신 직전의 정책 평균을 복원하도록 Actor 평균망을 학습 |
| Actor 추가 PPO | 같은 관측에서 PPO의 제약 포함 이점을 최적화하도록 Actor 평균망을 학습 |

표현 학습, 모방 초기 정책, PID, 기본 PPO 갱신 및 학습 날짜 188일은 e50과 같다. 두 추가 단계는 2,048개 적합 표본, 1,024개 점검 표본, 같은 학습률과 최대 50회의 Adam 갱신을 쓴다. 두 가치망과 행동 표준편차는 추가 단계에서 고정한다. 보정은 출력 오차가 줄어든 후보를, 추가 PPO는 KL 한도 안의 마지막 후보를 수락한다. 따라서 두 조건의 차이에는 목적 함수와 수락 방식이 함께 들어간다.

시드 10~14 각각에서 401,280개 전이로 학습한 마지막 정책을 겨울 개발 날짜 40일과 GBM 구성원 5개 조합에서 평가한다. 정책별 200개 경로에서 얻은 평균을 시드별로 비교한다. 독립 반복 단위는 학습 시드 5개다. 사전 기준은 두 대조 각각에서 평균 공기가 감소하고 세 수질 지표가 비증가하며, 같은 시드 4개 이상에서 이 조건이 두 대조에 동시에 성립하는 것이다.

## 재현

`bash Yoo/experiments/e133/batch.sh <새_결과_경로> 8` 로 서버의 e50 준비물과 e113 가속 의존성을 이용한다. 실행 디렉터리에 입력 검산 로그, 학습 코드 커밋, 시드별 설정, 최종 가중치, 학습 로그, 원 sklearn으로 재평가한 에피소드 및 15분 경로가 저장된다. [학습과 원 추론기 교차 확인](trial.py), [평가 집계와 판정](report.py)

학습 실행 커밋은 `c7475c5`, 사전 설계는 `fb322bb`다. 원자료는 Kaggle DARROW의 온라인 센서와 유입 자료이며 e50 준비 파일 7개의 SHA256을 원 기록과 대조했다. 11개 관측에서 행동을 총 공기 공급률 0~9,000 Nm³/h로 변환하며 스텝 보상은 공급률을 −9,000으로 나눈 값이다. PyTorch 2.14.1+cu130의 CPU 경로, scikit-learn 1.9.1, NumPy 1.26.4, pandas 2.2.3, Numba 0.63.1을 사용한다. [데이터 및 전처리](../e50/README.md)

실행 경로는 `/home/jio/fcsrl_src/results/e133/main` 이다. 겨울 개발 40일은 이전에 사용한 날짜이고, 이번 평가에서는 별도로 보관한 시험 41일을 쓰지 않는다.
