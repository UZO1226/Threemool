# Park/e82: 검증 구간 날짜 블록으로 본 대표 대 차단 위 예측 제어 (Kaggle DARROW)

상태: **완료 (2026-11-26). H1 차이 없음 (-0.233, 구간 -0.550 ~ +0.010), H2 차이 없음 (-0.313, 구간 -0.906 ~ +0.171).** 사전 등록 커밋 `fd39af0` (main 병합 #252). 설정, 가설, 판정 규칙은 이 실험의 결과를 보기 전에 정했다. 대표는 바꾸지 않는다.

## 목적

Park/e81 은 차단 위 예측 제어가 대표보다 낮다는 결론이 검증 40일에서만 나왔다고 정리했다. 또 e74 ~ e80 에서 가설이 자주 기각된 까닭 하나는, 이웃한 설정 사이 비용 흔들림이 0.1 가까이 되는데 점 하나의 차이를 0.05 기준으로 판정했기 때문이다. 이 실험부터는 판정 방식을 바꾼다. 같은 날끼리 짝지은 하루 비용 차이의 날짜 블록 95% 구간 (Park/e49, e64) 으로, "예측 제어가 낮음 / 대표가 낮음 / 차이 없음" 세 갈래로 판정한다. 먼저 검증 구간에서 Park/e81 의 핵심 두 설정이 날짜 흔들림을 넘어 대표보다 낮은지 본다.

## 방법

- 차단 위 예측 제어 두 설정을 스텝 기록 (`rollout_log`) 과 함께 검증 구간에서 돈다: 기본 (NH4 여유 1.2, 공기 가중치 1.5, Park/e58 의 82,238 / 4.425), Park/e79 의 공기와 비용 동시 감소 점 (여유 1.8, 가중치 2.0, 80,374 / 4.345). 둘 다 1시간, 대표 차단
- 대표의 스텝 기록은 Park/e44 (묶음 5개) 를 쓴다
- 날짜마다 구성원 5개 평균 (대표는 묶음 5개도 평균) 을 내고 (예측 제어 빼기 대표) 를 날짜 단위로 짝짓는다. 이어진 5일 원형 이동 블록 다시 뽑기 10,000번 (seed 0) 의 95% 백분위 구간 (Park/e49 와 같음)

## 평가

검증 40일 x 구성원 5개 = 200 에피소드, 결정적. test 는 쓰지 않는다.

## 가설 (사전 등록)

방향은 이전 결과에서 정했다 (Park/e59, e66, e67 은 검증 구간에서 예측 제어가 5/5 낮았다).

- H1. 기본 설정 (여유 1.2) 의 (예측 제어 빼기 대표) 블록 95% 구간이 0 아래다
- H2. 여유 1.8, 가중치 2.0 의 같은 구간이 0 아래다
- 판정은 지지 (0 아래), 반대 (0 위), 차이 없음 (0 포함) 의 세 갈래로 적는다

## RESULT.md 처리 (미리 정함)

- 지지: "검증 구간에서 차단 위 예측 제어 (그 설정) 는 날짜 흔들림을 넘어 대표보다 낮다" 고 적는다
- 차이 없음: "검증 구간의 예측 제어 이득은 날짜 흔들림 안에 있다" 고 적고, Park/e59, e66, e67 의 결론을 "묶음 단위에서만" 으로 좁힌다
- 반대: "검증 구간에서도 날짜 단위로는 대표가 낮다" 고 적는다

## 미리 밝히는 한계

- Park/e64 는 학습 구간에서 고른 예측 제어 (공기 3.6% 많음) 와 대표의 차이가 블록 구간으로 "차이 없음" 이었다. 이번 두 설정은 공기량이 대표와 더 가깝다 (+0.2%, -2.1%)
- 대표 스텝 기록 (Park/e44) 은 감사용 차단 (`AuditBrake`) 으로 돌린 것이다. 묶음 값이 대표 (Park/e35) 와 같다 (예: 묶음 0 ~ 3 에서 79,457 / 4.585). 검증 구간은 e10 부터 반복해서 썼다

## 해석

- 사전 등록 처리에 따라 "검증 구간의 예측 제어 이득은 날짜 흔들림 안에 있다" 고 적고, Park/e59, e66, e67 의 결론을 "묶음 단위에서만" 으로 좁힌다
- 방향은 두 설정 모두 예측 제어 쪽이다. 나은 날이 13일, 나쁜 날이 2 ~ 3일이고 나머지 24 ~ 25일은 둘 다 위반이 없어 같다. 날짜를 하나씩 독립으로 뽑으면 기본 설정의 구간은 0 아래 (-0.493 ~ -0.028) 지만, 이어진 날의 위반이 함께 움직이는 것을 담은 블록 구간에서는 0 을 겨우 넘는다
- 즉 "검증 구간에서 예측 제어가 낮다" 는 묶음 5/5 판정 (e66, e67) 은 같은 40일을 묶음만 바꿔 본 것이라, 날짜 흔들림은 담지 않았다. 차이를 가르는 것은 위반이 생기는 약 16일이고, 그 날들이 몇 개의 이어진 구간에 몰려 있다
- 사후 관찰 (판정 없음): Park/e79 의 공기와 비용 동시 감소 점 (-2.1% 공기, -0.313) 은 평균으로는 가장 크지만 구간이 가장 넓다. Park/e85 의 사전 등록 규칙에 따라 한계 칸에 둔다
