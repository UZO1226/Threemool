# Lee/e13: 원래 FCSRL 의 비용 한도별 에너지와 안전 곡선 (DARROW 환경)

## 목적

Lee/e12 에서 학습 한도 8 은 비용을 줄였지만 공기량이 늘었다. 학습 한도 8 도 **같은 원래 FCSRL 의 설정값 하나**라서 확장이 아니라
"손잡이"일 수 있다. 원래 FCSRL 을 여러 한도로 돌려 (공기량, 비용) 곡선을 그리고, 앞선 확장들(승수 8배, 벌점 0.1)과 한도 8 이 그 곡선보다
나은 쪽(같은 공기량에서 비용이 낮음)에 있는지 본다.

## 구성

새 실행: 한도 6, 10, 16 x seed 0 에서 4 = 15개 (원래 FCSRL, 방법과 나머지 설정은 e07 과 같음).
곡선에 쓰는 기존 점: 한도 8 (e12, seed 0 에서 9), 한도 12 (e07, e10, seed 0 에서 9). 보고는 선택 모델 기준, 모든 점의 비용은 검증 구간에서 잰다.
한도 값 6, 10, 16 은 결과를 보기 전에 정했다.

## 가설과 판정 기준 (결과를 보기 전에 정함)

- H32. 한도가 낮을수록 선택 모델의 평균 공기량이 단조롭게 늘고 평균 비용이 단조롭게 줄어든다(곡선이 존재).
- H33. 곡선을 (공기량, 비용)의 선분으로 이은 선보다 한도 8 점(공기량 99,174, 비용 8.25)이 같은 공기량에서 비용이 0.5 이상 낮으면 곡선보다 낫다고 적는다. 그 외에는 곡선 위 이동이다.
- H34. 같은 방식으로 승수 8배(10 seed 평균 공기량 92,111, 비용 10.19)와 벌점 0.1(93,716, 10.63)도 곡선과 비교한다. 비용이 곡선보다 0.5 이상 낮을 때만 곡선보다 낫다고 적는다.
- seed 편차보다 작은 차이는 우연으로 본다. 결과가 반대여도 기록한다.

## 한계

대리 모델 정확도 낮음, 점마다 seed 5 에서 10개, 곡선은 선분 보간이라 거칠다. 한도가 다르면 모델 선택 규칙(그 한도 기준)도 다르다.
