# e40: DARROW 연속 NH4 점수 판정 대조

## 실행 전 고정한 질문

e39의 isotonic 확률 동점 때문에 선택할 수 없었던 판정 경계를 원래 연속 예측값으로 선택하면, 검증에서도 탐지율과 거짓양성률의 상충이 줄어드는가?

변경은 위험 판정 경계를 고르는 입력 한 가지다. e39의 저장된 기존/이력 모델 예측을 재사용한다. 모델 140일 학습, 48일 보정, 40일 검증 분할, 기록 행동과 외생입력, 예측 농도, NH4>4 실제 위반 정의, DO, 비용 한도와 공기량은 유지한다. 재학습과 새 RL은 없다. 과거 Avedore/BSM1은 사용하지 않는다.

보정 날짜에서만 두 규칙의 경계를 구한다. 주 조건은 탐지율 80% 이상 중 거짓양성률이 가장 낮은 경계, 보조 조건은 거짓양성률 10% 이하 중 탐지율이 가장 높은 경계다. 같은 탐지 수에서는 오경보가 적은 경계를 고른다. 원 점수의 동점은 함께 판정한다. 경보 없음은 별도 규칙으로 저장하며, 확률 전용 1 초과 상수를 농도 경계로 사용하지 않는다. 경계와 해시를 저장한 다음 검증 예측을 읽는다.

각 모델에서 연속값과 e39 확률 판정을 비교하고, 별도로 연속값을 쓰는 기존/이력 모델을 비교한다. 점추정치의 탐지율이 낮지 않고 거짓양성률이 높지 않으며 하나 이상 좋아야 두 지표 동시 우위다. 목표 80%/10%의 검증 달성 여부도 따로 공개한다. 날짜 7일 블록 bootstrap 2000회로 차이의 불확실성을 보고한다. 모델 구성원 5개는 독립 정책 seed가 아니다.

이번 설계는 이미 본 e39 결과에서 나온 후속 대조다. 경계를 보정 자료에서만 고정해도 반복 사용한 검증 40일이 독립 최종 시험이 되지는 않는다. test41일은 사용하지 않는다. 검증 결과로 경계를 다시 고르거나 두 프로필 중 유리한 것만 선택하지 않는다. 이 대조로 상충이 남으면 경계 탐색을 반복하지 않고 NH4 반응 예측 문제로 돌아간다.

## 결과와 판단

2026-11-10 완료. 실행 커밋 `218e70d`, 최종 평가 시간 0.164초다. [전체 결과](results.md), [원본 집계](comparison.json), [독립 검산](verification.json)을 보관한다. 계산은 저장된 예측의 경계 선택과 집계이며 새 학습이 아니다.

| 이력 모델 조건 | 검증 탐지율 | 검증 거짓양성률 | 판단 |
| --- | --- | --- | --- |
| 원래 예측 NH4>4 | 35.41% | 13.14% | 참조 |
| isotonic, 탐지율 80% 목표 | 73.65% | 43.81% | e39 참조 |
| 연속값, 탐지율 80% 목표 | 72.55% | 42.35% | 오경보 감소와 탐지 감소가 함께 발생 |
| isotonic, FPR 10% 목표 | 0.00% | 0.00% | 경보 없음 |
| 연속값, FPR 10% 목표 | 36.08% | 13.51% | 경보 회복, FPR 목표 미달 |

기존 모델에서도 주 조건의 탐지율 97.45%→92.80%, FPR 93.63%→79.26%로 둘 다 낮아졌다. 보조 조건은 계속 경보 없음이었다. 두 모델 모두 연속 판정이 isotonic 판정에 대해 탐지율/FPR 동시 우위를 달성하지 못했다. 서로 실제 달성한 검증 탐지율이 다르므로 동일 탐지율 비교가 아니다.

이력 모델의 FPR 제한 조건은 보정 자료에서 탐지율 61.08%, FPR 9.984%였으나 검증에서 36.08%/13.51%였다. e39의 원 점수 진단에서 보고한 FPR 9.998%보다 조금 낮은 것은 같은 TP 907개에서 최소 FP를 고르는 규칙에 따라 FP 3개를 제외했기 때문이다. 검증 결과에 맞춰 고른 변화가 아니다.

확률 동점으로 경보가 전부 사라지던 문제는 원 연속값을 쓰면 피할 수 있다. 그러나 이 대조는 위험 판별력 자체를 높이지 않으며 기간이 바뀔 때 같은 목표가 유지된다는 보장도 주지 않는다. e39의 보정/검증 실제 위반률 6.51%/17.32%, 수온 차이는 그대로다. 그 차이의 인과적 기여율을 분해한 결과는 아니다.

공기 감소 후 실제 NH4가 상승한 구간도 남은 한계를 보여준다. 3시간 평가 55구간 중 실제 NH4>4인 것은 25구간이다. 이력 모델의 연속 판정은 주 조건 탐지율 32.8%, FPR 11.33%, 보조 조건 탐지율 11.2%, FPR 8.67%였다. 실제 위반을 많이 놓친다. 미래 상승 조건은 평가 부분집합 정의에만 사용했으며 판정 입력에는 넣지 않았다. 관측 구간의 조건부 예측이므로 공기 감소의 인과 효과로 단정하지 않는다.

## 남길 것과 다음 결정

- 연속 점수 판정과 명시적 경보 없음 처리는 보존한다. 확률 범위 전용 상수를 농도에 쓰지 않고 원 점수의 순서를 유지한다.
- 이번 경계를 제어 환경에 채택하지 않는다. 물리 농도 예측과 DO, 공기량, 보상, 실제 위반 정의와 비용 한도는 바뀌지 않았다. FCSRL 적용/확장 구조도 그대로다.
- 경계나 보정 함수를 더 바꾸는 대조는 여기서 끝낸다. 원래 목표인 공기량/NH4/DO 동시 개선을 위해, 다음은 NH4 전이가 공기 감소 후 상승을 놓치는 문제를 다루는 학습 변경 후보를 정해야 한다. e38 이력 모델의 오차 감소는 보존하고, 반응 예측과 위반 탐지가 함께 개선되는지를 확인해야 한다.
- 새 모델 학습이나 RL은 아직 시작하지 않았다. 이번 결과는 최종 정책의 효율 개선이나 신규 알고리즘 기여가 아니다.

## 검증과 산출물

1000개 작은 합성 자료의 완전탐색과 비교해 경계 선택을 검산했다. 점수 범위가 1보다 크거나 음수인 경우, 동점, 정확히 FPR 10%인 경계, 모든 점수가 같은 경우, 미래 점수가 큰 경우의 경보 없음도 확인했다. sklearn ROC로 실제 경계 4개를 독립 재계산하고 분류 집계 34개와 날짜별 confusion matrix 400개를 확인했다. 입력 모델/보정기/예측, 실행 코드, 고정 경계와 protocol SHA256은 변하지 않았다.

`verify.py`와`report.py`는 위 실행 명령과 같은 환경에서 `--out /home/jio/fcsrl_src/results/e40/main_v2`로 실행한다. 원본 경보 배열은 runtime의 `alerts.npz`에 있고 Git에는 넣지 않는다. 로그는 `/home/jio/fcsrl_src/results/e40-main-v2.log`다. 최초 `/home/jio/fcsrl_src/results/e40/main`은 사건별 지표의 단위 필드 이름을 날짜에서 구간으로 바로잡기 전 출력이며 보존한다. 최종 실행에서 경계와 검증 수치가 모두 같음을 확인했다. 결과를 보고 경계를 변경하지 않았다.
