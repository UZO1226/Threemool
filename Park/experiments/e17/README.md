# Park/e17: 회복 가능성 검사를 더한 차단 (Kaggle DARROW)

상태: **완료 (2026-11-11). H1, H2 지지, H3 지지 안 됨.** rec H3 lim 3.5 는 평균 공기량 80,944, 비용 5.08 로 기준(84,031, 5.51) 보다 둘 다 낮고 seed 4/5 에서 성립했다. e12 이후 처음으로 사전 등록 규칙을 통과했다. 가설과 판정 규칙은 검증 결과를 보기 전에 정했고 (사전 등록 커밋 `41577a5`) 결과를 본 뒤 바꾸지 않았다. 설정은 학습 구간만으로 골랐다.

## 목적

목표는 공기량과 하루 비용을 함께 낮추는 것이다. Park/e16 의 p1 설정은 평균 공기량과 비용을 둘 다 낮췄지만, 검증 구간에서 NH4 위반이 3.43% 에서 3.80% 로 늘어 seed 별로는 2/5 만 성립했다.

## 실패 원인 (e15, e16 진단)

- 1스텝 NH4 예측 오차는 작다. 위반의 대부분은 한 번 4 를 넘은 뒤 이어지는 연쇄 위반이다.
- 1스텝 차단은 "다음 스텝만 4 아래" 를 본다. 유입이 몰려 오는 때에 지금 공기를 아끼면, 몇 스텝 뒤에는 공기 9,000 으로도 NH4 를 되돌리지 못하는 상태가 된다.
- NH4 여유를 줄이면 (p1) 이 완충이 사라져 연쇄가 늘어난다.
- e11 처럼 같은 공기량을 여러 스텝 유지한다고 보는 긴 horizon 은 너무 보수적이라 공기량이 늘었다.

## 차단 (`min_brake.py`, recover=(H, lim))

e16 의 p1 + do 1.8 (trim, NH4 여유 표 + 0.1, DO 기준 1.8, futile 없음) 에 회복 가능성 검사를 더한다.

- 격자 후보마다 지금은 그 공기량, 그 뒤 H-1 스텝은 9,000 이라고 두고 H 스텝을 굴린다 (다른 구성원 4개 평균, 외부 입력은 지속 예측)
- 2 ~ H 스텝의 예측 NH4 최댓값 <= lim 인 가장 작은 후보 rr 을 구해, 필요 공기량을 max(r, rr) 로 올린다
- 9,000 으로도 회복이 안 되는 경우에는 rr 을 쓰지 않는다 (헛수고 방지)
- 즉 "나중에 최대로 넣으면 따라잡을 수 있는 한" 지금 공기를 아끼고, 따라잡을 수 없을 때만 미리 넣는다

## 설정 고르기 (학습 구간만)

e12 A 정책 seed 5개, 학습 구간 40일(4일 간격) x 구성원 5개. 규칙은 e16 과 같고 결과를 보기 전에 정했다: "평균 비용이 한 방향 3.5 보다 0.1 이상 낮은 설정 중 평균 공기량이 가장 적은 것".

## 조건과 평가

학습 없음. e12 A 정책 seed 0 ~ 4 에 차단만 바꿔, 검증 40일 x 구성원 5개 = 200 에피소드를 결정적으로 돈다. p1_do1.8 (회복 검사 없음) 도 함께 보고한다. test 는 쓰지 않는다.

## 가설 (사전 등록)

비교 기준은 같은 seed 의 e12 A 정책 + 한 방향 target 3.5 (seed 평균 84,031, 5.51) 다. seed 5개 중 3개 이상에서 공기량과 하루 비용이 둘 다 기준보다 낮고, seed 평균도 둘 다 낮으면 지지로 적는다.

- H1 (주 가설). rec H3 lim 3.5 (규칙으로 고른 설정)
- H2. rec H9 lim 3.5 (2시간 15분을 내다봄)
- H3. rec H3 lim 4.0

NH4 와 DO 위반률은 보고만 한다. 가설이 기각되는 결과도 그대로 기록한다.

## 미리 밝히는 한계

- 외부 입력을 지속 예측으로 두므로 H 가 길수록 유입 변화를 놓친다
- 학습 구간에서 고른 설정이 검증 구간(겨울, NH4 높음) 에서도 같은 순서일지는 모른다
- e10 ~ e16 과 같은 대리 모델 한계 (차단 모델과 환경 모델이 같은 방법의 구성원, 그 시각의 유입 성분을 안다고 둠)
- 정책은 e12 A 5개뿐이다

## 실행 명령

```bash
python run_e17.py report --out <결과>/e17 --e12 <결과>/e12 --md results.md
```

## 해석

- 회복 가능성 검사는 여유를 줄인 p1 에서 늘었던 NH4 위반(3.69%) 을 기준 수준(3.48%) 으로 되돌렸다. 연쇄 위반이 실패 원인이라는 진단과 맞는다.
- 공기량은 오히려 1,300 Nm3/일 더 줄었다. 미리 조금 넣는 공기가 나중의 9,000 개입을 줄인다. 기준 대비 공기량 3.7% 감소, 비용 7.9% 감소다.
- H3 와 H9 는 거의 같다. 회복이 안 되는 상태는 대부분 2 ~ 3 스텝 안에 드러난다. lim 4.0 은 너무 느슨해 거의 작동하지 않았다.
- seed 2 는 여전히 비용이 기준보다 조금 높다 (5.61 대 5.54). 공기량은 4,179 줄었다.
- Park/e16 의 futile 을 빼니 p1_do1.8 비용이 5.40 에서 5.30 으로 내려갔다 (보고만, 가설 아님). 헛수고 방지는 검증 구간(겨울) 에서 손해였다.
