# Lee/e10: 벌점 0.1 효과를 새 seed 로 확인 (DARROW 환경)

## 목적

Lee/e09 에서 이점 벌점 0.1 의 선택 모델은 공기량 +3.5%(5% 이내)에서 비용 -9.5%, 한도 만족 seed 4/5에서 5/5 였지만
차이가 seed 표준편차 안(p=0.36)이라 단정하지 못했다. 같은 설정을 **새 seed 5, 6, 7, 8, 9** 로 반복해 방향이 유지되는지 본다.
원래 FCSRL 도 같은 새 seed 로 다시 돌려 짝을 맞춘다. 변경 없음(설정은 e07, e09 와 같음). 새 실행은 2 방법 x 5 seed = 10개.

## 가설과 판정 기준 (결과를 보기 전에 정함)

- H26. 새 seed 의 선택 모델에서 벌점 0.1 이 원래 FCSRL 보다 비용이 낮고 한도 만족 seed 수가 같거나 많으며 공기량 증가가 5% 이내다.
- H27. e09 와 합친 10개 seed 에서 비용 차이의 seed 별 짝 차이가 음수인 seed 가 7개 이상이다(부호 방향 확인용이고 검정이 아니다).
- 합친 10개 seed 에서도 차이가 표준편차보다 작으면 개선이라 단정하지 않는다. 결과가 반대여도 그대로 기록한다.
