# Park/e41: 틀린 차단 모델에 온라인 NH4 오차 보정 (Kaggle DARROW)

상태: **완료 (2026-11-19). H1 기각 (0/5): 온라인 보정을 켜면 틀린 차단의 비용이 오히려 11.23 에서 12.12 로 오른다. H2 기각 (1/5), H3 기각 (0/5).** 대표는 바꾸지 않는다. 가설과 판정 규칙은 검증 결과를 보기 전에 정했다 (커밋 `71defa6`). 설정은 Park/e31 이 고른 값을 그대로 쓰고 새로 고르지 않는다.

## 목적

Park/e38 에서 공기 효과를 절반만 아는 차단 (w = 0.5) 은 NH4 위반을 크게 늘렸고, Park/e40 에서 학습 구간 시운전으로 고른 고정 여유 (+0.6) 는 비용을 낮췄지만 공기량이 기준선보다 많아졌다. e40 은 학습 구간에서는 오류가 드러나지 않아 고정 여유가 검증 기간에 맞지 않았다. 이 실험은 기간과 상관없이 실제 관측으로 예측을 계속 고치는 방법을 본다. 매 스텝 지난 스텝의 NH4 예측과 지금 관측의 차이 e 로 에피소드마다 b <- lam b + (1 - lam) e 를 갱신하고, 1 스텝 여유 검사의 예측에 b 를 더한다 (Park/e31 의 `bias`, 모델 예측 제어의 외란 추정). 틀린 차단이 공기를 너무 줄여 NH4 가 예측보다 높아지면 b 가 커져 공기를 다시 늘린다.

## 방법

- 환경: 그대로 GBM 대리 모델 (PROTOCOL v1.1)
- 차단: Park/e38 의 w = 0.5 차단 (대표 차단 + 예측만 0.5 x GBM + 0.5 x MLP), 여유 P1 그대로, `bias=0.8` (Park/e31 이 고른 lam, 여유 배율 1.0). 보정은 1 스텝 NH4 여유 검사에만 들어가고, 회복 검사와 회복 계획, DO 예측은 바꾸지 않는다 (e31 과 같음)
- 참고 조건: 맞는 차단 (w = 0) 에 같은 보정
- 정책: FCSRL 대표, 구성원이 겹치지 않는 묶음 5개. 다시 학습하지 않는다
- 비교 값은 Park/e35 (맞는 차단), Park/e38 (틀린 차단), Park/e40 (틀린 차단 + 여유 0.6) 을 그대로 쓴다
- 평가 10번: 차단 2 x 묶음 5

## 평가

검증 40일 x 구성원 5개 = 200 에피소드, 결정적. test 는 쓰지 않는다.

## 가설 (사전 등록)

- H1 (보정이 듣는가). 틀린 차단 + 보정의 FCSRL 대표가 같은 묶음의 틀린 차단 (e38) 보다 하루 비용이 낮은 묶음이 5개 중 4개 이상이고, 평균도 낮다
- H2 (기준선 위로 돌아오는가). 틀린 차단 + 보정이 RESULT.md 공식 표의 기본 PPO-Lag (차단 없음, 90,121 Nm3/일, 하루 비용 10.79) 보다 공기량과 비용이 둘 다 낮은 묶음이 4개 이상이고, 평균도 둘 다 낮다
- H3 (시운전 여유보다 나은가). 틀린 차단 + 보정이 같은 묶음의 e40 (틀린 차단 + 여유 0.6) 보다 공기량과 비용이 둘 다 낮은 묶음이 4개 이상이고, 평균도 둘 다 낮다

참고 (판정 없음): 맞는 차단과의 남은 차이, 맞는 차단에 보정을 켰을 때의 변화.

## RESULT.md 처리 (미리 정함)

대표 방법은 바꾸지 않는다 (참고 조건이 좋아도 바꾸지 않고, 바꾸려면 새 사전 등록이 필요하다).

- H2 지지: "공기 반응이 틀린 모델이라도 온라인 오차 보정을 켜면 기준선보다 공기량과 비용이 둘 다 낮다" 고 적고, 실제 적용 권고 (물리 제약 모델 + 온라인 보정) 로 정리한다
- H1 만 지지: "보정은 듣지만 기준선 위로는 돌아오지 못한다" 고 적는다
- H1 기각: "1 스텝 오차 보정으로는 공기 반응 오류를 고칠 수 없다" 고 적는다
- H3 는 e40 과 비교한 결과로 따로 적는다

## 미리 밝히는 한계

- 보정 b 는 공기량과 상관없는 더하기 보정이다. 공기 반응 (기울기) 자체를 고치지는 않는다
- 보정은 1 스텝 여유 검사에만 들어간다. 회복 검사와 회복 계획은 틀린 모델 그대로다
- lam 은 맞는 차단에서 고른 값 (e31) 이다. 틀린 차단에 맞는 값은 다를 수 있다
- 섞음 w = 0.5 는 인위적인 불일치 단계다. 묶음 5개는 판정 표본이 작다 (4/5 기준). 검증 구간은 e10 부터 반복해서 썼다

## 해석

- 사전 등록 처리에 따라 "1 스텝 오차 보정으로는 공기 반응 오류를 고칠 수 없다" 고 적는다. 보정은 듣지 않았을 뿐 아니라 방향이 반대였다
- 가능한 설명 (직접 확인하지 않은 추정): 보정 b 는 공기량과 상관없는 더하기 값인데, 공기 반응을 작게 아는 모델의 오차는 공기량에 따라 부호가 바뀐다. 공기를 많이 넣은 스텝 (회복 검사, 회복 계획) 에서는 모델이 NH4 를 실제보다 높게 예측해 b 가 음수로 쌓이고, 그 b 가 다음 스텝의 적은 공기 후보 (모델이 NH4 를 실제보다 낮게 예측하는 곳) 에도 더해져 공기를 더 줄인다. 기울기 오류는 더하기 보정으로 고칠 수 없다
- e38 ~ e41 을 합친 결론: 차단의 이득은 대리 모델의 공기 반응이 맞는지에 달려 있다. 측정할 수 없는 입력이 빠져 오차가 커지는 것은 견디지만 (e39), 공기 반응이 틀리면 고정 여유 (e40) 로 일부만 되찾고 더하기 온라인 보정 (e41) 으로는 되찾지 못한다. 실제 적용에서는 물리 방향을 지키는 모델을 쓰는 것이 먼저다. 틀린 모델을 고치려면 공기량에 따라 달라지는 보정 (기울기 추정) 이 필요하다
