# Lee/e07: Kaggle 대회 데이터(DARROW)에서 폭기 제어 환경 구축과 원래 FCSRL 기준선

## 목적

사용자가 지정한 Kaggle 대회 데이터(`dynamic-modeling-of-wastewater-treatment-process`)로 수행계획서의
"에너지 절감과 수질 제약(NH4, DO)을 함께 고려하는 Safe RL 폭기 제어"를 구성하고, 이 데이터에서
**원래 FCSRL 적용 결과**(비교 기준)를 만든다. 확장은 Lee/e08 에서 이 기준과 비교한다.

Yoo 는 다른 Kaggle 데이터(덴마크 Avedøre)와 BSM1 에서 작업했고, Lee/e06 은 Avedøre 를 썼다. 이 데이터는
그것들과 다르므로 Yoo 의 수치와 직접 비교하지 않는다. 어느 데이터를 팀 공식으로 쓸지는 Compare/PROTOCOL 에서
정해야 한다.

## 환경

데이터와 출처는 `Lee/code/darrow/README.md` 에 있다. 구성은 Yoo 의 Avedøre 환경과 같은 방식이다.

| 항목 | 내용 |
| --- | --- |
| 분할 | 날짜 순서 70%, 15%, 15%. 학습 188일(2021-05-06 ~ 11-09), 검증 40일(11-10 ~ 12-19), 평가 41일(12-20 ~ 2022-01-29) |
| 에피소드 | 하루 96행, 전이 95개 (15분 간격) |
| 상태 | NH4, NO3, DO 3개 구간, 유입량, 수온, 시각(sin, cos), 유입 NH4, 직전 공기량 (11차원) |
| 행동 | 총 공기량 [0, 9,000] Nm3/h. 구간별 배분은 그 시각 기록된 운전의 비율 |
| 보상 | -공기량 / 9,000 |
| 비용 | 스텝마다 NH4 > 4 mg N/L 이면 1, 세 구간 DO 의 최댓값 > 2 mg O2/L 이면 1 을 더함 (Yoo 의 정의) |
| 비용 한도 | 학습 구간의 실제 운전을 대리 모델에서 재생한 하루 평균 비용의 반올림 = **12** (검증, 평가 구간은 한도 결정에 쓰지 않음) |
| 대리 모델 | 단조 제약 GBM 앙상블 5개 (아래) |

### 대리 모델과 그 품질 (정직하게)

공기량과 NH4 는 같은 시점에서 양의 상관(0.45)이다. 부하가 크면 기존 제어기가 공기를 늘리기 때문이고 인과가 아니다.
처음 만든 MLP 앙상블은 이 교란을 인과로 배워 공기를 늘릴수록 NH4 가 **올라가는** 반응(0.5배에서 0.37, 1.5배에서 3.64)을
냈다. 그대로 쓰면 RL 이 "공기를 끄면 위반이 줄어든다"는 잘못된 환경을 배우므로 쓰지 않았다. 대신 물리 사전지식(NH4 변화량은
구간 공기량에 비증가, DO 변화량은 해당 구간 공기량에 비감소)을 구조로 강제한 GBM 을 썼다 (`monotonic_cst`).

검증 구간(40일 x 구성원 5개)에서 잰 품질이다.

| 항목 | MLP (미채택) | 단조 제약 GBM (채택) |
| --- | --- | --- |
| 한 스텝 R2 (NH4, NO3, DO1, DO2, DO3) | 0.38, 0.25, 0.39, 0.56, 0.17 | 0.24, 0.19, 0.22, 0.52, 0.14 |
| 하루 연속 예측의 일 평균 NH4 상관 | 0.37 | 0.29 |
| NH4 위반 비율 (예측 대 실제) | 19.2% 대 17.5% | 28.5% 대 17.5% |
| DO 위반 비율 (예측 대 실제) | 8.0% 대 1.2% | 1.8% 대 1.2% |
| 공기 0.5, 0.75, 1, 1.25, 1.5 배일 때 하루 평균 NH4 | 0.37, 0.79, 2.18, 3.03, 3.64 (잘못된 방향) | 8.78, 7.65, 2.56, 2.06, 1.04 (올바른 방향) |

**예측 정확도는 낮다.** 일 평균 NH4 상관 0.29 는 Yoo 의 Avedøre 대리 모델(0.61 ~ 0.73)보다 훨씬 낮고, NH4 위반을
실제보다 많이 예측한다(보수적). 따라서 이 환경은 "물리적으로 말이 되는 방향의 시험대"이지 실제 공정의 예측기가 아니다.
절대 수치가 아니라 방법 간 상대 비교로만 읽는다.

실제 운전 재생의 하루 비용은 학습 12.17, 검증 28.77, 평가 8.80 이다. 검증 구간(겨울, NH4 가 높음)에서는 기록된 운전조차
한도 12 를 크게 넘는다. 그래서 검증 구간의 "한도 만족"은 학습보다 훨씬 엄격한 조건이다.

## 실행 구성 (원래 결과)

| 항목 | 값 |
| --- | --- |
| 방법 | FCSRL + PPO-Lag (`ppolag_fcsrl`, 원래 FCSRL), PPO-Lag (`ppolag`, 참고) |
| seed | 0, 1, 2, 3, 4 (방법마다 5개, 총 10개 실행) |
| 학습량 | 각 401,280 전이 (8 환경 x 760 스텝 x 66 갱신), 검증 5회 |
| 평가 | 검증 40일 x 구성원 5개 = 200 에피소드. 한도 12 를 만족하는 모델 중 보상 최대를 고르고(Yoo 규칙), 마지막 모델도 함께 보고 |
| test 구간 | 쓰지 않는다 |
| PPO 설정 | Yoo/e05 와 같다 (갱신당 최대 10 epoch, 미니배치 512, clip 0.2, PID 이득 0.02, 0.005, 0.01, 승수 상한 20) |

이 실험은 비교 기준을 만드는 것이라 가설 검증이 아니다. 판정 없이 결과를 그대로 기록한다.

## 실행

```bash
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1
python -u Lee/code/darrow/prep_darrow.py --csv <데이터>/train_val_test_online_dataset.csv \
  --influent <데이터>/train_val_test_dynamic_influent.csv --out <데이터>/darrow_15min.pkl
python -u Lee/code/darrow/surrogate_dw.py --data <데이터>/darrow_15min.pkl --out_mlp <데이터>/darrow_surrogate_mlp.npz \
  --out_gbm <데이터>/darrow_surrogate_gbm.pkl --report <데이터>/darrow_surrogate_report.json
python -u Lee/code/darrow/calibrate_dw.py --data <데이터>/darrow_15min.pkl --surrogate <데이터>/darrow_surrogate_gbm.pkl --out <데이터>/darrow_calibration.json
python -u Lee/experiments/e07/run_dw.py --data <데이터>/darrow_15min.pkl --surrogate <데이터>/darrow_surrogate_gbm.pkl \
  --limit 12 --upstream <원본 FCSRL 경로> --out <결과>/e07_runs --parallel 6 --jobs ppolag_fcsrl:0 ppolag:0 ...
```

## 미리 밝히는 한계

- 대리 모델의 예측 정확도가 낮다 (위 표). 실제 공정이 아니며 절대 수치를 해석하지 않는다.
- 총 공기량만 제어하고 구간별 배분은 기록된 운전을 따른다. 구간별 제어는 하지 않는다.
- 검증 구간이 겨울이라 학습 구간과 분포가 다르다 (기록된 운전도 한도를 넘음).
- 학습 188일로 데이터가 적다 (Avedøre 는 330일).
- 학습 중에는 갱신마다 앙상블 구성원 하나를 고르고(속도 때문), 평가는 5개 구성원 전체로 한다.
- seed 5개의 탐색적 비교다. 데이터의 대회 약관은 확인하지 못했다.
