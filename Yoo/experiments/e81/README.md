# e81 증량 후 공기를 나눠 회수한 결과

**기본 FCSRL 대비 공동 개선이 0/5 seed여서 회수 규칙을 채택하지 않았다.** 하루 평균 NH4 위반이 14.087에서 13.973스텝으로 줄고 NH4 초과 적분이 6.2744에서 6.2600 mg h/L로 줄었다. 공기는 84,788.55에서 84,930.74 m³/23.75h로 늘고 DO 위반은 1.648에서 1.655스텝으로 늘었다.

증량 단독 대비 회수 모드의 평균은 NH4 위반 -0.008스텝, DO 위반 -0.020스텝, NH4 초과 적분 -0.0166 mg h/L였다. 세 수질 지표가 평균에서 소폭 낮았지만 총공기는 +45.42 m³였다. 증량한 375/1,000 에피소드 중 261개에서 적어도 한 번 회수했고, 235개에서 두 번 모두 회수했다. 이 분모에는 같은 날짜의 서로 다른 GBM 구성원과 정책 seed가 들어간다.

**공기를 직접 뺀 양과 하루에 실제로 아낀 양이 달랐다.** 같은 최초 증량에서 출발해 회수한 경우, 에피소드 전체 평균으로 보정기가 직접 31.00 m³를 뺐지만 각 경로에서 기본 정책이 낸 명령 부피 차이는 +76.42 m³였다. 두 값의 합이 실제 차이 +45.42 m³다. seed 4에서는 -94.06와 +268.91가 합쳐져 +174.85 m³가 됐다. seed 1과 3에서는 회수로 총공기가 감소했다. 이 분해로 기본 명령이 더 커진 경로는 식별할 수 있지만 어떤 관측 변수가 반응을 유발했는지는 구분하지 못한다.

가장 관심이 컸던 seed 1에서 회수 모드는 기본 대비 NH4 위반 0.475스텝과 초과 적분 0.0556 mg h/L를 줄였다. 증량 단독의 NH4 위반 감소 0.485스텝 대부분이 남았다. 다만 기본보다 하루 공기 68.61 m³, DO 위반 0.085스텝이 늘었다. 이 결과는 기본 명령 이후의 후속 반응까지 합산해야 공기 절감을 판단할 수 있음을 보여준다.

## 무엇을 바꿨나

FCSRL의 인코더와 정책, DARROW 대리 환경 및 구간별 공기 배분은 e78과 같다. 매 에피소드에서 e78 트리가 증량을 제안하고 기록 유량 범위 안에 든 최초 시점에만 15분간 500 m³/h를 더했다. 하루가 끝날 때까지 이후 6시간을 관찰할 수 있는 시점으로 한정했다. 증량 단독은 이후 기본 명령을 따른다. 회수 모드는 이후 6시간 안에 NH4가 4 이하이고 직전보다 오르지 않으며 감량할 유량이 기록 범위 안에 드는 첫 두 시점에서 250 m³/h씩 뺐다. 한 번 감량은 62.5 m³다.

겨울 40일 모두에서 같은 초기 상태, 유입, 수온, GBM 구성원을 세 모드가 공유한다. 증량하지 않은 에피소드도 분모에 포함한다. 독립 현장 실험 수는 0이며, 5개 정책은 같은 날짜와 모델을 재사용했다. 공기는 송풍 전력의 대리지표이고 지표의 NH4와 DO 위반은 연구에서 정한 센서 기준이다. 겨울 검증은 이전 개발에서 여러 번 사용한 구간이다. 공식 시험 날짜를 평가하거나 추가로 학습하지 않았다.
