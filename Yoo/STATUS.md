# Yoo 현재 상태 (한 페이지)

2026-11-18 05:00 e71 완료 기준. 자세한 이력은 [README](README.md) 와 각 실험 폴더에 있다. 모든 수치는 DARROW 관측으로 만든 대리 환경 안의 결과이며 현장 성능이 아니다.

## 연구 질문

하루 NH4 누적 예산 제약 (예산 초과 스텝 0.3 / 일 이하, 연구용 한도이며 규제 기준이 아님) 에서 FCSRL 의 표현 학습이 같은 망의 고정 표현 PPO 보다 한도를 지키면서 공기를 덜 쓰는가. 비용 정의는 [e68](experiments/e68/README.md) 에서 정했고, 이전 순간 NH4/DO 합산 비용의 결과와 섞지 않는다.

## 현재 대표 결과: e70, e71

[e70](experiments/e70/README.md) 은 e68 설정에서 PID 승수 이득만 한도 비율 (25 / 0.3) 로 키웠고, [e71](experiments/e71/README.md) 은 같은 설정을 갱신 500번으로 늘렸다. dev 146일 x 5, 표본 행동, seed 0 ~ 9.

| 방법 | 실행 | 공기량 m³/23.75h | 예산 초과 스텝/일 | 한도 충족 seed | NH4 초과 mg h/L |
| --- | --- | --- | --- | --- | --- |
| FCSRL | e70 (250번) | 41,581 | 0.32 | 6/10 | 16.63 |
| FCSRL | e71 (500번) | 39,712 | 0.30 | 4/10 | 13.66 |
| 고정 표현 PPO | e70 (250번) | 42,750 | 0.41 | 3/10 | 28.70 |
| 고정 표현 PPO | e71 (500번) | 40,764 | 0.55 | 2/10 | 27.62 |
| ABAC (설정값 2.9) | | 62,427 | 0.28 | | 1.47 |

- 한도 미달의 첫 원인은 원본 승수 이득의 단위였다 (e68, e69 는 두 방법 모두 0/10 또는 1/10). 이득을 맞추자 충족이 늘었다.
- 학습을 두 배로 늘려도 충족 seed 는 늘지 않았다. 한도를 넘은 seed 는 대부분 승수가 상한 20 에 걸려 있었다 (e71 사후 분석, 2026-11-18 정정).
- **FCSRL 대 고정 표현 PPO (H1) 는 네 번 연속 차이 불명확이다.** 제약 지표 방향은 e68 ~ e71 모두 FCSRL 쪽이고, e71 에서 세 조건 7/10 (NH4 초과 10/10) 으로 가장 근접했지만 사전 기준 8/10 에 못 미쳤다.
- **ABAC 대비 우위 아님.** RL 은 공기를 33 ~ 36 % 적게 쓰지만 위반일과 NH4 초과가 ABAC 보다 많다. 공기 절감을 효율 승리로 쓰지 않는다.

## 다음 질문 (아직 실행하지 않음)

1. e72: 승수 상한을 올리고 학습 한도를 0.2 로 두는 마지막 조정 (사용자 승인 2026-11-18). 결과와 무관하게 이후 설정을 고정한다.
2. 원 관측만 쓰는 표준 PPO-Lag 대조. 고정 표현 PPO 는 같은 망의 제거 대조이지 일반 PPO-Lag 를 대표하지 않는다.
3. 기전 제거 대조 (feasibility 손실 제거, dynamics 손실 제거).
4. 결과를 보지 않은 새 seed 묶음으로 확인.
5. 최종 방법을 고정한 뒤 holdout 42일 한 번 평가. holdout 은 과거 정책 개발과 대리 모델 학습에 쓰인 날짜라 처음 보는 시험 자료가 아니다. test 는 e66 에서 썼으므로 다시 쓰지 않는다.

순서와 진행 여부는 사용자가 정한다.
