# e36: 기존 정책의 단순 기준 대비 효율과 환경 민감도

## 질문과 사전 결정

e01~e35 전체 검토에 따라 추가 NH4 증상 진단과 신규 RL 학습을 보류했다. 기존 Actor 보정이 단순 공기량 조정보다 유리한지, DO 구간 연결 오류 수정에도 판단이 유지되는지 확인한다. FCSRL의 dynamics/feasibility 표현과 정책은 변경하지 않는다.

Kaggle DARROW e30 준비 파일의 train188일에서 BC 공기 보정 범위를 정한다. 유량의 q10~q90 폭 절반을 500m³/h 단위로 올림하고 최대4500으로 제한한다. 범위 안에서 500 간격으로 고정한 모든 후보를 평가한다. 행동은 기존 범위0~9000에 clip한다. BC는 실제 미래 수질 대신 자기 궤적의 상태를 입력받는다.

수정 환경의 train에서 NH4/DO 평균 비용이 각각6 이하인 후보 중 최소 공기량을 대표 기준으로 고른다. 없으면 두 비용 중 큰 값이 가장 작은 후보를 고르고 미충족이라고 표시한다. 동률이면 공기량으로 정한다. protocol.json과 selection.json의 SHA256을 검증 평가 전에 잠근다. val 결과로 범위를 넓히거나 대표 기준을 교체하지 않는다.

val40일 x 모델5구성원에서 모든 기준을 공개한다. 같은 NH4 평균 비용을 끼우는 인접 공기 보정 후보 중 양끝과 정책 DO비용이6 이하인 구간에만 선형 보간한다. 모든 교차 구간을 보고하며 유리한 교차점만 선택하지 않는다. 이는 곡선의 기술적 비교이며 보간된 실제 제어기를 실행한 결과가 아니다. 범위 밖 외삽은 하지 않는다. 초과 농도 적분과 나쁜 날짜도 확인한다.

## 평가 대상과 해석

- e33 PPO, FCSRL, Actor 보정 최종 정책 각seed0/1, 총6개. 각각401280전이 학습 체크포인트를 고정한다.
- e34 기존 환경 결과를 재사용한다. 새 환경은 e35 corrected_surrogate.pkl이다. 잘못된 기존 대응은 민감도 참고이며 채택 대상이 아니다.
- 초기 BC와 고정 유량 보정 기준, 기록 행동의 모델 재생, 실제 관측 수질을 구분한다.
- 15분 x95전이=23.75시간. 공기량은 m³, 전력(kWh)은 미측정이다. NH4>4, max(DO)>2의 표본 수와 평균 한도6/6은 역사적 연구 설정이며 현장 법적 기준으로 주장하지 않는다. 농도 단위는 원출처mg/L에 맞춘다.
- 통계 단위는 날짜다. 모델 구성원은 날짜 안에서 평균한다. 7일 이동블록 bootstrap2000회는 개발 자료의 탐색적 불확실성 표시이며, seed2개로 재현 성공을 확정하지 않는다.
- 단순 기준 대비 이점이 없으면 보정 강도/seed를 자동 확대하지 않는다. 환경 변경에 제약 충족이나 순위가 크게 달라지면 알고리즘 우열 주장을 보류한다. 양쪽 모델에서 좋아도 실제 공정의 인과적 절감 증거는 아니다.
- 관측 가능한 정보, 기록된 구간 배분, 일별 reset과 외생 입력은 기존 환경 그대로다. test41일은 사용하지 않는다.

## 실행

### 남은 이점과 실패를 구분한다

1. Actor 보정은 초기 BC 대비seed별16.84%, 16.24% 적은 공기를 썼다. 그러나 NH4 비용8.370, 6.655로 모두 한도6을 넘었다. 기준 정책도 검증 NH4 7.625로 미충족이다. 이 절감만으로 안전 제어 성공이라고 주장할 수 없다.
2. 고정 보정9개 중 검증에서 두 한도를 충족한 +500 기준은 공기122985, NH4 4.765였다. 이것은 사전에 선택한 대표 기준이 아니며 검증 결과를 보고 최종 정책으로 채택하지 않았다. 단순 기준에도 모델 내 충족점이 있으므로 제약이 불가능하다고 주장할 근거는 없다.
3. Actor 보정의 동일 NH4 비용 기준 곡선 대비 공기는16.66%, 21.31% 낮았다. 다만 500m³/h 간격의 인접점 선형 보간이며 중간 제어기를 실제 실행하지 않았다. 특히 -500~0 사이 NH4 비용이 급변한다. 따라서 이 수치를 정밀한 동일 수질 절감률로 확정하지 않는다. 비교 가능한10개 정책/환경 조합 모두 곡선 아래에 있어 Actor 보정만의 독자적 이점도 아니다. 두 FCSRL seed1 조합은 DO 조건을 유지하는 보간 구간이 없어 비교 불가다.
4. Actor 보정 대 기본 FCSRL은seed0에서 공기7.82% 감소와 NH4 14.03→8.37의 동시 개선을 보였다. seed1은 공기11.73% 감소와 함께 NH4 4.575→6.655, 초과 적분4.075→4.876으로 악화했다. 평균만 합치면 이 상충이 가려진다. 날짜 블록 구간은 comparison.json에 있으며seed2개로 알고리즘 재현성을 확정하지 않는다.
5. PPO 대비 Actor 보정의 평균 공기는 약1.13% 적지만 NH4는7.310→7.512로 높다. 양쪽 모두0/2충족이며 우월한 확장으로 채택할 근거는 없다. 현재 비교는 학습 seed를 고정한 정책 평가이지 수정 환경에서 새로 학습한 알고리즘 비교가 아니다.

### 환경 의존성과 다음 판단

수정 전후 PPO seed1의 NH4는5.995→6.405로 경계 판정이 충족에서 미충족으로 바뀌었다. FCSRL seed0은 같은 가중치인데27.73→14.03으로 크게 달라졌다. Actor 평균 공기는84470→86280으로 늘어 실제 기록84860보다 약1.67% 많아졌다. 실제 수질과 모델 수질은 직접 대체할 수 없다.

NH4 평균 순서는 기존 Actor<PPO<FCSRL에서 수정 PPO<Actor<FCSRL로 바뀌었다. Actor/PPO 차이는 작고 통계적 우열을 입증한 것이 아니지만, 기존 점수만으로 확장의 우월성을 확정할 수 없음을 보여준다. 공기량 순서는 유지됐다.

**결정:** Actor 보정은 후보로 보존하되 성공 채택이나 추가seed/보정 강도 탐색을 바로 진행하지 않는다. 단순 고정 공기 조정보다 나은 제어의 단서는 남았으나 PPO 대비 확장 기여와 제약 만족은 확인하지 못했다. e35 수정 환경도 기록 행동 NH4 비용33.47, 실측16.45로 차이가 크므로 새 RL 본 학습보다 평가 환경을 제어 비교에 사용할 수 있는 범위의 판단을 우선한다. 원인 진단을 또 시작하기 전, 행동 변화에 대한 공정 반응을 관측 자료로 검증할 수 있는 범위와 필요한 독립 근거를 정해야 한다. 이번 작업에서 추가 환경 실험은 시작하지 않았다.
