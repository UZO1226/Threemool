# Park/e73: e66 ~ e72 를 반영한 주장 지도 갱신 (Kaggle DARROW)

상태: **완료 (2026-11-24).** 갱신 규칙은 지도를 고치기 전에 정했다 (사전 등록 커밋 `6b99370`). 새 학습과 새 평가는 없다. 대표는 바꾸지 않는다.

## 목적

Park/e65 는 대표 교체 여부를 팀 결정 사항으로 올리고, 공기량을 다시 맞춘 공정한 비교를 제안했다. 그 뒤 e66 (묶음마다 공기량을 맞춘 짝), e67 (곡선 대 곡선), e68 (지연 손해 나누기), e69 (평균 제어기), e70 (차단 위 ABAC), e71 (비용 차이 나누기), e72 (예측 구간) 가 끝났다. 이 실험은 그 결과를 주장 지도에 넣고 팀 결정 사항을 고친다.

## 갱신 규칙 (사전 등록)

e66 ~ e72 의 결과는 이미 알고 있다. 이 규칙은 결과를 예측하는 가설이 아니라, 알려진 결과를 어느 칸에 어떻게 넣을지를 미리 고정하는 것이다.

- 분류 규칙은 Park/e50, e55, e65 와 같다. 수치는 Park/RESULT.md 와 각 실험의 README, results.md 에 이미 있는 값만 쓴다. 이전 지도의 항목은 지우지 않고 바뀐 곳에 **(갱신)** 을 붙인다
- 주 주장의 비교 (대표가 다시 고른 ABAC 와 차단만보다 낮음) 는 그 판정이 바뀌지 않았으면 유지한다
- 이득의 원천: 대리 모델도 학습도 쓰지 않는 제어기 (ABAC) 를 대표 차단 위에 두었을 때 대표가 낮다는 판정 (e70 H1) 이 기각되면, 주 주장의 원천을 "차단 위의 제어기" 에서 "최소 개입 예측 차단" 으로 옮기고, 차단 위 제어기는 "공기를 적당히 넣어 차단이 덜 끼어들게 하는 것이면 된다" 로 적는다
- 대표 교체 근거: 공정한 비교 (e66 공기량 맞춤 짝, e67 곡선 대 곡선) 가운데 차단 위 예측 제어가 4/5 이상 낮다는 판정 (H2) 이 둘 다 지지되면, 팀 결정 사항의 Park 제안을 "(3) 공정한 비교 뒤 정하기" 에서 "(2) 대표를 차단 + 예측 제어로 바꾸기" 로 고친다. 하나만 지지되면 제안은 (3) 으로 두고 근거만 더한다. 어느 경우에도 Park 혼자 대표를 바꾸지 않는다
- 학습 정책이 예측 제어 위에 더하는 몫 (e69 H2) 이 기각되면 그 열린 질문을 "근거 없음" 으로 닫는다
- 지연 (e68): 지연 손해가 주로 차단에서 오면 한계 칸의 지연 항목에 그 사실을 더하고, 예측 제어가 덜 나빠지는 이유는 열린 질문으로 둔다
- 판정하지 못한 것과 기각된 가설은 한계와 실패 칸에, 지지된 조건 결과는 보조 근거에 둔다

## 미리 밝히는 한계

- 정리 실험이라 새 증거를 만들지 않는다
- 모든 결과는 같은 대리 모델 계열의 환경과 반복 사용한 검증 40일에서 나왔다. test 는 쓰지 않았다

## 규칙 적용

- 주 주장의 비교: e66 ~ e72 는 대표 대 다시 고른 ABAC, 대표 대 차단만의 판정을 바꾸지 않았다. 유지한다
- 이득의 원천: e70 H1 (차단 위 ABAC 보다 대표가 낮음) 이 0/5 로 기각됐다. 원천을 "최소 개입 예측 차단" 으로 옮긴다
- 대표 교체 근거: e66 H2 와 e67 H2 가 둘 다 지지됐다. 팀 결정 사항의 Park 제안을 (2) 로 고친다
- 학습 정책이 예측 제어 위에 더하는 몫: e69 H2 가 기각됐다. 열린 질문을 "근거 없음" 으로 닫는다
- 지연: e68 에서 지연 손해의 73% 가 차단 쪽이다. 한계 칸에 더한다

## 갱신한 주장 지도 (한 쪽)

모든 값은 검증 40일 x 구성원 5개, 같은 PROTOCOL v1.1 환경이다. "차단" 은 대표 차단 (`MinAirBrake`, 최소 개입 예측 차단), "차단 위 예측 제어" 는 그 위의 1시간 초과량 예측 제어 (NH4 여유 1.2) 다. Park/e65 에서 바뀐 곳은 **(갱신)** 으로 표시했다.

### 보조 근거 (조건을 넓힘, 모두 사전 등록 지지)

- 새 seed (Park/e32, e51), 측정하지 않는 유입 변수를 모를 때 (Park/e39), 15분 지연 (Park/e46), 30분 지연 보정 (Park/e53), 사건 단위 (Park/e45), 틀린 차단에서 FCSRL 이 PPO-Lag 보다 덜 무너짐 (Park/e38 H2): Park/e65 와 같다
- 계산 시간 (Park/e63): 두 방법 모두 15분 스텝보다 훨씬 짧다
- **(갱신)** 비용 차이의 출처 (Park/e71, 가설은 기각): 다시 고른 ABAC 대비 대표의 이득은 77% 가 DO 위반에서, 차단 위 예측 제어 대비 대표의 손해는 98% 가 NH4 위반에서 온다

### 한계와 실패 (주장 옆에 둠)

- 공기 반응이 틀린 차단 모델에서는 무너진다 (Park/e38 H1, e40 ~ e42). 모델이 틀릴 때 학습 정책이 예측 제어보다 견고하다는 근거도 없다 (Park/e61)
- 지연이 있으면 ABAC (Park/e53) 와 차단 위 예측 제어 (Park/e62) 가 대표보다 낮다. **(갱신)** 대표의 지연 손해는 73% 가 늦은 NH4 를 보는 차단에서 오고, 학습 정책만 늦은 NH4 를 보면 거의 나빠지지 않는다 (Park/e68, +0.03). 같은 차단을 쓰는 예측 제어가 덜 나빠지는 이유 (차단 개입이 적음) 는 열린 질문이다
- **(갱신)** 같은 차단 위에서는 1시간 예측 제어가 대표보다 낮다 (Park/e59, e66, e67 모두 5/5). 학습 정책을 이득의 원천으로 주장할 수 없다
- **(갱신)** 차단 위 제어기가 공기를 너무 적게 넣으면 (차단 위 ABAC 설정값 3.8 이상, 30분 예측 제어) 차단 개입이 35 ~ 75% 로 늘고 비용이 오른다 (Park/e70, e72)
- 학습 구간에서 고른 차단 위 예측 제어는 검증 공기량이 3.6% 어긋나 판정하지 못했다 (Park/e60)
- 다시 고른 ABAC 는 대표보다 공기를 1.7% 덜 쓴다 (Park/e54). 회복 계획의 목적은 OR 로 계산됐다 (Park/e35)
- 차단, 보정, 예측 제어는 모두 환경과 같은 대리 모델 계열이다. 검증 40일은 e10 부터 반복 사용했고 한 계절이다. test 확인은 아직 없다

### 사후 관찰 (근거로 쓰지 않음)

- 대표는 위반이 생긴 스텝마다 차단이 공기량을 바꿨다. 차단 위 예측 제어는 위반의 약 4분의 1 이 차단이 공기량을 바꾸지 않은 스텝에서 생긴다 (e71)
- 대표 정책 공기량에 배율 1.25 를 곱하면 공기가 늘고 차단 개입이 줄며 비용이 묶음 5개 모두 낮아진다 (e67)
- 학습 정책과 예측 제어의 평균은 둘 다보다 공기를 13% 더 쓴다 (e69)

## 팀 결정 사항 (Park 혼자 정하지 않음)

- **(갱신) 대표 교체 (Park 제안: 선택지 (2)):** 공정한 두 비교에서 모두 같은 차단 위의 1시간 예측 제어가 대표보다 5/5 낮다 (e66 공기량 맞춤 짝 +0.229, e67 곡선 대 곡선 +0.135). 사전 등록 갱신 규칙에 따라 Park 의 제안을 "(2) 대표를 차단 + 1시간 (또는 2시간) 예측 제어로 바꾸고 학습 정책을 비교 대상으로 내리기" 로 고친다. 바꾸면 주 결과 표의 대표 값 (82,104 / 4.658) 이 차단 위 예측 제어 값으로 바뀌고, 학습 정책 (FCSRL 앙상블) 은 기여 분리와 조건 확장 (차단이 없을 때, 모델이 틀릴 때) 의 비교 대상이 된다. 대표를 바꾸지 않는 경우 (선택지 (1)) 에는 "차단 위 제어기로는 예측 제어가 더 낮다" 를 주 주장 옆의 한계로 적는다
- 결정 전까지 Park 의 모든 실험은 지금 대표 (FCSRL 4 x 16 + 대표 차단) 를 계속 쓴다

## 원고 흐름 제안 (갱신)

1. 문제: 같은 공기량에서 위반을 줄일 수 있는가 (공식 기준선과 다듬은 ABAC)
2. 방법: 최소 개입 예측 차단 (주 기여) + 차단 위 제어기 (예측 제어, 학습 정책, ABAC 비교)
3. 주 결과: 다듬은 ABAC 와 차단만 대비 비교 (e43, e54, e64), 차단 몫의 직접 측정 (e70)
4. 차단 위 제어기 비교: e66, e67 (예측 제어가 낮음), e70 (ABAC 도 비슷), e69 (섞어도 더하는 것 없음), e72 (예측 구간)
5. 학습 정책의 자리: 차단이 없으면 예측 제어보다 크게 낮음 (e56, e57), 차단 개입을 줄이는 표현 (e51)
6. 조건 확장과 한계: e32, e39, e45, e46, e53, e63, e38 ~ e42, e61, e62, e68, e60, e35
