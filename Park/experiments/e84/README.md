# Park/e84: 학습하지 않는 기준으로 학습한 날의 이점 가르기 (Kaggle DARROW)

상태: **사전 등록 (2026-11-26).** 설정값, 가설, 판정과 해석 규칙은 이 실험의 결과를 보기 전에 정했다. 대표는 바꾸지 않는다.

## 목적

학습 구간 마지막 40일에서는 대표가 차단 위 예측 제어보다 낮고 (Park/e60, e80, e83 에서 날짜 블록으로 확인 중), 검증 40일에서는 반대였다 (Park/e59, e66, e67). 이 날은 대표 정책이 학습한 날이라, 대표의 우위가 "학습한 날의 이점" 인지 "날짜에 따라 예측 제어가 약해지는 것" 인지 가려야 한다. 학습하지 않는 기준인 차단 + ABAC 를 두 구간 모두에 놓고 각 방법을 같은 공기량에서 비교한다. 차단 + ABAC 는 어느 날도 학습하지 않으므로 두 구간에서 같은 잣대다.

## 방법

- 차단 + ABAC: Park/e54 가 고른 이득 (Kp 4,000, Ki 1,600) 에 대표 차단을 씌운다 (Park/e70 과 같음)
- 학습 구간 마지막 40일: 설정값 2.6, 2.9, 3.2, 3.8, 5.0. 검증 40일: 설정값 2.6, 3.2 (Park/e70 에서 89,495 와 80,602 로 대표와 예측 제어 공기량을 감쌈). 모두 스텝 기록과 함께 돈다
- 학습 구간의 설정값은 학습 구간 공기량이 검증보다 10% 안팎 적은 것 (Park/e60) 과, 차단 + ABAC 의 공기량이 높은 설정값에서 차단 하한 근처 (검증 약 80,000) 에 머무는 것 (Park/e70) 을 보고 넓게 두었다
- 비교 대상: 대표 (학습 구간은 Park/e83, 검증은 Park/e44 의 스텝 기록), 차단 위 예측 제어 기본 (여유 1.2, 가중치 1.5, 학습 구간은 Park/e83, 검증은 Park/e82)
- 같은 공기량 맞추기: 비교 대상의 전체 공기량을 감싸는 두 설정값의 날짜별 비용을 전체 공기량 기준 선형 보간한다. 감싸는 두 점이 없으면 판정하지 않는다
- 판정 방법은 Park/e82 와 같다 (날짜 짝 차이, 이어진 5일 블록, 10,000번, seed 0, 95% 구간, 세 갈래)

## 평가

학습 구간 마지막 40일과 검증 40일, 각각 x 구성원 5개 = 200 에피소드, 결정적. test 는 쓰지 않는다.

## 가설 (사전 등록)

- H1. 학습 구간 마지막 40일에서 차단 위 예측 제어 기본의 (예측 제어 빼기 같은 공기량의 차단 + ABAC) 블록 95% 구간이 0 아래다 (검증 구간에서 본 방향, Park/e70 의 사후 비교)
- H2. 학습 구간 마지막 40일에서 대표의 (대표 빼기 같은 공기량의 차단 + ABAC) 블록 95% 구간이 0 아래다
- 검증 40일의 같은 두 비교는 해석 규칙의 짝으로 적는다 (판정 없음)

## 해석 규칙 (미리 정함)

- 학습한 날의 이점: H2 가 지지되고 검증 40일의 대표 비교가 0 아래가 아니면 (차이 없음이나 반대), "대표의 학습 구간 우위는 학습한 날의 이점으로 설명된다" 고 적는다
- 날짜에 따른 예측 제어 약화: H1 이 반대 (차단 + ABAC 가 낮음) 이고 검증 40일의 예측 제어 비교가 0 아래면, "예측 제어의 이득은 날짜에 따라 뒤집힌다 (학습과 무관)" 고 적는다
- 둘 다 해당하면 둘 다 적고, 어느 것도 아니면 "가르지 못함" 으로 적는다

## 미리 밝히는 한계

- 차단 + ABAC 의 이득 (Kp, Ki) 은 학습 구간에서 고른 값이다 (Park/e43, e54). 학습 구간에 조금 맞춰져 있을 수 있지만 정책 학습만큼은 아니다
- 차단 + ABAC 의 공기량이 설정값을 따라 고르게 움직이지 않으면 (차단 하한) 보간이 거칠다. 보간한 두 설정값과 비중을 표에 적는다
