# e96 첫 감량의 6시간 지표별 효과 예측

| 행동 결과를 여러 지표로 예측한 뒤 선택 | Dosovitskiy와 Koltun, Learning to Act by Predicting the Future 3절, 4절 및 실험의 다중 시점 측정 [논문](https://arxiv.org/pdf/1611.01779). make_targets가 시점별 측정 변화와 에피소드 경계를 처리하고 make_losses가 실행 행동의 지표별 제곱오차, act_net이 예측 가중합으로 행동을 선택한다. [표적 코드](https://github.com/isl-org/DirectFuturePrediction/blob/ea2e9c699b632dcbc423d680abaaf49533c9dfe1/DFP/future_target_maker.py), [선택 코드](https://github.com/isl-org/DirectFuturePrediction/blob/ea2e9c699b632dcbc423d680abaaf49533c9dfe1/DFP/future_predictor_agent_basic.py). | 여러 측정량의 예측과 의사결정을 분리한다. 같은 시점에서 두 분기를 모두 재생할 수 있으므로 감량 경로 B의 6시간 누계 빼기 기본 A의 누계를 직접 회귀한다. 네 출력 각각의 제곱오차로 적합하고 세 수질 조건을 개별 적용한다. 원문의 게임망, 가중합, 온라인 정책훈련은 사용하지 않는다. |
| 기존 실험과 차이 | main 4493ab8의 Lee/Park README 및 RESULT, Lee/e63, Park/e71, 열린 PR 없음. Yoo/e88, e93, e95. | Lee는 허용 행동들의 예측 위험을 비교하고 Park는 모델 기반 차단을 쓴다. Yoo/e88은 공동 성공 이진 표적, e93은 수질 회복 불가 이진 표적이었다. e95와 같은 후보에서 첫 행동만 선택하고 6시간 끝까지 기본 FCSRL이 자기 관측에 반응한다. |

- 앞 140개 학습일의 e88 비중복 감량 후보 전체를 사용해 seed별 날짜 동일 가중 표준화 및 네 출력 Ridge(alpha=1, 절편 포함)를 적합한다. 입력은 e88의 감량 직전 공정 관측 11개다. 탐색 및 문턱 보정 없음. 실제 사용 시 e93의 동결된 최초 후보에만 규칙을 적용한다. 뒤 48일은 회귀 적합, 문턱 결정에 사용하지 않는다. 기존 대리 모델 및 기본 정책에는 이미 쓰인 개발 날짜다.
- 6시간 공기 차이가 음수이고 NH4 위반, DO 위반, NH4 초과 적분 차이 예측이 각각 0 이하이면 실행한다(수치 허용 1e-8). 주 사례는 e95 거리 조건 안 1,185개, 감량 후보는 495개다. 보조로 전체 1,433개 및 해당 후보를 평가한다. 예측에는 미래 정보가 없다. 결과는 저장된 두 6시간 분기 중 선택한 쪽을 사용한다.
- 비교는 기본 FCSRL, e93 그대로 감량, 같은 seed 및 날짜 안에서 후보 중 같은 수만 무작위 감량한 정확한 기대값, e95의 완전정보 첫 감량 선택이다. 진단으로 공기 또는 세 수질만 정답으로 대체하되 다른 쪽은 같은 예측을 유지한다. 대체 결과는 실제로 사용할 수 없는 선택이며, 각 방식의 감량 수가 다를 수 있다.
- 제어 성과는 미선택 창까지 포함한 6시간 차이의 날짜 평균, 이후 seed 동일 가중. 기본 대비 공기 엄격 감소, 세 수질 비악화가 평균 및 4/5 seed 이상에서 성립해야 하며 같은 조건으로 무작위 대비도 확인한다. 감량 후보에 한정한 지표별 날짜가중 RMSE, 학습 날짜의 고정 평균 예측 대비 제곱오차 개선율, 양쪽 판단을 동시에 만족한 선택의 적중 수를 기록한다. 상수보다 낮은 예측 오차가 곧 제어 성공을 의미하지 않는다.
- 입력 해시, 날짜/창 키, 기존 최초 명령과 누계, e93 실행 결과 및 e95 첫 감량만 허용한 상한을 재현한다. 날짜별 무작위 수와 누계, 다중 출력과 단일 출력 회귀 동등성, 인공 예제의 부호 및 희소 후보를 검산한다. 새 동역학이나 행동 후보를 추가하지 않는다.
