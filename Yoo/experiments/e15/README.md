# Yoo/e15 초기 오차 기반 편향 보정의 선행 검사

**2026-11-06 22:17:32 KST, 선행 검사 완료. 추가 예측력 기준 미통과로 보정기는 시험하지 않았다.** e14의 `day_mse` 모델을 seed 0, 1 각각 고정했다. 초기 한 시간의 모델 오차가 이후 NH4 과대예측을 예측하는지 먼저 확인하고, 추가 정보가 확인될 때만 작은 보정기로 진행하도록 아래 설정을 실행 전 커밋으로 고정했다. FCSRL + PPO, 대리 모델 가중치, 보상과 물리 위반 기준은 유지했다.

## 왜 이 검사가 먼저인가

e14에서는 실제 현재 농도를 매번 주면 NH4 recall 89.31%, FPR 2.25%지만 하루 자기 예측은 50.52%, 10.42%였다. 실측 상태 피드백의 효과와 오프라인 보정은 다르다. 정책이 실제 기록과 다른 공기량을 선택한 뒤에 기록된 NH4를 정답처럼 주입할 수 없다. 이번 시험에서는 01:00까지의 관측만 보정 입력 후보로 쓰고 이후 농도를 읽어 보정하지 않는다.

[편향과 외란 추정의 기존 원리](https://arpi.unipi.it/handle/11568/759798), [MHE 공개 구현](https://www.do-mpc.com/en/latest/mhe_example.html)은 참고 자료다. 이번 선행 검사는 MHE나 offset-free 제어의 재현이 아니며, 초기 오차의 예측력을 검사하는 고정된 작은 선형 회귀다. e10의 단순 이력 추가가 실패했으므로 이력 사용 자체를 개선 근거로 보지 않는다.

## 입력과 목표

현재 e14 평가에 이미 주어진 초기 13개 관측(00:00부터 01:00)을 사용한다. 초기 혁신 잔차는 00:00부터 00:55의 12개 전이에서 `실제 다음 농도 - 실제 현재 상태를 넣은 모델의 다음 농도`다. 이때의 다음 관측은 모두 01:00까지 이미 알려져 있다. 각 날짜 NH4 및 DO 평균 혁신 잔차 2개를 사용한다.

배경 조건 6개는 01:00의 NH4, DO, 첫 13관측의 수온과 유량 평균, 운전 단계 0과 2의 비율이다. 이전에 확정한 날짜 단위 day_mse 예측을 실제 운전으로 재생하고, 01:05부터 23:55까지 NH4 `예측 - 실측` 평균을 회귀 목표로 삼는다. 미래 실측은 학습 목표 계산에만 사용하고 입력에는 사용하지 않는다. 초기 오차가 농도 및 계절 조건의 대리변수에 불과한지 분리하기 위해 다음 네 가지를 모두 비교한다.

| 회귀 | 입력 |
| --- | --- |
| constant | 이전 학습 날짜의 평균 편향만 |
| context | 배경 조건 6개 |
| residual | 초기 NH4 및 DO 잔차 2개 |
| context_residual | 배경 조건 6개 및 잔차 2개 |

주 비교는 context_residual 대 constant 및 context다. 회귀는 학습 날짜만으로 입력을 표준화하고 평균 제곱 오차 + 0.1 x 계수 제곱합을 최소화한다. 절편은 벌점에서 제외한다. 계수 탐색, 변수 선택, 결과를 보고 구간 변경은 하지 않는다.

## 시간 분할과 사전 진행 기준

e14 fit 263일만 사용한다. 내부 holdout 66일, 외부 val, test는 이 선행 검사에서 쓰지 않는다. 0부터 시작하는 날짜 인덱스로 아래 세 순방향 분할을 고정한다. 학습과 확인 사이의 날짜 한 개를 제외한다.

| 분할 | 회귀 학습 | 제외 | 회귀 확인 |
| --- | --- | --- | --- |
| 1 | 0~130 | 131 | 132~174 |
| 2 | 0~174 | 175 | 176~218 |
| 3 | 0~218 | 219 | 220~262 |

**기반 day_mse 모델은 이미 fit 263일 전체를 학습했다.** 따라서 이 분할은 보정 회귀만 시간 순서로 평가하는 조건부 탐색이다. 전체 예측 시스템의 새 독립 검증이나 미관측 날짜 일반화로 주장하지 않는다. 연속 시점 275개를 독립 표본으로 늘리지 않고 날짜 단위 129개의 확인 예측을 집계한다.

두 seed 각각에서 context_residual이 constant 및 context 양쪽보다 확인 MSE를 통합 평균 5% 이상 낮추고, 세 분할 중 적어도 두 분할에서 MSE가 낮아야 통과한다. 한 seed만 좋아지거나 초기 조건만으로 설명되는 이득은 통과시키지 않는다. 상관관계나 학습 오차 감소만으로 진행하지 않는다.

실패하면 이번 입력 구성의 보정기를 추가하지 않고 예측력의 한계를 기록한다. 통과하면 초기 관측만 사용하는 작은 보정기의 구조와 기준을 먼저 고정한 뒤 별도 시험한다. 선행 검사의 통과 자체가 FPR 감소나 안전성의 증거는 아니다. 이후에도 NH4 > 4, DO > 2 및 기존 recall 유지 조건을 완화하지 않는다.

## 실행과 검증

기존 Python 3.10.19, torch 2.14.1+cu130 venv와 CPU 1 thread를 사용한다. torch 모델은 다시 학습하지 않는다. 원자료 및 모델 해시를 e14 기록과 대조하고 fit 전체 재생 지표의 완전 일치를 확인한다. 실제 모델의 01:05 이후 입력과 농도를 모두 바꿔도 초기 특징이 같아야 한다. 회귀 정규화는 각 분할의 학습 날짜만 사용한다.

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
 /home/jio/fcsrl_src/.venv/bin/python Yoo/experiments/e15/verify_signal.py

OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
 /home/jio/fcsrl_src/.venv/bin/python -u Yoo/experiments/e15/initial_signal.py \
 --raw /home/jio/사물/Yoo/data/avedore/aved_raw.csv \
 --data /home/jio/사물/Yoo/data/avedore/aved_5min.pkl \
 --e14 /home/jio/fcsrl_src/results/e14/trial \
 --out /home/jio/fcsrl_src/results/e15/signal
```

비어 있지 않은 결과 경로를 덮어쓰지 않는다. 실행 커밋, 코드 및 입력 해시, 날짜 분할, 실제 회귀 계수, 날짜별 확인 예측을 저장한다. 전체 예측과 초기 잔차 배열은 서버에 보관하고 작은 요약만 Git에 기록한다. 팀 공식 비교가 아닌 개인 탐색이며 정책 실험으로 세지 않는다.

## 결과

실행 커밋 `1d181fe65570dea690600948f347eb52270af2f6`. 원자료 준비 후 회귀 및 고정 모델 재생 계산을 2026-11-06 22:17:32 KST에 완료했다. 4가지 회귀 x 3개 분할 x seed 2개의 총 24개 작은 회귀를 적합했고, 신경망 가중치는 갱신하지 않았다.

| 입력 | seed 0 편향 예측 MSE | seed 1 편향 예측 MSE |
| --- | --- | --- |
| 평균 편향만 | 0.3482 | 0.3167 |
| 초기 조건 6개 | 0.3150 | 0.2884 |
| 초기 평균 잔차 2개 | 0.3545 | 0.3235 |
| 초기 조건 및 잔차 | 0.3422 | 0.3123 |

초기 조건에 잔차를 더하면 MSE가 seed 0에서 8.62%, seed 1에서 8.31% 증가했다. 세 분할 모두 초기 조건만 사용한 회귀보다 나빴다. 평균 편향만 사용하는 기준 대비 이득도 1.73%, 1.37%로 사전 기준인 5%에 못 미쳤으며, 개선된 분할은 각각 1/3이었다.

따라서 초기 평균 잔차를 사용하는 보정기를 추가할 근거를 확보하지 못했다. 사전 계획대로 보정기 학습, 보정된 농도 재생 및 내부 holdout 평가를 진행하지 않았다. 이 수치는 편향을 예측하는 회귀 MSE이지 FPR 변화가 아니다. 보정 후 FPR이 좋아졌거나 나빠졌다고 보고하지 않는다.

회귀 확인 날짜는 첫 분할 2023-03-12~05-03, 두 번째 2023-05-06~08-04, 세 번째 2023-08-08~10-12다. 기반 모델이 이 날짜를 이미 학습한 한계는 유지된다. 초기 조건 회귀도 세 번째 분할에서는 평균 편향만 사용하는 기준보다 나빴으므로, 평균 이득만 보고 다른 후보로 바꿔 채택하지 않았다.

## 해석과 범위

앞서 제안한 것은 초기 오차에 이후 편향을 예측할 신호가 있을 때 보정기를 붙이는 조건부 접근이었다. 이번 고정 ridge 및 평균 잔차 2개 구성에서는 그 신호의 추가 예측력을 확인하지 못했다. 이 결과를 모든 비선형 추정기, 더 긴 이력, 실제 운전에서 새로 들어오는 센서 측정까지 무효라는 뜻으로 확대하지 않는다. 상관관계가 완전히 없거나 미래 상태가 원리적으로 예측 불가능하다고 결론짓지도 않는다.

관측된 이후 측정으로 상태를 계속 보정하는 장치와, 초기 한 시간만으로 남은 하루를 보정하는 장치는 정보 조건이 다르다. 과거 운전의 수질 기록을 바뀐 정책의 반사실적 정답으로 주입하지 않았다. e14에서 확인한 하루 길이 학습의 결과와 기존 FCSRL + PPO는 유지하고, 이번 신호로 보정기나 RL 재학습을 추가하지 않았다. 현재 실행 중인 실험은 없다.
