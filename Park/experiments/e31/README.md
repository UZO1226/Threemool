# Park/e31: 최근 예측 오차로 보정한 차단 (Kaggle DARROW)

상태: **고르기 단계 (2026-11-16).** 고르기 규칙은 결과를 보기 전에 정했다 (아래 그대로).

## 목적

목표는 공기량과 하루 비용을 함께 낮추는 것이다. e24 ~ e29 에서 정책이 공기를 더 아끼게 만드는 방법은 검증에서 NH4 위반이 늘어 비용이 올랐다. 차단 쪽에서 예측을 더 정확하게 만들면 두 방향을 함께 얻을 수 있다. 예측이 낮게 치우친 구간에서 공기를 미리 넣으면 NH4 위반이 줄고, 오차 폭이 줄어든 만큼 여유를 줄이면 공기가 준다.

## 진단 (학습 구간 마지막 40일, e22 H1 과 같은 seed 0 ~ 3 앙상블 + e19 차단)

차단의 1 스텝 NH4 예측 (다른 구성원 4개 평균, 실제로 쓴 공기량) 과 실제 NH4 의 차이를 쟀다. 19,000 스텝 중 경계 근처 (예측 3.0 ~ 4.5) 는 10,138 스텝이다.

| 항목 | 값 |
| --- | --- |
| 직전 스텝 오차와의 상관 (전체, 경계 근처) | 0.68, 0.66 |
| 에피소드 평균 오차가 설명하는 오차 분산 | 17% |
| 지수 평균 (lam 0.5) 으로 보정한 경계 근처 오차 표준편차 | 0.067 에서 0.050 |
| 같은 보정의 99% 분위수, 1% 분위수 | 0.172 에서 0.135, -0.159 에서 -0.137 |
| lam 0.8, 0.9, 0.95 의 99% 분위수 | 0.138, 0.144, 0.149 |

지금 차단은 매 스텝 방금 관측한 예측 오차를 쓰지 않는다. 오차는 대부분 몇 스텝 동안 이어지는 치우침이고, 하루 내내 같은 치우침 (환경 구성원 고유의 치우침) 은 일부다.

## 방법

`min_brake.py` 에 `bias`, `margin_scale` 을 더했다. 매 스텝 지난 스텝 예측과 지금 관측 NH4 의 차이 e 로 에피소드마다 b <- lam b + (1 - lam) e 를 갱신하고, 여유 검사 (mu + 여유 <= 4) 의 mu 에 b 를 더한다. 모델 예측 제어의 외란 추정과 같은 방법이다. `margin_scale` 은 e15 여유 표 (+0.1) 에 곱한다. 여러 스텝 예측 (회복 가능성 검사, DO 예측) 은 바꾸지 않는다. 정책은 e22 와 같은 4 x 16 앙상블이다 (새 학습 없음).

| 후보 | lam | 여유 배율 |
| --- | --- | --- |
| B5 | 0.5 | 1.0 |
| B5s8 | 0.5 | 0.8 |
| B8s8 | 0.8 | 0.8 |
| B5s7 | 0.5 | 0.7 |

여유 배율 0.8 은 진단의 99% 분위수 감소 (22%) 에서, 0.7 은 그보다 조금 더 줄인 값이다.

## 고르기 규칙 (결과 전에 기록)

"학습 구간 마지막 40일 (2021-10-01 ~ 11-09) x 구성원 5개, seed 0 ~ 4 의 4개 조합 5개를 같은 조합의 e19 차단 (Park/e26 의 기준값) 과 짝 비교. 조합 평균 공기량 < 기준, 평균 비용 < 기준, 둘 다 이긴 조합 최다 (3/5 이상), 같으면 공기량 최소. 없으면 버린다. 규칙을 통과한 후보 중 평균 비용이 가장 낮은 후보가 고른 후보와 다르면 보조 가설로 함께 검증한다".
