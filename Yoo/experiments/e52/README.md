# e52: 대리 모델 구성원 불일치로 NH4 제약을 비관적으로 세는 학습

2026-11-12 시작. Yoo 개인 탐색이며 공통 평가 조건과 공식 채택을 바꾸지 않는다. test 구간 사용 없음.

## 동기

Yoo/e44, e45 의 기본 FCSRL 은 학습 날짜에서는 NH4 와 DO 평균 한도 6 / 6 을 지키지만 검증 날짜(겨울)에서는 지키지 못한다. 대리 모델은 학습 날짜 밖에서 더 부정확하고(e30, e37, e51), 정책은 모델이 틀리는 영역을 안전하다고 배울 수 있다. 모델 기반 오프라인 RL 에서 쓰는 불확실성 비관(MOPO, MOReL 계열)을 Safe RL 제약 쪽에 적용한다. 모델 정확도를 올리는 대신 모델이 모르는 상태에서 정책이 여유를 두게 하는 것이 목적이다.

## 바꾼 것 (하나)

학습 중 NH4 비용만 바꾼다.

    학습 NH4 비용 = 1[ NH4_next(선택 구성원) + kappa x std_m(구성원 5개의 한 스텝 NH4 예측) > 4 ]

- 상태 전이, 보상, DO 비용, 한도, 관측(e44 padded 16개), 에이전트, 수집과 갱신은 e44 와 같다. FCSRL 의 실현 가능성 목표도 이 비용을 쓴다
- 평가는 비관 없이 원래 비용으로 한다
- kappa = 0 이면 e44 와 같다. smoke 에서 kappa 0, FCSRL seed 0 의 처음 두 갱신 학습 기록 15개 항목이 e44 와 모두 같았다

### kappa 정하기 (학습 날짜만 사용, 정책 학습 전)

구성원 간 한 스텝 NH4 예측 표준편차는 기록 운전 재생에서 학습 날짜 평균 0.020 mg/L, 검증 날짜 0.047 mg/L 다(검증에서 2.4배). 그대로 쓰면 영향이 거의 없어 배율이 필요하다. 기록 운전 재생의 비관 NH4 비용이 학습 날짜의 실제 기록 NH4 위반(5.62, e33 에서 한도 6 을 정한 값)과 같아지는 kappa 를 골랐다. 모델은 학습 날짜 기록 운전의 NH4 위반을 4.51 로 과소 예측하고, 그 차이를 불확실성 여유로 메우는 셈이다.

| kappa | 0 | 5 | 10 | 20 | 30 |
| --- | --- | --- | --- | --- | --- |
| 학습 날짜 재생 비관 NH4 비용 | 4.51 | 5.05 | **5.62** | 7.25 | 9.11 |
| (참고) 검증 날짜 재생 비관 NH4 비용 | 33.47 | 35.18 | 37.72 | 43.85 | 49.20 |

kappa = 10 으로 고정한다. 검증 행은 참고로 같이 계산했지만 kappa 선택에 쓰지 않았다. 비관 효과는 학습 날짜 +1.1, 검증 날짜 +4.3 으로 모델이 모르는 날짜에서 더 크다.

## 판정 (결과를 보기 전에 정함)

방법마다 따로 본다. seed 짝 비교(kappa 10 − kappa 0).

- H1: 검증 NH4 비용이 seed 3개 중 2개 이상에서 낮고 평균도 낮다
- H2: 일반화 격차(검증 NH4 − 학습 NH4)가 평균적으로 줄어든다
- 교환 확인: 검증 공기량이 평균 +5% 를 넘게 늘면, H1 이 지지돼도 "공기를 더 쓰는 보수화" 로 적고 개선으로 부르지 않는다. 공기량, NH4, DO 세 평균이 모두 낮아질 때만 전체 개선으로 적는다
- 부가: 검증 두 평균 한도(6 / 6) 충족 seed 수, NH4 초과 적분, 최악 날짜 NH4 를 함께 적는다

seed 3개 탐색이라 검정은 하지 않는다. kappa 는 하나만 시험하며 결과를 보고 다른 값을 고르지 않는다.

### 관찰

- FCSRL + PPO-Lag 에서 효과가 크다. 기준의 seed 간 검증 NH4 편차(19.23 ± 9.36)가 5.26 ± 0.76 으로 줄었고, 학습 날짜와 검증 날짜의 NH4 격차도 14.01 에서 2.93 으로 줄었다. 검증 두 한도 충족 seed 는 0/3 에서 2/3 이 됐다(seed 0 은 NH4 6.32 로 한도를 0.32 넘음). 다만 공기량이 81,019 에서 93,281 로 늘었고, 늘어난 seed 1, 2 는 기준에서 NH4 를 크게 어기며 공기를 아끼던 seed 다
- PPO-Lag 는 검증 NH4 가 세 seed 모두 줄었지만 폭이 작고, seed 2 는 비관 후에도 검증 NH4 12.79 로 한도를 넘는다. 격차 감소도 0.2 로 작다
- 학습 중 구성원 표준편차(구성원 5개 한 스텝 NH4 예측)는 평균 0.03 mg/L 안팎이었고 학습이 진행되며 0.035 ~ 0.037 로 조금 커졌다. 정책이 모델이 덜 확실한 상태 쪽으로 약간 이동했음을 뜻하며 kappa 10 에서 0.3 ~ 0.4 mg/L 의 여유가 된다
- 비관 비용은 학습 날짜 NH4 위반을 실제보다 더 크게 세므로 정책은 학습 날짜에서 NH4 1.9 ~ 3.0 까지 낮췄다. 즉 이 결과의 상당 부분은 "불확실한 곳을 피함" 보다 "NH4 목표를 전반적으로 더 엄격하게 둠" 으로도 설명될 수 있다. 같은 공기량에서 NH4 가 낮아졌는지는 이 실험만으로 가를 수 없다

### 한계와 해석 범위

- seed 3개 탐색이고 검정을 하지 않았다. 기준 seed 0, 1 은 e44 정책의 e45 평가를 재사용했다 (kappa 0 학습 경로가 e44 와 같음은 smoke 로만 확인)
- 비관 대신 NH4 문턱을 단순히 낮추는 대조(예: 4 대신 3.7)가 없어, 불확실성 정보 자체의 기여는 분리되지 않았다
- 대리 모델 안의 비교이며 실제 처리장 절감이 아니다. scikit-learn 1.7.2 의 e35 수정 모델 환경이라 공통 평가 조건 v1.1 수치와 같은 표에 놓지 않는다
- 채택하지 않는다. 다음에 한다면 같은 공기량 기준 비교나 문턱 낮춤 대조가 먼저다

## 사후 검산

평균 공기량 판정은 집단 평균의 비율로 바로잡았다. seed별 변화율은 별도로 보존한다. H1, H2 및 공기 증가에 따른 미채택 결론은 동일하다. [고정 정책 상세 분석](audit/README.md)은 새 학습 없이 원 정책을 재평가한다.
