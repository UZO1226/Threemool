# Park/e87: 같은 차단 위의 예측 제어 대 ABAC, 학습 구간 188일 (Kaggle DARROW)

상태: **사전 등록 (2026-11-26).** 설정값, 가설, 판정 규칙은 이 실험의 결과를 보기 전에 정했다. 대표는 바꾸지 않는다.

## 목적

Park/e84 의 참고 비교에서 차단 위 예측 제어는 검증 40일에 같은 공기량의 차단 위 ABAC 보다 0.178 낮았고 블록 구간이 0 아래였다. 날짜 흔들림을 넘은 차단 위 제어기 차이는 그것 하나였다. 학습 구간 마지막 40일에서는 차이 없음이었다 (+0.712). 둘 다 학습하지 않는 방법이라 학습 구간 188일 전체로 날짜를 늘려 다시 판정한다.

## 방법

- 차단 위 예측 제어 기본 (`ShortMPC`, NH4 여유 1.2, 공기 가중치 1.5, 1시간) 과 차단 위 ABAC (Kp 4,000, Ki 1,600, 설정값 2.6, 2.9, 3.5) 를 학습 구간 188일에서 스텝 기록과 함께 돈다. 설정값 3.2 는 Park/e86 의 기록을 쓴다
- 같은 공기량 맞추기: 예측 제어의 전체 공기량을 감싸는 두 ABAC 설정값의 날짜별 비용을 선형 보간 (Park/e84 와 같음). 감싸는 두 점이 없으면 판정하지 않는다
- 설정값은 학습 구간 마지막 40일에서 예측 제어 기본 (72,192) 이 ABAC 설정값 3.2 (71,933) 근처였던 것을 보고 3.2 양옆에 두었다
- 판정 방법은 Park/e82 와 같다 (세 갈래)

## 평가

학습 구간 188일 x 구성원 5개, 결정적. test 는 쓰지 않는다.

## 가설 (사전 등록)

방향은 날짜 흔들림을 넘은 유일한 이전 결과 (Park/e84 검증 40일, -0.178) 에서 정했다.

- H1. 학습 구간 188일에서 (예측 제어 빼기 같은 공기량의 ABAC) 하루 비용의 블록 95% 구간이 0 아래다

## RESULT.md 처리 (미리 정함)

- 지지: "같은 차단 위에서 1시간 예측 제어는 ABAC 보다 낮다 (검증 40일과 학습 구간 188일)" 고 적고, 차단 위 제어기 선택이 부차적이라는 Park/e85 정리에 "예측 제어는 ABAC 보다 낫다" 는 단서를 단다
- 차이 없음: "차단 위 예측 제어와 ABAC 의 차이는 날이 많아도 날짜 흔들림 안" 이라 적고 Park/e84 의 참고 비교를 "검증 40일에서만" 으로 좁힌다
- 반대: "날이 많으면 차단 위 ABAC 가 예측 제어보다 낮다" 고 적는다

## 미리 밝히는 한계

- ABAC 이득은 학습 구간 마지막 40일에서 고른 값이다 (188일에 포함)
- 예측 제어의 대리 모델과 환경은 같은 계열이다. ABAC 는 대리 모델을 쓰지 않지만 차단은 쓴다
