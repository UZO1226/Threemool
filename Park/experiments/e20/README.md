# Park/e20: 정책 앙상블 + e19 차단 (Kaggle DARROW)

상태: **완료 (2026-11-12). H1 지지 안 됨 (2/5), H2 지지 (5/5), H3 지지 안 됨 (2/5).** 평균 앙상블은 공기량 78,933, 비용 4.82 로 e19 H1 seed 5개 모두보다 둘 다 낮았다. 주 가설인 중앙값은 비용이 4.97 로 거의 같아 기각됐다. 학습 예산이 5배라 대표 결과는 바꾸지 않는다 (미리 정함). 가설과 판정 규칙은 검증 결과를 보기 전에 정했고 (사전 등록 커밋 `785759b`) 결과를 본 뒤 바꾸지 않았다.

## 목적

목표는 공기량과 하루 비용을 함께 낮추는 것이다. 비교 기준은 대표 결과인 Park/e19 H1 (검증 seed 평균 공기량 80,748, 비용 4.98) 이다.

## e19 까지 남은 문제

- NH4 위반은 바닥에 가깝고 (하루 종일 9,000 이어도 검증 3.12%), 차단으로 줄일 여지가 작다.
- 정책 공기량을 위에서 자르면 공기량이 오히려 늘었다 (아래 버린 후보). 정책이 미리 넣는 공기가 나중의 큰 개입을 줄인다.
- 그래서 남은 여지는 정책 쪽에 있다. seed 사이 차이가 크다 (e19 H1 비용 4.82 ~ 5.41). seed 마다 잘하는 때와 못하는 때가 다르면, 여러 정책의 행동을 합치면 서로의 실수가 상쇄될 수 있다.

## 버린 후보 (학습 구간)

e17 H1 차단 뒤에 공기량 상한 = 필요 공기량 + slack (500, 1,000, 2,000, 3,000, 4,000) 을 걸었다. 모든 slack 에서 e17 H1 (68,293, 2.410) 보다 공기량이 많았다 (68,400 ~ 70,442). e14 진단 (정책 공기량 상한) 과 같은 결과라서 버렸다.

## 방법

e12 A 정책 seed 0 ~ 4 다섯 개가 같은 관측에서 낸 행동 (-1 ~ 1) 을 하나로 합쳐 제어기 하나로 쓰고, e19 H1 차단을 그대로 건다. 합치는 방법은 중앙값, 평균, 75% 분위수다.

## 설정 고르기 (학습 구간만)

학습 구간 40일(4일 간격) x 구성원 5개. 규칙은 결과를 보기 전에 정했다: "평균 비용과 평균 공기량이 e19 H1 seed 평균보다 낮은 방법 중, 둘 다 이긴 seed 가 가장 많은 것 (3 이상, 같으면 공기량이 적은 것). 없으면 앙상블을 버린다".

| 방법 | 공기량 | 하루 비용 | e19 H1 보다 둘 다 낮은 seed |
| --- | --- | --- | --- |
| e19 H1 seed 평균 | 68,224 | 2.375 | |
| **중앙값 (규칙으로 고름)** | **66,381** | **2.075** | 4/5 |
| 평균 | 66,874 | 2.040 | 3/5 |
| 75% 분위수 | 67,143 | 2.065 | 3/5 |
| 25% 분위수 | 68,184 | 2.375 | 2/5 |

## 조건과 평가

학습 없음. 검증 40일 x 구성원 5개 = 200 에피소드를 결정적으로 돈다. 앙상블은 제어기 하나라 값이 하나다. test 는 쓰지 않는다.

## 가설 (사전 등록)

앙상블 값과 같은 차단을 쓴 e19 H1 의 seed 5개를 비교한다. 앙상블이 seed 5개 중 3개 이상보다 공기량과 하루 비용이 둘 다 낮고, seed 평균보다도 둘 다 낮으면 지지로 적는다.

- H1 (주 가설). 중앙값
- H2. 평균
- H3. 75% 분위수

NH4 와 DO 위반률은 보고만 한다. 가설이 기각되는 결과도 그대로 기록한다.

## RESULT.md 처리 (미리 정함)

앙상블은 학습을 5번 한 정책을 함께 쓰므로 학습 예산이 PROTOCOL v1 의 5배다. 지지되더라도 대표 결과는 바꾸지 않고, RESULT.md 에 "조건이 다른 결과" 로 따로 적는다.

## 미리 밝히는 한계

- 학습 예산 5배, 실행 시 계산도 5배다
- 정책이 e12 A 5개뿐이라, 다른 정책 묶음에서도 같은 효과일지는 모른다
- 학습 구간에서 고른 방법이 검증 구간(겨울, NH4 높음) 에서도 같은 순서일지는 모른다
- e10 ~ e19 와 같은 대리 모델 한계

## 해석

- 세 방법 모두 공기량이 e19 H1 seed 평균 이하였고, 평균 앙상블은 공기량 2.2%, 비용 3.2% 를 함께 줄였다.
- 평균, 75% 분위수로 갈수록 차단 개입이 33% 에서 22%, 12% 로 줄었다. 여러 정책을 합친 행동이 차단이 필요한 상황을 미리 피한다.
- 학습 구간에서는 중앙값이 가장 좋았지만 검증 구간에서는 비용이 줄지 않았다. 고르는 규칙이 학습 구간의 작은 차이에 따라 달라졌다.
- 정책 하나의 행동을 시간 방향으로 평활하면 (지수 이동 평균 0.3 ~ 0.7, 3스텝 중앙값) 학습 구간에서 e19 H1 보다 나빴다 (Park/e21 준비 진단). 앙상블 효과는 행동이 덜 흔들려서가 아니라 서로 다른 정책을 합쳐서 생긴다.
- 학습 예산이 5배라 PROTOCOL v1 의 같은 조건 비교가 아니다. 같은 예산으로 비슷한 효과를 얻는 방법은 Park/e21 에서 본다.
