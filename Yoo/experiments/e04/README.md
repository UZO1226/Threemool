# Yoo/e04 학습 전 점검과 오류 분리 진단

목표는 FCSRL 확장 전에 과도한 보수성, 공격성 및 설정 불일치를 확인하는 것이다. e03 결과와 체크포인트는 그대로 보관한다. 팀 공식 비교가 아닌 개인 탐색 실험이다.

## 실행 전 판정

- e03의 `pess_k=0`, `unc_pen=0`은 환경 불확실성 보정을 끈 설정이다. `train.py`에는 이를 변경할 CLI도 없다. 환경 기능의 존재를 실험에 사용했다는 뜻으로 해석하지 않는다.
- UCB는 critic 5개와 k=0.5다. 원본 target의 최대값보다 항상 보수적이지 않다. 샘플 표준편차를 쓰므로 critic 1개는 NaN을 만든다. 2개 미만과 음수 및 비유한 계수를 거부하도록 수정했다.
- TD3의 `--epochs 0` 및 `--grad_steps 0`은 원래 값으로 조용히 돌아갔다. 이제 양수만 받는다. 음수 및 비유한 승수 상한과 기존 결과 폴더 덮어쓰기도 거부한다.
- PID는 누적 오차의 상한이 없다. 승수가 상한에 붙은 동안에도 적분 항이 계속 커질 수 있다. 상한 부착만으로 현재 제약 압력이 부족하다고 결론낼 수 없다. 원본 갱신기는 수정하지 않고 과거 로그 및 별도의 입력 스트레스 시험으로 확인한다.
- 하루 종료는 truncation으로 처리하고 PPO와 TD3 모두 마지막 상태에서 bootstrap한다. 따라서 할인 비용 Q를 단순한 하루 비용 15와 직접 비교하면 안 된다. 하루 유한 과제로 정의할지, 연속 운전의 표본 구간으로 정의할지는 후속 학습 전에 명시해야 한다.
- 할인율 0.99와 feasibility 할인율 0.9는 5분 시간 간격에서 각각 다른 시간 범위를 나타낸다. 원본 로봇 환경의 기본값이 폐수 공정에 최적이라는 근거는 없다. 이번 진단에서는 임의 변경하지 않는다.
- NH4 앙상블 불일치가 실제 오차를 예측하는지 먼저 확인한다. 관련성이 약하면 k만 높인 비용 벌점의 본 학습을 시작하지 않는다.

## 첫 실험

대상은 e02 15개, e03 20개의 저장된 선택 모델이다. 학습 및 가중치 갱신 없이 검증 43일 x 모델 구성원 5개에서 다음을 측정한다.

1. 실제 운전 상태와 행동에서 다음 NH4 및 DO를 예측한다. NH4에는 예측 DO를 입력하여 실제 환경 실행과 맞춘다. 두 시점은 같은 검증 날짜 안에 있어야 한다.
2. 모델 표준편차와 절대 오차 관계, k=0, 0.5, 1, 2, 3의 예측 상한 포함률, 위반 누락률과 오경보율을 기록한다. 전체, 호기, 낮은 DO 호기, 제약 경계 부근을 구분한다.
3. 정책의 12스텝(1시간) 비용 합과 끝 상태 Q로 만든 bootstrap 목표를 시작 Q와 비교한다. 같은 할인율 0.99를 사용하며 날짜 경계를 넘지 않는다. 이 목표에는 Q 오차가 남아 있으므로 실제 환경의 독립적인 정답이나 과소평가의 확정 증거가 아니다. target policy smoothing과 수집 정책 차이도 남는다.
4. 하루 할인 비용과 마지막 Q 기여를 분리한다. 공기량, 비용, 행동 상하한 부착, 호기 중 낮은 DO 비율을 함께 본다.

현재 검증 데이터는 과거 모델 선택에 이미 사용됐다. 독립적인 확증 또는 불확실성의 형식적 보정 보장을 주장하지 않는다. 기존 test 구간을 추가 튜닝에 사용하지 않는다. 작은 seed 차이를 유의한 개선으로 해석하지 않는다.

## 학습 착수 기준

새 벌점의 값이 더 크다는 이유만으로 안전 개선을 가정하지 않는다. 검증에서 오차를 구분하지 못하는 불확실성 신호, 지나친 오경보, 행동 상한 부착 또는 극단적 비용 증가가 확인되면 해당 벌점의 대규모 학습은 보류한다. 진단 결과로 대상 오류를 고른 뒤 기본 방법과 같은 학습 예산의 작은 비교 실행을 정한다. 단순한 비용 한도 축소도 대조군으로 포함할 계획이다.
