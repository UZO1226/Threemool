# Park/e60: 학습 구간에서 고른 차단 위 예측 제어와의 같은 공기량 비교 (Kaggle DARROW)

상태: **사전 등록 (2026-11-21).** 격자, 고르는 규칙, 가설은 격자를 돌리기 전에 정했다. 대표는 이 실험만으로 바꾸지 않는다.

## 목적

Park/e58 은 대표와 같은 차단을 씌운 1시간 예측 제어가 같은 공기량에서 대표만큼 (또는 더 잘) 한다는 것을 보였다. 그런데 e58 은 검증 구간에서 손잡이를 바꿔 만든 곡선이라 예측 제어에 유리하다. 이 실험은 Park/e43, e54 와 같은 공정한 절차 (학습 구간에서 대표 공기량에 맞춰 고르고 검증에서 한 번 돈다) 로 "차단 위의 학습 정책" 과 "차단 위의 계획기" 를 비교한다. 대표를 바꿀지 팀에 올릴 근거가 되는 비교다.

## 방법

- 기준: `ShortMPC` (`objective='excess'`, 1시간, 후보는 e48 과 같음) + 대표 차단 (`MinAirBrake(dyn, 3.5, 1, 'others', **BRAKE)`)
- 격자: NH4 여유 0.8, 1.2, 1.6 x 공기 가중치 0.7, 1.0, 1.5, 2.0 = 12 조합. 학습 구간 마지막 40일 x 구성원 5개
- 고르기: Park/e43 과 같은 규칙. 대표 학습 구간 공기량 73,345 의 ±2% 안에서 하루 비용 최소, 없으면 공기량이 가장 가까운 조합
- 격자 범위는 Park/e58 의 학습 구간 4일 사전 점검 (차단 위 NH4 여유 1.2 에서 공기 가중치 1.0 이 80,231, 3.0 이 65,631) 과 4일, 40일의 공기량 차이 (차단 없는 가중치 1.0 에서 79,706 대 74,042) 를 보고 정했다
- 대표는 Park/e35 orig 의 묶음 5개 값을 쓴다

## 평가

검증 40일 x 구성원 5개 = 200 에피소드, 결정적. test 는 쓰지 않는다.

## 가설 (사전 등록)

- H1. 고른 차단 위 예측 제어의 검증 공기량이 대표 평균의 ±3% 안이고, 대표의 하루 비용이 더 낮은 묶음이 5개 중 4개 이상이며 평균도 낮다
- H2 (반대 방향, 대표 교체 검토 조건). 공기량이 ±3% 안이고, 차단 위 예측 제어가 더 낮은 묶음이 4개 이상이며 평균도 낮다
- 공기량이 ±3% 밖이면 둘 다 판정하지 않는다

## RESULT.md 처리 (미리 정함)

- H1 지지: "학습 구간에서 고른 차단 위 예측 제어보다 같은 공기량에서 대표가 낮다" 고 적고, Park/e58 의 결론은 "검증 구간에서 곡선을 만든 유리한 조건에서만" 으로 좁힌다
- H2 지지: "같은 차단 위에서 학습 구간에서 고른 1시간 예측 제어가 대표보다 낮다" 고 한계에 적고, 대표를 차단 위 예측 제어로 바꿀지 팀에 올린다 (Park 혼자 바꾸지 않음)
- 둘 다 아님: "같은 차단 위에서 학습 정책과 1시간 예측 제어는 비슷하다" 고 적는다

## 미리 밝히는 한계

- 격자는 12 조합이고 대표는 다시 고르지 않는다
- 예측 제어와 차단은 같은 대리 모델 계열을 쓰고 환경도 같은 계열이다. 검증 구간은 e10 부터 반복해서 썼다
