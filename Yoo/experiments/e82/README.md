# e82 회수 뒤 공기 명령의 관측별 분해와 사전 판단

**감량 직후 공기 명령은 평균 138.35 m³/h 내려갔다. 하루가 끝나면 기본 명령 부피는 반대로 76.42 m³ 늘었다.** 같은 e81 에피소드에서 증량 단독 경로와 회수 경로의 입력을 교환해 동결된 정책의 명령 차이를 분해했다. 감량 시 직접 뺀 평균 31 m³는 아래의 기본 명령 기여에 포함하지 않는다.

| 입력 묶음 | 첫 감량 다음 명령 기여 (m³/h) | 하루 누적 명령 기여 (m³/23.75h) |
| --- | ---: | ---: |
| NH4 | +20.89 | +52.33 |
| NO3 | +0.11 | -17.66 |
| DO 3개 | +29.29 | +13.45 |
| 직전 공기량 | -188.64 | +28.30 |
| 합계 | -138.35 | +76.42 |

첫 열은 첫 감량이 있었던 261개 짝에서의 평균, 둘째 열은 개입이 없었던 에피소드까지 포함한 5개 seed의 하루 평균이다. 직후의 직전 공기 입력 기여는 5개 seed 모두 음수였다. 하루 증가가 컸던 seed 4에서는 NH4 +145.10, 직전 공기 +118.45, DO +79.50, NO3 -74.13 m³였다. seed 1에서는 DO +67.37이 NH4 -37.94, 직전 공기 -24.26, NO3 -5.36과 거의 상쇄됐다. 이는 정책이 받은 입력에 따라 출력 차이를 배분한 값이다. 어느 센서가 공정 변화를 최초로 일으켰는지는 판별할 수 없고, 서로 다른 경로의 입력을 섞은 조합은 공정에서 드물 수 있다.

**감량 직전 정보로 유리한 경우를 가려내는 고정 로지스틱 회귀는 겨울에 판별력이 부족했다.** 학습 날짜 188일의 적격 에피소드 1,130개(양성 335개)로 학습했다. 입력은 첫 감량 직전 NH4, 지난 15분 NH4 변화, DO 센서 3개, 직전 공기량이다. 겨울에서는 회수가 증량 단독보다 공기를 절약하면서 세 수질 지표를 유지한 경우가 적격 261건 중 75건(28.7%)이었다. 분류기가 선택한 218건 중 실제 양성은 62건(28.4%)이었고 AUC는 0.482였다. seed별 AUC는 0.433~0.546이었다. 적격 표본 수는 서로 다른 현장 날짜 수와 구별한다.

겨울 40일 전체에서 이 선택 규칙은 항상 회수하는 e81보다 하루 공기를 60.09 m³ 적게 썼다. 그러나 기본 FCSRL 대비 공기 +82.10 m³, NH4 위반 -0.097스텝, DO 위반 +0.007스텝, NH4 초과 적분 -0.0077 mg h/L였다. 공동 개선은 0/5 정책으로 채택 기준을 충족하지 못했다. 에피소드별 분류 성적과 하루 평균 효과는 개선폭의 크기를 다르게 반영한다. 이 분석은 해당 사전 입력과 한 가지 선형 규칙에 대한 개발 검증이다.

## 검산과 재현

설계 커밋 8ec01d2, 학습 짝 생성 d9a20f5, 겨울 진단 44c8b10. e81 양쪽 경로가 첫 감량 전까지 같고 첫 결정 관측이 일치함을 검사했다. 회수를 선택하면 그 에피소드의 기존 회수 규칙 전체(최대 두 번)를 적용하고 생략하면 증량 단독으로 끝낸다. 이 한 번의 선택에서 기존 경로 전체로 하루 결과를 재구성할 수 있다. 양쪽 원 명령 복원, 네 그룹 기여 합 및 원 궤적 하루 지표를 검산했다. 정책에 들어간 외생 입력은 짝 사이에서 동일했다. 기존 겨울 검증을 다시 사용했고 공식 시험은 평가하지 않았다.
