# Park/e07: Kaggle Avedøre 데이터에서 실행 시점 안전 차단

상태: **완료 (2026-11-09). 모든 차단이 차단 없음보다 하루 비용을 늘렸다. H1 은 규칙상 지지지만 의미가 작고, H2, H3 지지 안 됨.** 규칙은 학습 전에 정했고 결과를 본 뒤 바꾸지 않았다.

## 목적

Park/e01 ~ e06 은 BSM1 에서 했다. 팀은 2026-11-09 수행계획서의 Kaggle 데이터로 본 실험을 옮겼다 (Yoo/e23, Lee/e06). 사용자의 지시에 따라 Yoo 와 같은 Kaggle Avedøre 데이터와 환경에서, BSM1 에서 찾은 실행 시점 안전 차단을 다시 시험한다.

BSM1 에서 배운 점 (보조 검증):

- 순간 위반을 줄인 효과의 대부분은 차단을 거는 것 자체였다 (e01)
- 같은 에너지에서 관측 전체 로지스틱 회귀 예측기 차단이 NH4 측정값 규칙보다 약 2 %p 나았다 (e05). 그러나 날씨가 바뀌자 그 이점이 사라졌다 (e06)
- 위험에 비례해 폭기 하한을 올리는 방식이 켜고 끄기보다 조금 나았다 (e05, e06)

## Avedøre 환경이 BSM1 과 다른 점

| 항목 | BSM1 (e01 ~ e06) | Avedøre (이번) |
| --- | --- | --- |
| 환경 | 물리 시뮬레이터 | Yoo 가 실제 운전 기록으로 학습한 대리 모델 (`Yoo/experiments/e02/surrogate.json`) |
| 비용 | NH4 > 4 만 (0 또는 1) | NH4 > 4 와 DO > 2 를 더한다 (스텝당 0, 1, 2), 하루 한도 15 |
| 행동 | 5번 조 KLa | 호기 단계의 공기량 0 ~ 8000 Nm3/h. 다른 단계는 공기량 0 |
| 학습과 평가 | 건기 0 ~ 6일, 14일 연속 평가 | 학습 330일 (2022-09 ~ 2023-12), 검증 43일 (2024-01 ~ 02) x 구성원 5개 = 215 에피소드 |

비용에 DO 상한이 있으므로 최대 폭기로 차단하면 DO 위반이 늘 수 있다. 그래서 차단 폭기량을 최대값이 아니라 학습 구간 호기 공기량의 90% 분위수 근처(5,370 Nm3/h) 인 **5,400 Nm3/h** 로 정한다. 검증 구간은 겨울이라 학습 구간보다 수온이 낮다 (평균 10.7 대 15.2 C).

## 차단

차단은 공기량을 올리기만 한다. 실행 공기량 = max(정책 공기량, 차단 공기량). 호기 단계가 아니면 공기량은 0 이다.

| 차단 | 차단 공기량 | 설정 (곡선) |
| --- | --- | --- |
| NH4 규칙 | 현재 NH4 측정값 >= theta 이면 5,400 | theta 2.0, 2.5, 3.0, 3.5, 4.0 |
| 예측기 켜고 끄기 | 예측 확률 p >= 기준이면 5,400 | 기준 0.05, 0.1, 0.2, 0.3, 0.5, 0.7, 0.9 |
| 예측기 비례 | 5,400 x min(1, p / c) | c 0.1, 0.25, 0.5, 1.0 |

예측기는 정책마다 맞춘 로지스틱 회귀다. 입력은 관측 11개와 하루 중 시각의 2, 3배 주기 sin, cos 4개 (15개). 정답은 "다음 12 스텝(1시간) 안에 NH4 > 4 인 스텝이 있는가". 맞추는 자료는 그 정책을 차단 없이 학습 구간에서 돌린 궤적이며, 학습 구간 (날짜, 구성원) 중 정해진 난수(seed 7000 + 정책 seed) 로 고른 300 에피소드다. 표준화, L2 1e-3, 뉴턴법 50회 (Park/e03 과 같은 방법). 검증 구간으로는 맞추지 않는다.

## 지표와 비교

- 지표: 에피소드 평균 하루 공기량(Nm3/일), 하루 비용(NH4 와 DO 위반 스텝 수의 합), NH4 위반 %, DO 위반 %, 한도 15 만족 에피소드 %, 개입 % (호기 스텝 중 차단이 공기량을 올린 비율)
- 같은 공기량 차이: 한 곡선의 각 점에서, 비교 곡선의 점을 공기량 순으로 이은 선형 보간 하루 비용을 뺀다. 비교 곡선 범위 밖의 점은 뺀다. 정책마다 평균을 낸다. 음수면 앞 곡선이 같은 공기량으로 비용이 낮다

## 가설 (사전 등록)

FCSRL 정책 seed 3개 중 2개 이상에서 성립하고 seed 평균도 성립하면 지지로 적는다. 비교 점이 없는 seed 는 성립하지 않은 것으로 센다.

- H1 (주 가설). 예측기 켜고 끄기 곡선의 같은 공기량 차이가 NH4 규칙 곡선 대비 음수다
- H2. 예측기 비례 곡선의 같은 공기량 차이가 예측기 켜고 끄기 곡선 대비 음수다
- H3. NH4 규칙 theta 3.0 차단의 하루 비용이 차단 없음보다 낮다 (DO 상한이 있는 환경에서도 차단이 비용을 줄이는가)

가설이 기각되는 결과도 그대로 기록한다. 학습된 정책의 성능(단계 1) 은 Lee/e06, Yoo/e06 과 나란히 보고하되 판정하지 않는다.

## 미리 밝히는 한계

- 환경은 실제 공정이 아니라 대리 모델이다. Yoo/e09 ~ e15 는 이 대리 모델이 NH4 위반을 낮게 예측하는 경향을 보고했다
- 예측기와 정책 모두 학습 구간(대부분 따뜻한 계절) 으로 맞췄고, 검증 구간은 겨울이다. BSM1 e06 처럼 분포가 바뀌면 예측기의 이점이 줄 수 있다
- 관측 정규화 통계를 학습 중에 갱신하지 않는다 (Yoo 와 다름). 차단 공기량 5,400 하나만 본다
- seed 3개, 404,096 전이의 탐색적 실험이다

## 실행 명령

```bash
# 데이터: Yoo/experiments/e02/README.md 의 Kaggle 주소에서 받아 Park/data/avedore/ 에 둔다 (Git 제외)
#   dl.zip sha256 2058148f...c2e5ec, aved_raw.csv sha256 b57bc042...a2e, 둘 다 Yoo 기록과 일치 확인
python Yoo/code/wwtp/prep.py --raw Park/data/avedore/aved_raw.csv --out Park/data/avedore/aved_5min.pkl   # pandas 2.2.3
cd Park/code
export WANDB_MODE=disabled OMP_NUM_THREADS=1
python check_avedore.py --data ../data/avedore/aved_5min.pkl --out ../experiments/e07/check_avedore.json
for m in fcsrl ppo; do for s in 0 1 2; do
  python train_avedore.py --method $m --seed $s --data ../data/avedore/aved_5min.pkl --out <결과>/av_runs/${m}_s$s
done; done
cd ../experiments/e07
for s in 0 1 2; do python run_e07.py one --seed $s --data ../../data/avedore/aved_5min.pkl --runs <결과>/av_runs --out <결과>/e07; done
python run_e07.py report --out <결과>/e07 --runs <결과>/av_runs --md results.md
```

전처리 pickle 의 sha256 은 패키지 버전 차이로 Yoo 기록과 다르지만, 그 pickle 로 재생한 val, test 지표 12개가 Yoo 기록과 같다 (단계 0).

## 실행 결과

전체 표는 [results.md](results.md).

### 단계 1: 학습된 정책 (검증 215 에피소드, 마지막 정책, seed 3개)

| PPO-Lag | 33,158 | 15.45 | 4.93 | 0.45 | 76.7 |

### 단계 2: 차단 (FCSRL 정책 seed 평균)

| 조건 | 공기량 | 하루 비용 | NH4 위반 % | DO 위반 % |
| --- | --- | --- | --- | --- |
| 차단 없음 | 23,699 | **16.17** | 5.54 | 0.09 |
| NH4 규칙 theta 4.0 | 25,969 | 22.47 | 6.48 | 1.35 |
| NH4 규칙 theta 3.0 | 33,417 | 32.82 | 7.92 | 3.52 |

모든 차단 설정이 차단 없음보다 하루 비용이 높았다. 공기량을 올리면 DO 위반만이 아니라 **NH4 위반도 늘었다.**

### 사전 등록 가설 판정

- H1 지지 (규칙상, 의미 작음). 같은 공기량에서 예측기 켜고 끄기가 NH4 규칙보다 하루 비용이 1.06 ~ 1.31 낮았다 (3/3, 비교 점 각 2개). 그러나 둘 다 차단 없음보다 나쁘므로 "덜 나쁜 차단" 이라는 뜻이다.
- H2 지지 안 됨. 비례가 켜고 끄기보다 0.02 ~ 0.14 높았다 (0/3).
- H3 지지 안 됨. NH4 규칙 theta 3.0 은 하루 비용을 15.2 ~ 18.2 늘렸다 (0/3).

### 사후 진단 (사전 등록 아님): 대리 모델의 국소 반응

차단이 걸리는 순간(호기 단계, NH4 측정값 >= 3) 마다, 같은 상태에서 정책 공기량과 5,400 Nm3/h 를 각각 대리 모델에 넣어 다음 스텝 NH4 변화를 비교했다 (검증 215 에피소드).

| seed | 해당 스텝 | NH4 변화, 정책 공기량 | NH4 변화, 5,400 | 5,400 에서 NH4 가 덜 내려간 비율 | 다음 DO, 정책 / 5,400 |
| --- | --- | --- | --- | --- | --- |
| 0 | 5,179 | -0.042 | -0.028 | 75.4% | 1.02 / 1.52 |
| 1 | 6,602 | -0.033 | -0.013 | 84.0% | 0.77 / 1.33 |
| 2 | 6,223 | -0.031 | -0.016 | 75.2% | 0.94 / 1.44 |

이 대리 모델에서는 NH4 가 높은 순간에 공기를 더 넣으면 DO 는 오르지만 NH4 는 오히려 덜 내려간다. 실제 질산화 반응과 반대 방향이다. Yoo/e02 의 배율 시험(실제 운전 공기량 전체를 0 ~ 2배로 바꿈) 에서는 공기량을 늘릴수록 NH4 위반이 줄었으므로, 이 반대 반응은 전체 평균이 아니라 학습된 정책이 가는 낮은 공기량 영역과 NH4 가 높은 순간에서의 국소 반응으로 보인다. 원인(운전 기록의 교란, DO 를 거친 NH4 모델의 외삽) 은 확인하지 않았다.

### 해석

- 이 환경에서는 실행 시점에 공기를 올리는 차단이 NH4 와 DO 모두를 나쁘게 한다. BSM1 에서 본 차단의 효과는 Avedøre 대리 모델로 옮겨지지 않았다.
- 같은 이유로, 이 대리 모델에서 학습한 정책이 실제 운전보다 공기를 훨씬 적게 쓰면서(23,699 대 53,596) 비슷한 NH4 위반을 내는 결과는, 대리 모델의 국소 반응을 이용한 결과일 수 있다. 팀의 Avedøre 결과를 해석할 때 함께 봐야 한다.

### 한계

- 사후 진단은 한 스텝 반응만 봤다. 여러 스텝 누적 반응과 원인 분석은 하지 않았다.
- 차단 공기량 5,400 하나만 봤다. 평가 전용 GBM 대리 모델(Yoo/e03) 로 교차 확인하지 않았다.
- seed 3개, 404,096 전이, 마지막 정책만 본 탐색적 실험이다.
