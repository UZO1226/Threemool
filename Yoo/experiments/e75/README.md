# e75: 현재 대리 환경의 개선 여지 진단

2026-11-21 완료. 본16개 조건 모두 정상 종료했고 사후 이전 대조 및 저장 궤적 독립 검산도 통과했다. 본 계산은15:19~15:23 KST에 끝났다. 새 RL/환경 학습이 아니라 e74의 고정 환경에서 ABAC를 개선하는 행동열이 존재하는지 검사한다. [실행 전 근거와 설계](REFERENCES_AND_DESIGN.md).

## 결과와 판단

[전체16개 결과](results.md), [기계 판독 요약](summary.json), [사후 열린 고리 대조](transfer_control.md), [독립 검산](final_audit.json).

표는 CEM 탐색 난수0/1을 모두 평균한 기술 통계다. dev/val 각12일 x 구성원5개이며 e74 전체146/40일 평균과 직접 비교하지 않는다. 비용은 e74의 순간 NH4 또는 누적 예산 위반 스텝이다.

- **이 대리 환경 안에서 개선 가능한 행동열은 발견했다.** 비교 조건으로 고정한 NH4 초과 적분, 순간 위반 수, 누적 위반 수와 DO 위반 수가 날짜/구성원마다 ABAC 이하임을 저장 궤적으로 다시 확인했다. 비악화는 후보 허용 규칙으로 보장한 것이고, 발견된 추가 개선 크기가 관측 결과다.
- 발견한 공기 절감은5% 기준에 못 미쳤고 비용 감소는 CEM 두 난수 각각에서 dev/val10% 기준을 넘었다. 이들은 탐색용 크기 기준이며 통계적 유의성이나 전역 최적값이 아니다.
- 무작위 탐색은 dev 비용 목적에서 CEM보다 더 낮았다(3.417/3.517 대3.900/3.767). val에서는 CEM이 더 낮다. 따라서 탐색기 한 종류의 성과를 성능 상한으로 부를 수 없다.
- val 계획 비용6.842는 여전히 한도4.75보다 높다. 정확한 모델과 미래 정보가 있어도 이 탐색이 겨울 준수를 해결하지 못했다. 그렇다고 최적 계획도 불가능하다는 뜻은 아니다.
- **다른 구성원에 고정 행동열을 이전한 실패는 후보만의 문제가 아니었다.** 사후 대조에서 ABAC 고정 행동열도 dev41.75/val47.30으로 악화했다(동일 target에서 수질을 보고 반응하는 ABAC는5.783/8.000). 후보는 dev42.10~44.75/val47.97~49.27이다. 모델 차이와 피드백을 없앤 영향을 섞어 "모델 착취 확정"이라고 해석하지 않는다. 사후 대조는 처음 이전 결과를 본 뒤 추가한 것으로 명시했다.
- 원래 모델에서 ABAC 행동열 재생은 상태까지 정확히 일치하므로, 이 이전 악화가 단순 행동 배열 순서/비용 집계 오류라는 설명은 검산에서 지지되지 않았다.

## 무엇부터 고칠 것인가

주제 폐기나 새 네트워크보다 **고정된 비용과 정보 조건에서, 현재 수질을 매번 반영하는 평가 설계와 모델 반응 신뢰도**를 먼저 확인해야 한다. e74 목표를 다시 바꾸지 않고, 동일한 온라인 관측을 받는 짧은 재계획 제어와 ABAC/RL을 비교해야 탐색 여지가 온라인 제어로 접근 가능한지 구분할 수 있다. 이후 다른 구성원/모델에서 유지되는지와 실제 기록 반응 검사를 함께 봐야 한다. 모델끼리의 일치만으로 실제 공기 인과 효과를 입증할 수는 없다.

이번 결과는 FCSRL의 고유 이득이 아니다. DARROW만 사용하고 FCSRL의 큰 구조를 유지한다는 범위는 바꾸지 않았다. 후속 온라인 제어 비교와 모델 개선은 이번에 실행하지 않았다. [제안 문장별 검토](REVIEW.md).

## 제안 검토

환경 신뢰도는 큰 병목이지만 환경 하나만 문제라고 확정하지 않는다. 누적 비용이 순간 NH4 초과를 놓치는 설계 문제도 있었고, 13차원 관측은 전이가 쓰는 모든 변수를 포함하지 않는다. 원 FCSRL은 벡터 관측에서도 효과를 시험한 방법이므로 저차원이라는 이유만으로 주제를 폐기할 수 없다.

Park/e57,e58은 이미 짧은 MPC를 평가했다. 이번에는 e74의 비용과 모델에서 정확한 환경 구성원과 미래 외생 입력을 주고 하루 전체 행동열을 탐색한다. 기존 결과와 같은 순위표에 섞지 않는다. 이 정보는 실제 제어기에 허용되는 정보보다 많다.

**발견한 실행 가능해는 최적 성능 상한이 아니다.** 개선을 찾으면 대리 환경 안의 여지가 있다는 근거다. 못 찾으면 탐색기/예산/후보 제한 때문일 수도 있어 환경이나 FCSRL이 쓸모없다고 결론 내리지 않는다. 실제 공기의 인과 효과나 환경 신뢰도를 검증하는 실험도 아니다.

## 비교

- 기존 e74 선택 ABAC (sp3.5, kp0, ki1e6), 재조정 없음.
- dev/val 각 날짜순 등간격12일 x 모델5개, holdout/test 평가 없음.
- 미래 입력을 아는95스텝 행동열, 공기 최소/비용 최소 두 목적.
- CEM과 같은 후보 수 random shooting, 탐색 seed0,1. 32후보 x 8세대, 2세대 성과도 보존. 모두16개 계산이며 정책 학습 seed16개가 아니다.
- 각 날짜/구성원에서 공기, 비용, NH4 초과 적분, 순간 NH4 위반 수, 누적 위반 수, DO 위반 수가 ABAC보다 나쁘지 않은 후보만 채택. 비악화 자체는 baseline fallback의 설계 성질이다.
- 최종 행동열을 다른 구성원에 그대로 옮겨 민감도 확인. 독립 모델/실제 환경 검증은 아님.
